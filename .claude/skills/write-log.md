# /write-log — 工作日志记录

## 触发

用户说 `/write-log` 或 "记录日志" 或 "写日志" 或 "记录到日志" 或 "总结今天"

## 执行步骤

### 1. 回顾当日

回顾本次会话中完成的所有工作：
- 新建/修改了哪些文件
- 解决了什么问题
- 产出了什么成果

### 2. 确认标题

向用户确认日志标题（20 字以内中文），用户未指定时 AI 根据内容提议。

### 3. 生成日志

按 `works/_template.md` 结构生成完整日志：

- **问题解决日志**：遇到了什么 / AI 怎么协作 / 产出结果 / 关联项目
- **视频生产草案**：三幕结构 + 金句候选 + 素材清单

### 4. 写入文件

- 文件名：`works/YYYY-MM-DD-简短描述.md`
- 写入后告知用户路径

## 约束

- **一事一记**：多主题拆分为多个文件
- **必须含视频草案**：为后续内容生产储备素材
- **不主动写**：等用户指令，不自动创建
