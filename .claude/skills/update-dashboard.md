# /update-dashboard — 仪表盘更新

## 触发
用户说 `/update-dashboard` 或 "仪表盘更新" 或 "更新仪表盘"

## 执行步骤

### 1. 检查来源
仪表盘共 8 个页签，检查 `tools/collect-data.ts` 中的数据：
- **系统总览**：信条标语、统计卡片（SKILL/工作流/工具/日志/提交/活跃项目）、系统信息
- **项目状态**：5 个项目的状态、进度、产出、阻塞项
- **工作流清单**：9 个工作流 + 52 个 SKILL（4 二级页签：全部/日常/业务工作流/SKILL）
- **近期动态**：works/ 日志 + Git 提交（自动采集，无需手动维护）
- **任务看板**：16 个任务（状态/分类）
- **目标计划**：用户需求 + 系统问题 + AI 建议
- **知识库**：5 个工具及文档链接
- **资产地址**：内部资产路径 + 外部平台

### 2. 更新脚本
- 发现过时数据 → 告知用户 → 修改 `collect-data.ts` 中对应页签的硬编码数据
- 动态数据（SKILL 统计/works 日志/Git 提交）自动采集，无需维护

### 3. 生成
- 执行 `npx tsx tools/generate-dashboard.ts`
- 输出：`reports/造化坊仪表盘.html`（独立 HTML，8 Tab 切页，浏览器直接打开）

### 4. 验证
- 生成成功后，提示用户在浏览器中打开 HTML 抽查各页签

## 约束
- HTML 是衍生文件，数据来源是 `collect-data.ts`
- SKILL 统计自动扫描 `.claude/skills/`，无需手动维护
- works/ 描述自动从标题行提取

> 完整流程见 [docs/workflows/仪表盘更新.md](../docs/workflows/仪表盘更新.md)
