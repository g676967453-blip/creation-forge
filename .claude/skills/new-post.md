# /new-post — 创建小红书图文笔记

## 触发
用户说 `/new-post` 或 "做一期小红书" 或 "发小红书"

## 执行步骤

### 1. 选材
- 读取 `works/` 下最近 5 篇日志（按文件名倒序）
- 从每篇日志提炼一个候选选题（一个问题 + 一个解法 + 一个结果）
- 列出 3 个候选，等待用户选定

### 2. 文案
用户选定选题后：
- 按 6 卡结构出完整文案：
  - Card 1：封面/提出问题（大标题 + 副标题 + 痛点）
  - Card 2：拆解/痛点（把问题拆开）
  - Card 3：工具/方法（用什么）
  - Card 4：流程/行动（具体步骤，人做什么 AI 做什么）
  - Card 5：结果/洞察（产出规格、核心认知）
  - Card 6：CTA（行动号召 + 固定口号）
- 展示文案，等待用户审核

### 3. HTML
文案确认后：
- 询问 accent 色（默认珊瑚红 `#ff6b6b`）
- 从最新帖子拷贝样式，生成单文件 `index.html`
- 放入 `xiaohongshu/YYYY-MM-DD-主题/`
- 自动用浏览器打开预览

### 4. Pixso 导入
提醒用户：
- 在 Pixso 中点击画布空白取消选中
- 用 MCP `code_to_design` 导入 `index.html`
- 用 `apply_design` 重命名 frame 为 `YYYY-MM-DD-主题`
- 导出 PNG，放入 `Pixso截图/日期-主题/`

### 5. 发布 + 记录
用户发布后告知 AI，AI 记录到当日 works/ 日志。

## 约束
- CTA 固定口号：「关注我：每天解决一个问题」（永不变）
- 品牌标记：底部「造化坊」
- 卡片尺寸：1080 × 1440px
- 先文案后 HTML，不跳过
- 素材来源：works/ 日志，不从宣言直接取材
