# /organize-files — 文件梳理

## 触发
用户说 `/organize-files` 或 "梳理文件" 或 "整理文件夹" 或 "文件结构乱了"

## 执行步骤

### 1. 全面扫描
用 `find` + `ls` 扫描整个项目目录树：
- 根目录文件清单（标记散落杂物）
- 对比 `CLAUDE.md` 声明的结构 vs 实际目录
- 深入 `docs/`、`projects/`、`造化仪表盘/works/`、`shared/`、`templates/`、`tools/`、`造化仪表盘/reports/`
- 检查 `.claude/`、`.workbuddy/` 等隐藏目录
- 检查命名一致性、空目录、嵌套 `.git`

### 2. 诊断报告
输出三级问题清单：

| 级别 | 示例 |
|------|------|
| 🔴 严重 | 散落文件、重复记忆系统、声明不符、嵌套 Git |
| 🟡 中等 | 目录职责混乱、命名不统一、定位模糊 |
| 🟢 轻微 | 空目录、gitignore 不完整、模板空壳 |

每项标注位置 + 现状 + 建议处理。

### 3. 方案确认
需要用户决策的问题用 `AskUserQuestion` 逐项确认：删/移/合并/保留。
确认后形成最终整理方案。

### 4. 执行修改
按方案逐项执行，执行顺序：
1. 先创建/迁移目标位置
2. 再删除源位置
3. 全局搜索并更新所有引用（`CLAUDE.md`、SKILL 文件、仪表盘、工作流文档）

### 5. 同步仪表盘
执行 `npx tsx 造化仪表盘/tools/generate-dashboard.ts` 更新仪表盘。

## 约束
- 绝不跳过扫描直接修改
- 结构性变更必须用户批准
- 移动文件后必须全局搜索更新引用
- 删除 `.git/` 等不可逆操作需单独 ⚠️ 确认
- 完成后在 `造化仪表盘/works/` 生成整理日志
