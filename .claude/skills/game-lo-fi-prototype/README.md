# 游戏低保真交互原型 (Game Lo-Fi Interactive Prototype)

> 造化坊 (Creation Forge) — 独立游戏开发中的低保真交互原型技能

---

## 这是什么？

一个 Claude Code 技能，用于快速制作游戏的**低保真交互原型**。

在进入高保真 HTML/CSS 设计之前，用**等宽线框 + 4色灰度**快速产出可点击的 HTML 线框图，验证屏幕流转和交互逻辑是否合理。

**核心理念**：先跑通流程，再追求好看。

---

## 为什么要用？

游戏 UI 开发中最常见的浪费是：做了一版精美的 UI（高保真 HTML），然后发现交互流程有问题，要返工。

低保真原型的目标就是**用最低成本（线框图）验证最高风险（交互流）**。

| 传统做法 | 用本技能 |
|----------|----------|
| 策划案 → 直接高保真 HTML | 策划案 → 线框图验证 → 高保真 |
| 发现流程问题 → 改 HTML（成本高） | 发现流程问题 → 改线框图（成本低） |
| 视觉干扰交互评估 | 剥离色彩，专注布局和交互 |

## 两种模式

### 🚀 快速模式（3 步，15 分钟）

新项目首次使用时，快速声明交互规则+视觉系统：

```
① 选择平台（竖版/横版/PC/主机）
② 交互规则声明（安全区、热区、按钮、导航、过渡、反馈）
③ 视觉系统声明（色板、字体、间距、线框样式、占位符）
→ 直接画线框图
```

### 📋 完整模式（六步）

复杂项目或首次使用完整流程：

```
① 场景梳理   →  ② 交互骨架   →  ③ 视觉规范
     ↓               ↓               ↓
  有哪些屏幕？    状态机+焦点？   线框图长什么样？

④ 线框图草稿  →  ⑤ 交互串接   →  ⑥ 走查清单
     ↓               ↓               ↓
  一屏一个HTML    可点击走通     有没有坑？
```

## 视觉风格

低保真线框图遵循严格的视觉约束：

- 🎨 **4色系统**：线框黑 `#222` / 填充灰 `#E0E0E0` / 强调灰 `#999` / 背景白 `#FAFAFA`
- 🔤 **单字体**：等宽字体，仅 2 个字号（24px 标题 + 16px 正文）
- 📐 **8px 网格**：所有间距为 8 的倍数
- ✏️ **线框风格**：2px 宽边框、4px 圆角、无阴影、无渐变、无彩色
- 🖼️ **占位符**：图片用斜线填充，文字用 `[占位符]` 标注

## 适用范围

- **引擎无关**：输出纯 HTML/CSS 线框图，Godot/Phaser/Unity 项目均可使用
- **平台无关**：默认竖版手游（750×1334），可调整画布适配横版/PC
- **项目无关**：任何需要交互原型验证的游戏功能均可使用
