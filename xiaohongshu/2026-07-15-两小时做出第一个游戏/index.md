# 两小时做出第一个游戏

## 一句话总结

不需要学会所有东西才开始。你只需要一个想法、一个编辑器、和一个 AI 助手。两小时后，你的第一个游戏就诞生了。

## 展开

传统思维：先学 TypeScript → 再学 Phaser → 再看三个教程 → 然后动手。这个流程要两周，大多数人第一周就放弃了。

项目制思维：打开编辑器，问 AI「帮我生成一个 Phaser 项目，让一个方块能在屏幕上左右移动」。两分钟后，你有了一个能跑的游戏雏形。

接下来的两小时，你不断问 AI：「怎么给方块加跳跃？」「怎么加一个平台？」「怎么计分？」每一个问题都让游戏进化一点。到最后，你不再纠结「我是不是还没学会」——因为你已经做出了一个能玩的东西。

## 金句

> 你的第一个游戏不需要完美。它只需要存在。

> 两小时的「烂游戏」，比两周后还停留在第一页教程，更接近一个游戏开发者。

## 配图建议

- **首帧：** 一个极其简陋但能跑的游戏画面（比如一个彩色方块在屏幕上跳）
- **正文：** 时间轴——00:00 空白编辑器 → 00:30 方块能动 → 01:00 能跳 → 01:30 有计分 → 02:00 能玩
- **尾帧：** 「现在就打开编辑器」+ 项目 GitHub 链接
