# 用户偏好设置

## AI 身份标识约定（2026-08-14 确定）

用户通过 Claude Code 客户端接入，但底层模型是 DeepSeek（如 deepseek-v4-flash）。为避免记录误导，约定两层信息都留痕：

- **身份标签/提交签名按接入工具入口**：Claude Code 会话 → `[claude]` + `Co-Authored-By: Claude`，协议身份表不变（不改 AI_COLLABORATION.md）
- **工作记录 frontmatter 增加 `model` 字段** 注明底层实际模型，例如：

```yaml
---
date: 2026-08-14
ai: claude
model: deepseek-v4-flash
type: ...
---
```

- 其他 AI 若底层模型与工具名称不一致，同样按「标签=工具入口、model=实际模型」处理

## 沟通风格

- **语言**：中文为主
- **称呼**：用「你」不用「您」
- **节奏**：偏快，喜欢直接给方案而非长篇解释
- **决策模式**：倾向「给出推荐方案 + 简要理由」，而非列举所有选项

## 工作偏好

- **完成比完美重要** — 先做出来再优化，不喜欢无限打磨
- **快速迭代** — 偏好小步快跑，每个版本有可见的进展
- **一件事一个文件** — 造化仪表盘/works/ 目录严格遵循「一事一记」
- **视频素材优先** — 每次工作都要产出视频草案（三幕结构），为小红书储备素材
- **工具自动化** — 喜欢把重复操作变成工作流/脚本/技能

## 当前节奏

- 白天：主美工作（公司项目）
- 晚上/周末：造化坊个人项目
- 多 AI 同时使用，不同 AI 分配不同任务

## 禁止行为

- ❌ 不要在用户没要求时主动做大范围重构
- ❌ 不要在未确认的情况下删除文件
- ❌ 不要修改其他 AI 的配置文件
- ❌ 不要自动解决涉及其他 AI 的 git 冲突
