# 游戏美术部门 AI 协作中台

**状态：** 📋 已规划 | **优先级：** 🔴 高 | **来源：** 个人待办 D-014

## 定位

面向游戏美术部门的内部协作平台，作为美术团队与 AI 工具链之间的「中台」层，解决以下问题：

1. **资产管理**：美术资产的统一存储、版本管理、检索与复用
2. **AI 生成**：接入 AI 图像生成工具（Lovart 等），提供标准化 Prompt 模板与批量生成能力
3. **管线集成**：连接美术生产工具（PS/Figma）→ AI 生成 → 游戏引擎（Godot/Unity）的端到端流程
4. **协作流转**：美术需求的提交、分配、审核、交付闭环
