# 造化坊 (Creation Forge)

## 身份定位

造化坊是「AI 时代的新学习思想」的实践场。

核心理念：**定项目 → 遇问题 → 学知识 → 解决问题 → 完成。**
AI 让「做中学」第一次真正可行。落地载体是独立游戏开发。

金句：**匠心造化，万物可成** —— 每一个小项目都是创造的淬炼。

## 日常运转

```
遇到问题 → AI 协作解决 → 产出交付 → 写入 works/（一事一记）
                                       ↓
                              视频生产草案（三幕结构）
                                       ↓
                               制作 + 发布（有素材就发）
```
