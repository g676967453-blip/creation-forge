## 是什么

- 流程文档：`docs/workflows/05-概念设计.md`（6 步框架）

## 核心方法：图生图法（★ 已验证）

纯文本 prompt 反复跑偏 → 用「对味底图 + 只改 N 处」的 edit_media 图生图法，风格一次到位。

- 以「赤瞳_双剑版」底图批量生成三国武将，风格 100% 统一
- 已定稿：刘备（双股剑/绿袍/发髻）、关羽（青龙偃月刀/红脸/美髯）、张飞（丈八蛇矛/黑脸/络腮胡）、曹操（佩剑/白脸/金冠）
- 经验：不要用游戏名做风格引导；概念词需逐字澄清（「双手剑」≠「双股剑」= 两把剑）
