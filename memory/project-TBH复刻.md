# TBH 复刻项目（调研日志）

## 项目背景
1. 目标：复刻独立游戏《TBH: 塔斯克巴·英雄》（AppID 3678970），桌面放置挂机 RPG + Steam 市场交易模式。
2. 技术方向：Godot 2D（复用老邓的 Godot 经验）。
3. 角色：老邓（主美/独立制作人）+ 助手。

## 市场与销售数据（2026-08-06）
1. 开发商 Nugem Studio + Tesseract Studio（韩国首尔小团队）；2026-05-27 上线，F2P，仅 Windows。
2. 实时在线 139,156（08-06 09:57）；峰值 23 万→近 30 万（有报道称冲 50 万）。
3. 评价：全语言 43,497 条 Mixed；简中 9,118 条 Mostly Negative（好评率约 24%）。
4. 变现：本体免费 + DLC（职业包/仓库包/礼包）+ Steam 市场交易分成。
5. 市场事件：6/8 关市场、6/25 部分重开；贸易船至今受限。

## 跟风/复刻产品
1. 有跟风者批量赶工上架，但暂无叫得上名的 TBH 复刻爆款。
2. 赛道前身：《Banana》（峰值91万，泡沫崩盘）、《Bongo Cat》；爆款复刻先例《花园世界》《占城大师》。

## 实机录制与画面分析（2026-08-06）
1. 工具链：OBS WebSocket + obsctl.mjs + Windows OCR（zh-Hans-CN）。
2. 踩坑：OBS 窗口采集对最小化窗口抓黑帧 → 需还原游戏窗口；OCR 中文乱码 → 写 UTF-8 文件。
3. 实测发现：
   - 主 HUD：等级/经验/DPS/攻击伤害/当前HP/技能点/技能。
   - 底部导航：英雄/背包/商店/编队。
   - 装备：装饰系统（带装饰槽装备+装饰材料→随机属性）、魔方系统、仓库联动。
   - 贸易船：提示「暂时无法打开」（市场受限）。
   - 商店 DLC：职业包（猎人/屠萨）、仓库包、贸易船礼包。
   - 设置：缩放/透明窗口/窗口小(Shift+F11)/恢复位置(F12)/置顶/版本1.04。
   - 章节：传送门→第1/2/3章。
   - 实测角色：游侠 Lv.21-22，攻击伤害 861。

## 复刻方案要点
1. 技术：Godot 2D，桌面迷你窗口 + 自适应 UI。
2. 最难三件事：Steam Inventory Service 市场交易接入、经济系统设计、反作弊+服务器。
3. 差异化：数值做扎实（TBH 最大差评源）、运营跟上、美术做精致（主美优势）。
4. 排期（2 人）：MVP 1-3 月，带市场全功能 3-6 月。
5. 风险：玩法可复刻、素材不可抄；挂机+交易模式有泡沫属性。
