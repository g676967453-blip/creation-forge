1. 产品定位
1.1 游戏类型
《惊喜花园》是一款面向移动端用户的轻度模拟经营、收获抽卡、宠物养成、放置 RPG 冒险与轻社交游戏。
玩家经营一座魔法花园，通过种植花朵、等待成熟、收获随机奖励，逐步获得金币、花园经验、花朵精华、宠物、宠物
记忆、建筑方块、外域种子和特殊事件。宠物既能为花园提供生产增益，也能组成三宠小队前往外域进行放置冒险，并
根据模拟战斗结果生成探索日志和战斗战报。
1.2 第一核心卖点
花园收获即是抽卡。
本游戏的核心差异化不是传统意义上的“种菜收菜”，而是将抽卡行为包装进花园经营体验中。玩家不是在卡池界面点
击抽卡按钮，而是通过播种、等待、照料和收获，在花朵成熟时触发随机奖励结算。
种植是铺垫，收获是抽卡，养成是消耗，宠物与家园是长期目标。

1.3 商业化核心表达
免费玩家靠经营慢慢抽，付费玩家花钱加速抽。
付费不直接出售毕业答案，而是出售更多收获机会、更高阶收获池、更快成长节奏、更漂亮的宠物和家园表达。
商业化原则：
卖效率，不直接卖花园等级。
卖抽卡机会，不直接卖毕业 UR 宠物。
卖便利，不制造强制付费卡点。
卖外观，不把外观做成强战力。
卖社交归属感，不让私有小镇碾压普通小镇。
2. 世界观
2.1 世界设定
游戏世界名为「绒光群岛」。这里的生命由一种被称作「花源力」的能量维持。很久以前，一场「星尘花潮」降临群
岛，星尘融入土壤，普通花朵从此获得变异能力。
成熟花朵不再只结出花瓣和种子，也可能结出金币、精华、宠物蛋、天气符文、建筑方块、外域线索，甚至被遗忘的故
事碎片。
玩家继承了一座沉睡的花园。随着花园逐渐复苏，花源力重新流动，宠物伙伴从花朵、露水、星尘和土壤中诞生。它们
既是玩家的陪伴者，也是花园生产和外域冒险的核心力量。
2.2 世界调性
整体气质应保持轻松、治愈、有惊喜感，同时保留足够的长期收集深度。外域可以有战斗、怪物和危机，但表达上偏童
话冒险、奇遇探索，而不是黑暗压迫。

4. 核心循环
4.1 基础循环
播种 → 等待成长 → 收获抽卡 → 获得随机奖励 → 升级花园、扩地、养宠、建造 → 解锁高级花朵与外域区域。
4.2 长期循环
高级花朵 → 更高价值收获池 → 更多花朵精华、萝卜材料和宠物记忆 → 宠物升级进化 → 提升生产与冒险效率 → 获得
更多抽卡机会和更高价值奖励。
4.3 付费循环
星露购买加速、幸运花盆、高级种子包、花园祝福和探索栏位 → 增加收获抽卡频率或提升奖励池质量 → 更快获得精
华、宠物、宠物记忆和进化材料 → 更快推进养成。
4.4 经济产销循环
金币买种子 → 种子占用地块与成长时间 → 花朵成熟 → 收获抽卡 → 获得花朵、少量金币、花园经验、花朵精华和随机
稀有物 → 花朵进入小镇订单、探索补给、建造和活动消耗 → 小镇订单将花朵库存变现为金币和声望 → 金币继续用于
买种子、扩地、宠物升级和建筑。
金币不应主要由花园直接产出。花园负责生产花朵、经验、精华和抽卡惊喜；小镇订单负责将花朵库存变现为金币和声
望。
金币来源 占比 定位
小镇订单 35% 主销售端，消耗花朵与材料，产出金币和声望
花园基础收获 25% 基础现金流，覆盖买种子和轻量日常
外域探险 20% 放置收益，补充金币和外域材料
活动任务 10% 周期性补贴、追赶和促活
预留缺口 10% 留给后续系统、运营调参或新玩法
5. 收获抽卡系统
5.1 系统定位
收获抽卡是游戏最核心的反馈系统。每块成熟地块在收获时都会进行一次随机结算。普通花朵提供稳定收益，变异花朵
提供惊喜收益，高级花朵拥有更高价值的奖励池。
玩家获得抽卡机会的方式：
自然等待花朵成熟。
使用加速券或星露加速成熟。

奖励层级 内容 作用

5.3 保底机制
建议设计「幸运花粉」：
每次普通收获未出变异，获得 1 点幸运花粉。
每次变异但未出稀有奖励，获得 3 点幸运花粉。
100 点幸运花粉后，下次变异奖励至少为高级种子、宠物记忆、金萝卜碎片、建筑方块之一。
触发保底后清空幸运花粉。
低品质花触发保底时仍受奖池上限限制，例如普通花不直接保底金萝卜碎片。
高阶付费收获池需要清楚展示概率和保底说明。
保底的目标不是让玩家快速毕业，而是降低连续低收益带来的挫败感。
5.4 抽卡价值点
为了防止 1 分钟作物靠次数碾压 24 小时作物，收获抽卡不直接按次数估值，而使用“抽卡价值点”作为中间口径。
单地块抽卡价值点  = 成长分钟数  × 品质系数  × 花期系数
批次抽卡价值点  = 本批收获地块数  × 单地块抽卡价值点
基础收益  = 阶段日目标  ÷ 当前阶段地块数  ÷ 每日实际收获轮次
变异概率  = 品质基础变异率  + 花期修正  + 宠物 / 天气 / 祝福加成
奖池等级  = 花朵品质  + 花园等级  + 活动状态
关键口径：抽卡价值点主要用于衡量稀有奖励容量和奖池质量，不直接等比转化为金币、花园经验和花朵精华。基础资
源必须按当前阶段最大地块数和目标日收益反推。

9. 宠物养成
9.1 获取规则
宠物采用唯一终身制。
第一次获得某只宠物时，解锁宠物本体。
重复获得同名宠物时，不生成第二只宠物，而是自动转化为同名宠物记忆。
该规则保留了重复掉落的商业价值，同时避免“吞同名宠物升阶”的重度卡牌感，更符合花园陪伴型产品气质。

10. 战斗系统
10.1 系统定位
《惊喜花园》首版不重新设计一套独立战斗系统，而是保留并复用《世界之光》的既有战斗内核。《世界之光》负责属
性、技能、克制、回合流程、状态、伤害、胜负和掉落判定；《惊喜花园》只替换战斗表现层，将原本可视化战斗画面
改为探索日志和战斗战报。
核心结构：
《世界之光》战斗系统
→ 负责战斗规则、属性、技能、怪物、流程、胜负和结算
《惊喜花园》表现层
→ 不播放战斗画面
→ 读取战斗过程事件
→ 生成探索日志、战斗战报和策略反馈
战斗系统目标：
让战报可信，玩家能理解胜负原因。
让宠物养成与探索结果产生明确关系。
复用成熟战斗逻辑，节省研发时间和数值验证成本。
让三宠小队仍具备搭配策略，但策略来源继承《世界之光》既有规则。
为后期异步 PVP 预留复用通路。

10.9 PVP 预留
后期如果开放 PVP，建议继续复用《世界之光》战斗内核，并采用异步自动模拟。

三宠防守队 + 三宠进攻队 → 调用《世界之光》战斗模拟 → 输出战斗战报。
PVP 奖励建议以称号、头像框、宠物外观道具、小镇荣誉和装饰材料为主，不大量投放核心养成资源，避免休闲玩家被
迫卷战斗。

《世界之光》战斗内核接入。
宠物到《世界之光》战斗单位的数据映射。
战斗事件记录与战报生成。
三宠冒险小队。
3 个外域区域。
区域怪物情报与战报输出。
基础小镇订单、订单刷新和花朵库存变现。

22. 合规提醒
只要付费购买包含随机虚拟物品，例如幸运花盆、高级种子包、主题收获池、随机宠物、随机装饰箱、异色花露随机刷
色，就需要在购买前清楚展示概率，并说明保底和重复转化规则。

23. 最终设计总结
《惊喜花园》的完整设计核心是：
用花园包装抽卡，用宠物承接养成，用外域战斗提供策略，用家园和小镇承接长期表达，用商业化加速抽卡和强化外
观。
玩家每天回来，是为了看看花园这一次会开出什么。
玩家长期留下，是因为宠物、花朵、家园、小镇和外域故事都在持续成长。
