## 日常管理：四个核心动作

### 1. 信息输入

| 来源 | 具体做法 |
|------|---------|
| **对标产品** | 定期游玩竞品/标杆产品，截图、分类、分析 |
| **当前产品资产** | 每天花时间查看实际游戏内效果，不是只看设计稿 |
| **核心人员反馈** | 制作人、发行、美术总监的关切点就是你的优先级 |

> 信息输入是主美工作的"燃料"。信息不足时做的决策，大概率是错的。

### 2. 任务管理

```
需求确认 → 任务分配 → 制作跟进 → 验收反馈 → 完成归档
```

- **被动**：查看项目需求表，处理排期中的任务
- **主动**：梳理新增需求，提前预判资源缺口

### 3. 人员状况

- **核心成员**：能力评估 + 协作契合度（不是能力最强的就是最合适的）
- **执行人力**：数量够不够？产能能否支撑下个里程碑？
- **对接人员**：策划、程序的接口人是否稳定？

### 4. 任务制作

主美自己也要做设计，**保持手感**。脱离一线太久，审美判断会失真。

## 项目规划：五个关键节点

```
概念设计 → Demo → 量产 → 测试调优 → 上线运营
```

### 概念设计
- 结合买量数据判断美术方向的市场接受度
- 定风格不是凭个人喜好，**用数据说话**

### Demo 制作
- 核心最小体验：只做能验证核心玩法+核心美术风格的界面
- 不要贪多，Demo 的目的是**验证方向**，不是展示工作量

### 量产规范
- 各版块**质量标杆**（不是所有界面同等重要，核心界面定标杆）
- **协作流程**（上下游怎么对接）
- **产能标准**（一个人一天能产出多少）
- **人力配置**（哪些自己做，哪些外包）

### 测试调优
- 美术资产基础质量核查
- 核心体验 + 付费体验 + 重点品阶资产的体验优化
- **配合调付费**：付费界面的视觉引导和品质感直接影响收入

### 上线运营
- 功能开发量预估
- 核心资产开发周期
- **人力预留**（别把所有人都排满，留出应急空间）

## 成本规划

用"工期"作为成本度量单位，三种口径：

| 口径 | 含义 |
|------|------|
| 预计人日成本 | 计划阶段估算 |
| 执行人日成本 | 实际排期出来的 |
| 实际人日成本 | 最终完成的 |

> 三种口径的差异就是管理能力的体现。差异越小，预估越准。

## 核心心法

### 1. 最小循环
不要追求一步到位。每个阶段产出最小可用版本，快速验证→反馈→迭代。

### 2. 质量标杆 + 生产线
- **标杆**解决"做成什么样"的问题
- **产线**解决"怎么稳定复制"的问题
- 两者缺一不可：有标杆无产线 = 只能自己画；有产线无标杆 = 量产质量失控

### 3. 体验优化
设计稿好看 ≠ 游戏里好用。**在手机上跑起来才是真的。**

### 4. 商业付费思维
主美不只是画画的——**你做的每个界面最终都要帮游戏赚钱或留人。**

### 5. 脑袋与手
主美既要能想（脑袋），也要能做（手）。脑袋决定方向对不对，手决定能不能落地。
