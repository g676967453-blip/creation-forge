# 旁观的一些问题

问题：

1.  引擎效果与美术完成度是否脱节，脱节多久，原因是什么？
    
    1.  当前效果是否与美术进度对齐。
        
    2.  不要做加法，先做减法。
        
    
    2.事没做好，是流程问题，还是人的问题？
    
    a:例如战斗。
    
    3.团队阶段核心目标是什么？
    
    1.  团队目标是什么
        
    2.  美术目标是什么
        
    3.  主美目标是什么
        
    
    4.实现目标需要多少成本？
    
    1.  实现目标的阻碍是什么？
        
    2.  实现目标的成本是什么？

容易错误的表现地方

1.  被事情推着走，没有自己的节奏
    
    1.  苗总需求
        
    2.  策划需求
        
    3.  别人需求
        
2.  掌控度不明确
    
    1.  人的问题
        
        1.  策划能力如何
            
        2.  程序能力如何
            
        3.  团队成员能力如何
            
    2.  项目目标与进度问题。
        
        1.  目标需求
            
        2.  团队产能
            
3.  边界感。
    
    1.  策划是否干涉美术表现。
        
    2.  苗总的需求是马上响应，还是按照团目标分类，排期？
        
4.  资源调度
    
    1.  目标需求与现有资源的匹配，要量化。
