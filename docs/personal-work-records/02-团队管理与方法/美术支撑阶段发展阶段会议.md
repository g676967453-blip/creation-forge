# 管理项：

##   任命

1.部门-岗位负责。

  部门负责：挑选各个版块岗位负责。

  原有版块负责离职或者转项目执行主美：可以建议接替人员。

2.项目-岗位负责。

*   确定项目-执行主美后，由执行主美挑选，部门岗位负责建议。不可挑选已稳定组合。
    
*   由部门-岗位负责，挑选副手，岗位负责，可以自行调配人力。
    

  3.项目-执行主美。

*   公司指定。
    
*   部门负责建议。
    
*   自行建议：态度，能力，信任背书。
    

##   回收

1.项目完结：解散人员：回归美术支撑，配合美术支撑版块的任务安排，人力管理。

2.项目上线运营：转移人力：回归美术支撑，配合美术支撑版块的任务安排，人力管理。

# 美术支撑管理绩效考核规则。

  1.项目-岗位负责绩效，由项目-主美考核填写。 2.执行人员-绩效，分版块由部门-岗位负责考核填写。部门-岗位负责，由部门负责考核绩效填写。

  3.绩效连续3个月不合格，走人事流程。出现绩效不合格由人事跟进流程。

# 团队晋升路径

1.能力级别：初级-中级-高级。 2.职责：执行-项目岗位负责-部门岗位负责-执行主美。
