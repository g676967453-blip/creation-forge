# 美术支撑中心价值定位。

## 对内：在游戏研发中

美术支撑中心主要承担两个方面的价值

1.  视觉包装体验。
    
2.  美术资产规范、量产、品控。
    

## 对于市场定位：

1.在AI加持的时代背景下，AIGC的内容将大量充斥于市场，游戏也是文化娱乐的一种传播形式。美术支撑可以扮演“编辑”的角色，对于优秀的新潮文化，或者强化宣传传统文化题材的游戏，以及游戏新人，给予更多的机会，建议与支持。

2.在游戏玩法不变，单纯换皮，会导致同质化竞争激烈，有独到品位与价值观“编辑”，更能站住脚。

## 对于校企协作。

1.  协调进度、监督质量、解决争议。
    
2.  建立校企协作，研学结合的游戏开发生成线。
