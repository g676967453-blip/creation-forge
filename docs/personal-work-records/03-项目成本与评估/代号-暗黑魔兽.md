# 代号-暗黑魔兽

项目背景与目标

项目背景：基于镇魂的玩法数值框架+换皮暗黑风格的魔兽题材，上架小程序渠道。

目前用户群：30到40岁魔兽粉丝群，以及年轻男性泛用户。

项目开发时间：4个月，1个月准备工作，3个月正式立项研发。12月为准备工作月，1月，2月，3月为研发月份。

# 当前买量视频开发与项目DEMO的区别。

1.  从制作需求发起区别
    
    1.  买量视频
        
        1.  发起端：买量视频团队，
            
        2.  需求：没有以项目玩法
            
        3.  制作方式：走一步看一步，小步快走，逐步迭代。
            
    2.  DEMO
        
        1.  发起端：项目组
            
        2.  需求：规范化的战斗表现策划案，明确战斗表现流程规划。
            
        3.  制作方式：明确质量对标，明确工作量版本，明确分工板块和责任人。
            
2.  从落地要求上的区别
    
    1.  买量视频
        
        1.  引擎交互：Y3视觉演示，
            
        2.  功能保真：以表达视觉风格为主，砍掉游戏相对正式，真实的功能表现。
            
        3.  落地实现：以实现效果为主
            
    2.  DEMO
        
        1.  引擎交互：U3D引擎，
            
        2.  功能保真：设计为功能服务，在保证功能基础上，强化视觉表现。
            
        3.  落地实现：在实现对标效果的同时，也考虑量产落地成本，技能性能测试与验证。
            
3.  以及做买量视频，可以为后续工作提供那些帮助……
    
    1.  定风格
        
    2.  试错时间
