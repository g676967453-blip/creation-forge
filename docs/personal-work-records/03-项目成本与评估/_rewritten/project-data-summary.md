## 一、策划文档（2 份 .md）

### 代号-暗黑魔兽

暗黑风魔兽换皮项目，基于镇魂玩法框架，目标微信小程序渠道。

**关键方法论：买量视频 ≠ Demo**

| 维度 | 买量视频 | Demo |
|------|---------|------|
| 发起端 | 买量团队 | 项目组 |
| 需求 | 无玩法约束 | 规范化战斗策划案 |
| 制作方式 | 走一步看一步，小步快走 | 明确质量对标+工作量版本+分工 |
| 引擎交互 | Y3 视觉演示 | U3D 引擎 |
| 功能保真 | 以表达视觉风格为主 | 设计为功能服务 |
| 落地实现 | 以实现效果为主 | 考虑量产落地成本+性能测试 |

> 💡 买量视频的价值：可以提前定风格、提供试错时间，但**不能替代 Demo**。

### 当前换皮模板项目-情况摸底

"众神之役"西幻 MMO 换皮模板审计，三个核心瓶颈：

| 瓶颈 | 表现 | 解法 |
|------|------|------|
| 程序支援不足 | 代码框架封闭，无专职程序 | 提供接口文档 + 低代码引擎降低门槛 |
| 资源管理混乱 | 命名规则混乱，引擎英文界面 | 标准化命名规范 + 汉化教程 |
| 远程协作障碍 | 无统一开发环境，会议效率低 | 云端 IDE + 版本控制 + 实时协作工具链 |
