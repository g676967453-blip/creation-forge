## 模板（新建时复制）

文件建议放在对应分类目录，文首：

```markdown
# <标题> · 对话认知点

> 📌 来源：…
> 📅 记录日期：YYYY-MM-DD
> 🏷️ 类型：认知 / 对话摘录
> 🎯 适用：…

## 要点…
## 一句话收束
## 待跟进
```

然后在**本表最上方**加一行。
