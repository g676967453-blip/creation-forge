## 核心理念

培训不是在教室里听课，而是**在真实项目中轮岗、踩坑、解决真问题**。

基于游戏行业"换皮开发"模式（成熟框架下替换美术/剧情快速出新品），学员全程参与从原型设计到产品落地的完整流程。

---

## 项目制 vs 传统培训

| 维度 | 传统培训 | 项目制培训 |
|------|---------|-----------|
| 学习目标 | 单一技能（如原画绘制） | 全流程能力 + 跨职能协作 |
| 教学模式 | 理论授课 + 模拟练习 | 真实项目实战 + 角色扮演 |
| 成果评估 | 作业评分 | 项目上线 / 商业化验证 |
| 就业适配 | 需二次适应企业流程 | 无缝对接 |

---

## 五种角色轮换

学员不只是一个"学生"，在项目中轮流扮演：

| 角色 | 职责 |
|------|------|
| **策划者** | 参与玩法设计、需求梳理 |
| **标杆制作者** | 制定美术/技术标准（"做成什么样"） |
| **验收审核者** | 把控质量、检查规范 |
| **执行制作者** | 完成具体模块开发 |
| **最终体验者** | 参与测试、收集反馈、推动迭代 |

> 💡 角色轮换的价值：让学员理解每个岗位的难点和语言，以后跨职能沟通不再是"对牛弹琴"。

## 实施流程

### 第一阶段：前期准备与团队组建
- 按 4-6 人/组划分，覆盖原画、UI、动效、策划
- 明确项目范围（如二次元卡牌换皮）
- 开发周期：8-12 周

### 第二阶段：能力摸底与分工
- 测试题 + 作品集评审 → 确定擅长领域
- 结合项目需求分配角色

### 第三阶段：规范与工具准备
- 岗位工作流培训（原画/UI/动效各自的标准操作流程）
- 统一开发环境（Jira、Perforce 等企业工具链）

### 第四阶段：全流程实战

```
前期创意 → 资源量产 → 引擎集成 → 测试调优
```

- **前期**：选定核心玩法、确定美术风格、产出标杆（主角立绘、场景概念图）
- **量产**：需求清单 → 批量产出 → 每日站会 → 导师实时反馈
- **集成**：资产导入引擎 → 调试交互 → APK 包体验
- **测试**：内部测试 → 收集反馈 → 迭代

### 第五阶段：成果输出
- 模拟企业立项会，向导师组汇报答辩
- 整理个人作品集（项目中负责的模块）
- 导师根据表现推荐职业方向

## 评估体系

| 评估类型 | 内容 |
|---------|------|
| 过程评估 | 每周进度报告（完成度 + 协作能力） |
| 终期考核 | 项目商业化潜力、个人贡献度 |
| 导师评价 | 专业技能 / 团队协作 / 抗压能力 三维度 |

## 与造化坊的对应

造化坊的核心方法论正是项目制学习：

| 项目制培训 | 造化坊实践 |
|-----------|-----------|
| 实战驱动，真实项目贯穿 | 定一个你想做的游戏 → 遇到问题 → 解决 → 完成 |
| 角色动态转换 | AI 三种模式：协作者/导师/加速器 |
| 产出可商业化的作品 | works/ 一事一记 + 视频生产草案 |
| 企业导师实时反馈 | AI 即时反馈，学习从"检索"变"对话" |
