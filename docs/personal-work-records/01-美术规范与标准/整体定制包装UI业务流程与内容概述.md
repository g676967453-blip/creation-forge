### 阶段一：需求分析

> 当前阶段：主要解决问题，所有关键人员对项目需求达成基础的统一认知。

### 内容包含

*   项目需求确认
    
    *   玩法特色提取
        
    *   美术方向确认
        
    *   用户定位确认
        
*   IP特点分析
    
    *   世界观
        
    *   主要阵营
        
    *   文化特色：建筑，服装，物件，符号。
        
    *   官方IP资料
        
*   竞品分析  
    
    *   同IP手游与主机游戏
        
    *   同游戏类型，已上线火爆和将要上线一线大厂游戏。

*   设计概念效果展示
    
*   设计体验目标说明
    
    *   设计主色调
        
    *   材质
        
    *   风格
        
    *   元素
        
    *   UI动效方向
        
    *   UI特效方向
        
*   技术风险评估

*   角色系统
    
*   背包系统

*   副本到战斗系统

### 阶段五：通用规范梳理加量产生产线建立。（定品质保障，底线）

> 梳理通用规范，明确生产沟通规范和版本计划，建立组内UI制作人员团队。

### 内容包含

*   通用规范
    
    *   基础框架
        
    *   面板层级
        
    *   字体类规范
        
    *   按钮类规范
        
    *   图标图形设计规范
        
    *   资源出图管理规范
        
    *   适配规范
        
*   版本计划通知
    
    *   项目量产开发计划
        
*   生产沟通对接明确
    
    *   UI界面重要程度分级
        
    *   日常任务沟通反馈规则确认
        
*   组内UI人员配置齐全
    
    *   UI组长最好能在概念设计和五图设计期间到位。
        
    *   执行UI可以在量产前后到位。
