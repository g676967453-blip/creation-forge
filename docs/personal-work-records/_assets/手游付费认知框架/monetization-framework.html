Monetization Framework

手游付费认知框架
玩家路径 × 付费入口 × 付费数据

核心不是单看礼包或数值，而是看「玩家在什么体验节点产生需求 → 系统用什么付费入口承接 → 最终反映到什么付费数据上」。框架以主表 + 分析表结构呈现，并完整拆解《英雄没有闪》。

主表 + 分析表 适用：策划 / 运营 / 商业化 案例：英雄没有闪
PART 01

认知框架模板

框架回答三个问题：付费数据 = 玩家花了多少钱、代表什么心理；付费入口 = 游戏用什么商品与界面承接需求；玩家路径 = 玩家在什么流程中被触发需求、何时看到入口。

1.1 三者关联模型

1.8 用户分层维度

框架中同一个路径节点，对不同用户的意义完全不同。必须叠加两个分层维度：维度一 · 游戏熟练度（新人 / 熟手）决定"玩家状态"，维度二 · 付费层级（小R / 中R / 大R）决定"付费数据"定位。

用户分层小R（0–98 元）中R（98–328 元）大R（328+ 元）
新人（0–7 天） 首充破冰、月卡试水；对价格敏感，追求"试一下"的低风险感 新手期直购礼包、抽卡起步；目标明确，愿意花钱换进度 开服全入口扫货、冲榜；追求先发优势与碾压感
熟手（7 天+） 月卡续费、每日限购；习惯性小额，断缴损失敏感 基金 + 限时礼包 + 抽卡保底；目标驱动，为成型与排名付费 排行礼包、限时池、高阶养成；竞争驱动，追求领先与稀缺

同一路径节点的分层差异（以新手 Boss 战卡点为例）

用户分层玩家状态需求承接入口预期数据
新人 · 小R首次卡关、心疼钱低风险尝试，变强一点点首充 6 元破冰转化
新人 · 中R卡关、目标明确快速成型，直接推图新手礼包 + 抽卡中度付费
新人 · 大R卡关但想领先全入口起步，冲榜直购礼包 + 抽卡冲刺高价值启动
熟手 · 小R效率焦虑、时间不足更多次数、更快刷取月卡、自动特权复购率
熟手 · 中R成型冲刺、活动截止确定性返利拿满基金、限时礼包ARPPU
熟手 · 大R排名被超越领先与稀缺资源排行礼包、限时池大R占比、LTV
分层设计三原则：① 同一节点、分层承接——一个路径节点要同时挂小额（破冰）、中额（成型）、大额（领先）三层入口；② 同一入口、分层定价——首充既服务新人小R破冰，也给大R当开服福利；③ 分层目标分开考核——小R看转化率、中R看 ARPPU、大R看 LTV，不能混在一起看。
框架核心观点：看付费设计，不是看"这个礼包卖什么"，而是看"玩家走到哪里、为什么需要、入口怎么接、最后形成什么付费数据"。后面拆任何手游模块，统一用固定九列格式：模块 | 玩家路径 | 玩家状态 | 付费入口 | 付费数据 | 商品内容 | 转化逻辑 | 验证指标 | 风险点，并在玩家状态列标注用户分层。

2.1 游戏概览

《英雄没有闪》是一款竖屏横版卷轴视角的放置 ARPG 刷宝手游，核心卖点是"单手挂机刷宝 + 流派构筑"，由安徽盈趣网络科技研发，37 网游与 iplay 联合发行[3][6]。上线 11 天流水约 6400 万元，App Store 评分 4.7（16 万评分）[1][6]。

核心循环与商业化关系

玩家核心循环为：自动战斗刷宝 → 装备 / 符文 / 侍从养成 → 推图 / 秘境 / 竞技场验证战力[3][8]。战斗消耗"混沌石"（体力类资源），而混沌石获取量有限 —— 这条资源线是全游戏付费设计的总引擎：时间压力（混沌石耗尽）→ 效率付费（月卡 / 永久卡 / 自动挖矿）→ 战力差距（符文 / 侍从）→ 情绪与社交付费（基金 / 抽卡）。

从运营机制看，整条付费链由三大压力引擎驱动：

① 时间压力 → 效率型入口

混沌石（体力）每日获取有限，消耗快、缺口大。月卡 30 元的 3 倍速、永久卡的扫荡上限、自动挖矿，全部锚定"单位时间收益"痛点。[5]

② 情绪压力 → 确定性入口

符文 36 选 1、200 抽保底的概率深坑制造不确定性焦虑，基金以约 1500% 返利 + 阶梯领取提供确定性出口，承接中R。[5]

③ 社交压力 → 稀缺型入口

竞技场、穹顶之战、公会红包与弹幕文化形成"被碾压 / 被比较"压力，驱动高价值带在结算节点集中爆发。[1][2]

2.6 数据验证与诊断

数据面信号：社区口碑存在明显分歧 —— App Store 4.7 分（16 万评分）[1]，而 TapTap 仅 6.0 分，负面评论集中在"不氪基本玩不下去""自动挖矿也要付费""分多期基金从 68 到 648"[4]。说明破冰层做得好（低门槛），但体验层的付费压力感知过强。

做得好的地方

① 破冰门槛极低：6 元多入口（首充 / 翅膀 / 秘典 / 升级包），覆盖所有转化路径。
② 效率型卡点清晰：混沌石 → 3 倍速 → 刷暗能，入口与痛点一一对应。
③ 基金返利结构完整：从 68 到 648 分档承接不同深度玩家。[2][5]

框架视角的风险点

① 首充奖励物"用过即弃"：6 元礼包很快被淘汰，缺失"路径展示"设计[3]。
② 30–98 元到 198 元之间入口断层：小R升中R缺少平滑承接（无战令 / 赛季通行证类常态入口）。
③ 重度带过度依赖概率与"托"弹幕引导，存在合规与口碑双重风险[3][4]。

优化建议（按框架逐环修复）：

① 路径补体验：为首充奖励物设计"BOSS 战 / 秘境展示场景"，让玩家实际用起来，延长其感知生命周期（修复首充模块的路径缺口）。
② 入口补常态化：新增赛季通行证 / 战令类入口，承接 30–98 元向 198 元过渡，缓解付费带断层。
③ 数据补透明：对 200 抽保底与侍从概率做显性化公示，降低"概率深坑 + 托"的负面口碑，用长期信任换长期 LTV。
④ 节奏补版本：赛季宝石系统（2026 年 8 月上线）与付费节奏绑定，将一次性爆发拆为赛季周期复购[7]。
