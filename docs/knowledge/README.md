## 登记规则

新增领域长文或重要认知时，**先在本表加一行**，再决定是否物理搬家：

```text
| 短标题 | 相对路径链接 | 一句话 | 标签（iaa/立项/发行/审查/…） |
```

可选物理目录（未建则保持索引制）：

```text
docs/knowledge/
  iaa/
  publishing/
  review/
```
