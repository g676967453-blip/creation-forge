## 10. 三层归属自查

> 确认新增/修改的代码不跨层污染。

| 层 | 文件 | 职责 | 改动类型 |
|----|------|------|---------|
| 表现层 | `scripts/ui/xxx.gd` | [UI渲染+用户输入] | 新增/修改 |
| 逻辑层 | `scripts/managers/xxx.gd` | [业务逻辑+信号协调] | 新增/修改 |
| 数据层 | `scripts/data/xxx.gd` | [数据加载+类型定义] | 新增/修改 |
| 数据层 | `data/xxx.csv` | [配置数据] | 新增/修改 |

### 跨层检查

```
□ 表现层代码是否直接读了 CSV？
  → 否。数据应通过 DataManager 获取，表现层只接收处理后的数据。

□ 逻辑层代码是否直接操作了 UI 节点？
  → 否。逻辑层通过发射信号通知表现层，不持 UI 节点引用。

□ 数据层代码是否发射了信号给 UI？
  → 否。数据层只提供数据读取接口，不关心数据被谁消费。
```
