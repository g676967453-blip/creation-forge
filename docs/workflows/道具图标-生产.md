# 道具图标生产

> 版本：v1 | 最后更新：2026-07-24 | 对应 SKILL：/item-icon | 关联项目：asset-pipeline

> **4×4 绿底网格 → PS 抠图 → PS 脚本切 16 张 256×256**

---

## 总览

```
流程一：Lovart 生成          流程二：PS 手动抠图          流程三：PS 脚本切图
──────────────────          ──────────────────        ──────────────────
GPT Image 2                 色彩范围 → 取样绿底        ps_chroma_slice.jsx
绿底 #00FF00                 容差200 → 反选 → Ctrl+J   16×256×256 透明 PNG
4 行 × 4 列                  隐藏原图层                 图标居中，多边透明
```

---

## Step 1: 定义道具清单

人类列出 16 个道具，**用英文物质名词描述**（2-4 个词）。Prompt 中不要用中文、不要加文化标签。

```
✅ crescent blade          ❌ 青龙偃月刀
✅ feather fan             ❌ 诸葛孔明羽扇  
✅ bronze ritual cup       ❌ 古代青铜酒器
```

**为什么**：`Chinese` `ancient` `traditional` 等词会触发模型的国风水墨偏差，污染风格。

---

## Step 2: 风格探索（必要时）

如果不是纯像素/动漫等已有模板的风格，需要先探索正确的风格关键词：

| 轮次 | 做什么 | 怎么判断 |
|------|--------|---------|
| 第 1 轮 | 用 Nano Banana Pro 快速试 2-3 组风格词 | 看大方向对不对 |
| 第 2 轮 | 选定方向，用 GPT Image 2 精修 | 风格命中后**锁死 Prompt** |

**风格锁定后**：后续只换 `items:` 列表，风格部分一个字不改。

**已验证的风格关键词**：

| 游戏对标 | Prompt 关键词 |
|---------|-------------|
| 皇室战争/荒野乱斗 | `Supercell 3D cel-shaded rendering, bright saturated colors, clean bold outlines, playful cartoon proportions` |
| 火影忍者二次元 | `cel-shading anime art style, clean lineart, flat colors` |
| 像素艺术 | `pixel art, limited color palette, clean pixel edges, no anti-aliasing` |

---

## Step 3: 组装 Prompt

模板来自 [templates/item-grid.md](../templates/item-grid.md)：

```text
16 game item icons in 4 rows of 4, evenly spaced, no grid lines,
items: {16 个道具英文名},
{已锁定的风格关键词},
pure green #00FF00 solid background,
game UI asset
```

**关键**：`no grid lines` 防止 AI 画格子线；`pure green #00FF00` 用于 PS 色彩范围抠图；`game UI asset` 表示最终用途。

---

## Step 4: Lovart 生成

模型选择：

| 场景 | 模型 | 命令 |
|------|------|------|
| 非像素艺术（二次元/3D/Supercell 等） | GPT Image 2 | `--prefer-models '{"IMAGE":["generate_image_gpt_image_2"]}'` |
| 像素艺术 | Nano Banana Pro（草稿） | `--include-tools generate_image_nano_banana_pro` |
| 像素艺术 | Midjourney（成品） | `--prefer-models '{"IMAGE":["generate_image_midjourney"]}'` |

```bash
python3 agent_skill.py chat \
  --prompt "{组装好的 Prompt}" \
  --prefer-models '{"IMAGE":["generate_image_gpt_image_2"]}' \
  --json --download
```

---

## Step 5: PS 手动抠图

> PS 2026 的 Color Range API 在 JSX 中不可用，手动操作 30 秒即可完成。

1. PS 打开绿底 1024×1024 图
2. **选择 → 色彩范围** → 取样左上角绿色 → 容差 **200** → 确认
3. **Ctrl+Shift+I** 反选（选中图标）
4. **Ctrl+J** 复制到新图层（透明底）
5. 点击原图层 → **隐藏**（眼睛图标点掉）

---

## Step 6: PS 脚本切图

```
文件 → 脚本 → 浏览 → 选 ps_chroma_slice.jsx
→ 选输出目录 → 确认 → 16 张 PNG
```

输出：`item_r0_c0.png` … `item_r3_c3.png`，每张 256×256，透明底，图标居中。

---

## Step 7: 验收

人类逐张查看：
- 满意的 → 重命名为道具名
- 不满意的 → 对那一格单独用 1×1 模式重新生成

---

## 备选：全自动 PIL 管线

适合像素艺术或对边缘精度要求不高的场景：

```bash
# 色键抠图（绿底→透明，含 despill 去绿边）
python3 scripts/postprocess.py \
  --input grid_raw.png \
  --output grid_clean.png \
  --width 1024 --height 1024 \
  --chroma-key green

# 切片
python3 scripts/slice_grid.py \
  --input grid_clean.png \
  --output-dir outputs/GAME-XXX/icons \
  --prefix GAME-XXX_item \
  --trim
```

> PIL 自动但有绿边风险。PS 手动抠图结果更干净。

## 关键参数卡

| 参数 | 值 |
|------|-----|
| Lovart 画布 | 1024×1024 |
| 排列 | 4 行 × 4 列，无格子线 |
| 每格输出 | 256×256 |
| 生成背景 | 纯绿 #00FF00 |
| 最终背景 | 透明 RGBA |
| 非像素模型 | GPT Image 2 |
| 像素模型 | Nano Banana Pro → Midjourney |
| PS 抠图 | 色彩范围 → 容差200 → 反选 → Ctrl+J |
| PS 切图 | ps_chroma_slice.jsx |
