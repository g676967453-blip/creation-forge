# 汇报说明书同步

> 版本：v1 | 最后更新：2026-07-21 | 对应 SKILL：`/同步报告`

## 触发条件

- 用户说 `/同步报告` 或 "同步汇报说明书" 或 "更新 Excel"
- 项目结构发生变更后

## 人机分工

| 步骤 | 人 | AI |
|------|-----|-----|
| 1. 检查来源 | — | 读取 `tools/generate-report.ts`，确认代码与当前状态一致 |
| 2. 更新脚本 | 告知需要更新的内容 | 修改 `generate-report.ts` 中的硬编码数据 |
| 3. 生成 | 关闭 Excel 文件 | 执行 `npx tsx tools/generate-report.ts` |
| 4. 验证 | 打开 Excel 抽查 | — |

## 执行步骤

### 1. 检查来源

AI 检查 `generate-report.ts` 中的以下硬编码段是否与当前状态一致：
- 简介 Sheet 的项目描述
- 近期动态 Sheet 的 `workDescs` 映射表
- 任务看板的任务列表
- 架构层的项目结构描述
- 项目地址 Sheet 的路径列表

### 2. 更新脚本

AI 更新 `generate-report.ts` 中过时的数据，用户确认。

### 3. 生成

用户关闭 Excel 文件后，AI 执行：
```bash
npx tsx tools/generate-report.ts
```

如果 Excel 被锁定（EBUSY），提示用户关闭文件后重试。

### 4. 验证

用户在 Excel 中抽查关键 Sheet 内容是否正确。

## 产出物

- `reports/造化坊汇报说明书.xlsx`（重新生成）

## 约束与规则

- **生成前关闭 Excel**：文件打开时无法写入
- **数据来源是 generate-report.ts**：Excel 是衍生文件，不应手动编辑
- **works/ 日志驱动近期动态**：新增 works/ 文件后，需同步更新 `workDescs` 映射表
