# 工作流目录

> 项目标准化协作流程。每个流程定义：什么时候触发、人做什么、AI 做什么、产出什么。  
> 总导航：[../README.md](../README.md)  
> 索引最后全量核对：2026-09-04

## 使用方式

- **人**：打开对应文档，了解完整流程和人机分工  
- **AI**：对应的 SKILL（`/xxx`）可自动执行，见「SKILL」列  
- **状态**：`mature` 常用稳定 · `active` 在用可改 · `testing` 试验 · `legacy` 已被替代（见 [_archive/](./_archive/)）

## 文档模板

新建工作流时建议文首 YAML：

```yaml
---
name: 流程名
version: v1
status: active
skill: /xxx   # 或 待建 / —
category: 造化坊 | 内容 | 美术 | 功能 | 工程 | 元流程
updated: YYYY-MM-DD
---
```

正文结构：触发条件 → 人机分工 → 执行步骤 → 产出物 → 约束与规则。  
元流程：[创建工作流.md](./创建工作流.md)。
