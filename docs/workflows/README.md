# 工作流目录

> 项目标准化协作流程。每个流程定义：什么时候触发、人做什么、AI 做什么、产出什么。

## 使用方式

- **人**：打开对应文档，了解完整流程和人机分工
- **AI**：对应的 SKILL（`/xxx`）可自动执行，见右列

## 文档模板

新建工作流时复制以下结构：

```markdown
# 流程名称

> 版本：v1 | 最后更新：YYYY-MM-DD | 对应 SKILL：/xxx

## 触发条件
（什么时候启动这个流程）

## 人机分工
| 步骤 | 人 | AI |
|------|-----|-----|

## 执行步骤
（详细展开）

## 产出物
（流程结束后的交付物及存放位置）

## 约束与规则
（固定不变的东西）
```

## 与 SKILL 的关系

- `docs/workflows/` = 完整流程（给人看，给 AI 参考）
- `.claude/skills/` = 精简执行清单（给 AI 执行，通过 `/xxx` 调用）
- 一个工作流成熟后，同时拥有知识层文档和 SKILL 文件
