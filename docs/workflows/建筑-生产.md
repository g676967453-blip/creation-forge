# 建筑生产

> 版本：v1 | 最后更新：2026-08-13 | 对应 SKILL：待建 | 关联项目：asset-pipeline

> **2×2 绿底网格 → PS 抠图 → 切片 4 张 1024×1024 透明 PNG**

---

## 总览

```
流程一：Lovart 生成          流程二：PS 手动抠图          流程三：切片
──────────────────          ──────────────────        ──────────────────
GPT Image 2                 色彩范围 → 取样绿底        slice_grid_2x2.py
绿底 #00FF00                 容差200 → 反选 → Ctrl+J   4×1024×1024 透明 PNG
2 行 × 2 列                  隐藏原图层                 建筑居中，多边透明
```

---

## Step 1: 定义建筑清单

人类列出 4 个建筑，**用英文物质名词描述**（3-6 个词）。Prompt 中不要用中文、不要加文化标签。

```
✅ medieval blacksmith forge with chimney    ❌ 中式仙侠铁匠铺
✅ fantasy wizard tower with crystal orb     ❌ 魔法师高塔带水晶球
✅ rustic tavern with wooden signboard       ❌ 乡村小酒馆木招牌
```

**为什么**：`Chinese` `ancient` `traditional` 等词会触发模型的国风水墨偏差，污染风格。

---

## Step 2: 风格探索（先做，再固化模板）

建筑管线的风格关键词尚未锁定。在生产前需先探索：

| 轮次 | 做什么 | 怎么判断 |
|------|--------|---------|
| 第 1 轮 | 用 Nano Banana Pro 快速试 2-3 组风格词 | 看 45° 等距视角是否正确、建筑比例是否合理 |
| 第 2 轮 | 选定方向，用 GPT Image 2 精修 | 风格命中后**锁死 Prompt 模板** |

**风格探索时使用的 Prompt（轻量版）**：

```text
single 3D isometric building, 45-degree top-down view,
{一个建筑的描述},
{风格候选词},
pure green #00FF00 solid background,
game building asset for 2D isometric game
```

**风格候选池**：

| 游戏对标 | 候选风格关键词 |
|---------|-------------|
| Clash of Clans | `Clash of Clans style, bright saturated colors, playful cartoon proportions, clean bold outlines` |
| Hay Day | `Hay Day style, warm pastel colors, cozy farm aesthetic, soft rounded shapes` |
| Boom Beach | `Boom Beach style, tropical military aesthetic, weathered textures, realistic proportions` |
| 通用低模 | `low-poly 3D isometric, flat shaded, clean geometric shapes, minimal texture detail` |
| 通用写实 | `real-time 3D game asset, PBR materials, detailed textures, realistic lighting` |

**风格锁定后**：后续只换 `buildings:` 列表，风格部分一个字不改。

---

## Step 3: 组装 Prompt

模板来自 [building-grid.md](../../asset-pipeline/templates/building-grid.md)：

```text
4 3D isometric game buildings arranged in 2 rows of 2, evenly spaced,
no visible grid lines or borders between buildings,
45-degree isometric top-down camera angle,
buildings: {4 个建筑英文描述},
each building standalone with spacing around it,
3D pre-rendered isometric game building,
clean lighting with soft ambient occlusion,
{已锁定的风格关键词},
pure green #00FF00 solid background,
game building asset for 2D isometric game
```

**关键**：`no grid lines` 防止 AI 画格子线；`pure green #00FF00` 用于 PS 色彩范围抠图；`game building asset` 表示最终用途。

---

## Step 4: Lovart 生成

模型选择：

| 场景 | 模型 | 命令 |
|------|------|------|
| 风格探索（快速迭代） | Nano Banana Pro | `--include-tools generate_image_nano_banana_pro` |
| 成品输出 | GPT Image 2 | `--prefer-models '{"IMAGE":["generate_image_gpt_image_2"]}'` |

```bash
python3 agent_skill.py chat \
  --prompt "{组装好的 Prompt}" \
  --prefer-models '{"IMAGE":["generate_image_gpt_image_2"]}' \
  --json --download
```

---

## Step 5: PS 手动抠图

> PS 2026 的 Color Range API 在 JSX 中不可用，手动操作 30 秒即可完成。

1. PS 打开绿底 2048×2048 图
2. **选择 → 色彩范围** → 取样左上角绿色 → 容差 **200** → 确认
3. **Ctrl+Shift+I** 反选（选中建筑）
4. **Ctrl+J** 复制到新图层（透明底）
5. 点击原图层 → **隐藏**（眼睛图标点掉）
6. **文件 → 导出 → 快速导出为 PNG**（或另存为 PNG）

---

## Step 6: 切片

```bash
python3 scripts/slice_grid_2x2.py \
  --input grid_clean.png \
  --output-dir outputs/buildings/ \
  --prefix building
```

输出：`building_r0_c0.png` `building_r0_c1.png` `building_r1_c0.png` `building_r1_c1.png`，每张 1024×1024，透明底。

---

## Step 7: 验收

人类逐张查看：
- 满意的 → 重命名为建筑名（如 `blacksmith_forge.png`）
- 不满意的 → 对该格单独用 1×1 模式重新生成

**验收检查项**：

| 维度 | 检查点 |
|------|--------|
| 视角 | 是否严格 45° 等距？建筑的三个面是否清晰可见？ |
| 比例 | 建筑是否占据网格的合理比例？不过大不过小 |
| 光照 | 光影方向是否一致？四个建筑的阴影角度是否统一？ |
| 细节 | 建筑特征是否可辨识？门窗、屋顶等结构是否完整？ |
| 边缘 | 绿底去除是否干净？有无绿边残留？ |
| 透明度 | 建筑外区域是否完全透明？ |

## 备选：全自动 PIL 管线

适合对边缘精度要求不高的场景：

```bash
# 色键抠图（绿底→透明，含 despill 去绿边）
python3 scripts/postprocess.py \
  --input grid_raw.png \
  --output grid_clean.png \
  --width 2048 --height 2048 \
  --chroma-key green

# 切片
python3 scripts/slice_grid_2x2.py \
  --input grid_clean.png \
  --output-dir outputs/buildings/ \
  --prefix building \
  --trim
```

> PIL 自动但有绿边风险。PS 手动抠图结果更干净。
