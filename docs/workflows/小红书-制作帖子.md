# 小红书制作帖子

> 版本：v3 | 最后更新：2026-07-30 | 对应 SKILL：`/new-post`

## 触发条件

- 用户说 `/new-post` 或 "做一期小红书"
- 或从 works/ 日志中积累了新素材，由 AI 主动提醒

## 人机分工

| 步骤 | 人 | AI |
|------|-----|-----|
| 1. 选材 | 从 AI 给出的候选选题中选定一个 | 读取 works/ 最近日志，提炼 3 个候选选题 |
| 2. 文案 | 审核文案是否准确、有吸引力 | 按 _template.md 结构出完整文案 |
| 3. HTML | 确认 accent 色 | 生成 `index.html`（6 张卡片，单文件，1080×1440px） |
| 4. 截图 | 检查截图效果 | Puppeteer 逐卡截图，输出 6 张独立 PNG |

## 执行步骤

### 1. 选材

AI 读取 `works/` 下最新日志，提炼选题方向。标准：一个问题、一个解法、一个结果。给出 3 个候选，用户选一个。

### 2. 文案

AI 用 `_template.md` 格式出文案，确认 6 张卡片方向：

| 卡片 | 用途 | 内容规范 |
|------|------|---------|
| Card 1 | 封面/提出问题 | 大标题 + 副标题 + 痛点问题 |
| Card 2 | 拆解/痛点 | 把问题拆开 |
| Card 3 | 工具/方法 | 用什么工具、什么方法 |
| Card 4 | 流程/行动 | 具体步骤，人做什么 AI 做什么 |
| Card 5 | 结果/洞察 | 产出规格、核心认知 |
| Card 6 | CTA/金句 | 行动号召 + 固定口号 |

### 3. HTML

文案确认后，AI 生成 `index.html`，6 张卡片合并在一个文件。放入：

```
projects/xiaohongshu/YYYY-MM-DD-主题/index.html
```

### 4. 截图导出

AI 用 Puppeteer 脚本对 `index.html` 逐卡截图，每张 `.card` 元素输出一张独立 PNG：

```
YYYY-MM-DD-主题/
├── index.html
├── 卡片1-封面.png      # Card 1
├── 卡片2-根因.png      # Card 2
├── 卡片3-解法.png      # Card 3
├── 卡片4-流程.png      # Card 4
├── 卡片5-洞察.png      # Card 5
└── 卡片6-CTA.png       # Card 6
```

截图脚本复用 `projects/xiaohongshu/_screenshot.mjs`，修改 `CARD_NAMES` 数组即可适配不同主题的卡片命名。

> 依赖：`puppeteer-core` + 系统已安装的 Chrome 浏览器

### 5. Pixso 导入（可选）

如需在 Pixso 中进一步编辑排版，单文件导入流程：Pixso 点击画布空白取消选中 → `code_to_design` 导入 `index.html` → 重命名 frame。

> 详细操作见 [Pixso-导入操作](Pixso-导入操作.md)

## 产出物

| 产出 | 位置 |
|------|------|
| 文案 | `projects/xiaohongshu/YYYY-MM-DD-主题/index.md` |
| HTML | `projects/xiaohongshu/YYYY-MM-DD-主题/index.html` |
| 截图 | `projects/xiaohongshu/YYYY-MM-DD-主题/卡片N-描述.png`（6 张） |

## 约束与规则

- **CTA 固定口号**：「关注我：每天解决一个问题」（所有帖子尾页，永不变）
- **品牌标记**：底部 `.creation-badge`「造化坊」
- **卡片尺寸**：1080 × 1440px
- **背景色**：`#141414`（奇数卡）/ `#1a1a1a`（偶数卡）交替
- **Accent 色**：按期独立（默认 `#f0a040` 琥珀金）
- **字体**：Noto Sans SC
- **素材来源**：从 `works/` 工作日志提炼，不从宣言直接取材
- **文件夹命名**：`YYYY-MM-DD-主题`（日期 + 中文主题）
- **先文案后 HTML**：不跳过文案直接写 HTML
- **逐卡截图**：Puppeteer 直接对 HTML 截图导出 6 张独立 PNG，不经过 Pixso
