# 05 — 概念设计

> 版本：v1 | 最后更新：2026-08-26 | 对应 SKILL：/concept | 关联项目：概念设计工作流
> 关联画布：[Lovart 概念设计](https://www.lovart.ai/canvas?projectId=46f30e5f3ac1488c8176ebd715e8a2d3)

> **核心原则：边使用边记录** —— 每次概念设计都产出一张概念图 + 一条工作记录，流程随实际使用持续沉淀。

---

## 触发条件

用户描述了一个游戏想法、角色、场景或氛围，需要先确定**视觉方向**再进入正式美术制作。

典型场景：
- "帮我画一个修仙题材的主角概念"
- "这个 Boss 应该是什么风格？先出几张概念图看看"
- "游戏整体是暗黑还是明亮？用概念图定调"

## 流程定位

```
[游戏想法] → 本阶段 → [风格方向 + 概念图]
                          ↓
                   → 阶段 2：功能需求（玩法确认）
                   → 04-美术资产（资产规格化）
```

本阶段只看**视觉方向**：什么风格、什么色调、什么氛围。不产出正式资产，只定调。

## 人机分工

| 步骤 | 人 | AI |
|------|-----|-----|
| 1. 一句话想法 | 说出想设计什么（角色/场景/道具/氛围） | 倾听，转译成 Prompt 方向 |
| 2. 风格锚点 | 指定对标游戏或参考图（可选） | 提炼风格关键词 |
| 3. 概念图生成 | 确认生成方向 | 调 Lovart 生成（模型自动路由） |
| 4. 风格确认 | 看概念图，判定"对/不对" | 记录命中/偏差 |
| 5. 迭代细化 | 给出修改方向 | 同线程继续生成（保留上下文） |
| 6. 验收归档 | 确认定稿 | 归档画布链接 + 写工作记录 |

## 执行步骤

### 1. 一句话想法

用户自由描述。不要求结构化，想到什么说什么。

**产出：概念关键词**（3 个维度各 1 词）

| 维度 | 含义 | 示例 |
|------|------|------|
| 题材 | 背景取材 | 三国 |
| 氛围 | 基调/情绪 | 诡异（但颜色明亮） |
| 造型 | 比例/风格 | Q版（2头身） |

> ✅ 已跑通案例（2026-08-26）：`三国 + 诡异 + Q版（2头身）`
> 2头身比"Q版"更精确，模型理解更准。

### 2. 风格锚点

| 锚点类型 | 做法 | 示例 |
|---------|------|------|
| 对标游戏 | 说出游戏名，AI 提炼风格关键词 | "参考《王国橡果传说》" |
| 参考图 | 提供本地文件路径，AI 逐张分析 | `C:\...\fenggecanao\`（10 张角色立绘） |
| 文字描述 | 直接说风格 | "东方玄幻，青绿色调" |

> **优先级**：角色立绘图（单角色、透明底）> 游戏场景截图（俯视塔防）> 文字描述。
> 立绘图最能精确传达造型/线稿/配色。

**已提炼的风格关键词（王国橡果传说基底 + 明亮诡异）**：
```
chibi 2-head-tall proportions, cartoon rounded shapes,
clean bold dark outlines, flat colors with cel shading,
high saturation per-character color, isolated character on white,
playful yet eerie mood, three kingdoms theme
```

> ⚠️ **风格矛盾处理**：若用户关键词内部有张力（如「诡异 × 明亮」），需主动澄清融合方式——
> 本案例用户明确「设计诡异元素，但颜色保持明亮」，采用明亮色板 + 诡异内容设计，而非变暗调色。

### 3. 概念图生成（★ 首选图生图法）

> **核心结论（用户验证）**：纯文本 prompt 生成难以精确复刻参考立绘（跑偏风险高）。
> **图生图（`edit_media`，以风格对味的底图做编辑）是贴合风格的最优解。**

**操作步骤**：
1. `upload` 用户提供的**对味底图** → 拿 CDN 链接
2. `chat --attachments <底图CDN>` → 触发 `edit_media` 图生图
3. prompt 只说「**要改的 N 处**」，并强调其余**全部沿用底图**

**Prompt 模板**：
```text
Based on this reference image, edit the character to become {目标角色},
KEEPING the exact same artistic style, body proportions, pose, facial structure,
line weight, shading, and color rendering of the reference.
ONLY change these {N} things: {逐条列出要改的点}.
```

**已验证案例（刘备）**：底图「赤瞳_双剑版.png」→ 只改 3 处（武器→双股剑、衣服→刘备绿袍、头部→发髻）→ 风格 100% 对齐，用户认可。

**纯文本生成的形体规则**（图生图前或需要时补充）：

| 特征 | prompt 关键词 |
|------|--------------|
| 身材比例 | `egg-shaped plump body, stubby short limbs, no visible joints` |
| 线条 | `thick rough hand-drawn outlines` |
| 眼睛 | `sharp upturned almond eyes with white highlights` |
| 上色 | `flat colors, minimal shading, painterly hand-drawn texture` |

> **⚠️ 两个重要词**：
> - **不借助游戏名**做风格引导（会误导模型参考错误画法）
> - **武器用词**：「双手剑」= 一把大剑双手握；**「双股剑」= 两把剑**（雌雄双股剑），刘备/关张辨识武器

### 2. 风格锚点

| 锚点类型 | 做法 | 示例 |
|---------|------|------|
| 对标游戏 | 说出游戏名，AI 提炼风格关键词 | "参考《风来之国》" → pixel art, warm palette |
| 参考图 | 上传图片作为风格参考 | 上传画师作品 → AI 分析线条/配色 |
| 文字描述 | 直接说风格 | "东方玄幻，仙气飘飘，青绿色调" |

> 复用已验证的风格关键词（见 [道具图标-生产](道具图标-生产.md) 的风格锁定法）：
> - 二次元：`cel-shading anime art style, clean lineart, flat colors`
> - 像素：`pixel art, limited color palette, clean pixel edges`
> - Supercell 3D：`Supercell 3D cel-shaded rendering, bright saturated colors, clean bold outlines`

### 3. 概念图生成

调用 Lovart Agent（本项目已链接）：

```bash
python agent_skill.py chat \
  --project-id "46f30e5f3ac1488c8176ebd715e8a2d3" \
  --prompt "{组装好的 Prompt}" \
  --json --download --output-dir "C:\tmp\lovart-concept"
```

**Prompt 组装要点**：
- 用**英文**描述主体（角色/场景），避免中文文化标签污染风格（参考道具图标流程的教训）
- 结构化：主体 → 服装/道具细节 → 环境 → 风格关键词 → 用途说明（concept art）
- 模型选择交给 Agent 自动路由；需要指定时可用 `--prefer-models`

### 4. 风格确认

- 概念图符合预期 → **锁定 Prompt**，进入细化
- 不符合 → 分析偏差（风格不对？主体不对？），修改 Prompt 重试

### 5. 迭代细化

复用同一线程（`--thread-id`），Agent 保留上下文，可以：
- "换一个配色方案"
- "把这个角色改成女性"
- "加上武器"

### 6. 验收归档

- [ ] 概念图已下载到本地
- [ ] 画布链接已确认（作品同步到 Lovart 画布）
- [ ] 概念图已发送给用户确认
- [ ] 工作记录已写入 `works/`（一事一记）

## 约束与规则

- **概念设计≠正式资产**：本阶段产出是方向参考，不承诺可交付资产
- **风格锁定后不要乱改**：一旦确认风格，迭代时只改主体/细节，风格词保持不变
- **每次使用都要记录**：这是"边使用边记录"的底线
- **画布固定**：概念设计统一进「概念设计」画布，不散落到其他项目
