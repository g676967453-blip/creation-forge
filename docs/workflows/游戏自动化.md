# 游戏自动化

> 版本：v1 | 最后更新：2026-08-19 | 项目目录：`projects/game-bot/`

## 触发条件

- 运行 `projects/game-bot/start.cmd` 或 `node projects/game-bot/loop.mjs`
- 当前仅支持「点兵成将」(com.yk.zjsg2)

## 架构

```
loop.mjs (主循环，3s 间隔)
├── lib/mumuctl.mjs   → MuMu 模拟器 ADB 控制
├── lib/ocr.mjs       → 截图 + OCR 文字识别 + UI 状态检测
├── lib/ai.mjs        → AI 决策引擎（状态→动作）
└── lib/obs.mjs       → OBS 录屏（备选 ADB screenrecord）
```

## 状态机

| 状态 | 决策 | 卡住恢复 |
|------|------|----------|
| gameplay | 随机探索点击 | 16 次同状态 → 按 BACK |
| unknown | 暂停等待外部决策 | 写入 aid_request.json |

## 已知问题

- OCR 持续失败，实际退化到随机点击模式
- OBS 连接失败，录制由 ADB screenrecord 兜底
