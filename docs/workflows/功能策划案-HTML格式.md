# 功能策划案 — HTML 格式

> 版本：v1 | 最后更新：2026-07-29 | 状态：**已归档（内容迁移至 v0.1）**

## 这是什么

一份 HTML = 完整的策划案。5 个一级页签覆盖功能全流程，策划 + AI 协作填充。HTML 同时服务人类阅读和机器解析。

## 5 页签结构

```
┌─────────────────────────────────────────────────────────┐
│ [功能简介] [功能规则] [界面说明] [动态交互] [资产需求]     │
├─────────────────────────────────────────────────────────┤
│ 当前选中 tab 内容                                        │
│                                                         │
│ 资产需求 tab 包含 5 个二级页签：                          │
│   [UI] [原画] [动作] [特效] [3D资产]                     │
└─────────────────────────────────────────────────────────┘
```

| Tab | 内容 | 写法规范 |
|-----|------|---------|
| **功能简介** | 文档信息 + 变更日志 + 功能定位 + 关联CSV + 不在范围内 + 颜色图例 | 简洁，一张 card 一组信息 |
| **功能规则** | Excel 层级格式：● 绿色底线标题 → 一./1./1）/① 逐层缩进 → 示意：举例 | 直接陈述事实，标注「支持配置」项 |
| **界面说明** | 左：16:9 原型框 + 黄色编号锚点 / 右：功能效果、规则、多种状态 | 不写美术尺寸颜色，只写功能和规则 |
| **动态交互** | 可点击的功能模拟，含完整状态机流程，支持入场→交互→退场动画 | CSS+JS，无外部依赖 |
| **资产需求** | 二级 tab 表格：一个资产一行 | 编号/名称/类别/规格/格式/数量/优先级/Prompt |

## 颜色标注约定

| class | 效果 | 用途 |
|-------|------|------|
| `.mark-yellow` | 黄色背景 | 未定案/待讨论（定案后清除） |
| `.mark-green` | 绿色背景 | 定案后改动标注，须带日期 |
| `.text-blue` | 蓝色文字 | 邮件、系统提示文字 |
| `.text-red` | 红色文字 | 强调、需重点关注 |

## 执行步骤

1. 复制 `templates/功能策划案-HTML模板.html` → 重命名
2. AI 按 5 个 tab 逐项与策划协作填充
3. 保存到 `策划文档/03-功能规格/{日期}-{功能名}/{日期}-{功能名}-功能策划案.html`

## 已知待改进

- 模板为通用空白骨架，实例包含完整 CSS/JS，后续应合并为一份可配置模板
- 动态交互的状态机代码当前内联在实例中，后续抽取为通用函数
- 缺少 SKILL 文件（`/功能策划案`），无法一键触发
- 颜色标注只在文档底部有图例，没有 `<style>` 内置为固定 class
- 资产需求表格列项可能因项目类型不同需要调整

## 与完整流水线的关系

- 本流程是 `功能开发-流水线.md` 的轻量替代
- 中小功能（≤5 界面、≤20 资产）用本流程
- 大型功能仍建议走完整 4 阶段流水线
- 两个流程可混用：先用本流程快速出案，需要时补完整需求文档
