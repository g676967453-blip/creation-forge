# 仪表盘更新

> 版本：v2 | 最后更新：2026-07-27 | 对应 SKILL：`/update-dashboard`

## 触发条件

- 用户说 `/update-dashboard` 或 "仪表盘更新" 或 "更新仪表盘"
- 项目结构或数据发生变更后

## 人机分工

| 步骤 | 人 | AI |
|------|-----|-----|
| 1. 检查来源 | — | 读取 `tools/collect-data.ts`，确认 8 个页签的数据与当前状态一致 |
| 2. 更新脚本 | 告知需要更新的内容 | 修改 `collect-data.ts` 中的硬编码数据 |
| 3. 生成 | — | 执行 `npx tsx tools/generate-dashboard.ts` |
| 4. 验证 | 打开 HTML 抽查各页签 | — |

## 执行步骤

### 1. 检查来源

AI 检查 `collect-data.ts` 中的数据，确认与当前状态一致。仪表盘共 **8 个页签**：

| 页签 | 数据来源 | 检查内容 |
|------|---------|---------|
| 系统总览 | `collectData()` 动态采集 | 信条标语、6 统计卡片（SKILL 文件/工作流数/工具知识库/工作日志/Git 提交/活跃项目）、系统信息表（AI 模式/SKILL/项目结构/活跃项目数） |
| 项目状态 | `projects[]` 硬编码 | 5 个项目各字段：engine、status、progress、output、blocker（GAME-002/小红书/asset-pipeline/tutorial/originals） |
| 工作流清单 | `workflows[]` + `skills[]` | 11 个工作流（二级页签：全部/造化坊/自媒体/游戏开发/主美工作/SKILL仓库）；SKILL 文件（类型/难度/用途描述/关联工作流） |
| 近期动态 | `listWorks()` + `gitLog()` 自动采集 | works/ 日志（文件日期+描述）、Git 提交历史（hash+message） |
| 个人待办 | `loadPersonalTasks()` 解析 `docs/个人待办.md` | 5 分类个人任务（汇总卡片 + 分类筛选 + 任务表格 + 周度归档折叠），通过 `/todo` SKILL 管理。已合并旧「任务看板」页签的历史数据 |
| 目标计划 | `goalsUser[]` + `goalsIssues[]` + `goalsAI[]` 硬编码 | 用户需求（6 条）、系统问题（7 条诊断）、AI 建议（4 条） |
| 知识库 | `toolGuides[]` 硬编码 | 5 个工具（Git/GitHub/Pixso/Claude Code Skills/Claude Code 配置），每个含入门/操作/协作文档链接 |
| 资产地址 | `assets[]` + `external[]` 硬编码 | 11 个内部资产路径（系统层 6 + 项目层 4 + 外部 1）、3 个外部平台（Pixso/GitHub/小红书） |

### 2. 更新脚本

AI 更新 `collect-data.ts` 中过时的数据，用户确认。需关注的硬编码数据：

- `projects[]` — 项目状态、进度、产出、阻塞项
- `workflows[]` — 工作流列表、版本、对应 SKILL（`skill` 字段）
- `tasks[]` — 任务看板
- `goalsUser[]` / `goalsIssues[]` / `goalsAI[]` — 目标计划
- `toolGuides[]` — 工具知识库
- `assets[]` / `external[]` — 资产地址

动态采集的数据（无需手动维护）：
- SKILL 文件统计（自动扫描 `.claude/skills/`）
- 工作日志（自动扫描 `works/`）
- Git 提交历史（`git log`）

### 3. 生成

```bash
npx tsx tools/generate-dashboard.ts
# 输出 reports/造化坊仪表盘.html
```

### 4. 验证

用户在浏览器中打开 HTML，抽查各页签内容是否正确。

## 产出物

- `reports/造化坊仪表盘.html`（独立 HTML，8 Tab 切页，浏览器打开即看）

## 约束与规则

- **数据来源是 `collect-data.ts`**：HTML 是衍生文件，不应手动编辑
- **works/ 日志驱动近期动态**：新增 works/ 文件后自动出现在近期动态中
- **SKILL 文件自动扫描**：无需手动维护 SKILL 文件数量
- **生成后即用**：HTML 是独立文件，可直接在浏览器中查看，也可通过 `npm run dashboard` 启动本地服务器
