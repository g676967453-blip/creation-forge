## 动效规范

### 过渡动画

| 动画 | 时长 | 缓动 | 用途 |
|------|------|------|------|
| Push | 0.3s | ease-out | 进入子页面 |
| Pop | 0.25s | ease-in | 返回父页面 |
| 弹窗弹出 | 0.25s | ease-out | scale + opacity |
| 弹窗消失 | 0.2s | ease-in | opacity |
| 列表入场 | 0.3~0.4s | stagger 0.05s | 逐项淡入 |
| 数值变化 | 0.4s | ease-out | 数字滚动 |

### 转场方向

| 转场 | 方向 |
|------|------|
| Push (进入) | 从右向左 ← |
| Pop (返回) | 从左向右 → |
| Present (模态) | 从下向上 ↑ |
| Dismiss (关闭) | 从上向下 ↓ |

### 设计原则

1. 时长 ≤400ms
2. 操作反馈 <100ms
3. 统一缓动曲线
4. 可关闭动效（减弱动态效果设置）
5. 首屏不延迟
