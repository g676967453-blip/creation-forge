网易式场景化主界面（模板A）

不同于传统扁平功能入口列表，网易游戏主界面使用有纵深感的场景承载功能：阴阳师的町中庭院、梦幻的长安城、哈利波特的霍格沃茨城堡。功能入口散布在场景中（NPC/建筑），而非纯图标网格。底部4~5个Tab导航为辅助。

网易式战斗HUD（模板B）

极简原则——战斗时隐藏大部分UI。逆水寒探索时几乎完全无UI。仅保留：顶部状态条+底部技能/道具栏。参照「左手开火」理论：左侧移动，右侧动作。

11 动效规范

转场方向（网易标准）：
Push   ← 右→左 进入子页面
Pop    → 左→右 返回父页面
Present ↑ 下→上 模态弹出
Dismiss ↓ 上→下 模态关闭
动画时长缓动网易标杆
Push0.3sease-out阴阳师庭院→式神录
Pop0.25sease-in返回
弹窗弹出0.25sease-out+spring梦幻西游弹窗
列表入场0.3~0.4sstagger 0.05s哈利波特卡牌入场
数值变化0.4sease-out伤害数字滚动

原则：①时长≤400ms ②反馈<100ms ③统一缓动 ④可关闭动效 ⑤首屏不延迟。参照网易"生动细致"之「达」原则。
