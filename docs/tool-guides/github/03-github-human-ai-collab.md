# GitHub — 人机协作

## AI 能帮你做什么

| 场景 | 人的操作 | AI 的操作 |
|------|---------|----------|
| 创建仓库 | 在 GitHub 网页上点 New | AI 给地址，帮你 `git remote add` + `git push` |
| 提交推送 | 说 "提交并推到 GitHub" | `git add` → `git commit` → `git push`，一气呵成 |
| 认证问题 | 在 GitHub 生成 Token | AI 指导步骤，帮你排查认证报错 |
| 查看线上状态 | 问 "仓库地址是什么" | 告诉你远程地址和最新提交状态 |
| 处理冲突 | 决定保留哪边的修改 | AI 识别冲突 → 展示给你 → 你拍板 → AI 执行 |

## 协作原则

1. **仓库创建由人在网页上完成** — AI 不能代你点 GitHub 网页上的按钮
2. **push 前 AI 会告知内容** — 推送到 GitHub 意味着公开可见，AI 会先让你确认
3. **敏感信息不上传** — Token、密码、API Key 等应在 `.gitignore` 中排除
4. **README 是门面** — 仓库主页的 README.md 是别人第一眼看到的，AI 负责保持它更新
