# GitHub — 代码托管平台

## 是什么

GitHub 是最大的**代码托管平台**，基于 Git 构建。它把 Git 仓库放在云端，并提供协作工具（Issue、Pull Request、Actions 等）。

## 和 Git 的关系

```
Git = 你电脑上的版本控制系统
GitHub = 互联网上的 Git 仓库托管服务
```

你用 Git 在本地管理代码，用 GitHub 把代码备份到云端、和别人协作、展示作品。

## 核心功能

| 功能 | 说明 |
|------|------|
| Repository（仓库） | 存放项目代码的地方 |
| Push / Pull | 上传代码 / 下载代码 |
| Clone | 把别人的仓库复制到本地 |
| Issue | 任务追踪、Bug 报告、讨论 |
| Pull Request（PR） | 提交修改请求，别人审核后合并 |
| Actions | 自动化流水线（测试/部署） |

## 为什么用 GitHub

- **备份**：代码不在本地硬盘，不会丢
- **协作**：多人同时开发，PR 审核流程
- **展示**：你的 GitHub Profile 就是你的作品集
- **开源**：全球最大的开源社区，可以学习和贡献
