# Git — 版本控制

## 是什么

Git 是一个**分布式版本控制系统**。它记录文件的每一次修改，让你可以：

- 回到任何一个历史版本
- 查看谁在什么时候改了什么
- 同时开多条工作线（分支），互不干扰
- 把多条工作线合并在一起

## 解决什么问题

**没有 Git 的时候**：改代码靠 Ctrl+Z → 关了就没了；多人协作靠 U 盘拷来拷去 → 版本混乱；不知道谁改了哪行 → 出了问题追溯不了。

**有了 Git 之后**：每一次修改都是一次 commit（快照），随时可以回退。多人协作各自在 branch 上工作，最后 merge 到一起。

## 核心概念

| 概念 | 一句话解释 |
|------|-----------|
| repository（仓库） | 被 Git 跟踪的项目文件夹 |
| commit（提交） | 一次修改的快照，带描述信息 |
| branch（分支） | 一条独立的工作线，不影响主线 |
| merge（合并） | 把分支的修改合入主线 |
| remote（远程） | 托管在服务器上的仓库副本（如 GitHub） |
| push/pull | 推送本地修改到远程 / 拉取远程修改到本地 |

## 和 GitHub 的关系

Git 是**工具**，GitHub 是**平台**。Git 在你的电脑上运行，GitHub 是网站，用来存放 Git 仓库、协作、备份。
