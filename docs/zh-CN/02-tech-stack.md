# 02 — 技术栈详解

## 概览

造化坊采用**双栈策略**：

| 栈                            | 角色                          | 引入时机                  |
| ----------------------------- | ----------------------------- | ------------------------- |
| TypeScript + Phaser.js + Vite | **主栈** — 日常开发的首选     | 第一天                    |
| Godot 4 + GDScript            | **探索栈** — 体验原生游戏引擎 | 完成 3-4 个 Phaser 项目后 |

---

## 主栈：TypeScript + Phaser.js + Vite

### 为什么选这套

1. **AI 协作效率最高** — TypeScript 是 LLM 训练语料中最丰富的语言之一。当你在代码中遇到困难，AI 能给出最准确的帮助。

2. **迭代速度极快** — Vite 的热模块替换（HMR）让修改在 100ms 内反映到浏览器。改一个值，立刻看到效果。这对学习至关重要。

3. **学习价值高** — TypeScript 的类型系统、模块化、异步编程等概念是通用的。学会这些技能可以迁移到任何语言和框架。

4. **零摩擦发布** — 构建产物是静态 HTML/JS/CSS，可以部署到任何地方。把游戏链接发给朋友，他们打开浏览器就能玩。

5. **生态成熟** — Phaser 有 37k+ GitHub Stars，海量教程和示例。遇到问题很容易找到解决方案。

### 各组件职责

| 组件       | 版本  | 做什么                                    |
| ---------- | ----- | ----------------------------------------- |
| TypeScript | 5.x   | 类型安全、智能提示、重构支持              |
| Phaser     | 3.80+ | 2D 游戏引擎：渲染、物理、音频、输入、动画 |
| Vite       | 6.x   | 开发服务器、HMR、生产构建                 |
| Vitest     | 3.x   | 单元测试、组件测试                        |
| ESLint     | 9.x   | 代码质量检查                              |
| Prettier   | 3.x   | 代码格式化                                |

```

```

## 探索栈：Godot 4

完成 3-4 个 Phaser 项目后，我们引入 Godot 4 来：

- 体验拥有可视化编辑器的「真正」游戏引擎
- 学习基于节点的架构思维
- 探索 GDScript（类 Python 语法的领域语言）
- 构建需要 Tilemap 编辑器或复杂动画状态机的项目
- 导出原生桌面和移动应用

Godot 不是要取代 Phaser，而是拓宽视野。两者各有擅长：

| 场景                | Phaser (主栈)         | Godot (探索栈) |
| ------------------- | --------------------- | -------------- |
| 快速原型            | ⭐⭐⭐⭐⭐            | ⭐⭐⭐         |
| 2D 平台游戏         | ⭐⭐⭐⭐              | ⭐⭐⭐⭐⭐     |
| 需要 Tilemap 编辑器 | ⭐⭐                  | ⭐⭐⭐⭐⭐     |
| AI 协作             | ⭐⭐⭐⭐⭐            | ⭐⭐⭐         |
| Web 发布            | ⭐⭐⭐⭐⭐            | ⭐⭐⭐         |
| 原生桌面导出        | ⭐⭐⭐ (via Electron) | ⭐⭐⭐⭐⭐     |

## 不推荐的技术（及原因）

| 技术                    | 不推荐原因                                                                          |
| ----------------------- | ----------------------------------------------------------------------------------- |
| Unity + C#              | 太重（多 GB 下载）、编辑器驱动（学习被工具牵着走）、迭代慢（domain reload 5-30 秒） |
| Three.js（裸用）        | 不是游戏引擎，缺少物理/音频/场景管理/输入，需要自己造太多轮子                       |
| 纯 JavaScript（无类型） | 缺少智能提示和重构支持，AI 协作效率降低，不适合中型以上项目                         |

---

## 版本策略

- 主版本锁定（如 TypeScript 5.x），次版本自由升级
- Phaser 锁定 3.x（4.x 发布后评估迁移）
- 其他 devDependencies 保持最新稳定版
- 每年至少一次依赖审查和升级
