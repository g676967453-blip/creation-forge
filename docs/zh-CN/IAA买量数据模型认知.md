# IAA 游戏买量 · 数据模型认知手册（新人版）

> 目标读者：刚入行、对买量和数据模型还不熟的同学。
> 本文回答三个问题：买量到完结的流程是什么？流程里有哪些核心数据节点？怎么用这些节点搭模型、判断好坏？

---

## 0. 先想清楚：IAA 买量是一门什么生意

- **IAA（In-App Advertising）**：靠游戏内广告变现（激励视频、插屏、横幅、开屏等），玩家不花钱，广告主花钱。
- **买量（UA / User Acquisition）**：在广告平台（Meta、Google、TikTok、穿山甲、Mintegral 等）花钱买用户进游戏。
- 这门生意的本质是 **流量差价**：低价买进用户，高价（通过广告变现）卖出去，赚中间的差。
- 所以整条链路只有一句话：

> **能不能赚钱 = 买进来的流量成本（CPI）< 每个用户带来的广告收入（LTV）**

所有数据模型，都是围绕这句话展开的。

## 1. 全流程：从买量到完结

### 阶段 1｜产品准备（上线前）
- 目标：把游戏做到「能测」的状态，接好广告 SDK（AdMob、AppLovin、穿山甲…）和归因 SDK（AppsFlyer / Adjust / 热云）。
- 关键动作：定好埋点（启动、关卡、广告曝光、广告点击、广告完看），因为后面所有模型都依赖埋点数据。
- 新人重点：**埋点和归因没接好，后面算的账全是错的。**

### 阶段 2｜测试调优（0～1 个月，小规模买量）
- 目标：用少量钱验证「产品行不行、账算不算得过来」。
- 买量：小预算（每天几百到几千美金）跑测试，通常按 CPI 或 AEO 出价。
- 看什么：D1/D3/D7 留存、人均时长、eCPM、ARPDAU、D0/D1 回收。
- 决策：数据达到可买门槛 → 进入起量；达不到 → 调产品（改留存/改变现点位）或放弃。
- 新人重点：**测试期不是看赚不赚钱，是看「有没有可能赚钱」。**

### 阶段 3｜起量放量（1～3 个月）
- 目标：模型验证成立后，把钱花出去，把 DAU 规模做起来。
- 动作：多国家多素材矩阵测试 → 找到 ROI 高的组合 → 加预算、扩渠道、批量上素材。
- 核心指标：CPI 稳定性、D7 ROI、回本周期、素材 CTR/CVR。
- 风险：放量后 CPI 会涨（流量变贵）、留存会掉（用户质量稀释），要盯边际 ROI。
- 新人重点：**放量不是闭眼加钱，是「加钱的同时模型不能崩」。**

### 阶段 4｜稳定运营（持续）
- 目标：在回本周期内让 ROI ≥ 1，然后持续赚利润。
- 动作：素材工业化（每周几十上百条）、变现场景优化（加激励视频点位、做插屏频控）、老用户运营（活动、更新）。
- 核心指标：整体 ROI、ARPDAU 趋势、留存曲线、广告渗透率。
- 新人重点：这个阶段拼的是 **变现效率和素材效率**，不是产品大改。

### 阶段 5｜衰退收割（产品进入尾期）
- 信号：买量边际 ROI 持续 < 1，新用户算不过来账。
- 动作：停止或大幅缩减买量 → 只服务存量用户 → 提高广告频次（收割）→ 减少运营投入。
- 核心指标：存量 DAU、存量 LTV 剩余价值、运营成本。
- 新人重点：**停买不是失败，是把剩余价值榨干，是正常的商业动作。**

### 阶段 6｜完结复盘
- 动作：拉全生命周期数据复盘：LTV 模型预估 vs 实际误差、分地区/分素材的 ROI、方法论沉淀。
- 产出：一份「这个游戏为什么赚钱/亏钱」的结论，喂给下一个项目。
- 新人重点：**复盘才是买量团队真正的资产，比单个游戏的盈亏更重要。**

## 2. 核心数据节点（四层漏斗）

### 2.1 投放层（买量漏斗）
```
展示(Impression) → 点击(Click) → 安装(Install) → 启动(Launch)
```
- **CTR** = 点击 ÷ 展示 → 衡量素材是否吸引人
- **CVR** = 安装 ÷ 点击 → 衡量素材与产品的匹配度（素材骗进来 vs 真实兴趣）
- **CPI** = 投放花费 ÷ 安装 → 买量成本，账本的核心
- **IPM** = 每千次展示带来的安装 → 素材效率的综合指标
- **归因**：靠 MMP（AppsFlyer/Adjust）把「安装」归给「哪条广告」，归因错了整个模型就错了

### 2.2 用户层（产品质量）
- **留存**：D1 / D3 / D7 / D30 —— 判断产品好不好玩的核心
- **时长**：人均时长、人均启动次数、次均时长 —— 广告库存的来源
- **进度**：关卡通过率、流失点 —— 找到玩家在第几关流失
- **广告行为**：广告渗透率（看过广告的用户占比）、人均广告次数、激励视频渗透率

### 2.3 变现层（收入效率）
- **eCPM**：每千次广告展示的收入（由广告主出价决定，地区差异巨大）
- **填充率**：广告请求被成功填充的比例（填充不足 = 有流量但没收入）
- **ARPDAU** = 广告收入 ÷ DAU —— **变现效率最核心的指标**
- **人均展示次数**：广告库存消耗量（受游戏时长和点位设计影响）

### 2.4 商业层（算账）
- **LTV**：单个用户整个生命周期的总收入
- **ROI** = LTV ÷ CPI（或 收入 ÷ 花费）
- **回本周期**：累计收入超过买量成本所需天数
- **毛利率** = (LTV − CPI) ÷ CPI

## 3. 核心数据模型

### 模型 1：广告收入模型（一切收入的起点）
```
广告收入 = DAU × 人均广告展示次数 × eCPM ÷ 1000
```
拆开看：
- DAU = 买量带来的留存用户（投放 × 留存）
- 人均展示 = 游戏时长 × 广告点位设计（产品）
- eCPM = 地区 + 广告形式 + 用户价值（市场）

> 所以收入不是单点决定的，是「量 × 频 × 价」三个乘数。任何一项塌了，收入就塌。

### 模型 2：留存衰减模型
- 留存曲线通常符合幂律衰减：R(t) ≈ a × t^(−b)
- 用 D1、D7 拟合出曲线参数，就能预测 D30、D90 留存
- 判断产品：D1 决定「能不能留住人」，D7 决定「长线有没有戏」，D30 决定「能赚多久」

### 模型 3：LTV 预估模型
```
LTV(n) = Σ (第 i 天 ARPDAU × 第 i 天留存率)，i = 1..n
```
- 简化版：LTV ≈ ARPDAU × 平均生命周期天数（或 ARPDAU × 留存面积）
- 实际工作中，按地区/渠道/素材分别算 LTV（不同人群 LTV 差好几倍）

### 模型 4：ROI / 买量决策模型
```
能不能买：LTV(回本周期内) ≥ CPI
出价上限：目标 CPI = 目标 LTV × 目标 ROI 系数（例如想 30 天回本且要 20% 利润）
放量/停量：看边际 ROI —— 新增预算带来的 ROI 还 ≥1 就继续加，跌破就停
```
- IAA 游戏特别看重 **D0/D1 回收**（插屏、激励视频当天就能产生收入）
- **D7 ROI** 通常是 IAA 放量与否的一票否决指标

## 4. 好坏怎么评判

### 4.1 参考门槛（行业经验值，帮你建立感觉）

| 指标 | 不及格 | 及格 | 优秀 |
|---|---|---|---|
| D1 留存 | <25% | 30% | 40%+ |
| D7 留存 | <8% | 10–12% | 15%+ |
| D30 留存 | <3% | 5% | 8%+ |
| 人均时长/天 | <15 分钟 | 25–30 分钟 | 45 分钟+ |
| 广告渗透率 | <50% | 65–75% | 85%+ |
| ARPDAU（休闲） | <$0.03 | $0.05–0.10 | $0.15+ |
| 回本周期 | >90 天（危险） | 45–90 天 | <30 天 |

⚠️ 注意：
1. 以上是**超休闲/休闲品类的经验值**，中度游戏、不同地区（美区 eCPM 是东南亚的 5–10 倍）差异巨大。
2. **永远拿「自己的产品 vs 自己的历史」对比**，行业值只用来建立第一感觉。
3. eCPM 看地区：美/日/韩/西欧高（激励视频 $15–30），东南亚/印度/拉美低（$1–5）。

### 4.2 评判逻辑（比数值更重要）

**三看原则：**
1. 一看留存 —— 产品行不行（D1/D7）
2. 二看变现 —— 每个用户每天能产出多少（ARPDAU、人均广告次数、eCPM）
3. 三看账 —— 综合 ROI 和回本周期（LTV vs CPI）

**常见误判（新手最容易犯）：**
- ❌ 只看 CPI 便宜就买 —— 便宜流量往往质量差，D1 留存可能只有 15%，算总账是亏的
- ❌ 只看留存好就放量 —— 留存好但 eCPM 低（比如全是中国低价值流量），同样不赚钱
- ❌ 只看单日 ROI —— 要看回本周期内累计 ROI，D0 回收高不代表 30 天账能平
- ❌ 不看归因 —— 归因窗口、自归因渠道、自然量混入，都会让数据虚高

## 5. 观点（给新人的认知框架）

1. **IAA 买量是流量差价生意**：一切模型的起点是「CPI < LTV」，其他都是派生指标。
2. **核心公式只有三个**：收入 = DAU × 人均展示 × eCPM ÷ 1000；LTV = ARPDAU × 生命周期；能不能买 = LTV ÷ CPI ≥ 1。
3. **看数据的顺序**：先留存（产品），再变现（效率），最后算账（ROI）。顺序反了会被单点数据误导。
4. **素材即产品**：买量素材决定流量质量和 CPI。同一个游戏，素材好 CTR 翻倍、CVR 翻倍、CPI 减半。买量团队一半的功夫在素材。
5. **归因是地基**：AppsFlyer/Adjust 配错一个参数，所有模型输出都是垃圾。新人入职先搞清楚归因链路。
6. **模型是活的**：按地区、渠道、素材、版本切片看数据，不要看大盘。大盘好看可能只是美区在撑。
7. **阈值要动态**：不要死记「D7 要 10%」，要结合 CPI 和 eCPM 算账。CPI $0.1 的 D7 8% 可能比 CPI $0.8 的 D7 15% 更赚钱。
8. **混变是趋势**：纯 IAA 利润薄、受广告市场波动影响大，现在主流是 IAA + IAP 混合变现（IAA 保底、IAP 拉利润）。大富翁这类棋盘游戏就是典型。
9. **完结是正常商业动作**：游戏不是都要运营到天荒地老，算不过账就停买收割，把复盘经验留给下一个项目。
10. **新人最快的成长路径**：把上面的漏斗画在纸上 → 找到自己产品的每个节点数据 → 亲手算一遍 LTV 和 ROI → 再回来看这篇文章，你会发现全通了。

## 6. 数字演练（把模型跑一遍）

假设一个休闲游戏，美区买量：
- CPI = $0.30
- D1 = 35%，D7 = 12%，D30 = 5%
- 人均广告展示 = 8 次/天，eCPM = $10 → ARPDAU = 8 × 10 ÷ 1000 = $0.08
- 30 天留存面积（Σ日留存）≈ 4.5（D1 35% 衰减到 D30 5% 的典型曲线）
- LTV30 ≈ $0.08 × 4.5 = **$0.36**
- ROI30 = 0.36 ÷ 0.30 = **1.2** → 30 天回本并盈利 20% ✅ 可以放量

如果同样的游戏放量后 CPI 涨到 $0.45：
- ROI30 = 0.36 ÷ 0.45 = **0.8** → 亏钱 ❌ 停买或换素材/换地区

这就是买量团队每天都在做的判断：**盯住 LTV 和 CPI 这两个数，其他指标都是解释这两个数为什么变。**

## 7. 术语表

| 术语 | 含义 |
|---|---|
| IAA | In-App Advertising，应用内广告变现 |
| IAP | In-App Purchase，内购付费（混变游戏的另一半） |
| UA / 买量 | User Acquisition，付费获取用户 |
| CPI | Cost Per Install，单安装成本 |
| CTR | 点击率 = 点击/展示 |
| CVR | 转化率 = 安装/点击 |
| IPM | 每千次展示安装数 |
| eCPM | 每千次广告展示收入 |
| ARPDAU | 每活跃用户日均收入 = 广告收入/DAU |
| LTV | 用户生命周期价值 |
| ROI | 投入产出比 = LTV/CPI |
| 回本周期 | 累计收入覆盖买量成本的天数 |
| 留存面积 | 一段时间内日留存的累计和，用于估生命周期 |
| AEO | App Event Optimization，按事件（启动/付费等）优化投放 |
| MMP | 移动归因平台（AppsFlyer、Adjust、热云） |
| 填充率 | 广告请求被填充的比例 |
| 渗透率 | 看过广告的用户占比 |
| 混合变现 | IAA + IAP 同时做 |

## 8. 单用户成本（CPI）价位参考

（经验值，随市场波动，用于建立价格感觉）

### 8.1 按地区 + 品类（美元）

| 地区 | 超休闲 | 休闲/中度 | 备注 |
|---|---|---|---|
| 美国 | $0.3–1.0 | $1–4 | 全球最贵但 eCPM 也最高（激励 $15–30） |
| 日本 | $1.0–2.5 | $3–8 | eCPM 高，量少 |
| 韩国 | $0.8–2.0 | $2–5 | 买量竞争激烈 |
| 西欧 | $0.2–0.6 | $0.8–2 | 性价比之选 |
| 东南亚 | $0.05–0.2 | $0.2–0.5 | 便宜但 eCPM 低（$1–5） |
| 印度 | $0.02–0.08 | $0.1–0.3 | 极便宜，变现也极低，常算不过账 |
| 巴西 | $0.05–0.15 | $0.2–0.6 | 量大价低，中低 eCPM |
| 中国安卓 | ¥1–5 | ¥5–15 | 国内安卓生态，按人民币 |

### 8.2 其他影响因素
- iOS 普遍比 Android 贵 50%–100%（美区 iOS 休闲 $2–4）
- 渠道差异：Meta/TikTok 大盘价，穿山甲/Mintegral 超休闲便宜量
- 按事件出价（AEO）：按启动/付费优化后，「有效用户成本」会高于表面 CPI

### 8.3 整体预算体量（给个人/小团队）—— 美元 + 人民币对照（按汇率 ≈7.2 估算）

| 项目 | 美元 | 人民币（≈） |
|---|---|---|
| 一轮完整测试 | $10k–30k | ¥7万–22万 |
| 超休闲小测 | $1k 内 | ¥7,000 内 |
| 测试期日预算 | $200–2,000/天 | ¥1,400–1.4万/天 |
| 测试周期 | 2–4 周 | 2–4 周 |
| 起量期单市场月预算 | $50k+ | ¥36万+/月 |
| 头部产品全球月投放 | 数百万美金 | ¥1,400万–3,600万+/月 |

- 说明：买量结算主要是美元，盯美元最准，人民币只作换算参考。
- 实操阶梯：独立个人先花 ¥7,000 内做超休闲「体检」→ 有戏再上 ¥7万–22万完整测试；小团队直接一轮完整测试 ¥10万–20万，通过后起量 ¥30万–100万/月。

### 8.4 关键认知
- CPI 便宜 ≠ 划算：印度 $0.05 的用户 eCPM 只有 $1–2，美区 $0.5 的用户 eCPM $15–30，算总账往往美区更赚
- 超休闲美区现在普遍是「亏着买」在赌素材优化和混变：CPI $0.5 vs LTV7 $0.2 是常态，所以行业在卷素材降 CPI、加 IAP 提 ARPDAU
