# 提示词模板：重构

## 用途

当代码开始变得难以维护时，安全地重构。

## 提示词

```
请帮我重构以下代码。重构目标：

### 当前问题
- [代码太长？重复太多？逻辑太耦合？]

### 重构要求
1. 保持功能不变（行为完全一致）
2. 提取可复用的函数/类
3. 改善命名
4. 分离关注点（逻辑 / 渲染 / 数据）

### 约束
- 使用项目中已有的模式和工具（见 shared/utils）
- 遵循项目的编码规范（见 docs/zh-CN/05-coding-standards.md）
- 注释用中文

### 代码
```

[粘贴要重构的代码]

```

请先总结你打算做的改动（让我确认），再给出重构后的代码。
```
