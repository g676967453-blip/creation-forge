# 提示词模板：代码审查

## 用途

让 AI 审查代码质量、发现潜在问题和改进空间。

## 提示词

```
请审查我的代码，关注以下维度：

### 1. 正确性
- 有没有明显的逻辑错误？
- 边界条件处理是否正确？
- 有没有潜在的 null/undefined 引用？

### 2. 可读性
- 命名是否清晰表达了意图？
- 函数是否太长（超过 30 行）？
- 有没有需要注释的复杂逻辑？

### 3. Phaser 最佳实践
- 场景管理是否合理？
- 是否正确使用了对象池？
- 物理计算是否放在 update() 中？

### 4. TypeScript
- 有没有用了 any 的地方？
- 类型定义是否足够严格？
- 有没有类型可以简化的地方？

### 5. 可改进之处
- 有没有重复代码可以提取？
- 有没有过度设计可以简化？

请按严重程度排序：🔴 严重 → 🟡 建议 → 🟢 风格
对每个问题给出具体的修复建议和代码示例。
```
