# 提示词模板：Bug 排查

## 用途

当游戏出现意外行为时，帮助快速定位和修复 Bug。

## 提示词

```
我的游戏出现了以下问题：

### 问题描述
[描述你期望的行为 vs 实际发生的行为]

### 复现步骤
1. [第一步]
2. [第二步]
3. [观察到的问题]

### 环境信息
- 浏览器：[Chrome / Firefox / Edge]
- Phaser 版本：[3.80+]
- 操作系统：[Windows / Mac / Linux]

### 相关代码
```

[粘贴相关代码片段]

```

### 控制台输出
```

[粘贴控制台错误信息]

```

请：
1. 分析可能的原因（从最可能到最不可能）
2. 对每种原因给出验证方法（加个 console.log？改个值？）
3. 给出最可能的修复方案
```
