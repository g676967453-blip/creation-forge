# 提示词模板：游戏设计文档 (GDD)

## 用途

与 AI 一起头脑风暴并生成一份完整的游戏设计文档。

## 提示词

```
我想设计一个游戏，请以协作者的身份和我一起讨论。不要直接给我完整方案，而是逐步引导我思考。

游戏类型：[平台跳跃 / 射击 / 解谜 / RPG / 其他]
目标平台：[Web / 桌面 / 移动]
核心玩法想法：[一句话描述你的想法]

请：
1. 先问 3 个关键问题帮我明确核心玩法
2. 根据我的回答，提出 2-3 种可行的核心循环 (core loop)
3. 一起选定一个方向后，帮我写一份一页纸的游戏设计文档

一页纸 GDD 应包含：
- 游戏名称（暂定）
- 一句话描述 (elevator pitch)
- 核心循环 (30秒内的玩法流程)
- 操作方式
- 视觉风格参考
- 技术需求（我们用的技术栈是 Phaser + TypeScript）
- 最简可行产品 (MVP) 范围
```
