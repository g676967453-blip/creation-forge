## 🎬 视频生产草案（三幕结构）

### 第一幕：遇到了什么问题

git status 一屏刷不完：产出图、迭代归档、重复 json 全堆在工作区，哪些该提交、哪些该忽略全靠人肉判断。

- 核心问题：产出物和流程产物混在一起，仓库边界模糊
- 为什么这是个问题：提交噪音大、回看历史困难、协作时容易误提交大文件
- 如果没有 AI 会怎样：逐个文件判断去留，再手写忽略规则，一下午起步

### 第二幕：AI 怎么协作解决的

- 我是这样问 AI 的：先「拉取 GIT」，再一句「整理文件」
- AI 给了什么方案：核对既有惯例 → 忽略规则白名单化 → 目录归位 → 按逻辑分块提交，先问清做到哪一步再动手
- 中间有什么调整/追问：用选择题确认范围（清理+提交+日志），不猜
- 最终方案是什么：一条 gitignore 规则解决 100+ 文件噪音，三个语义清晰的提交收尾

### 第三幕：效果展示

- 最终效果：git status 干净到只剩刻意未提交的内容，历史可回溯
- 演示方式（截图/GIF/屏幕录制）：整理前后 git status 对比截图
- 学到的关键点：仓库卫生不是删文件，是「惯例 + 规则 + 分块提交」三位一体

### 一句话总结（金句候选）

> 整理文件不是把东西藏起来，而是让 git 只看见值得被看见的东西。
