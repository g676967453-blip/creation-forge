## 📋 问题解决日志

### 遇到了什么

用户要把角色概念设计探索从「单张试错」扩大到「100 角色批量生产」：定位（战士/刺客/辅助/谋士/将军）、4 种异化路线、浸染度 30%-90%、模型（MJ / Nano Banana Pro / GPT Image 2）、风格（风格化3D / 欧美卡通 / 日韩卡通）全部随机配置。

第一批 100 张产出后，用户一句话点破：「不是说好了锁定 3-4.5 头身吗？」——批量提示词里的裸短语 `3.5 heads tall` 被图片模型集体无视，视觉上大面积破锁。

### AI 怎么协作的

1. **批量架构**：随机参数表（确定性种子）+ 9 组（模型×风格）独立线程 + 管道重命名助手 `tools/batch100_helper.py`，chat JSON 不进上下文。
2. **客观复核**：Claude 看不到图，用 Lovart agent（多模态）当测量工具——每组抽样本上传，让它量「头高÷全身高」：v1 实测 2.0~8.5 头身，1/9 达标，坐实用户判断。
3. **三轮校准**（本日核心）：
   - v1 裸短语 → v2 分数锚点句（`head height equals one quarter of full body height` + 体型词）→ 4/9 达标
   - v2 → v3 按组校准：过Q组删 `toy-like` 前缀 + `not chibi` 负向；写实组加 `big head small body` 拉力 → 11/18 达标（5 组合 100%）
   - **钟摆现象**：风格化3D 在 Q↔写实之间来回甩（2.0 → 6.0），MJ×韩系三轮纹丝不动（7.0）。提示词对这三个组合的比例控制力到顶，用户裁决「就此收尾」。
4. 每轮都归档旧版（v1-weak-ratio / v2-overshoot），数据可复盘。

## 🎬 视频生产草案（三幕结构）

### 第一幕：遇到了什么问题

- 核心问题：跟 AI 说「画个 4 头身角色」，9 种模型×风格组合画出 2 头身到 8.5 头身——提示词里的数字，图片模型根本不听。
- 为什么这是个问题：手工一张张试错要试 100 次；不测量就不知道破锁——「参数表锁了 ≠ 画面锁了」。

### 第二幕：怎么用 AI 解决

- AI 当测量员：让多模态 agent 量头身比，三轮校准数据说话（1/9 → 4/9 → 11/18）。
- AI 当生产员：100 张随机参数批量，9 线程并行，管道自动命名落盘，积分 0。

### 第三幕：收获与洞察

- 提示词工程的黑盒现实：模型是「风格引力场」，不是参数机器——同一句话在不同模型×风格下位移方向都不同。
- 适配矩阵比完美提示词值钱：5 个可控组合直接投产，3 个不可控组合标注禁用，比硬调第 4 轮更经济。
- 「先测量，再修」的工作流：眼睛发现 → AI 量化 → 按数据收敛，三轮到位。

## 📋 续：west 重定向与第四轮校准

### 遇到了什么

ref 线稿风 20 小样比例 20/20 达标后，用户裁定**整批换欧美卡通（west）**。第一轮 west 20 小样全灭：

- **比例 0/20**：`_COMPRESS`（MJ×west 的压缩校准句）被 gpt2 严格服从，全部压成 2.5 头身 Q 版
- **风格 2.75/5**：impasto 笔触缺失、配色暗淡（vibrant 纪律 agent 实测 8/8 违反）
- **道具 14/20 缺失**：根因是 mini_prompt 漏拼 class_desc（职业描述只进了文件名没进提示词）

### AI 怎么协作的

1. 用户两项决策：模型继续 GPT Image 2 + west 专属提亮配色（同 kr 模式：2主色+1点缀结构不变，主色换高饱和撞色）。
2. 6 张单图校准轮：_Q_FIX（含 not chibi）× 4 档 + _MID × 2 档 → agent 量：**qfix 系统性 +0.5 拉长（写3.0→3.5，写4.5→5.0），mid 向 Q 下漂**。
3. **第四轮定稿 `_GPT2_WEST`：写目标值 -0.5 补偿**（要 4.0 写 3.5；3.0 档写 2.5 + 40% 锚点，保留 not chibi 抗Q）。
4. 顺手排掉三个批量坑：产物乱序（行-图错位，靠 agent 汇总表映射）、遗留同名文件（Windows 重命名崩溃）、class_desc 缺失。
5. 20 小样重跑：west v1 归档 → westbatch 重建 → 组0/组1 重跑 → agent 复核 → 用户目视。

### 关键教训

**比例句是模型×风格的二元函数**：同是欧美卡通，MJ 拉长要压、GPT2 反而 Q 化要抬 —— 同风格他模型的校准不可沿用。校准要按组合逐一实测，哪怕目标风格相同。
