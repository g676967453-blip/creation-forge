# 游戏UI设计系统调参工具 v1.0

## 做了什么

完成了一个自包含的网页调参工具，用于实时调节游戏UI设计系统的参数并预览效果。

## 产出

- `projects/interaction-spec-system/dist/tuner/index.html` (57KB, 1110行)

## 功能

- **左侧实时预览**：360×640 手机框，4 屏切换（主页/列表/详情/弹窗）
- **右侧调参面板**：
  - 主风格滑块：写実 (0) ↔ Q版 (100)，驱动所有默认值
  - 9 个独立参数：网格(列数/沟槽/边距)、间距密度、圆角比例、头像/按钮/卡片比例、字体比例
  - 独立滑块覆盖主滑块后标记橙色圆点
- **导入**：解析设计系统 HTML 的 CSS 变量，回填到滑块
- **导出**：生成完整设计系统 HTML，参数烘焙到 CSS 变量
- **纯前端**：零依赖，浏览器直接打开

## 视频草案

**标题**：AI帮你做游戏UI调参工具——写实一键切Q版

**三幕结构**：
1. 问题：游戏UI从写实风格改Q版，要一个个改CSS变量—太慢
2. 方案：一个滑块，写实↔Q版，网格/间距/圆角全部自动插值
3. 结果：调完一键导出完整设计系统HTML，直接给美术用
