## 3. 小程序深度参考数据

### IAA vs IAP 双路径对比

| 维度 | IAA（纯广告） | IAP（含内购） |
|------|-------------|-------------|
| 版号 | 不需要 | **必须** |
| 主体 | 个人或企业 | **仅企业** |
| 上线周期 | 最快 **1 个月** | 通常 **6-12 个月** |
| 收入分成 | 约 50/50 | 约 60/40（优质新游最高 70%） |
| 税务 | 平台代扣 20% 个税 | 企业 0-6% |
| 激励 | 无 | 首发新游最高 **400 万** |

### 你的 IAA vs IAP 决策

```
你是个人开发者吗？
├─ 是 → 只能走 IAA（纯广告）或找发行商合作
└─ 否（有公司）→ 评估：
    ├─ 能等 6-12 个月吗？
    │   ├─ 能 → IAP 或混合变现
    │   └─ 不能 → 先 IAA 验证，后迁移到 IAP
    └─ 游戏类型适合内购吗？
        ├─ 适合（有可收费的虚拟道具/增值服务）→ IAP
        └─ 不适合（纯单机/一次性体验）→ IAA
```

## 5. 关键认知

> Steam 用户是"主动寻找好游戏"，小程序用户是"被动刷到游戏"。前者需要深度和品质，后者需要即时爽感和社交裂变。两种平台对一个"好游戏"的定义完全不同。
