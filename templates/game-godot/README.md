# Godot 游戏模板

> ⏳ **占位符** — Godot 模板将在完成 3-4 个 Phaser 项目后创建。

Godot 4 将作为星火工坊的**探索栈**，用于：

- 体验拥有可视化编辑器的原生游戏引擎
- 学习基于节点的架构
- 构建需要 Tilemap 编辑器或复杂动画状态机的项目
- 导出原生桌面和移动应用

## 计划内容

- Godot 4 项目结构
- 基础场景模板（2D）
- GDScript 编码规范
- 常用节点配置（CharacterBody2D, TileMap, AnimationPlayer 等）
- Phaser 与 Godot 的概念对照表
