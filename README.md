## AI 时代的新学习思想

造化坊是一套 **「做中学」** 的实践体系。

传统教育告诉你「先学完再去做」，但现实世界没有学完的一天——你永远觉得「没准备好」，永远不开始。

我们的答案是**项目制学习**：定一个你想做的项目 → 遇到问题 → 学需要的知识 → 解决问题 → 完成。AI 让这种学习方式第一次真正可行——当你卡住了,问 AI，秒回，附代码，继续做。

**学习的瓶颈从「获取知识」变成了「你有没有在做一个具体的事」。** 而我们的练习场是独立游戏开发——因为做游戏有即时反馈、跨学科整合、而且它本身就很有趣。

## 怎么学？

**项目制学习 —— 先做再学，不是先学再做。**

| 传统学习 | 项目制学习 |
|----------|------------|
| 先学再练 | 先做再学 |
| 按知识体系组织 | 按问题驱动组织 |
| 「学完了再做」 | 「做完了就算学会了」 |
| 知识的广度优先 | 知识的深度优先 |
| 评价标准：记住多少 | 评价标准：做出什么 |

你不是「学会 Phaser」再去做游戏。你决定「做一个平台跳跃游戏」——玩家怎么跳？学物理引擎。怎么碰撞？学碰撞检测。怎么加音效？学音频管理。

**每一个知识都是因为你真正需要它才学的。** 知识是你做出游戏之后留下的「副作用」。

> 完成比完美重要。先做出来，再优化。

| 层级     | 技术                | 为什么选它                     |

**不由课本决定，由你的项目决定。**

想做 2D 游戏 → 学 Phaser。想做 3D → 学 Godot。想做修仙塔防 → 那就开工。遇到什么学什么，做完就算学会。

## 快速开始

```bash
# 1. 安装依赖
npm install

# 2. 从模板创建项目（以 Phaser 为例）
cp -r templates/game-phaser projects/<你的项目名>
cd projects/<你的项目名>
npm install

# 3. 启动开发服务器
npm run dev
```

## AI 协作

本项目深度集成 AI 协作。AI 同时扮演两个角色：

- **即时学习引擎** — 卡住了就问 AI，学习变成「对话」而非「检索」
- **认知模式转换器** — 「学会」不再是「我记住了」，而是「我知道怎么驾驭 AI 做出来」

在协作中，AI 会根据上下文自动切换三种模式：

- 🤝 **协作者** — 创意讨论时平等贡献想法
- 🧑‍🏫 **导师** — 遇到困难时先解释「为什么」再教「怎么做」
- ⚡ **加速器** — 熟练任务时快速产出代码

详见 [CLAUDE.md](./CLAUDE.md) 了解完整的 AI 行为规范。
