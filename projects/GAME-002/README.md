# 开仙门（GAME-002）

> 🎮 **一句话定位**：桌面上的修仙宗门 —— 桌面伴侣 × 放置挂机 × 吸血鬼幸存者，Godot 4.7 独立游戏。
>
> **方向说明**：核心玩法已于 2026-07-29 由「弟子塔防」重构为「吸血鬼幸存者 + 放置」（GDD v3.0）。

## 📖 玩法概述

> 来源：[策划文档/01-愿景/开仙门-GDD-v3.0.md](策划文档/01-愿景/开仙门-GDD-v3.0.md)

1. **三态切换**：游戏常驻三种界面状态 —— 桌面放置态（1280×120 横板像素宗门，贴屏幕底部，器灵打坐挂机累积灵气）、全屏战斗态（类吸血鬼幸存者，器灵 360° 弹幕自动攻击）与最小化态（可拖动的器灵小窗，后台继续挂机）。
2. **战斗循环**：点击「⚔️ 挑战」消耗灵气进入全屏战斗，击杀敌人获得经验，升级时**祝福 3 选 1**，同类型祝福叠满 3 张触发**升阶质变**；精英与 Boss 掉落挂件，即时装备到 3 个槽位（武器/防具/饰品）。
3. **通关目标**：撑过 15 波（W15 为多阶段 Boss）即胜利，结算获得女娲石/流派秘宝/灵气与限时挂机加速 buff；失败时初始器灵「百世书」免死，直接回桌面态继续。
4. **放置养成**：用资源修复六座山峰（剑峰/佛峰/法峰/兽峰/器峰/魂峰），每座峰解锁一项器灵能力（弹射/护盾/分裂/穿透/范围/伤害）并扩充战斗祝福池。
5. **存档与离线**：自动存档（定时/结算/退出），离线期间灵气按基础速率持续累积，上限 24 小时。

1. 用 Godot 4.7 打开 `开仙门/project.godot`
2. 按 `F5` 运行（主场景 `res://scenes/main.tscn`，窗口 1280×720 置顶）
