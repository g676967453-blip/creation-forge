## 二、文档类型 × 模板对应

| 你要写什么 | 用哪个模板 | 放在哪里 |
|-----------|-----------|----------|
| 新功能需求 | `策划文档/05-元文档/模板/功能需求文档模板.md` | `策划文档/03-功能规格/` |
| 新功能规划 | `策划文档/05-元文档/模板/功能规划文档模板.md` | `策划文档/05-元文档/路线图/` |
| 游戏设计文档 | 无固定模板，参考 `开仙门-GDD-v0.1.md` 结构 | `策划文档/01-愿景/` 或 `策划文档/02-系统设计/` |
| 架构/设计决策记录 | `总指挥-协作原则/05-知识管理/02-决策记录模板.md` | `开发记录/memory/` 或决策相关文档 |
| 每日工作日志 | 无固定模板，参考 `AI记忆/` 中的已有日志 | `总指挥-协作原则/AI记忆/` |
| 问题/审计报告 | 无固定模板，参考 `issues/` 中的已有报告 | `策划文档/05-元文档/审计/` |
| 里程碑复盘 | `总指挥-协作原则/06-持续改进/02-里程碑复盘模板.md` | `开发记录/` |
| 协作规则 | 无固定模板，参考已有规则文档的结构 | `总指挥-协作原则/` 或 `程序规则/` |

## 四、文档更新触发条件

| 事件 | 需要更新的文档 |
|------|---------------|
| 新功能完成 | 工作日志、AI记忆索引、相关设计文档（如数值有变） |
| 架构变更 | `CLAUDE.md`（如果目录结构变了）、`Godot架构规范`（如果模块标准变了） |
| 规则调整 | 对应的规则文档 |
| CSV列变更 | `CLAUDE.md` 的数据流描述、受影响的Resource类文档 |
| Bug修复 | 工作日志（简单bug不强制，复杂bug或坑需要记录） |
| 发现设计问题 | `策划文档/05-元文档/审计/` + 工作日志 |
| 里程碑完成 | 复盘文档 + 工作日志 |
