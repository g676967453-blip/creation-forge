> 本文件夹是"开仙门"项目人机协作的**最高指挥层**。它定义**如何协作**，而非写什么代码或做什么功能。

## 🚀 快速开始

### 第一次使用？

1. 先读 [01-协作宪法.md](./01-协作宪法.md) — 5分钟了解核心原则
2. 再读 [02-角色分工.md](./02-角色分工.md) — 清楚你我各自擅长的领域
3. 遇到具体任务时，查 [03-工作流SOP/](./03-工作流SOP/) 对应阶段

### 对于AI

每次会话开始时，你应该：
1. 读取本 README 了解体系结构
2. 读取 `AI记忆/MEMORY.md` 了解项目最新进展
3. 根据当前任务类型，参考对应的 SOP 流程
4. 在完成阶段性工作后，主动提出改进建议

### 对于人类

你不需要记住所有流程。当你：
- 想提一个新功能 → 翻到 `03-工作流SOP/01-需求分析阶段.md`
- 不确定AI改的对不对 → 翻到 `04-质量体系/01-交付检查清单.md`
- 觉得协作方式需要调整 → 翻到 `06-持续改进/02-里程碑复盘模板.md`

## 📋 维护约定

- **人类**：定义和修改核心原则、角色分工、质量标准
- **AI**：根据实际使用反馈提出优化建议，协助更新文档
- **共同**：里程碑节点一起复盘，根据实战经验迭代规则
