## V0.1 — 核心闭环 MVP

**目标**：桌面挂机 → 挑战 → 单一战斗场 → 升级祝福 → 结算回桌面，最小闭环完整可玩

### 🔴 V0.1 核心闭环（必须交付）

```
桌面挂机（灵气累积）
    │
    ▼
[⚔️ 挑战] ──→ 全屏战斗（15波，WASD移动，360°弹幕）
    │              │
    │         [升级] → 暂停 → 3选1祝福 → 继续
    │              │
    │         [Boss]  ──→  结算（胜利/免死）
    │                        │
    ◄────────────────────────┘
         回到桌面，资源更新
```

| 模块 | 目标 | 进度 |
|------|------|------|
| 游戏启动 | 主菜单 / 开场黑幕 / 器灵选择 / 新游戏 vs 继续 | ✅ 策划案完成 |
| 存档系统 | 自动存档 / 读档 / 离线收益 / 24h 上限 | ✅ 策划案完成 |
| 仓库 | EconomyManager Autoload / 灵气+女娲石+秘宝 | ✅ 策划案完成 |
| 桌面放置态 | 1280×120 横板界面 / 灵气挂机(10/s) / 6 山峰显示 / 点击器灵爆发 | ✅ 策划案完成 |
| 器灵 | 百世书唯一可选 / 免死 / 7 级成长 | ✅ 策划案+代码就位 |
| 山峰修复 | 剑峰首修(500灵气) + 其余 5 峰自由顺序 | ✅ 策划案完成 |
| 全屏战斗态 | WASD only / 360°弹幕 / 15 波 / 3 秒倒计时 | ✅ 策划案完成 |
| 祝福系统 | 3 选 1 + 叠 3 升阶质变 / 9 条祝福线(初始3条+山峰解锁6条) | ✅ 策划案完成 + CSV 就位 |
| 敌人 | 普通 + 精英 + Boss（单阶段即可，多阶段延后） | ✅ 策划案完成 |
| 结算 | 胜利奖励 / 免死无惩罚 / 返回桌面 | ✅ 策划案完成 |

### 🟡 V0.1 明确延后到 V0.2

| 模块 | 原因 | 目标版本 |
|------|------|---------|
| 最小化态 | 复杂度高于核心闭环价值；桌面⇄战斗双态优先 | V0.2 |
| 挂件系统 | P1 优先级的扩展内容；先跑通无挂件的核心战斗 | V0.2 |
| Boss 多阶段 | 单阶段 Boss 即可验证战斗完整性 | V0.2 |
| 三态切换 | 简化为桌面⇄战斗双态 | V0.2 |
| 宝藏鼠 | 已在 GDD 中被砍掉，挂件掉落由精英/Boss 承担 | V0.3+ |

**详细任务**：[开仙门-V0.1-任务管理表.md](开仙门-V0.1-任务管理表.md)

### V0.1 明确砍掉（自 v2.0 塔防版）

- 弟子系统（招募/修炼/筑基/出战）
- 诛仙剑 / 神农鼎（V0.3+）
- 幸运转盘 / 宝藏鼠（宝藏鼠降为 P1）
- 深度经营（多种材料/灵植/丹药）

## V0.2 — 战斗好玩

**目标**：祝福池丰富、敌人多样、挂件体系扩展、形态变异

| 模块 | 目标 |
|------|------|
| 战斗 | 祝福池 20+、更多升阶线、挂件 20+、战斗中最小化 |
| 敌人 | 自爆/分裂/治疗/光环 4 种新敌人 |
| 祝福 | 每条祝福线 3 层升阶都有视觉变化 |
| Boss | W10 小 Boss + W15 大 Boss |
| 挂件 | 挂件可存入背包、战斗后选择保留 |

---

## V0.3 — 内容丰富

**目标**：多器灵、新敌人类型、更多山峰内容

| 模块 | 目标 |
|------|------|

| 敌人 | 宝藏鼠实装、5 种新精英怪 |
| 山峰 | 全部 6 峰可修复、各峰祝福池个性化 |
| 器灵成长 | 修复进度 → 器灵能力树完整 |
