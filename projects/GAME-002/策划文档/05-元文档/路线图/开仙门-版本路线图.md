## V0.1 — 可玩 MVP

**目标**：桌面伴侣 × 放置挂机 × 吸血鬼割草 最小闭环完整可玩

| 模块 | 目标 | 进度 |
|------|------|------|
| 游戏启动 | 主菜单 / 开场黑幕 / 器灵选择 / 新游戏 vs 继续 | ✅ 策划案完成 |
| 存档系统 | 自动存档 / 读档 / 离线收益 / 24h 上限 | ✅ 策划案完成 |
| 仓库 | 纯数值仓库（灵气/女娲石/秘宝） | ✅ 策划案完成 |
| 桌面放置态 | 1280×120 横板界面 / 灵气挂机 / 6 山峰显示 / 点击器灵爆发 | ✅ 策划案完成 (2026-07-31) |
| 最小化态 | 100×100 器灵打坐小窗 / 可拖动 / 呼吸动画 | ✅ 策划案完成 (2026-07-31) |
| 器灵 | 百世书唯一可选 / 免死 / 7 级成长 | ✅ 策划案+代码就位 |
| 山峰修复 | 剑峰首修(500灵气) + 其余 5 峰自由顺序(秘宝+女娲石+5千灵气) | ✅ 策划案完成 (2026-07-31) |
| 全屏战斗态 | WASD 移动 / 360°弹幕 / 15 波 / 3 秒倒计时 | ✅ 策划案完成 (2026-07-31) |
| 祝福系统 | 3 选 1 + 叠 3 升阶质变 / 9 条祝福线 | ✅ 策划案完成 (2026-07-31) |
| 挂件系统 | 3 槽即时装备 / 10 种挂件 / 新替旧 | ✅ 策划案完成 (2026-07-31, P1) |
| 敌人 | 普通 + 精英(4种) + Boss 多阶段 + 宝藏鼠 | ✅ 策划案完成 (2026-07-31) |
| 结算 | 胜利奖励(女娲石+秘宝+灵气+加速buff) / 免死无惩罚 | ✅ 策划案完成 (2026-07-31) |
| 三态切换 | 全屏⇄桌面⇄小窗 无缝过渡 | ✅ 策划案完成 (2026-07-31) |

## V0.2 — 战斗好玩

**目标**：祝福池丰富、敌人多样、挂件体系扩展、形态变异

| 模块 | 目标 |
|------|------|
| 战斗 | 祝福池 20+、更多升阶线、挂件 20+、战斗中最小化 |
| 敌人 | 自爆/分裂/治疗/光环 4 种新敌人 |
| 祝福 | 每条祝福线 3 层升阶都有视觉变化 |
| Boss | W10 小 Boss + W15 大 Boss |
| 挂件 | 挂件可存入背包、战斗后选择保留 |

## V0.3 — 内容丰富

**目标**：多器灵、新敌人类型、更多山峰内容

| 模块 | 目标 |
|------|------|
| 器灵 | 诛仙剑(通关1次)/神农鼎(通关2次) 解锁+特性实装 |
| 敌人 | 宝藏鼠实装、5 种新精英怪 |
| 山峰 | 全部 6 峰可修复、各峰祝福池个性化 |
| 器灵成长 | 修复进度 → 器灵能力树完整 |
