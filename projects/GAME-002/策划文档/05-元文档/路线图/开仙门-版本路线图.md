## V0.1 — 可玩 MVP

**目标**：选器灵 → 经营 → 战斗 → 结算 闭环完整可玩

| 模块 | 目标 | 进度 |
|------|------|------|
| 器灵 | 百世书唯一可选；免死机制；绑定+随修复成长 | ✅ 已实现 |
| 经营 | 修复剑峰(500灵气) → 招募弟子 → Lv10筑基 → 出战5人 | ⚠️ 山峰修复已实现，弟子招募待接入 |
| 战斗 | 15波、祝福3选1+升阶质变、挂件掉落、Boss多阶段、宝藏鼠 | ⚠️ 15波+卡牌已实现，祝福/弟子AI待接入 |
| 结算 | 胜利掉材料回经营；失败百世书免死/其他GameOver | ✅ 已实现 |
| 架构 | main_peak 拆分、CODE_WIKI 同步、文档修复 | ✅ 07-26 完成 |
| V0.1 新模块 | 弟子/赐福/法宝 CSV + 代码 | ✅ CSV+源码就位，待接入主循环 |

**详细任务**：[开仙门-V0.1-任务管理表.md](开仙门-V0.1-任务管理表.md)
