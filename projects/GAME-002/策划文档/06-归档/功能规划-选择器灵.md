# 功能规划：选择器灵

> ⚠️ 本文档已归档。最新版本见 `../03-功能规格/选择器灵.md`

> **状态：[已完成] | 验证日期：2026-07-09**

---

## 1. 功能在整体流程中的位置

```
[游戏启动] → [选择器灵界面] → [经营阶段] → [战斗阶段] → [结算] → [经营阶段] ↻
                  ↑               ↑            ↑                          │
                  └───────────────┴────────────┴──────────────────────────┘
                                    设置按钮（全程可用）
```

- 游戏启动后**第一步**就是选择器灵
- 经营阶段、战斗阶段均可通过左下角"设置"按钮返回重新选择器灵

---

## 2. 界面描述

### 2.1 待机状态

- 全屏深色半透明遮罩，背后主场景隐约可见
- 正中弹出面板，包含以下元素（从上到下）：
  - 标题："选择器灵"
  - 副标题说明文字："选好后点击开始游戏，进入运营阶段"
  - 三张卡片左右并排，每张卡片内容：

    | 卡片 | 图标 | 名称 | 描述 |
    |------|------|------|------|
    | 飞剑器灵 | 书本 | 飞剑器灵 | 开局器灵偏向飞剑弹道 |
    | 金刚器灵 | 佛像 | 金刚器灵 | 开局器灵偏向高伤与硬度 |
    | 寒冰器灵 | 鼎 | 寒冰器灵 | 开局器灵偏向更快出手 |

  - **默认无选中**：三张卡片外观一致，无高亮
  - 底部"开始游戏"按钮**置灰不可点击**

### 2.2 操作状态

- 点击某张卡片 → 该卡片外框变为金色高亮，其余两张保持原样
- 底部"开始游戏"按钮从置灰变为可点击（正常颜色）
- 点击另一张卡片 → 高亮切换到新卡片，旧卡片恢复
- 再次点击已选中的卡片 → 无变化

### 2.3 完成后

- 点击"开始游戏"按钮 → 整个选择面板消失（含遮罩）
- 主场景完全显示
- 器灵图标切换为所选类型（书/佛/鼎）
- 屏幕右上角出现 HUD（灵气=0，器灵等级=1）
- 屏幕右下角出现"开战"按钮
- 屏幕左下角出现"设置"按钮（齿轮图标或文字）

---

## 3. 交互方式

| 操作 | 反馈 |
|------|------|
| 点击未选中的卡片 | 该卡片金色高亮，"开始游戏"按钮激活 |
| 点击已选中的卡片 | 无变化 |
| 点击"开始游戏"（未选中） | 不可点击 |
| 点击"开始游戏"（已选中） | 关闭面板，进入经营阶段 |

---

## 4. 设置按钮（返回重选）

### 4.1 位置与外观

- 左下角
- 样式：小按钮，文字"设置"
- 经营阶段和战斗阶段均显示

### 4.2 点击行为

- 点击 → 游戏立即回到初始状态，重新显示选择器灵界面（无二次确认）

### 4.3 重置范围

- 灵气归零
- 山峰修复状态全部重置（所有山峰回到未修复）
- 器灵等级/经验归零
- 等同于重新开始游戏

---

## 5. 与其他功能的衔接规则

| 规则 | 说明 |
|------|------|
| 进入时机 | 游戏启动后直接进入，无其他入口进入此界面 |
| 退出时机 | 点击"开始游戏"后退出，进入经营阶段 |
| 设置按钮返回 | 经营和战斗阶段均可随时通过设置按钮返回，会重置全部进度 |
| 互斥 | 选择器灵期间，主场景不可操作 |

## 6. 模块边界草图

```
涉及的系统：
  ☑ UI 系统 — MainPeakSelectPanel 面板（scripts/ui/main_peak_select_panel.gd）
  ☑ GameManager — 状态管理、信号转发、场景重置
  ☑ SettingsButton — 设置按钮（scripts/ui/settings_button.gd）

可能需要新增：
  （无——所有模块已存在）

明确不涉及：
  - 山峰系统 — 选择器灵时山峰尚未加载
  - 敌人/波次/卡牌/功法 — 战斗阶段系统，选择器灵阶段不涉及
```

## 7. 数据流向草图

```
peak_config.csv（6 座山峰的 icon_path + entry_form_id）
      ↓
  DataManager.peak_database
      ↓
  MainPeakSelectPanel 读取 → 构建三张卡片 UI
      ↓
  玩家点击卡片 → _update_selection(profile_id)
      ↓
  玩家点击"开始游戏" → start_game_requested 信号
      ↓
  GameManager 接收 → 设置器灵图标 → 进入经营阶段
```

## 8. 什么不算在这个功能里

```
本功能不包括：
  1. 功法选择和详细配置 — 那是山峰修复后的流程
  2. 神器的差异化经营特性 — post-MVP，当前版本只做入门功法预选
  3. 从存档恢复 — 无存档系统

后续版本考虑：
  1. 4 神器的独特经营加成（诛仙剑·以战养战 / 神农鼎·灵植加速等）
  2. 新手指引 / 跳过选择的默认配置
```

## 9. 验收标准

1. 启动游戏 → 三张器灵卡片均未选中，"开始游戏"按钮置灰
2. 点击飞剑器灵卡片 → 该卡片金色高亮，"开始游戏"按钮变为可点击
3. 依次点击三张不同卡片 → 高亮跟随切换，始终只有一张高亮
4. 高亮飞剑器灵后点击"开始游戏" → 面板消失，器灵图标变为书本样式
5. 经营阶段左下角出现设置按钮
6. 经营阶段点击设置按钮 → 回到选择器灵待机状态，进度全部重置
7. 战斗阶段点击设置按钮 → 回到选择器灵待机状态，进度全部重置
