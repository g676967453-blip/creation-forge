# 功能规划：点击器灵获得灵气

> **状态：[已完成] | 验证日期：2026-07-09**

---

## 1. 功能在整体流程中的位置

灵气获取是经营阶段的核心资源产出，支撑后续修复山峰、升级功法等所有经营操作。

```
[进入经营阶段] → [自动产出灵气（持续）] + [手动点击器灵（可选）] → [累积灵气] → [用于修复/升级/开战]
```

- 灵气只在**经营阶段**产出，战斗中不产出
- 自动产出和手动点击**并行存在**，互不干扰

---

## 2. 灵气产出规则

### 2.1 自动产出

| 项目 | 数值 |
|------|------|
| 产出间隔 | 每 0.2 秒 |
| 每次产出量 | +5 |
| 生效阶段 | 仅经营阶段（PREPARATION） |
| 器灵等级影响 | 当前版本不影响 |
| 后续扩展 | 产出速度将与灵脉、聚灵法阵挂钩（非器灵等级） |

### 2.2 手动点击

| 项目 | 数值 |
|------|------|
| 每次点击 | +10 |
| 生效阶段 | 仅经营阶段（PREPARATION） |
| 冷却 | 无冷却，每次点击立即生效 |

---

## 3. UI 表现

### 3.1 HUD 灵气数字

- 位置：屏幕右上角 HUD 栏
- 显示格式："灵气：{数值}"
- 更新频率：实时（数值变化立即刷新）
- 自动产出时数字平滑增长，点击时数字跳动

### 3.2 自动产出浮字

- 显示频率：每 1 秒合并显示一次（内部每 0.2 秒 +5，5 次合并 = "+25"）
- 显示位置：器灵上方
- 动画：淡金色 "+25" 文字从器灵位置向上飘出，0.6 秒后消失
- 样式：与手动点击的 "+10" 浮字一致，颜色可稍作区分（淡金 vs 亮金）

### 3.3 手动点击浮字

- 显示频率：每次点击显示一次 "+10"
- 显示位置：点击位置
- 动画：亮金色 "+10" 向上飘出，0.6 秒后消失
- 与自动浮字互不覆盖，各自独立显示

---

## 4. 交互方式

| 操作 | 反馈 |
|------|------|
| 经营阶段鼠标左键点击器灵 | 灵气 +10，HUD 数字刷新，点击位置飘 "+10" 浮字 |
| 经营阶段自动计时到达 | 灵气 +5，HUD 数字刷新，每秒合并飘 "+25" 浮字 |
| 战斗阶段点击器灵 | 无反应（不处于经营阶段） |
| 战斗阶段自动计时 | 暂停（不产出灵气） |

---

## 5. 与其他功能的衔接规则

| 规则 | 说明 |
|------|------|
| 灵气作为消耗资源 | 修复山峰消耗 20，升级功法消耗 30，从 GameManager.spirit 扣除 |
| 灵气无上限 | MVP 阶段不设上限 |
| 灵气不跨局保留 | 设置按钮重置或结算后灵气归零 |
| 战斗阶段无产出 | 进入战斗 → 自动产出停止，点击无效；返回经营 → 恢复产出 |

---

## 6. 开发约束

- 浮字使用 `.tscn` 模板场景，不可纯代码创建节点。用户需能在 Godot 编辑器中打开并编辑字体、颜色、大小、动画参数。
- 本次不重构已有 HUD（BattleHUD 仍是代码生成），后续功能中逐步迁移。

## 7. 模块边界草图

```
涉及的系统：
  ☑ GameManager — 灵气值管理、计时器、浮字生成
  ☑ MainPeak/main_peak.gd — 点击检测、input_event 处理
  ☑ UI 系统 — HUD 灵气显示、FloatingText 浮字
  ☑ 数据层 — 自动产出参数（当前硬编码，后续可迁入 CSV）

可能需要新增：
  （无——所有模块已存在）

明确不涉及：
  - 山峰系统 — 点击器灵不触发山峰交互
  - 卡牌/功法/波次 — 战斗阶段系统
```

## 8. 数据流向草图

```
硬编码参数（wait_time=0.2s, +5/tick）
      ↓
  GameManager._auto_spirit_timer → _on_auto_spirit_tick()
      ↓
  spirit 值累加 → spirit_changed 信号
      ↓
  BattleHUD.update_spirit() ← 实时刷新
      ↓
  _auto_display_timer（1s）→ 合并显示浮字 "+25"
```

## 9. 什么不算在这个功能里

```
本功能不包括：
  1. 灵气消耗逻辑 — 那是山峰修复/功法选择的功能
  2. 灵气上限/溢出处理 — MVP 不设上限
  3. 灵气产出速率与器灵等级挂钩 — 后续版本

后续版本考虑：
  1. 灵脉等级影响产出速率
  2. 聚灵法阵加成
  3. 点击连击/暴击灵气
```

## 10. 验收标准

1. 进入经营阶段 → HUD 灵气数字从 0 开始，每秒自动增加 25（每 0.2 秒 +5 累计）
2. 经营阶段点击器灵 → 灵气立即 +10，点击位置飘出亮金色 "+10" 浮字并消失
3. 自动产出浮字每秒出现一次，显示 "+25"，从器灵上方飘出
4. 连续快速点击器灵 → 每次点击都 +10，浮字独立出现不互相覆盖
5. 灵气累积后 HUD 数字持续增长，用于修复山峰时可正常扣除
6. 点击"开战"进入战斗 → 自动产出停止，灵气数字不再增长
7. 战斗结束返回经营 → 自动产出恢复
