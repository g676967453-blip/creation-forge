# 需求文档：投射物系统

> **状态：[已实现] | 验证日期：2026-07-09**

> 器灵和功法发射的弹道投射物——从器灵位置飞向敌人，碰撞后造成伤害并触发功法效果。
> 数据来源：`form_config.csv`（projectile_count/projectile_color/projectile_shape）+ 代码层 projectile.gd。

---

## 1. 功能概述

**一句话**：器灵发射的弹道单位，沿直线飞行，命中敌人后造成伤害。

**详细描述**：战斗阶段中，器灵按 attack_interval 周期性发射投射物。投射物从器灵位置出发、朝目标敌人方向飞行，最大飞行距离 1800px。命中敌人时造成伤害并触发功法特殊效果（灼烧叠加/魂印标记）。穿透次数 > 0 时可穿透敌人继续飞行。飞行超距或穿透耗尽后自动销毁。投射物形状和颜色由功法配置决定（剑形/拳形/六边形/圆形）。

## 3. 触发条件与状态约束

| 维度 | 说明 |
|------|------|
| 触发方式 | 自动——MainPeak._physics_process() 中 attack_timer 归零时发射 |
| 发射条件 | GameState.BATTLE + main_peak.set_battle_active(true) + 攻击范围内有敌人 |
| 互斥状态 | PREPARATION / CARD_SELECTION / GAME_OVER 下不发射 |
| 可重复性 | 每个 attack_interval 发射一轮（projectile_count 发） |

## 4. 数据定义

### 4.1 Projectile 类属性（projectile.gd）

| 属性 | 类型 | 默认值 | 来源 | 说明 |
|------|------|--------|------|------|
| damage | float | 0.0 | MainPeak 设置（功法/card 加成后） | 命中伤害 |
| speed | float | 500.0 | main_peak_config.projectile_speed（520） | 飞行速度 px/s |
| direction | Vector2 | RIGHT | set_target() 计算 | 飞行方向 |
| pierce_count | int | 0 | 功法/card 的 pierce 参数 | 剩余穿透次数 |
| knockback_force | float | 0.0 | 功法设置 | 击退力度 |
| from_peak | Node2D | null | MainPeak 设置 | 发射者引用 |
| projectile_color | Color | Color(1,0.9,0.3,0.95) | form_config.projectile_color | 显示颜色 |
| projectile_shape | String | "circle" | form_config.projectile_shape | 形状（sword/fist/crystal/circle） |
| _max_distance | float | 1800.0 | 硬编码常量 | 最大飞行距离 |
| _travelled | float | 0.0 | 运行时累积 | 已飞行距离 |

### 4.2 涉及现有 CSV

| CSV 文件 | 相关列 | 用途 |
|----------|--------|------|
| `form_config.csv` | projectile_count, projectile_color_r/g/b, projectile_shape, damage, special_mechanic | 各功法的投射物属性 |
| `main_peak_config.csv` | projectile_speed | 全局投射物速度 |

### 4.3 是否需要新 CSV？

```
☑ 不需要——投射物无独立配置，所有参数来自 form_config 和 main_peak_config
```

### 4.4 是否需要新 Resource 类？

```
☑ 不需要——Projectile 已有 class_name，属性通过代码设置而非 Resource 加载
```

## 5. 信号契约

```
投射物使用 Godot 内置信号（非自定义信号）：

area_entered / body_entered
  连接：projectile._ready() 中 connect
  触发：投射物 Area2D 与其他 Area2D（enemies 组）或 PhysicsBody2D 重叠
  处理：_hit(target) — 伤害 + 功法效果 + 穿透判断
```

## 6. 逻辑流程

```
主流程：
  1. MainPeak._fire_projectile() 被调用
  2. 创建 Projectile 实例，设置属性:
     - damage = 当前攻击力（功法伤害 × card 倍率 × combo 倍率）
     - speed = main_peak_config.projectile_speed
     - pierce_count = channel 中的 pierce 参数
     - projectile_color = form_config.projectile_color
     - projectile_shape = form_config.projectile_shape
  3. set_target(enemy.global_position) → 计算 direction
  4. 投射物加入 battlefield，开始 _physics_process
  5. 每帧: position += direction * speed * delta
  6. _travelled 累加，超过 _max_distance → queue_free()
  7. 碰撞检测 → area_entered/body_entered → _hit(target)

_hit(target) 处理：
  1. 检查 target 是否已在 _hit_targets（防重复命中）
  2. target 加入 _hit_targets
  3. target.take_damage(damage)
  4. _apply_form_effects(target):
     - burn: target.apply_burn_stack(dmg_per_stack, duration, max_stacks)
     - soul_mark: target.apply_soul_mark(1)
  5. knockback_force > 0 → target.apply_knockback(force, position)
  6. pierce_count > 0 → pierce_count -= 1（继续飞行）
  7. pierce_count == 0 → queue_free()

分支：
  - 投射物飞行中目标死亡 → 继续飞行（不会因目标消失而销毁）
  - 多投射物命中同一敌人 → _hit_targets 防止重复命中（首个命中的投射物生效）

异常：
  - from_peak 为 null → _apply_form_effects 中 get_meta 返回空，跳过效果
```

| 形状 | 绘制方式 | 对应功法 |

## 8. 边界条件与互斥

```
☑ 投射物会飞出 battlefield 吗？会，但 1800px 后自动销毁
☑ 投射物能命中多个敌人吗？pierce_count > 0 时可以穿透，每穿透一个减 1
☑ 同一敌人被多投射物命中？_hit_targets 数组防重复，每发投射物只命中同一敌人一次
☑ 投射物之间会碰撞吗？不会，投射物 collision_mask 仅包含 enemies
☑ 快速连续发射的性能？每轮最多 6 发（御剑诀），场上同时存在 ≤ ~30 发，性能可忽略
☑ 投射物方向在飞行中会改变吗？不会，发射时 set_target 一次计算 direction，之后直线飞行
```

## 11. 验收标准

1. 器灵装备御剑诀，战斗开始 → 每 1.0s 发射 6 发剑形投射物（菱形，青色）
2. 投射物命中敌人 → 敌人 HP 减少（伤害=功法 damage × 倍率）
3. 投射物飞行超过 1800px → 自动消失
4. 器灵装备金刚咒 → 扇形攻击（非投射物，走 sector_effect.gd），不发射投射物
5. 器灵装备离火诀 → 圆形投射物，命中后叠加灼烧效果
6. 器灵装备炼魂诀 → 圆形投射物，命中后施加魂印标记
7. card 增加穿透 → 投射物可穿透一个敌人后继续飞行
8. 投射物未命中任何敌人 → 飞行 1800px 后消失（不崩溃）
