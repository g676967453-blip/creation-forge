## 子阶段 2：交互设计

### 界面 1：开场黑幕

#### 状态定义

| 状态 | 描述 |
|------|------|
| **初始态** | 纯黑屏幕，无文字，等 0.3s 后第一段淡入 |
| **播放态** | 当前段文字淡入 → 停留 → 淡出，4s 一个周期 |
| **快进态** | 当前段立即结束，下一段开始（点击/按键触发） |
| **结束态** | 最后段淡出 → 0.5s 黑屏 → 器灵选择界面出现 |

各状态下元素可见性：

| 元素 | 初始态 | 播放态 | 快进态 | 结束态 |
|------|--------|--------|--------|--------|
| 黑色背景 | ✅ | ✅ | ✅ | ✅ → 消失 |
| 叙事文字 | ❌ | ✅（当前段） | 瞬间切换 | ❌ |
| 任何按钮/UI | ❌ | ❌ | ❌ | ❌ |

#### 交互流程

```
用户不操作：
  初始态(0.3s) → 段1 淡入(1s) → 停留(2s) → 淡出(1s)
  → 段2 淡入(1s) → 停留(2s) → 淡出(1s)
  → 段3 淡入(1s) → 停留(2s) → 淡出(1s)
  → 段4 淡入(1s) → 停留(2s) → 淡出(1s)
  → 0.5s 黑屏 → 器灵选择

用户点击/按键（段1-3）：
  当前段淡出立即结束 → 下一段开始（同 auto_play 周期）

用户点击/按键（段4）：
  直接跳到结束态 → 器灵选择
```

#### 信息架构

- 文字内容：硬编码 4 段字符串（见需求文档 §4）
- 无外部数据源
- 首次进入判断：GameManager 内存状态

#### 异常分支

| 异常 | 处理 |
|------|------|
| 音频加载失败 | 跳过音频，文字正常播放 |
| 连点保护 | 每次点击只跳一段（0.3s 冷却） |
| 非首次进入 | 完全跳过 INTRO |

## 子阶段 3：视觉设计

### 界面 1：开场黑幕

#### 风格对齐

遵循 GAME-002 既有视觉体系（暗色修仙题材）：
- 无 UI 控件，纯叙事播放
- 最大化沉浸感，视觉噪音为零

#### 视觉方向

| 属性 | 值 |
|------|-----|
| 基调 | 极简、沉静、仪式感 |
| 背景 | `#000000`（纯黑） |
| 文字颜色 | `#FFFFFF`（纯白），无透明度 |
| 字体 | 阿里巴巴普惠体 3.0 Regular，20px |
| 行高 | 28px |
| 对齐 | 水平居中 + 垂直居中 |
| 文字区域宽度 | 840px（限制行长，提高可读性） |
| 淡入效果 | opacity 0 → 1，Tween 1s，EASE_IN_OUT |
| 淡出效果 | opacity 1 → 0，Tween 1s，EASE_IN_OUT |

#### 布局描述

```
┌──────────────────────────────────┐
│                                  │
│          (纯黑背景)               │
│                                  │
│       ┌─────────────────┐        │
│       │                 │        │
│       │   叙事文字       │        │
│       │   840px 宽      │        │
│       │   居中对齐      │        │
│       │                 │        │
│       └─────────────────┘        │
│                                  │
└──────────────────────────────────┘
         1280 × 720 (Godot 目标分辨率)
```

> 不需要 Pixso 设计——纯黑底白字，无视觉元素需要排版。

#### 字体与排版

| 层级 | 字号 | 颜色 | 用途 |
|------|------|------|------|
| 叙事正文 | 20px | `#FFFFFF` | 4 段世界观文字 |

| 类型 | 资产 | 大致规格 | 优先级 |

---

## 约束与规则

- **单界面**：不拆分、不嵌套、不弹窗
- **纯代码渲染**：无图片资产（P1 音频除外）
- **不阻塞**：音频缺失时主流程正常运行
- **连点保护**：0.3s 冷却，防止误触跳过全部
