# 器灵选择 — 功能简报

---

## 1. 一句话 + 流程位置

**一句话**：玩家在开场黑幕结束后，选择百世书器灵并确认，永久绑定后进入经营阶段。

**流程位置**：
```
[开场黑幕 INTRO] → [器灵选择 MAIN_PEAK_SELECT] → [经营阶段 PREPARATION]
                          ↑
                    仅首次进入（有存档则跳过）
```

---

## 2. 界面与交互

### 界面元素
- 纯黑背景 + 居中深色面板（720×480）
- 标题"选择器灵"（28px 白色）
- 提示文字"选好后点击开始游戏，进入运营阶段"（14px 灰色）
- 百世书卡片（240×320，金色边框，含图标+名称"百世书"+描述）
- 左右各一个锁定占位卡片（V0.1 不做，仅百世书居中）
- 「开始游戏」按钮（200×48，默认置灰不可点击）

### 操作 → 反馈

| 操作 | 反馈 |
|------|------|
| 点击百世书卡片 | 卡片高亮（金色光晕），开始按钮变亮可点击 |
| 再次点击已选中卡片 | 取消高亮，按钮置灰 |
| 点击「开始游戏」（无选中） | 无响应（按钮已置灰拦截） |
| 点击「开始游戏」（已选中） | 面板淡出 → 进入经营，器灵图标显示百世书 |

### 状态

| 状态 | 表现 |
|------|------|
| 默认态 | 百世书卡片居中，无高亮，开始按钮置灰 |
| 选中态 | 百世书卡片金色光晕 + modulate 暖色调，开始按钮亮色可点击 |
| 完成态 | 面板淡出 1s，切换到 PREPARATION 状态 |

## 3. 不在范围内的

```
本功能不包括：
  1. 诛仙剑/神农鼎器灵 — V0.3 实装（V0.1 连灰显占位都不做）
  2. 多器灵解锁系统 — V0.3
  3. 经营阶段器灵 HP 条 — 属经营器灵展示子功能
  4. 器灵成长/形态切换 — SpiritGrowthManager 负责

后续版本考虑（但本版本不做）：
  1. 卡片选中预览动画（器灵演示小动效）
```

## 4. 涉及的数据

**涉及 CSV**：

| 文件 | 操作 | 说明 |
|------|------|------|
| `data/spirit_profile_config.csv` | 读 | 当前仅 1 行：spirit_book/百世书。字段：profile_id, profile_name, desc, icon_path, special_ability |

**数据流**：
```
spirit_profile_config.csv
      ↓ DataManager.get_all_spirit_profiles()
MainPeakSelectPanel._build_ui() → 渲染卡片
      ↓ 玩家选择 → _update_selection(profile_id)
      ↓ 点击开始 → start_game_requested 信号
GameManager._on_start_game_requested()
      ↓ DataManager.get_spirit_profile(id) → profile
      ↓ main_peak.set_form(profile.icon_path)
      ↓ main_peak.set_meta("spirit_profile", profile_id)
UIStateCoordinator.set_state(PREPARATION)
```

---

## 5. 验收标准

1. 开场黑幕结束 → 看到器灵选择面板，百世书卡片居中，「开始游戏」置灰
2. 点击百世书卡片 → 卡片高亮（金色光晕），「开始游戏」变亮
3. 再次点击百世书 → 高亮取消，「开始游戏」恢复置灰
4. 选中百世书后点击「开始游戏」→ 面板消失，进入经营，器灵图标显示百世书
5. 无选中状态点击「开始游戏」→ 无响应（不崩溃）
6. 器灵绑定后无法返回选择界面
