# 器灵选择 — 功能需求

> 状态：[需求完成] | 验证日期：2026-07-27 | 基准：[器灵选择-功能规划](2026-07-27-器灵选择-功能规划.md)

---

## 1. 功能概述

**一句话**：玩家首次启动后，在器灵选择面板中选择百世书器灵，确认后永久绑定，进入经营阶段。

**详细描述**：开场黑幕播放完毕后，进入器灵选择界面。V0.1 仅百世书可选，居中单卡片展示。玩家点击卡片选中（金色光晕），点击「开始游戏」确认，面板淡出过渡，器灵图标飞入画面底部器灵位置，永久绑定。

---

## 2. 模块影响分析

```
触及的现有模块：
  1. MainPeakSelectPanel (main_peak_select_panel.gd) — 选择界面改造（单卡片+视觉对齐）
  2. GameManager (game_manager.gd) — 接收 start_game_requested 信号，绑定器灵
  3. UIStateCoordinator (ui_state_coordinator.gd) — MAIN_PEAK_SELECT 状态管理
  4. MainPeak (main_peak.gd) — set_form() 设置器灵图标

需要新建的模块：
  （无——选择阶段不涉及新模块）

不需要动的模块：
  - SpiritGrowthManager — 经营阶段才触发
  - MountainManager / WaveManager / CardManager — 无关
  - EconomyManager — 经营阶段才启动
```

---

## 3. 触发条件与状态约束

| 维度 | 说明 |
|------|------|
| 触发方式 | GameManager 在 intro_finished 信号后切换到 MAIN_PEAK_SELECT 状态 |
| 前置游戏状态 | INTRO → MAIN_PEAK_SELECT |
| 互斥状态 | 选择阶段 BattleHUD/BattleStartButton 均隐藏 |
| 可重复性 | 器灵选择仅一次，选后不再返回 |

## 4. 程序需求

### 4.1 选择面板（默认态）

- 深色背景 + 居中 PanelContainer（720×480）
- 标题"选择器灵" 24px 金色居中
- 提示文字"选好后点击开始游戏，进入运营阶段。" 13px
- HBoxContainer 卡片行，从 DataManager 加载器灵档案
- 每张卡片 PanelContainer（190×190）：图标 TextureRect + 名称 Label + 描述 Label + "选择" Button
- 「开始游戏」按钮初始 disabled

### 4.2 选中态

- 点击"选择"按钮 → `_update_selection(profile_id)`
- 选中卡片 modulate 调为 `Color(1.0, 0.96, 0.78)`（暖金色）
- 未选中卡片 modulate 保持 `Color(1.0, 1.0, 1.0)`
- 「开始游戏」按钮 enabled（非空 profile_id 时）

### 4.3 空选中/取消

- `_selected_profile_id` 初始为空字符串 `""`
- 点击已选中卡片的"选择"按钮 → 切换回空选中 → 所有卡片恢复白色 + 按钮 disabled

### 4.4 确认与过渡

- 点击「开始游戏」→ 检查 `_selected_profile_id` 非空
- 发射 `start_game_requested(profile_id)` 信号
- GameManager 接收 → 读 spirit_profile_config.csv → `main_peak.set_form(icon_path)`
- 切换到 PREPARATION 状态

### 4.5 防御式保护

- `_on_start_pressed()` 开头检查 `_selected_profile_id.is_empty()` → 空则 return
- `_on_start_game_requested()` 中 `DataManager.get_spirit_profile()` 返回 null → 则 return

## 6. 信号契约

```
start_game_requested(profile_id: String)
  发射者：MainPeakSelectPanel
  接收者：GameManager._on_start_game_requested()
  时机：玩家选中卡片后点击「开始游戏」
  参数：profile_id — 选中的器灵档案 ID（如 "spirit_book"）
  保护：profile_id 为空时面板层已拦截；GameManager 层再次检查 null
```

## 7. 数据定义

### 涉及 CSV

| CSV | 操作 | 说明 |
|-----|------|------|
| `spirit_profile_config.csv` | 读 | 当前仅 1 行：spirit_book / 百世书 |

### DataManager 接口

| 方法 | 用途 | 调用位置 |
|------|------|---------|
| `get_all_spirit_profiles()` | 获取全部器灵档案列表 | MainPeakSelectPanel._build_ui() |
| `get_spirit_profile(id)` | 按 ID 获取单个档案 | GameManager._on_start_game_requested() |

## 8. 逻辑流程

```
1. 开场黑幕结束 → intro_finished 信号
2. GameManager._on_intro_finished() → UIStateCoordinator.set_state(MAIN_PEAK_SELECT)
3. UIStateCoordinator:
   - intro_screen.visible = false
   - main_peak_select_panel.visible = true
   - main_peak.visible = false（选择阶段不显示器灵）
4. MainPeakSelectPanel._build_ui():
   - 从 DataManager.get_all_spirit_profiles() 加载器灵列表
   - 渲染卡片行 + 开始按钮（初始禁用）
5. 玩家点击卡片 → _update_selection(profile_id) → 高亮 + 按钮启用
6. 玩家点击「开始游戏」→ _on_start_pressed()
   - 空选中检查 → 通过
   - 发射 start_game_requested("spirit_book")
7. GameManager._on_start_game_requested("spirit_book"):
   - DataManager.get_spirit_profile("spirit_book") → profile
   - main_peak.set_form(profile.icon_path) → 加载图标
   - main_peak.set_meta("spirit_profile", "spirit_book")
   - UIStateCoordinator.set_state(PREPARATION)
8. UIStateCoordinator:
   - main_peak_select_panel.visible = false
   - main_peak.visible = true（器灵出现）
   - battle_hud.visible = true
   - economy_manager.set_active(true)
```

---

## 9. 边界条件

```
□ 快速连续点击卡片？→ _update_selection 幂等，重复设置同一值无副作用
□ 空选中点开始？→ _on_start_pressed 中 is_empty() 检查，直接 return
□ 无器灵档案？→ CSV 至少有一行；若 DataManager 返回空，面板无卡片显示
□ 图标路径失效？→ main_peak.set_form() 中 load() 返回 null，静默不显示
□ ESC 在选择阶段？→ game_manager._input() 在 INTRO 阶段拦截，MAIN_PEAK_SELECT 时走 restart_game()
□ 选完后能否返回？→ 不能，流程单向
```
