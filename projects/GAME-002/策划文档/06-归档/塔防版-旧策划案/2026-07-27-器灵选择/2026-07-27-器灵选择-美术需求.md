## 2. 交互需求摘要

| 状态 | 表现 | 操作 |
|------|------|------|
| 默认态 | 百世书卡片居中，无选中，开始按钮置灰 | 点击卡片 |
| 选中态 | 卡片金色光晕，开始按钮亮色 | 点击开始 / 再次点击卡片取消 |
| 确认过渡 | 面板淡出 1s，卡片飞入器灵位置 | —（自动播放） |

---

## 3. 视觉方向

| 维度 | 规范 |
|------|------|
| **基调** | 神秘庄重 — 深色云海衬托金色卡片的仪式感 |
| **主色调** | 底色 `#0a0a14`→`#1a1a2e`→`#16213e` 渐变，金色 `#f0c040` |
| **辅助色** | 暗紫 `#1a1a2e`，灰蓝 `#8888aa`（提示），灰紫 `#555577`（锁定占位） |
| **卡片** | 240×320，金色边框 2px `#f0c040`，圆角 8px，底 `rgba(240,192,64,0.18)`→暗紫 |
| **按钮** | 200×48，金色渐变 `#f0c040`→`#c09030`，圆角 6px，深色文字 |
| **字体** | 阿里巴巴普惠体 55R，标题 32px，名称 20px，正文 14px |
| **参考** | [HTML 原型](2026-07-27-器灵选择-HTML原型.html) — 完整 CSS 视觉稿 |

## 5. 引擎实现差异

| 需求项 | 状态 | 差异说明 |
|--------|------|---------|
| 背景 | ⚠️ | 当前用代码纯色，缺云海纹理（A1） |
| 标题字号/颜色 | ⚠️ | 当前 24px + 淡金，设计是 32px + `#f0c040` |
| 卡片尺寸/边框色 | ⚠️ | 当前 190×190 + 紫色边框，设计是 240×320 + 金色边框 |
| 百世书图标 | ⚠️ | 当前用 `主殿-书.png` 临时占位，非像素艺术风格 |
| 卡片高亮光晕 | ❌ | V1 未实现，当前仅 modulate 调色 |
| 按钮 4 态 | ⚠️ | 仅默认/禁用两态，缺悬浮/按下态和金色渐变 |
| 面板淡出过渡 | ❌ | V2 未实现，当前直接切换状态 |
| 卡片飞入动画 | ❌ | V2 未实现 |
| 默认无选中+按钮禁用 | ✅ | 已实现 |
| 空选中保护 | ✅ | 已实现 |
| 信号链 | ✅ | 已实现 |
