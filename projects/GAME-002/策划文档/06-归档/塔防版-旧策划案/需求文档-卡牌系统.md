# 需求文档：卡牌系统

> **状态：[已实现] | 验证日期：2026-07-09**

> 战斗中升级时弹出三选一卡牌面板——核心 roguelike 成长机制。29 张卡牌，含通用卡 + 功法专属卡，稀有度分层，可堆叠。
> 数据来源：`card_config.csv` + `card_manager.gd` + Channel Dictionary。

---

## 1. 功能概述

**一句话**：器灵升级时暂停战斗，弹出三选一卡牌面板，玩家选择后获得永久增益。

**详细描述**：战斗中击杀敌人积累经验，经验满后 GameManager 触发升级。战斗暂停（`get_tree().paused = true`），CardManager 从卡牌池中按已激活功法过滤、抽取 3 张可选卡牌。每张卡显示名称、描述、稀有度标签。玩家选择后 CardManager 应用效果到对应功法的攻击通道，通用卡作用于全部已激活功法。卡牌效果持续到本轮游戏结束。

```
触及的现有模块：
  1. CardManager/card_manager.gd — 卡牌池管理、抽卡、应用效果

  5. GameManager/game_manager.gd — _trigger_battle_upgrade() 触发升级
  6. DataManager/data_manager.gd — _load_cards() 加载卡牌池

需要新建的模块：
  （无）

不需要动的模块：
  - WaveManager — 卡牌不影响波次
  - MountainManager — 卡牌不在经营阶段使用
```

## 3. 触发条件与状态约束

| 维度 | 说明 |
|------|------|
| 触发方式 | 自动——GameManager 检测经验值达到升级阈值 |
| 触发条件 | GameState.BATTLE + 经验值 >= 升级阈值 |
| 前置游戏状态 | BATTLE |
| 互斥状态 | CARD_SELECTION 中不可再次触发升级 |
| 可重复性 | 每轮战斗可多次升级（无上限） |
| 暂停行为 | 升级弹窗期间 `get_tree().paused = true`（物理/计时器暂停） |

## 6. 逻辑流程

```
升级触发：
  1. GameManager 检测经验值 >= 升级阈值
  2. GameManager._trigger_battle_upgrade():
     a. 状态切换为 CARD_SELECTION
     b. 获取 active_form_ids
     c. CardManager.draw_three_cards(active_form_ids)
     d. CardSelectionPanel.show_cards(result)
     e. get_tree().paused = true

抽卡算法（draw_three_cards）：
  1. 从 card_pool 中排除 used_cards
  2. 保留 form_id == "通用" 或 form_id in active_form_ids 的卡
  3. 如果 available < 3 → 重置 used_cards（所有卡重新可用）
  4. 优先保证至少 1 张为第一个激活功法的专属卡
  5. shuffle → 取前 3 张

应用效果（apply_card）：
  1. 卡牌加入 used_cards
  2. 如果 form_id == "通用":
     → 对所有 active_form_ids 调用 MainPeak.apply_upgrade(form_id, effect_type, effect_value)
  3. 否则:
     → MainPeak.apply_upgrade(card.form_id, effect_type, effect_value)
  4. MainPeak.apply_upgrade() 中 match effect_type 更新对应 channel 字段
  5. get_tree().paused = false
  6. 状态恢复为 BATTLE

分支：
  - 卡牌池耗尽（所有 card 都在 used_cards 中且 available < 3）→ 重置 used_cards
  - stackable=0 的卡牌出现一次后不再出现（除非 card_pool 整体重置）
```

## 7. UI 表现

| 状态 | 表现 |
|------|------|
| 升级触发 | 屏幕居中弹出三张卡牌，背景半透明遮罩 |
| 普通卡 | 无特殊标签，显示 card_name + description |
| 稀有卡 | 显示"稀有"标签，视觉突出（如金色边框） |
| 悬停态 | 卡牌放大或高亮 |
| 选中态 | 卡牌点击 → 短暂高亮 → 面板消失 → 战斗继续 |
| 面板关闭 | 卡牌面板 hide() + paused = false |

## 8. 边界条件与互斥

```
☑ 0 个功法激活时升级？→ active_form_ids 为空，仅 4 张通用卡可选
☑ 同一卡牌多次选中？→ stackable=1 可叠加，stackable=0 仅出现一次
☑ 卡牌池全部用完？→ used_cards 重置，所有卡重新可用
☑ 升级期间敌人移动？→ paused=true，所有物理/计时器暂停
☑ 连续快速升级？→ 状态检查 CARD_SELECTION 防止重叠触发
☑ effect_type 未匹配？→ apply_upgrade 中 match 无 default 分支，静默跳过
```

## 11. 验收标准

1. 首次升级 → 弹出三选一卡牌面板，3 张卡各不相同
2. 仅激活御剑诀 → 卡牌仅含 4 通用 + 4 御剑诀专属（通用卡可出现在任何功法组合中）
3. 选择"灵力灌注"（通用卡）→ 所有已激活功法的 damage_multiplier 各 +0.20
4. 选择"剑气叠加"（御剑诀专属）→ 仅御剑诀通道 combo_max 增加
5. 第 3 次升级 → 之前选过的普通卡可再次出现（stackable=1），稀有卡不重复出现（stackable=0）
6. 卡牌池耗尽 → available < 3 时自动重置，所有卡重新可用
7. 升级弹窗期间 → 敌人静止（paused=true）
8. 选卡后 → 弹窗消失，战斗恢复，效果立即生效
