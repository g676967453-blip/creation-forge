# 功能规划：战斗数值配表

> ⚠️ 本文档已归档。最新版本见 `../03-功能规格/战斗数值配表.md`

> **状态：[已完成] | 验证日期：2026-07-09**

---

## 1. 目标

把器灵基础数值、功法属性、卡牌效果从硬编码改为 `.tres` 资源文件，实现**手动配表**：

- 不需要改代码，在 Godot 引擎 Inspector 面板里直接改数值
- 每项数据一个 `.tres` 文件，双击打开即可编辑
- 新增功法/卡牌时，复制现有 `.tres` 改数值即可

---

## 2. 配表文件结构

```
data/
├── main_peak_config.csv         ← 器灵基础属性（单行）
├── form_config.csv              ← 功法配置（6行）
├── card_config.csv              ← 卡牌配置（29行）
├── enemy_config.csv             ← 敌人配置（4行）
└── wave_config.csv              ← 波次配置（10行，后续）
```

每个 CSV 用 Excel / WPS / Google Sheets 编辑，第一行是列名（字段名），后续行是数据。另存为 UTF-8 编码的 CSV 即可被 Godot 读取。

## 3. 配表内容

### 3.1 器灵基础属性（main_peak_config.csv）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| max_hp | float | 500 | 基础血量 |
| base_damage | float | 18 | 基础伤害（每发） |
| attack_interval | float | 0.85 | 攻击间隔（秒） |
| projectile_speed | float | 520 | 飞剑飞行速度 |
| split_count | int | 0 | 默认弹道分裂数 |
| pierce_count | int | 0 | 默认穿透次数 |
| damage_multiplier | float | 1.0 | 伤害倍率 |

CSV 格式（单行）：
```
max_hp,base_damage,attack_interval,projectile_speed,split_count,pierce_count,damage_multiplier
500,18,0.85,520,0,0,1.0
```

## 4. 如何编辑配表

1. 用 Excel / WPS / Google Sheets 打开 `data/form_config.csv`
2. 表格形式显示，每行一个功法，每列一个属性
3. 直接修改数值（如把御剑诀 damage 从 6 改成 10）
4. 文件 → 另存为 → CSV UTF-8 → 覆盖原文件
5. 下次运行游戏，新数值生效

新增功法只需在 CSV 末尾加一行，新增卡牌同理。

## 6. 模块边界草图

```
涉及的系统：
  ☑ 数据层 — CsvLoader + DataManager（autoload/）
  ☑ Resource 类 — FormConfig/MainPeakConfig/CardData/EnemyData/PeakConfig/WaveData（scripts/data/）
  ☑ 6 份 CSV — main_peak/form/card/enemy/wave/peak_config.csv
  ☑ MainPeak — 从 DataManager 读 FormConfig/MainPeakConfig
  ☑ CardManager — 从 DataManager 读 card_database
  ☑ WaveManager — 从 DataManager 读 wave_database
  ☑ MountainManager — 从 DataManager 读 peak_database

可能需要新增：
  （无——所有模块已存在）

明确不涉及：
  - UI 表现层 — 配表是纯数据，不涉及界面
  - 敌人 AI — 敌人使用 EnemyData 但配表不定义行为
```

## 7. 数据流向草图

```
策划用 Excel 编辑 CSV（UTF-8）
      ↓
  CsvLoader.load_csv(path) → Array[Dictionary]
      ↓
  DataManager._load_*() → 逐行创建 Resource 对象
      ↓
  存入 database（Dictionary/Array）
      ↓
  逻辑层通过 get_* API 读取:
  - DataManager.main_peak_config → MainPeak._ready()
  - DataManager.get_form_config(id) → MainPeak.set_attack_channels()
  - DataManager.get_enemy(id) → WaveManager 创建敌人
  - DataManager.get_card(id) → CardManager
  - DataManager.wave_database → WaveManager
  - DataManager.peak_database → MountainManager
```

## 8. 什么不算在这个功能里

```
本功能不包括：
  1. CSV 编辑界面 — 策划用 Excel 编辑，不做游戏内编辑器
  2. 数据热重载逻辑 — 依赖 Godot auto_reload addon
  3. 数据校验/范围检查 — 不做 CSV 数值合法性验证

后续版本考虑：
  1. 策划配表工具（Godot 内 Inspector 编辑 .tres 代替 CSV）
  2. 数据版本管理/回滚
```

## 9. 验收标准

1. 用 Excel 打开 `form_config.csv` → 能看到表格式数据并修改
2. 修改功法 damage 值 → 保存 CSV → 运行游戏 → 器灵伤害变化
3. 修改器灵 max_hp → 保存 CSV → 运行游戏 → 器灵血量变化
4. 修改卡牌 effect_value → 保存 CSV → 运行游戏 → 卡牌效果变化
5. CSV 末尾加一行新功法 → 运行游戏 → 新增功法可选
