# 功能规划：山峰修复与功法选择

> **状态：[已完成] | 验证日期：2026-07-09**

---

## 1. 功能在整体流程中的位置

```
[进入经营阶段] → [点击场景中山峰] → [弹出修复面板] → [修复] → [选择功法] → [山峰激活]
                                                                          ↓
                                                              [开战 → 器灵按功法攻击]
                                                                          ↓
                                                              [战斗升级 → 功法关联的三选一]
```

- 仅在经营阶段可操作
- 六座山峰均可修复，一座一座来（先修复 → 再升级选功法 → 完成后可点下一座）

---

## 2. 山峰点击与选中反馈

### 2.1 待机状态

- 六座山峰散布在器灵前方半圆区域
- 未修复的山峰：半透明（modulate.a = 0.45），灰暗状态
- 鼠标悬停在可点击的山峰上：光标变为手型

### 2.2 点击选中

- 点击某座山峰弹出修复面板（见第 3 节）
- 点击另一座山峰 → 光圈移到新山峰，旧山峰光圈消失，面板内容刷新
- 点击空白区域 → 不取消选中（保持当前选中状态）

### 2.3 修复完成后

- 山峰透明度提升（modulate.a = 0.9），表示已修复但未激活功法
- 金色光圈保持，面板切换为功法选择状态

### 2.4 功法选择完成后

- 山峰完全点亮（暖金色 modulate = 1.0, 0.96, 0.78），表示已激活
- 金色光圈可移除或变淡（表示该山峰已完成）

## 3. 修复面板

### 3.1 面板结构（从上到下）

弹出位置：屏幕中央偏右，不遮挡器灵

| 元素 | 说明 |
|------|------|
| 标题 | 山峰名称（如"金刚峰"） |
| 状态文字 | "未修复" / "已修复" |
| 修复按钮 | 文字"修复山峰（20 灵气）"，灵气不足时置灰 |
| 分隔线 | 修复后可看到下方功法选择区域 |
| 功法标题 | "选择功法"（修复后显示） |
| 功法选项 | 三张功法卡片，每张显示功法名、攻击类型、伤害数值 |
| 关闭按钮 | 关闭面板 |

### 3.2 面板状态切换

**状态 A：未修复**
- 显示山峰名称 + "未修复"
- "修复山峰（20 灵气）"按钮可点击（灵气够）或置灰（灵气不够）
- 功法选择区域隐藏

**状态 B：已修复、未选功法**
- 显示山峰名称 + "已修复"
- 修复按钮消失
- 功法选择区域显示，三张功法卡片可点击
- 灵气不足 30 时，功法卡片置灰

**状态 C：已选功法**
- 显示山峰名称 + "已激活"
- 功法选择区域显示，已选的功法卡片高亮，其余置灰
- 不可重复选择

## 4. 功法选择

### 4.1 六种功法

| 功法 | 攻击类型 | 伤害 | 攻速 | 弹道数 | 射程 | 特性 |
|------|---------|------|------|--------|------|------|
| 御剑诀 | 飞剑弹道 | 6 | 1.0s | 6 发 | 600 | combo 连击系统 |
| 金刚咒 | 扇形音波 | 18 | 1.2s | 1 发 | 180 | stun 眩晕（12% 概率，0.5s） |
| ~~离火诀~~ | ~~火球弹道~~ | ~~10~~ | ~~0.8s~~ | ~~4 发~~ | ~~550~~ | ~~burn 灼烧~~ 已删除 |
| 炼魂诀 | 魂火弹道 | 8 | 1.0s | 2 发 | 520 | soul_mark 魂印（削弱+引爆） |
| 灵狐契 | 灵兽召唤 | 8 | 0.9s | — | — | summon_beast（灵狐自动攻击） |
| 御器诀 | 法器召唤 | 10 | 0.9s | — | 80 | summon_artifact（法器环绕防御） |

### 4.2 功法卡片展示

每张功法卡片上显示：
- 功法名称（御剑诀 / 金刚咒 / ~~离火诀~~ / 炼魂诀 / 灵狐契 / 御器诀）
- 攻击类型图标或文字（弹道 / 扇形 / 召唤）
- 伤害数值（"伤害：6" / "伤害：18" / ...）
- 特性描述（"combo 连击" / "stun 眩晕" / "灼烧" / "魂印" / "灵兽" / "法器"）

### 4.3 选择功法

- 点击某张功法卡片 → 消耗 30 灵气 → 该功法激活
- 面板状态切换为 C（已激活）
- 器灵外观和攻击方式随之改变
- 进入战斗后，器灵按所选功法攻击

## 5. 功法与战斗的关联

### 5.1 进入战斗

- 开战时，器灵激活所有已选山峰的功法，构建多攻击通道
- 如有多个山峰已激活功法，器灵**并行使用所有已激活功法**（多通道攻击系统已实现）
- 每个通道独立计时、独立发射、独立伤害计算

### 5.2 战斗升级三选一

- 器灵在战斗中升级时，弹出三张强化卡牌
- 卡牌内容与当前激活的功法关联，从 29 张卡牌池中按 form_id 过滤抽取：
  - 御剑诀专属（4 张）：剑气叠加、剑意贯通、分光化影、以神御剑
  - 金刚咒专属（4 张）：狮子吼·广、震慑心魄、金刚定身、不坏金身
  - ~~离火诀专属（4 张）：烈火燎原、三昧真火、附骨之火、焚天灭地~~ 已删除
  - 炼魂诀专属（4 张）：魂印加深、魂爆增幅、噬魂反哺、双魂缠绕
  - 灵狐契专属（4 张）：灵兽狂暴、灵兽护体、灵兽归元、灵兽召唤
  - 御器诀专属（4 张）：法器强化、法器疾风、灵镜反伤、万器护主
  - 通用卡牌（4 张）：灵力灌注、疾风术、天眼通、护体真气

当前卡牌池共 28 张（含普通/稀有双稀有度），详见 card_config.csv。

## 6. 与其他功能的衔接

| 规则 | 说明 |
|------|------|
| 进入条件 | 经营阶段（PREPARATION），点击场景中山峰 |
| 退出条件 | 点关闭按钮或点另一座山峰 |
| 灵气消耗 | 修复 20 + 升级 30 = 共 50 灵气完成一座山峰 |
| 与开战的关系 | 至少修复并激活一座山峰后才能开战，"开战"按钮在此之前置灰 |
| 重置 | 设置按钮重置后，所有山峰回到未修复状态 |

## 8. 模块边界草图

```
涉及的系统：
  ☑ 山峰系统（MountainManager + peak_base.gd）— 点击检测、修复状态、光圈反馈
  ☑ UI 系统 — RepairPromptPanel 修复面板（scenes/ui/repair_prompt_panel.tscn）
  ☑ GameManager — 灵气扣除、状态管理、信号转发
  ☑ 数据层 — peak_config.csv（山峰属性）、form_config.csv（功法属性）

可能需要新增：
  （无——所有模块已存在）

明确不涉及：
  - 敌人/波次系统 — 经营阶段无战斗
  - 卡牌系统 — 功法选择不触发卡牌（卡牌在战斗中升级时触发）
  - 投射物系统 — 经营阶段无攻击
```

## 9. 数据流向草图

```
peak_config.csv（peak_id/peak_name/icon_path）
      ↓
  DataManager.peak_database
      ↓
  MountainManager 管理山峰状态（未修复/已修复/已激活）
      ↓
  玩家点击山峰 → mountain_selected 信号 → GameManager
      ↓
  RepairPromptPanel 显示 → 读灵气余额判断按钮状态
      ↓
  修复：扣除灵气 → mountain_repaired 信号 → 山峰变亮
  选功法：扣除灵气 → mountain_state_changed 信号 → 记录 form_id
      ↓
  form_id 存入 MountainManager → 开战时传给 MainPeak
```

## 10. 什么不算在这个功能里

```
本功能不包括：
  1. 功法升级后的具体战斗效果 — 那是战斗阶段 + 多功法并行的范畴
  2. 山峰的摆放/移动 — 山峰位置由场景预设
  3. 山峰的二次升级/功法切换 — MVP 每座山峰仅一次选择
  4. 未修复山峰的自动生成 — 不做程序化山体

后续版本考虑：
  1. 功法切换（已激活的山峰可花灵气换功法）
  2. 山峰位置自由拖拽摆放
  3. 山峰之间的共鸣/组合加成
```

## 11. 验收标准

1. 经营阶段点击未修复山峰 → 山峰出现金色光圈，弹出修复面板，显示山峰名称和"未修复"
2. 灵气=20，点击"修复山峰" → 扣除 20 灵气，山峰变亮，面板切换显示功法选择
3. 灵气=15，点击"修复山峰" → 按钮置灰无法点击
4. 修复后点击功法卡片（灵气>=30）→ 扣除 30 灵气，功法激活，面板显示"已激活"
5. 灵气不足 30 → 功法卡片置灰
6. 点击另一座山峰 → 光圈移动到新山峰，面板刷新为新山峰状态
7. 开战后器灵按已激活功法攻击（御剑诀=6发弹道combo、金刚咒=扇形stun、~~离火诀=4发火球burn~~、炼魂诀=2发魂印、灵狐契=灵兽召唤、御器诀=法器环绕）
8. 已激活功法后不可重复选择同一座山峰的功法
9. 激活多座山峰 → 开战 → 所有功法并行攻击，各自独立
