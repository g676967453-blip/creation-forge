## 三、运行时对象关系

```
MainPeak ──owns──→ _attack_channels[N]
  │                 ├── form_id → FormConfig
  │                 ├── timer / energy / level
  │                 └── 攻击时: _perform_projectile_attack()
  │                           _perform_sector_attack()
  │                           _manage_summons()
  ├── spawns ──→ Projectile[] (弹道, 有回旋/链式/穿透)
  ├── spawns ──→ SummonFox[] (灵狐, 自动索敌)
  ├── spawns ──→ ArtifactSword[] (法剑, 环绕轨道)
  └── 防御: take_damage() → 5 层判定

WaveManager ──spawns──→ EnemyBase[]
  ├── 行进: quick/sneak/tank/ranged
  ├── 攻击: siege (贴脸) / ranged (远程射击)
  └── 死亡: enemy_destroyed → WaveManager → CardManager

CardManager ──draws──→ CardData[]
  ├── 过滤: 激活的山峰 form_id
  ├── 偏向: ≥1 张 form-specific
  └── 应用: apply_upgrade() → channel + _recalc_spirit_bonuses()
```

## 四、数据流

```
CSV 文件                     DataManager             Runtime
─────────────────────────────────────────────────────────────
form_config.csv        → form_database[D]     → MainPeak._attack_channels[].config
enemy_config.csv       → enemy_database[D]    → EnemyBase.data (EnemyData)
card_config.csv        → card_database[D]     → CardManager → MainPeak.apply_upgrade()
wave_config.csv        → wave_database[A]     → WaveManager.wave_configs
peak_config.csv        → peak_database[D]     → MountainManager → UI panels
spirit_profile.csv     → spirit_database[D]   → MainPeakSelectPanel
main_peak_config.csv   → main_peak_config     → MainPeak (HP, speed, etc.)
enemy_sprite_config.csv→ sprite_database[D]   → EnemyBase._setup_sprite()
mountain_sprite_map.csv→ (MountainManager)    → PSD layer ↔ logic mapping
```

## 五、信号/事件流

### 5.1 GameManager 路由表

```
Signal                         Emitter              → Receiver
──────────────────────────────────────────────────────────────────
start_game_requested           MainPeakSelectPanel   → GameManager._on_start_game_requested
repair_prompt_requested        MountainManager       → UIStateCoordinator → RepairPrompt
repair/upgrade_confirmed       RepairPromptPanel     → EconomyManager → MountainManager
mountain_state_changed         MountainManager       → BattleHUD + BattleStartButton
battle_start_button_pressed    BattleStartButton     → BattleFlowController.start_battle
upgrade_triggered              EconomyManager        → CardSelectionPanel.show (paused)
card_selected                  CardSelectionPanel    → EconomyManager.on_card_selected
card_resolved                  EconomyManager        → BattleFlowController (unpause)
wave_changed                   WaveManager           → BattleFlowController → HUD
wave_completed                 WaveManager           → BattleFlowController
all_waves_completed            WaveManager           → BattleFlowController._on_victory
main_peak_destroyed            MainPeak              → BattleFlowController.on_defeat
return_requested               ResultPanel           → BattleFlowController.return_to_prep
restart_requested              SettingsButton        → BattleFlowController.restart_game
```

### 5.2 战斗中信号

```
MainPeak.clicked          → EconomyManager (灵气 +10 × bonus)
EnemyBase.enemy_destroyed → WaveManager (计数 -1, 波次判断)
                          → EconomyManager (EXP +reward)
EnemyBase.reached_main_peak → WaveManager (计数 -1, Boss 除外)
Projectile/Sector/Summon  → EnemyBase.take_damage() / apply_lifesteal()
```
