## 1. 在整体流程中的位置

```
[战斗开始] → [器灵激活剑峰功法] → [御剑诀自动攻击]
                                          ├── 普通攻击：飞剑追踪 + 弧线回旋
                                          └── 能量满 → 万剑归宗（终极技）
```

御剑诀是剑峰的基础入门功法，属于战斗阶段的**自动普攻型主战技**。器灵激活剑峰后即开始自动发射飞剑，无需玩家手动操作。

---

## 2. 核心玩法描述

### 2.1 普通攻击：回旋飞剑

**发射阶段：**
- 飞剑从器灵位置发出，自动追踪场上最近的敌人
- 追踪为**一级自带能力**，不需要卡牌解锁
- 每把剑的飞行轨迹随机生成（直线或弧线），同一轮多把剑的轨迹各不相同
- 多把剑同时发出时，必须同时到达目标

**命中阶段：**
- 飞剑命中敌人 → 造成伤害 → 穿过敌人继续飞行约 30 像素
- 穿过 30px 后开始弧线转弯（侧面绕弧度），掉头朝同一目标飞回
- 回旋后再次命中同一敌人，再次造成伤害

**回旋次数：**
- 基础回旋 1 次（一去一回 = 共 2 次命中）
- 功法等级提升可增加回旋次数
- 天赋卡牌可进一步增加回旋次数
- 回旋次数耗尽后飞剑消失

**敌人死亡处理：**
- 回旋中途目标死亡 → 飞剑寻找最近的新目标
- 无目标可找 → 飞剑直接消失

### 2.2 轨迹系统

| 属性 | 说明 |
|------|------|
| 轨迹类型 | 直线 或 弧线（贝塞尔曲线，侧面绕弧切回目标） |
| 随机规则 | 每把剑独立随机选择轨迹类型和控制点 |
| 多剑约束 | 同一轮发出的多把剑轨迹必须各不相同 |
| 到达时序 | 多剑同时发出必须同时到达目标（弧线剑自动提速补偿路径差） |

**弧线轨迹示意：**
```
发射点 o
        \
         \    (随机控制点，侧面偏移 40-120px)
          \
           v  目标 ← 飞剑从侧面切入
```

### 2.3 终极技：万剑归宗

**蓄力阶段（1 秒）：**
- 器灵身上出现蓄力光效
- 50 把飞剑从无到有渐变浮现（透明度 0 → 1）
- 圆心点为器灵图片的圆心点，上方 180 度范围，半径 230 像素绕圈排列
- 蓄力期间器灵可正常移动（暂无状态限制）

**发射阶段：**
- 50 把剑一齐发出
- 每把剑各自追踪最近的敌人（优先不同目标，不够时允许重复）
- 每把剑的行为与普通飞剑完全一致（追踪 + 回旋 + 弧线轨迹）

## 3. 数值设计（初步，待精调）

### 3.1 基础数值调整

| 字段 | 原值 | 新值 | 调整原因 |
|------|------|------|----------|
| damage | 18 | **10-12** | 回旋增加命中次数，需下调单次伤害 |
| projectile_count | 1 | **1**（不变） | 基础保持单剑，多剑通过卡牌获取 |
| attack_interval | 1.0s | **1.0s**（不变） | 保持攻击节奏 |
| range | 600 | **600**（不变） | — |
| special_mechanic | combo | **cycle**（回旋） | 核心机制变更 |
| tracking | 卡牌解锁 | **自带** | 一级自带追踪 |

### 3.2 回旋参数（新增）

| 字段 | 默认值 | 说明 |
|------|--------|------|
| 回旋次数 | 1 | 基础 1 次回旋（共 2 次命中） |
| 回旋距离 | 30px | 穿过敌人后飞多远再转弯 |
| 回旋转弯时间 | ~0.3s | 转弯动画时长 |
| 弧线偏移范围 | 40-120px | 贝塞尔控制点随机偏移范围 |

### 3.3 DPS 估算

```
原 DPS: 18 × 1 = 18（单发，无回旋）
新 DPS: 12 × 2 = 24（单发，1 次回旋 = 2 hits）
实际约 20-22（扣除转弯耗时 0.3s）
```

与原 DPS 相近但玩法更丰富，且回旋次数可通过等级和卡牌成长。

### 3.4 终极技参数

| 字段 | 原值 | 新值 | 说明 |
|------|------|------|------|
| 飞剑数量 | 30（依次发射） | **50**（蓄力后齐发） | — |
| 发射方式 | 0.01s 间隔连发 | **一齐发射** | — |
| 排列方式 | 无 | **上方 180°，半径 230px** | 绕圈排列，圆心=器灵图片圆心 |
| 蓄力时间 | 无 | **1 秒** | 渐变浮现 |

```
涉及的系统：
  ☑ 功法系统（Forms）— form_config.csv special_mechanic 字段更新
  ☑ 投射物系统（Projectiles）— 回旋逻辑、弧线轨迹、多剑协同到达
  ☑ 敌人系统（Enemies）— 回旋目标存活判定、换目标逻辑
  ☑ 卡牌系统（Cards）— card_config.csv 4 张剑峰卡牌更新
  ☑ 器灵系统（MainPeak）— 终极技蓄力状态、50 剑排列发射
  ☑ UI 系统 — 终极技蓄力光效、飞剑浮现动画
  ☑ 数据层（DataManager / CSV）— form_config.csv、card_config.csv 更新

可能需要新增的模块：
  - 回旋飞剑状态机（扩展现有 Projectile）— 管理飞剑的追踪/命中/穿透/转弯/回旋状态

  - 山峰系统 — 剑峰基础配置不变
  - 波次系统 — 不涉及
  - 召唤物系统 — 不涉及
```

## 7. 与设计规范的对照检查

对照《六大山峰数值定位表》和《功法技能数值设计模板》：

| 检查项 | 结果 |
|--------|------|
| 单体输出 5 | 回旋多次命中同一目标，点杀能力极强 |
| 群体输出 2 | 基础单剑，群伤仅靠终极技和多剑卡牌 |
| 控场能力 1 | 无控制效果 |
| 生存贡献 1 | 无护盾/回血 |
| 不补群伤过头 | 弧线轨迹仅影响路径不增加命中目标数 |
| 不给回血/护盾 | 御剑诀不涉及任何生存机制 |
| 成长有层次 | 基础→卡牌→等级→终极技，四层递进 |

## 8. 验收标准

1. 战斗开始 → 飞剑自动从器灵发出，追踪最近敌人，无需卡牌
2. 飞剑命中敌人 → 造成伤害；穿过敌人约 30px 后弧线转弯，再次命中同一敌人
3. 基础回旋 1 次 → 飞剑命中 2 次后消失
4. 同时发出多把飞剑（如分光化影 +2）→ 轨迹各不相同，同时到达目标
5. 获得「剑气叠加」卡牌 → 回旋次数 +1，飞剑命中 3 次后消失
6. 回旋中途目标死亡 → 飞剑寻找最近新目标继续；无目标则消失
7. 能量满 100 → 器灵蓄力 1 秒，50 把剑浮现于上方 180° 圆弧排列，然后一齐发出
