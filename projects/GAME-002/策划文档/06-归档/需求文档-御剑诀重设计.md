## 1. 功能概述

**一句话**：御剑诀飞剑增加回旋机制，命中敌人后穿过并弧线返回再次攻击。

**详细描述**：御剑诀（form_sword_01）是剑峰的基础功法。飞剑发射后自动追踪最近敌人，命中后穿过敌人约 30px，以弧线轨迹掉头回旋，再次命中同一目标。基础回旋 1 次（共 2 hits）。追踪为一级自带能力。终极技"万剑归宗"改为蓄力 1 秒后 50 把剑从上方 180 度弧形一齐发出。此改动替换原有的 combo 连击机制（该机制在代码中从未实现）。

## 6. 逻辑流程

### 6.1 普通飞剑攻击流程

```
主流程：
  1. MainPeak._process() → _attack_timer 到期
  2. _perform_projectile_attack() 创建 Projectile 实例
  3. 设置 projectile_shape = "sword"
  4. 读取 channel["cycle_count"]、channel["cycle_distance"] 等参数
  5. 设置 Projectile 回旋参数
  6. 默认启用追踪（tracking = true，不再依赖卡牌）
  7. 计算轨迹类型（直线/弧线）和到达时间
  8. Projectile 发射

Projectile 回旋状态机：
  State.APPROACHING:
    - 追踪目标移动（如果 tracking=true）
    - 沿轨迹插值飞行（直线或贝塞尔弧线）
    - 命中目标时 → 造成伤害 → _total_hits += 1
    - 如果 _total_hits >= _max_hits → 飞剑消失
    - 否则 → 切换到 State.OVERSHOOTING
  
  State.OVERSHOOTING:
    - 沿当前方向继续飞行（不再追踪，保持命中时的方向）
    - 距离目标 >= cycle_distance 时 → 计算回旋弧线
    - 弧线: P0=当前位置, P1=侧面偏移控制点, P2=目标位置
    - 切换到 State.RETURNING
  
  State.RETURNING:
    - 沿回旋弧线飞回目标
    - 命中目标时 → 同 APPROACHING 命中逻辑

多剑同步到达：
  1. 为每把剑随机分配轨迹（直线或弧线）及控制点
  2. 计算每条轨迹的总路径长度
  3. 设定统一的到达时间 T_base
  4. 每把剑的速度 = 自身路径长度 / T_base
  5. 保证所有剑同时到达各自目标

分支流程：
  - 回旋中途目标死亡 → _find_new_target() 寻找最近存活敌人
    - 找到 → 更新追踪目标，继续回旋
    - 未找到 → 飞剑消失
  - 飞剑飞行距离超过 _max_distance → 飞剑消失
```

### 6.2 终极技"万剑归宗"流程

```
主流程：
  1. 能量累积到 100 → _trigger_ultimate() → _ultimate_sword()
  2. 蓄力阶段：
     a. 创建 50 个 Projectile 实例（初始不可见，alpha=0）
     b. 以器灵图片圆心为圆心，半径 230px，上方 180°（-90° 到 +90°）均匀排列
     c. 1 秒内 alpha 从 0 渐变到 1（Tween）
     d. 器灵可正常移动，飞剑跟随移动
  3. 发射阶段：
     a. 所有 50 把剑同时获得追踪目标
     b. 优先不同敌人，不够时允许重复
     c. 一齐发出（同普通飞剑的回旋逻辑）
     d. 伤害 = 普通伤害 × ultimate_dmg_mult

分支流程：
  - 蓄力期间场上无敌人 → 仍然排列完成，发射时找最近敌人
  - 蓄力期间器灵死亡 → 取消终极技，飞剑消失
```

## 8. 边界条件与互斥

```
☑ 能重复操作吗？
   → 是，每次 attack_interval 到期自动发射

☑ 有数值上下限吗？
   → cycle_count 下限 0（无回旋，1 hit），上限由卡牌和等级决定（建议 ≤ 5）
   → 弧线偏移 40-120px

☑ 和其他功能互斥吗？
   → 回旋机制仅对 projectile_shape="sword" 且 special_mechanic="cycle" 生效
   → 其他功法（离火诀、金刚咒等）的投射物行为不受影响

☑ 数据不够时？
   → 无目标时飞剑不发射

☑ 极端值处理：
   → cycle_count=0 → 飞剑命中 1 次后消失（行为等同于无回旋的旧版）
   → 目标在回旋中途被其他飞剑击杀 → 寻找新目标

☑ 快速连续攻击？
   → 每把飞剑独立状态机，互不干扰

☑ 终极技期间器灵死亡？
   → 所有终极技飞剑取消并消失
```

## 11. 验收标准

1. 战斗开始 → 飞剑自动从器灵发出，追踪最近敌人（无需卡牌）
2. 飞剑命中敌人 → 造成 -10 伤害浮字；穿过敌人约 30px 后弧线转弯，再次命中同一敌人
3. 基础 1 次回旋 → 飞剑命中 2 次后消失
4. 同时发出多把飞剑（分光化影 +2 = 3 剑）→ 轨迹各不相同（直线/弧线混合），同时到达目标
5. 获得「剑气叠加」卡牌 → 回旋 +1，飞剑命中 3 次后消失
6. 获得「剑意贯通」卡牌 → 回旋每击伤害 +15%
7. 获得「疾剑术」卡牌 → 飞剑飞行速度 +25%
8. 回旋中途目标死亡 → 飞剑寻找最近新目标；无目标则消失
9. 能量满 100 → 器灵上方 180°、半径 230px 弧线浮现 50 剑（alpha 0→1，1 秒），然后一齐射出
10. 终极技飞剑行为和普通飞剑一致（各自追踪 + 回旋）
