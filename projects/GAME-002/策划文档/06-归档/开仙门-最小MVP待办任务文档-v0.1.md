# 《开仙门》最小MVP待办任务文档

版本：v0.1  
用途：把最小MVP拆成可以执行的待办任务，方便按优先级推进。

## 1. 经营阶段待办

- [ ] 1.1 点击器灵获得灵气
  - 玩家每次点击器灵，获得10点灵气。
  - 需要在界面上看到灵气数值变化。

- [ ] 1.2 修复山峰资源
  - 灵气可用于修复场景中已经摆好的山峰资源。
  - 不做代码生成山峰，不做随机造山。

- [ ] 1.3 山峰升级与功法选择
  - 山峰修复后可以升级。
  - 升级时弹出功法选择。
  - 先只做最小可用的功法分类。

- [ ] 1.4 开战按钮
  - 经营阶段增加“开战”按钮。
  - 由玩家手动决定是否进入战斗。

## 2. 战斗阶段待办

- [ ] 2.1 进入战斗状态
  - 点击开战后切换到战斗阶段。
  - 经营阶段暂停。

- [ ] 2.2 波次刷怪
  - 战斗共10波。
  - 第1波50只怪。
  - 后续波次逐步递增。

- [ ] 2.3 击杀获得经验
  - 器灵攻击击杀怪物后获得经验。
  - 经验条需要能持续增长。

- [ ] 2.4 战斗中升级弹窗
  - 器灵升级后，战斗中立即弹出3个增强选项。
  - 不等战斗结束再选。

- [ ] 2.5 飞剑类型示例增强
  - 增强攻击。
  - 变成两个飞剑弹道。
  - 增强穿透。

- [ ] 2.6 结算与返回经营
  - 战斗结束后进入结算。
  - 结算后返回经营阶段。

## 3. 规则收敛待办

- [ ] 3.1 删除非最小MVP内容
  - 去掉不影响当前闭环的山峰扩展玩法。
  - 去掉代码生成山峰相关内容。
  - 去掉过多经营分支和复杂养成。

- [ ] 3.2 明确资源边界
  - 只保留灵气、山峰修复、山峰升级、战斗经验、战斗增强这几类核心资源。

## 4. 建议优先级

### P0

1. 点击器灵获得灵气。
2. 灵气修复山峰资源。
3. 山峰升级与功法选择。
4. 开战按钮进入战斗。
5. 战斗10波、首波50。
6. 击杀获得经验。
7. 战斗中升级弹出3选1。
8. 结算后返回经营。

### P1

1. 飞剑类型的增强分支。
2. 山峰修复与升级的基础表现优化。
3. 战斗波次递增的具体数值微调。

### P2

1. 其他功法类型扩展。
2. 更多怪物类型。
3. 更多经营系统。

## 5. 验收标准

最小MVP至少满足以下体验：

1. 玩家能在经营阶段点击器灵获得灵气。
2. 玩家能用灵气修复摆好的山峰资源。
3. 山峰能升级并选择功法类型。
4. 玩家能点击开战进入战斗。
5. 战斗共10波，首波50只怪。
6. 击杀怪物后器灵获得经验并升级。
7. 升级时会立即弹出3个增强选项。
8. 战斗结束后可以回到经营阶段继续玩。

## 6. 备注

这份待办只服务于最小MVP，不是完整功能清单。后续如果要扩展内容，再单独开第二版需求。
