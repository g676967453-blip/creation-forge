## 改动 1：新建 floating_text.tscn

在 `scenes/` 下新建场景文件。根节点为 Control，结构如下：

```
FloatingText (Control)
├── Label                    ← 显示 "+10" / "+25" 文字
```

根节点 Control 属性：
- `mouse_filter = MOUSE_FILTER_IGNORE`（不拦截鼠标）
- `z_index = 200`
- 挂载脚本 `res://scripts/floating_text.gd`

Label 属性（用户可在引擎中自行调整）：
- `horizontal_alignment = HORIZONTAL_ALIGNMENT_CENTER`
- 默认字体大小 22
- 默认字体颜色：亮金色 Color(1.0, 0.93, 0.45)
- 字体描边：颜色 Color(0.12, 0.08, 0.02)，大小 2

## 改动 2：新建 floating_text.gd

```gdscript
extends Control
## 浮字模板 — 用户可在 floating_text.tscn 中编辑 Label 样式

@onready var label: Label = $Label


func show_text(text: String, color: Color) -> void:
    label.text = text
    label.add_theme_color_override("font_color", color)
    _play_animation()


func _play_animation() -> void:
    var tween := create_tween()
    tween.set_parallel(true)
    tween.tween_property(self, "position", position + Vector2(0, -28), 0.6) \
        .set_trans(Tween.TRANS_QUAD).set_ease(Tween.EASE_OUT)
    tween.tween_property(self, "modulate:a", 0.0, 0.6) \
        .set_trans(Tween.TRANS_QUAD).set_ease(Tween.EASE_OUT)
    tween.finished.connect(queue_free)
```

## 改动 3：game_manager.gd

### 3.1 新增成员变量（约第 15 行后）

```gdscript
var _spirit_accumulated: int = 0
@onready var _auto_spirit_timer: Timer = $AutoSpiritTimer
@onready var _auto_display_timer: Timer = $AutoDisplayTimer
```

### 3.2 新增 OnReady 常量

```gdscript
const FLOATING_TEXT_SCENE: PackedScene = preload("res://scenes/floating_text.tscn")
```

### 3.3 _ready() 中初始化计时器

在 `_ready()` 末尾（`_update_ui()` 调用之前或之后）增加：

```gdscript
_auto_spirit_timer.wait_time = 0.2
_auto_spirit_timer.timeout.connect(_on_auto_spirit_tick)
_auto_display_timer.wait_time = 1.0
_auto_display_timer.timeout.connect(_on_auto_display_tick)
```

计时器启动/停止在 `_set_state()` 中根据状态管理（见 3.4）。

### 3.4 _set_state() 中管理计时器

在 `_set_state()` 函数末尾（或合适位置）增加：

```gdscript
if new_state == GameState.PREPARATION:
    _auto_spirit_timer.start()
    _auto_display_timer.start()
else:
    _auto_spirit_timer.stop()
    _auto_display_timer.stop()
    _spirit_accumulated = 0
```

### 3.5 新增计时器回调函数

在文件末尾（`_on_repair_prompt_requested` 之后）增加：

```gdscript
func _on_auto_spirit_tick() -> void:
    spirit += 5
    _spirit_accumulated += 5
    _update_ui()
    spirit_changed.emit(spirit)


func _on_auto_display_tick() -> void:
    if _spirit_accumulated > 0:
        _spawn_spirit_popup(Vector2(640, 600), _spirit_accumulated, Color(0.8, 0.85, 0.4))
        _spirit_accumulated = 0
```

说明：`Vector2(640, 600)` 是器灵上方固定位置（器灵在 640, 650）。自动浮字从固定位置飘出，区别于手动点击的点击位置。

### 3.6 修改 _spawn_spirit_popup 使用场景模板

将现有第 117-138 行的纯代码创建改为场景实例化：

```gdscript
func _spawn_spirit_popup(screen_position: Vector2, amount: int, color: Color = Color(1.0, 0.93, 0.45)) -> void:
    var ui_root := get_tree().current_scene.get_node_or_null("UI")
    if ui_root == null:
        return

    var popup := FLOATING_TEXT_SCENE.instantiate()
    popup.position = screen_position + Vector2(-14, -44)
    ui_root.add_child(popup)
    popup.show_text("+%d" % amount, color)
```

自动调用时传入淡金色，手动点击沿用默认亮金色。

### 3.7 主场景添加计时器节点

在 `scenes/main.tscn` 的 `Managers/GameManager` 节点下添加两个 Timer 子节点：

```
[node name="AutoSpiritTimer" type="Timer" parent="Managers/GameManager"]
wait_time = 0.2
one_shot = false

[node name="AutoDisplayTimer" type="Timer" parent="Managers/GameManager"]
wait_time = 1.0
one_shot = false
```

## 验收对照

| # | 规划验收标准 | 实现方式 |
|---|------------|---------|
| 1 | 经营阶段每秒自动增加 25 灵气 | `AutoSpiritTimer` 每 0.2s +5，`AutoDisplayTimer` 每 1s 显示合并浮字 |
| 2 | 点击器灵 +10，飘亮金浮字 | `_spawn_spirit_popup` 使用场景模板，默认亮金色 |
| 3 | 自动浮字每秒显示一次 "+25" | `_auto_display_tick` 显示累积量，使用淡金色 |
| 4 | 连续点击每次独立浮字 | 每次点击创建新实例，各自有独立 tween |
| 5 | 灵气可用于修复消耗 | 已有 `try_spend_spirit`，无需改动 |
| 6 | 进入战斗 → 产出停止 | `_set_state` 中 BATTLE 时 stop 计时器 |
| 7 | 返回经营 → 产出恢复 | `_set_state` 中 PREPARATION 时 start 计时器 |

## 用户可在 Godot 引擎中编辑的部分

- **浮字样式**：打开 `scenes/floating_text.tscn` → 选中 Label → 修改字体、字号、颜色、描边
- **浮字动画**：打开 `scripts/floating_text.gd` → 修改 tween 参数（位移距离、淡出时长、缓动曲线）
- **计时器参数**：打开 `scenes/main.tscn` → 找到 `Managers/GameManager/AutoSpiritTimer` → 修改 `wait_time` 调整产出频率
