## 1. 功能在整体流程中的位置

```
经营阶段 → [开战过渡] → [波次战斗（10波连续）] → [结算] → 返回经营
                ↓                    ↓              ↓
          倒计时提示          击杀→经验→升级    胜利/失败画面
                             升级→三选一卡牌
```

---

## 2. 开战过渡

- 点击"开战"后，不直接刷怪
- 画面中央显示大字提示："第 1 波即将来临"（约 1.5 秒后消失）
- 过渡期间器灵不攻击，敌人不出现
- 过渡结束后开始刷怪，器灵开始攻击

## 4. 战斗 HUD

### 4.1 HUD 布局（屏幕顶部横条，从左到右）

| 位置 | 元素 | 说明 |
|------|------|------|
| 左 | 波次信息 | "波次 3 / 10" |
| 左中 | 剩余怪物数 | "剩余：42" |
| 中 | 器灵等级 + 经验条 | "Lv.3" + 经验进度条（当前经验/升级所需） |
| 右中 | 灵气 | "灵气：150" |
| 右 | 器灵血量条 | 红色血条 + 数值（当前 HP / 最大 HP） |

### 4.2 经验条

- 显示格式：等级数字 + 横向进度条
- 进度条：当前经验占升级所需经验的比例，填充色为蓝色
- 升级时进度条清空，等级数字 +1

### 4.3 器灵血条

- 红色横向条，随血量减少而缩短
- 右侧显示具体数值："380 / 500"
- 血量低于 30% 时血条变红闪烁

## 5. 器灵战斗属性

### 5.1 基础属性

| 属性 | 数值 | 说明 |
|------|------|------|
| 基础血量 | 500 | 战斗开始时满血 |
| 基础伤害 | 18 | 每发投射物伤害 |
| 基础攻速 | 0.85s | 攻击间隔 |
| 弹道方式 | 单发 | 默认 1 发飞剑，直射最近敌人 |
| 穿透次数 | 0 | 默认击中一个敌人后消失 |
| 寻敌方式 | 最近优先 | 攻击距离器灵最近的敌人 |

### 5.2 功法对属性的影响

选择不同功法后，进入战斗时器灵属性变为：

| 功法 | 伤害 | 攻速 | 弹道 | 射程 | 特性 |
|------|------|------|------|------|------|
| 御剑诀 | 6 | 1.0s | 6 发 | 600 | combo 连击系统，每层+2% 伤害 |
| 金刚咒 | 18 | 1.2s | 1 发（扇形） | 180 | stun 眩晕（12% 概率，0.5s）+ 护盾 |
| ~~离火诀~~ | ~~10~~ | ~~0.8s~~ | ~~4 发~~ | ~~550~~ | ~~burn 灼烧~~ 已删除 |
| 炼魂诀 | 8 | 1.0s | 2 发 | 520 | soul_mark 魂印（叠 3 层，削弱+引爆） |
| 灵狐契 | 8 | 0.9s | 召唤 | — | 灵狐自动攻击（HP=120, ATK=8） |
| 御器诀 | 10 | 0.9s | 召唤 | 80 | 法器环绕攻击，可反弹伤害 |

### 5.3 战斗中升级增强

器灵每次升级选择卡牌后，属性在功法基础上叠加：

| 卡牌示例 | 叠加效果 |
|----------|---------|
| 灵力灌注 | 伤害 +20%（可多次叠加） |
| 分光化影 | 弹道 +2（不可叠加，稀有） |
| 以神御剑 | 飞剑自动追踪（不可叠加，稀有） |

### 5.4 自动攻击

- 进入战斗后器灵自动攻击，无需玩家操作
- 寻敌：优先攻击距离最近的敌人

### 5.5 受击

- 敌人到达器灵位置 → 器灵扣除对应伤害
- 器灵血量 ≤ 0 → 战斗失败

### 5.6 升级

- 击杀敌人获得经验：普通敌人 +10，精英敌人 +30
- 经验达到升级所需 → 器灵升级，暂停战斗，弹出三选一卡牌
- 选择卡牌后战斗继续
- 升级所需经验随等级递增

## 6. 升级三选一卡牌

### 6.1 触发时机

- 器灵经验达到升级所需 → 战斗立即暂停
- 暂停内容：敌人冻结不动、器灵停止攻击、波次计时暂停
- 弹出卡牌选择面板

### 6.2 面板布局

- 全屏半透明深色遮罩（比经营面板遮罩更深，突出紧急感）
- 居中面板，从上到下：
  - 标题："器灵升级！选择强化"
  - 副标题："Lv.X → Lv.X+1"
  - 三张卡牌左右并排
  - 底部提示文字："选择后继续战斗"
- 面板外不可点击（强制选择）

### 6.3 卡牌内容

每张卡牌显示：

| 元素 | 说明 |
|------|------|
| 卡牌名称 | 如"飞剑增伤" |
| 效果描述 | 如"器灵伤害提升 25%" |
| "选择"按钮 | 点击后生效 |

### 6.4 交互

| 操作 | 反馈 |
|------|------|
| 点击某张卡牌的"选择"按钮 | 效果立即应用到器灵，面板关闭，战斗恢复 |
| 鼠标悬停在卡牌上 | 卡牌轻微放大或高亮（可选，MVP 可跳过） |

### 6.5 连续升级

- 如果一次获得大量经验导致连升多级 → 依次弹出多个三选一
- 第一个选择完成后 → 立刻弹出第二个 → 直到所有升级处理完毕
- 战斗在全部选择完成前保持暂停

### 6.6 当前卡牌池

卡牌池共 29 张（含 4 张通用 + 25 张功法专属卡），每张卡牌含 form_id 标签和稀有度（普通/稀有）。升级时从已激活功法对应的卡牌中随机抽取 3 张不重复的卡牌供玩家选择。详见 `card_config.csv`。

## 7. 结算

### 7.1 胜利（10 波全部清除）

- 画面中央显示"战斗胜利"
- 显示战斗数据（击杀数等，MVP 可简略）
- "返回经营"按钮

### 7.2 失败（器灵血量归零）

- 画面中央显示"战斗失败"
- "返回经营"按钮

### 7.3 返回经营

- 点击"返回经营" → 清空战场 → 器灵血量恢复 → 重置等级和波次 → 回到经营阶段

---

## 8. 与其他功能的衔接

| 规则 | 说明 |
|------|------|
| 进入条件 | 经营阶段，至少激活一座山峰，点击"开战" |
| 战斗中学灵气 | 暂停产出（不自动增长、点击无效） |
| 战斗中修复 | 不可进行（山峰点击在战斗阶段无效） |
| 战斗中设置 | 设置按钮可见，点击可返回器灵选择（重置全部进度） |
| 退出条件 | 10 波全清（胜利）或器灵血量归零（失败） |

## 10. 模块边界草图

```
涉及的系统：
  ☑ GameManager — 状态切换、倒计时、胜败判定、升级触发
  ☑ WaveManager — 波次调度、敌人实例化（读 wave_config.csv）
  ☑ MainPeak/main_peak.gd — 自动攻击、HP 管理
  ☑ CardManager — 升级卡牌三选一
  ☑ BattleHUD — 波次/敌数/HP/经验/等级显示
  ☑ EnemyBase/enemy_base.gd — 敌人 AI、受击、死亡
  ☑ DataManager — wave/enemy/main_peak/card/form_config 读取

可能需要新增：
  （无——所有模块已存在）

明确不涉及：
  - MountainManager — 战斗中不可操作山峰
  - RepairPromptPanel — 经营阶段 UI
  - 灵气产出 — 战斗中停止产出
```

## 11. 数据流向草图

```
wave_config.csv + enemy_config.csv + main_peak_config.csv
      ↓
  DataManager 加载
      ↓
  GameManager.start_battle() → 收集 active_form_ids
      ↓
  MainPeak.set_attack_channels() → 构建攻击通道
  WaveManager.start_battle() → 逐波生成敌人
      ↓
  敌人移动 → 器灵攻击 → 碰撞检测 → HP 变化
      ↓                          ↓
  enemy_killed 信号          main_peak_hp_changed 信号
      ↓                          ↓
  GameManager 累加经验      BattleHUD 更新 HP 条
      ↓
  经验满 → level_up → CardManager → 三选一 → 效果应用
      ↓
  10 波全清 / HP=0 → battle_ended → ResultPanel
```

## 12. 什么不算在这个功能里

```
本功能不包括：
  1. 功法选择/山峰修复 — 那是经营阶段的功能
  2. 局内临时资源（局内灵石等）— post-MVP
  3. 天劫类型多样化（雷劫/心魔/阴风）— 当前仅有敌人生成
  4. 波次间剧情/对话 — post-MVP

后续版本考虑：
  1. Boss 专属机制/阶段
  2. 局内临时建筑/陷阱
  3. 天劫环境效果（减速场/灼烧地面等）
```

## 13. 验收标准

1. 点击"开战" → 显示"第 1 波即将来临"提示 → 1.5 秒后开始刷怪
2. 第一波 50 只红色小怪从上方出现，向器灵移动
3. 器灵自动发射飞剑攻击敌人
4. 敌人到达器灵 → 器灵血量减少，血条实时更新
5. 击杀敌人 → 经验条增长
6. 经验条满 → 器灵升级，战斗暂停，弹出三选一卡牌
7. 选择卡牌 → 效果生效，战斗继续
8. 10 波全清 → "战斗胜利" + "返回经营"按钮
9. 器灵血量归零 → "战斗失败" + "返回经营"按钮
10. 不同波次出现不同颜色和大小的敌人
