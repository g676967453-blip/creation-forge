---

## 1. 功能概述

**一句话**：玩家首次启动选择百世书器灵，绑定后进入经营阶段。

**详细描述**：游戏启动后播放世界观简介，然后进入器灵选择界面。V0.1 仅百世书可选，玩家选中后确认，器灵永久绑定，进入经营阶段。器灵有 HP，随山峰修复成长——HP 提升、出战槽增加、灵气和经验加成提升、形态变化。器灵 HP 在经营阶段自动恢复。战斗失败时百世书特性触发免死。

---

## 2. 模块影响分析

```
触及的现有模块：
  1. MainPeak (main_peak.gd) — HP 管理、形态切换、成长属性应用
  2. main.tscn — 器灵选择面板节点、经营 HP 条节点
  3. GameManager — MAIN_PEAK_SELECT 状态、selected_spirit_id 记录
  4. DataManager — 读 spirit_profile_config.csv、新增 spirit_growth.csv 加载
  5. MainPeakSelectPanel — 选择界面改造（单卡片+世界观）

需要新建的模块：
  1. SpiritGrowthManager — 监听山峰修复信号 → 更新器灵成长等级

不需要动的模块：
  - MountainManager — 只发射修复信号，SpiritGrowthManager 负责响应
  - WaveManager / CardManager / EnemyBase — 无关
  - 战斗系统 — 器灵战斗表现属于战斗模块
```

## 3. 触发条件与状态约束

| 维度 | 说明 |
|------|------|
| 触发方式 | 游戏启动时自动进入选择流程；器灵成长由山峰修复信号触发 |
| 触发对象 | GameManager 启动 → MainPeakSelectPanel → MainPeak |
| 前置游戏状态 | 无（游戏入口）；成长触发需 PREPARATION |
| 互斥状态 | 选择阶段不能进入战斗 |
| 可重复性 | 器灵选择仅一次；成长可多次（每修一座峰触发一次） |

## 4. 程序需求

### 4.1 启动与世界观简介

> ✅ 已实现（2026-07-16，`scripts/ui/intro_screen.gd`，按 Pixso「开场黑幕」设计稿）。实现差异：逐段淡入（4 段连续淡入，非每行 1s 间隔）；无自动淡出，改为点击/按键继续（第一次快进动画，第二次进入器灵选择），ESC 亦为跳过。

- 游戏启动 → 纯黑画面
- 逐行淡入世界观文字（4 行，每行 ~1s 间隔）
- 文字停留 2s → 整体淡出
- 过渡到器灵选择界面（~1s）

### 4.2 器灵选择界面

- 单卡片居中展示（百世书），金色边框
- 左右两侧空槽位（灰色虚影，"???"）
- 底部「开始游戏」按钮，选中前置灰
- 点击卡片 → 高亮（金色光晕）→ 按钮亮起
- 再次点击 → 取消选中 → 按钮置灰
- 点击「开始游戏」→ 过渡动画 → 进入经营

### 4.3 器灵绑定与存储

- 选定后 selected_spirit_id 写入存档
- 有存档时跳过选择，直接进经营

### 4.4 器灵 HP 系统

- 基础 HP：500（从 spirit_growth.csv 读取 repair_count=0 行）
- 经营阶段自动恢复（2%/s）
- 战斗失败免死（百世书特性，V0.1 无惩罚）

### 4.5 器灵成长

- SpiritGrowthManager 监听山峰修复信号
- 收到信号 → repair_count +1 → 读 spirit_growth.csv → 更新 MainPeak 属性
- 更新项：max_hp、出战槽数、灵气加成、经验加成
- 触发形态切换（7 级外形）

### 4.6 经营界面展示

- 器灵头顶 HP 条（绿色，≤30% 变红）
- 器灵形态随修复等级变化
- 点击器灵 → 显示当前等级和成长进度

## 8. 信号契约

```
新增信号：spirit_growth_changed(repair_count: int)
  发射者：SpiritGrowthManager
  接收者：MainPeak、UI（HP条/形态）
  时机：山峰修复成功后，repair_count 更新时

复用信号：mountain_repaired(peak_id: String)
  发射者：MountainManager（现有）
  接收者：SpiritGrowthManager（新增监听）
  时机：山峰修复成功时 → SpiritGrowthManager 响应 → 更新器灵成长
```

## 9. 逻辑流程

```
启动流程：
  1. 游戏启动 → 检查存档
     - 无存档 → 播放世界观 → 显示选择界面
     - 有存档 → 直接加载经营场景
  2. 玩家选中百世书 → 点击「开始游戏」
  3. 记录 selected_spirit_id → 切换到 PREPARATION

经营流程（器灵相关）：
  1. 器灵显示 HP 条 + 当前形态
  2. HP 每秒自动恢复 2% max_hp
  3. 山峰修复成功 → MountainManager 发射 mountain_repaired
  4. SpiritGrowthManager 收到信号 → repair_count +1
  5. 读取 spirit_growth.csv → 更新 MainPeak：
     - max_hp = 新值
     - 出战槽 = 新值
     - 灵气/经验加成 = 新值
     - 形态切换到新 visual_stage
  6. UI 更新：HP 条刷新上限、形态变化

战斗失败流程（百世书）：
  1. 器灵 HP 归零 → 判断 selected_spirit_id == "spirit_book"
  2. 免死 → HP 恢复到 1 → 回到经营阶段
  3. V0.1 不扣经验
```

## 10. 边界条件

```
□ 能重复选择器灵吗？→ 不能，选完永久绑定
□ 快速连续点击卡片？→ 只响应第一次选中/取消
□ 器灵 HP 降到 0？→ 触发免死（百世书），回到经营
□ 修复山峰超过 6 座？→ 不会发生，总共 6 座
□ 没有存档时直接进战斗？→ 不可能，必须先选器灵
□ 战斗中器灵 HP 条？→ 属于战斗系统模块，不在此需求范围
```

## 13. 验收标准

1. 启动游戏 → 黑屏世界观文字淡入 → 器灵选择界面浮现
2. 百世书居中 → 点击选中（金色光晕）→ 开始按钮亮起
3. 点击开始 → 过渡动画 → 进入经营，器灵显示百世书
4. 器灵头顶 HP 条显示，每秒自然恢复
5. 修复剑峰 → 器灵 HP 上限从 500 变为 800，出战槽从 1 变 2，形态变化
6. 战斗失败 → 免死（HP=1），回到经营
7. 再次启动 → 直接进经营（不重新选器灵）
