## 1. 功能概述

法宝是 V0.1 新增的弟子装备系统。每个弟子有 3 个装备槽位（武器/护甲/饰品），玩家在经营阶段可花费灵气为弟子装备法宝。法宝提供数值加成或特殊效果（概率触发），稀有度分级：普通/稀有/史诗/传说。

与 GDD 中"局外炼宝"的远期愿景不同，V0.1 法宝定位为**简单的装备系统**——预定义法宝库，灵气购买，即装即用。

### 在整体流程中的位置

```
[经营阶段] → 选中弟子 → 查看法宝槽位 → 花费灵气装备 → 属性即时生效
[战斗阶段] → 法宝被动/触发效果在战斗中生效
[跨局] → V0.1 法宝不跨局保留（roguelike 特性）
```

## 3. 源码实现状态

### 已实现

| 文件 | 职责 |
|------|------|
| `scripts/data/artifact_data.gd` | ArtifactData Resource 类，字段含 artifact_id/name/slot/rarity/description/effect_type/value |
| `autoload/data_manager.gd` | `_load_artifacts()` + `get_artifact()` / `get_all_artifacts()` 查询接口 |

### 待实现

- [ ] Artifact 管理器（类似 CardManager / BillManager）
- [ ] 装备槽位逻辑：每个 Disciple 实例维护 `equipped: Dictionary = {weapon: null, armor: null, accessory: null}`
- [ ] 装备/卸下 API：`disciple.equip(artifact)` / `disciple.unequip(slot)`
- [ ] 经营阶段 UI：弟子详情面板显示槽位 + 可装备法宝列表
- [ ] 灵气花费：不同稀有度不同价格（common=50, rare=150, epic=300, legend=500）
- [ ] 触发效果实现：`chain_chance`（概率连锁）、`reflect`（反伤）需战斗层支持

## 4. 关键接口

```gdscript
# DataManager 查询
DataManager.get_artifact("art_sharp_sword") → ArtifactData
DataManager.get_all_artifacts() → Array[ArtifactData]

# Disciple 装备接口（待实现）
disciple.equip(artifact_data) → bool     # 装备法宝
disciple.unequip("weapon") → bool        # 卸下法宝
disciple.get_equipped() → Dictionary     # 查询已装备

# ArtifactData 字段
artifact.slot        # "weapon" | "armor" | "accessory"
artifact.rarity      # "common" | "rare" | "epic" | "legend"
artifact.effect_type # 效果类型标识
artifact.effect_value # 效果数值
```

## 5. 与其他系统的关系

| 系统 | 关系 |
|------|------|
| 弟子系统 | 法宝装备在弟子身上，直接影响弟子属性 |
| 赐福系统 | 法宝与赐福效果叠加（先加基础值，再乘赐福系数） |
| 经济系统 | 灵气购买，稀有度决定价格 |
| 卡牌系统 | V0.1 不联动；远期可设计"法宝共鸣"卡牌 |
| GDD 远期 | GDD §2.3 的"4 神器"和归档中"法宝炼制"是远期愿景，V0.1 法宝是简化版 |
