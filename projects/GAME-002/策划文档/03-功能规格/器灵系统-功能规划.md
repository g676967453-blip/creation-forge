## 1. 在整体流程中的位置

```
[游戏启动] → [黑屏+世界观简介] → [选择器灵] → [经营阶段主场景]
                                        ↑              ↓
                                  仅首次进入       [下山历练] ⇄ [战斗]
                                                      ↓
                                                 通关 → 回经营
                                            （器灵永久绑定，不重选）
```

## 2. 界面描述

### 2.1 启动与世界观简介

- 游戏启动 → 纯黑画面
- 逐行淡入世界观文字（3-4 行，每行 ~1s 间隔）
- 文字停留 2s → 整体淡出
- 器灵选择界面从黑底中浮现（~1s）

### 2.2 选择界面（默认状态）

- 深色云海背景，中央百世书卡片居中展示
- 百世书卡片：亮色，可点击（古书/卷轴意象，金色边框）
- 左右两侧各一个空槽位（灰色虚影，标注"???"，暗示未来有更多器灵）
- 底部「开始游戏」按钮（未选中时置灰）
- 顶部标题"选择器灵"

### 2.3 操作状态

- 点击百世书卡片 → 卡片高亮（金色光晕）
- 「开始游戏」按钮变为可点击（亮色）
- 再次点击 → 取消选中，按钮置灰

### 2.4 完成态

- 点击「开始游戏」→ 面板淡出（~1s），进入经营主场景
- 器灵绑定（不可更换）

### 2.5 经营界面器灵展示

- 器灵位于画面底部中央
- 头顶显示 HP 条（绿色，≤30% 变红）
- 器灵形态随修复等级变化（7 级外形，见数值模板 §3）
- 点击器灵可查看当前等级和成长进度

|------|------|
| 点击百世书卡片 | 金色光晕高亮，开始按钮亮起 |

## 5. 模块边界草图

```
涉及的系统：
  ☑ 器灵（MainPeak）— 器灵数据绑定、HP管理、形态切换、随修复成长
  ☑ UI 系统 — 选择面板、过渡动画、经营HP条
  ☑ 数据层 — spirit_profile_config.csv + spirit_growth.csv

可能需要新增：
  - SpiritGrowthManager — 监听山峰修复信号 → 更新器灵成长等级

明确不涉及：
  - 多器灵解锁系统 — V0.3
  - 山峰系统 — 器灵只接收修复信号，不管理修复逻辑
  - 战斗系统 — 器灵战斗表现属于战斗模块
```

## 6. 数据流向草图

```
spirit_profile_config.csv（器灵档案：id/名称/特性/图标）
      ↓
  DataManager 加载
      ↓
  MainPeakSelectPanel 读取 → 渲染卡片 → 判断解锁状态
      ↓
  玩家选择 → 确认 → GameManager 记录 selected_spirit_id
      ↓
  GameManager 切换到 PREPARATION → 器灵形态显示
```

---

## 7. 与其他功能的衔接

| 维度 | 说明 |
|------|------|
| 进入条件 | 首次游戏启动进入；有存档则直接进经营 |
| 退出条件 | 确认选择后进入经营阶段，此后**不再返回** |
| 互斥功能 | 选择阶段不能进行经营或战斗操作 |
| 前置依赖 | 无（游戏入口） |
| 后续触发 | 器灵永久绑定，特性影响战斗失败处理（百世书免死） |

---

## 8. 什么不算在这个功能里

```
本功能不包括：
  1. 诛仙剑/神农鼎（V0.3 实装，V0.1 连灰显都不做——仅百世书）
  2. 战斗中器灵表现（属于战斗系统模块）

后续版本考虑（但本版本不做）：
  1. 多器灵解锁系统
  2. 器灵选择时的预览动画
```

## 9. 验收标准

1. 首次启动游戏 → 看到器灵选择界面，百世书居中展示
2. 点击百世书 → 卡片高亮，开始按钮亮起
3. 点击开始 → 过渡动画 → 进入经营场景，器灵显示为百世书
4. 器灵永久绑定，经营阶段无法返回更改
5. 经营界面器灵有 HP 条显示
6. 修复山峰后 → 器灵 HP 增长 + 器灵形态发生变化
