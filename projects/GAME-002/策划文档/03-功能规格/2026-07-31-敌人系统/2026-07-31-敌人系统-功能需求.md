> 版本：v0.1 | 日期：2026-07-31 | 状态：策划中

## 1. 功能概述

**一句话**：全屏战斗中的敌方单位——普通怪海量涌入、精英怪带特殊技能、Boss（V0.1 单阶段，多阶段 V0.2+）。击杀掉落经验/挂件/材料。

**详细描述**：敌人在全屏战斗态中从屏幕四面边缘刷出，朝器灵移动。普通怪数量最多，碰触器灵造成伤害。精英怪每 4-5 波出现，血量高+特殊技能（冲锋/远程/震荡波），掉落挂件。第 15 波 Boss（V0.1 单阶段，多阶段标准→狂暴→濒死延后至 V0.2）。所有敌人由 WaveManager 按波次配置生成，数据由 enemy_config.csv 驱动。

## 2. 模块影响分析

```
触及的现有模块：
  1. EnemyBase（scripts/enemy_base.gd）— 修改：新增精英/Boss 行为分支
  2. WaveManager — 修改：适配四面刷怪+精英/Boss 生成+波次计数
  3. enemy_config.csv — 修改：新增敌人类型、调整数值
  4. wave_config.csv — 修改：15 波完整配置
  5. ExperienceSystem（新建）— 修改：不同敌人掉落不同经验值

需要新建的模块：
  1. BossController（scripts/enemies/boss_controller.gd）
     职责：Boss 状态机（V0.1 单阶段入场→死亡；V0.2+ 多阶段）

不需要动的模块：
  - 桌面态/最小化态 — 敌人仅在战斗中
  - 山峰系统 — 敌人不涉及经营
```

## 3. 触发条件与状态约束

| 维度 | 说明 |
|------|------|
| 触发方式 | WaveManager 按波次配置自动生成 |
| 生成位置 | 屏幕四边外随机位置（上下左右均匀分布） |
| 前置游戏状态 | BATTLE |
| 互斥状态 | 非战斗状态下无敌人 |
| 敌人数量上限 | 单屏最多 200 只（性能保护） |
| 波间清理 | 每波结束清完该波敌人后停顿 2s 进入下一波 |

## 5. 信号契约

```
信号 1（复用现有）：enemy_spawned(enemy: EnemyBase)
  发射者：WaveManager
  接收者：GameManager（→计数）
  时机：每个敌人生成时

信号 2（复用现有）：enemy_killed(enemy_type: String, position: Vector2, drop_data: Dictionary)
  发射者：EnemyBase
  接收者：ExperienceSystem（→经验球）、TrinketManager（→挂件掉落）、WaveManager（→波次计数）
  时机：敌人 HP ≤ 0

信号 3（新建）：boss_phase_changed(phase: int, phase_name: String)
  发射者：BossController
  接收者：BattleHUD（→Boss 血条特效）、BattleCamera（→屏幕震动）
  时机：Boss 进入新阶段

信号 4（新建）：enemy_reached_spirit(enemy: EnemyBase, damage: int)
  发射者：EnemyBase
  接收者：MainPeak（→take_damage）
  时机：敌人碰触器灵（攻城模式）
```

## 6. 逻辑流程

### 6.1 普通怪

```
1. WaveManager 按波次配置定时生成
2. 生成位置：屏幕四边外随机（上/下/左/右各 25% 概率）
3. 生成后：朝器灵位置移动（速度由 CSV 定义）
4. 碰触器灵 Area2D → 进入攻城模式：
   → 停止移动
   → 每 1s 对器灵造成伤害
   → 视觉：敌人贴在器灵身边攻击
5. 被弹幕命中 → 扣血 → HP ≤ 0 → 死亡
   → 掉落经验球（朝器灵微移，80px 内自动吸入）
   → 发射 enemy_killed
```

### 6.2 精英怪

```
1. W5/8/11/14 波次开始时，额外生成精英怪
2. 精英怪入场：屏幕边缘红光闪烁 1s → 精英怪出现（带特殊视觉标识）
3. AI 逻辑：
   → 60% 时间：朝器灵移动（同普通怪）
   → 20% 时间：释放特殊技能（冲锋/远程弹幕/震荡波）
   → 20% 时间：游走/调整位置
4. 死亡 → 必定掉落挂件（概率见数值表）+ 大量经验球
   → BattleHUD 显示"精英击败！"提示
```

### 6.3 Boss 战

```
1. W15 开始 → 清完剩余小怪 → 2s 停顿 → Boss 入场
2. BossController 接管：
   → 入场动画 2s（从天而降+屏幕震动+红光+大字）
   → 阶段 1：标准攻击循环（近战挥击 + 3 发弹幕，间隔 2s）
   → HP < 50%：发射 boss_phase_changed(2, "狂暴")
     → 移速×1.5，攻击间隔×0.67，身体变红+粒子
   → HP < 20%：发射 boss_phase_changed(3, "濒死")
     → 停止移动 → 1.5s 蓄力 → 全屏震荡波
     → 进入虚弱 3s（受伤×2，不能动）
   → HP ≤ 0：发射 boss_phase_changed(0, "死亡")
     → 爆炸粒子 1s → 掉落物散射 → 战斗胜利
3. Boss 血条：屏幕顶部独立显示（不同于普通怪）
```

## 7. UI 表现

| 元素 | 表现 |
|------|------|
| 普通怪 | 像素小人，按类型有不同颜色/形状，默认无血条 |
| 精英怪 | 比普通大 1.5x，头顶独立血条，特殊颜色边框 |
| Boss | 巨大（3-5x），屏幕顶部独立 Boss 血条（红色粗条+阶段标记），入场大字「天魔降临」 |
| 伤害数字 | 从受击敌人飘出，白色普通/黄色暴击/红色受击 |
| 击杀特效 | 敌人碎裂粒子（颜色对应敌人类型），0.3s 消散 |
| 经验球 | 小光点（3-6px，随敌人类型大小不同），朝器灵缓慢飘移 |
| 挂件掉落 | 闪亮掉落物（比经验球大 2x），带旋转+光晕，自动吸入 |

## 8. 边界条件与互斥

```
☑ 单屏敌人超过 200 只？→ WaveManager 暂停生成新怪，直到数量 < 150
☑ 敌人刷新在屏幕内？→ 生成位置 clamp 到屏幕外 50-100px 处
☑ 敌人卡在障碍物？→ V0.1 无障碍物。V0.2+ 用导航网格
☑ Boss 阶段切换同时被击杀？→ 伤害溢出传递到下一阶段（允许 skip 阶段 2）
☑ 精英怪技能伤害到其他敌人？→ V0.1 不伤害友军。V0.2 可加友军伤害
☑ 器灵移动到屏幕边缘 → 敌人生成在器灵背后？→ 正常，四面刷新不因器灵位置改变
☑ 战斗中最小化 → 所有敌人暂停移动/攻击
```

## 11. 验收标准

### 普通怪
1. W1 开始 → 屏幕四面陆续刷出普通怪 → 朝器灵移动
2. 碰触器灵 → 每 1s 扣血（10 点），敌人停在器灵身边继续攻击
3. 被弹幕击杀 → 尸体碎裂 + 掉落经验球 → 经验球被器灵吸入

### 精英怪
4. W5 → 精英怪出现（明显比普通大，头顶血条，特殊颜色）
5. 精英怪释放冲锋技能 → 直线加速冲向器灵（有明显前摇动画）
6. 精英怪死亡 → 挂件掉落（闪亮掉落物）

### Boss
7. W15 → 清完小怪 → 屏幕震动 + 红光 + "天魔降临"大字 → Boss 从天而降
8. Boss 血条在屏幕顶部独立显示
9. Boss HP < 50% → 变红+加速 → 阶段 2
10. Boss HP < 20% → 全屏震荡波（有预警圈）→ 虚弱 3s（受伤加倍）
11. Boss HP = 0 → 爆炸粒子 + 掉落物散射 → 战斗胜利
