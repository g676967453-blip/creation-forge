## 1. 功能概述

**一句话**：类吸血鬼幸存者的全屏割草战斗。器灵在战场中央，360° 弹幕自动攻击。WASD/鼠标移动走位，海量敌人从四面涌入。升级 → 3 选 1 祝福 → 越打越密 → Boss。

**详细描述**：玩家在桌面态点击 [⚔️ 挑战] 后进入全屏战斗。器灵在战场中央，自动朝最近敌人发射弹幕（360°，无方向限制）。玩家控制器灵移动走位（WASD / 鼠标右键 / 鼠标指向），专注躲避敌人 + 构筑决策。战斗共 15 波，敌人从屏幕边缘四面涌入。击杀敌人获得经验 → 升级 → 暂停弹窗 3 选 1 祝福。精英怪每 4-5 波出现，掉落挂件。第 15 波 Boss 多阶段。胜利/死亡 → 结算 → 回桌面态。

## 2. 模块影响分析

```
触及的现有模块：
  1. GameManager — 重大修改：BATTLE 状态重构（器灵移动+360°弹幕+波次+升级判定）
  2. MainPeak（器灵战斗实体）— 重大修改：新增 WASD/鼠标移动、360° 弹幕发射逻辑
  3. WaveManager — 修改：波次配置适配 15 波+四面刷怪+精英/Boss
  4. Projectile 系统 — 修改：360° 弹道方向计算、祝福/挂件效果叠加
  5. Channel 系统 — 修改：360° 攻击通道

需要新建的模块：
  1. BattleCamera（scripts/battle/battle_camera.gd）
     职责：全屏战斗摄像机（跟随器灵微移或固定中央）+ 屏幕震动
  2. BattleInput（scripts/battle/battle_input.gd）
     职责：WASD/鼠标输入处理 → 器灵移动方向
  3. ExperienceSystem（scripts/battle/experience_system.gd）
     职责：经验累积 / 升级曲线 / 经验球掉落与拾取

不需要动的模块：
  - 桌面态/最小化态 — 独立状态
  - 弟子系统 — V3.0 砍掉
```

## 5. 信号契约

```
信号 1（新建）：battle_started()
  发射者：GameManager
  接收者：BattleCamera、WaveManager、BattleHUD、BattleInput
  时机：进入 BATTLE 状态、3 秒倒计时结束后

信号 2（新建）：battle_ended(result: String, stats: Dictionary)
  发射者：GameManager
  接收者：结算系统
  时机：Boss 死亡（胜利）或器灵 HP 归零（失败）
  参数：result — "victory"/"defeat"/"immortality"

信号 3（新建）：spirit_move_direction(dir: Vector2)
  发射者：BattleInput
  接收者：MainPeak（→移动器灵）
  时机：每帧 _process（WASD 输入 / 鼠标右键按下时指向方向）

信号 4（新建）：enemy_killed(enemy_type: String, position: Vector2)
  发射者：EnemyBase
  接收者：ExperienceSystem（→掉落经验球）、WaveManager（→波次计数）
  时机：敌人 HP ≤ 0

信号 5（新建）：experience_orb_collected(amount: int)
  发射者：MainPeak（Area2D 检测拾取）
  接收者：ExperienceSystem（→累积经验）
  时机：经验球进入拾取半径

信号 6（新建）：wave_changed(wave: int, total: int)
  发射者：WaveManager
  接收者：BattleHUD（→"第 X 波"大字）、GameManager（→记录进度）
  时机：进入新一波
```

## 6. 逻辑流程

### 6.1 入场流程

```
1. 桌面态点击 [⚔️ 挑战] → challenge_requested()
2. GameManager 检查灵气 ≥ 100：
   → 不足：提示"灵气不足"
   → 足够：Warehouse.consume_energy(100)
3. 切换窗口模式：桌面态横条 → 全屏（1280×720 或当前显示器分辨率）
4. 显示战场背景（俯视/斜 45°）+ 器灵在中央
5. 3 秒倒计时「准备迎敌」（大字居中倒数 3→2→1→战！）
6. 倒计时结束 → battle_started()
```

### 6.2 战斗主循环

```
1. BattleInput._process(delta):
   → 读取 WASD → 生成移动方向 Vector2
   → 读取鼠标右键按下 → 朝鼠标位置移动
   → 发射 spirit_move_direction(dir)
2. MainPeak._process(delta):
   → 应用移动方向 × speed × delta
   → 自动索敌（找最近敌人）→ 朝其方向发射弹幕
   → 弹幕频率 = 基础攻速 × 祝福加成 × 挂件加成
   → 弹幕方向 = (最近敌人位置 - 器灵位置).normalized()
3. WaveManager._process(delta):
   → 当前波次计时
   → 按 spawn_interval 从屏幕边缘随机位置刷怪
   → W5/W8/W11/W14 额外刷精英
   → W15 刷 Boss
4. 敌人朝器灵移动 → 碰触器灵 → 器灵扣血
5. 器灵弹幕命中敌人 → 敌人扣血 → 死亡 → 掉落经验球
```

### 6.3 经验与升级

```
1. 敌人死亡 → 掉落经验球（小光点，朝器灵微移）
2. 经验球进入器灵 80px 拾取半径 → 自动吸入 → 累积经验
3. ExperienceSystem 检查等级 → 经验满 → 发射 level_up()
4. GameManager → 暂停战斗 → 祝福选择（见 祝福系统 spec）
5. 选择完成 → 战斗恢复
```

### 6.4 波次结构

```
W1-4   热身：普通怪少量，弹道稀疏，走位为主
W5     精英：第一个精英怪（高血量+特殊技能）
W6-8   构筑成型：怪物密度增加，祝福开始叠加
W9-13  割草：流派成型，满屏弹幕+海量怪物
W11    第二个精英
W14    第三个精英
W15    Boss 战：多阶段 Boss
```

### 6.5 Boss 战

```
1. W15 开始 → 清完剩余小怪 → 2s 停顿
2. Boss 入场：屏幕震动 + 红光边框 + 大字「天魔降临」
3. 阶段 1（100%-50% HP）：标准攻击模式
4. 阶段 2（50%-20% HP）：狂暴（移动速度×1.5，攻击频率×1.5）
5. 阶段 3（<20% HP）：全屏震荡波 + 虚弱 3s（Boss 进入虚弱，受伤×2）
6. Boss 死亡 → 胜利 → battle_ended("victory")
```

## 8. 边界条件与互斥

```
☑ 战斗中切窗口/最小化？→ 战斗暂停（get_tree().paused = true），回来后继续
☑ 战斗中退出游戏？→ 自动存档（保存灵气消耗但无战斗进度），下次从桌面态开始
☑ 器灵移动到屏幕边缘？→ clamped 在战场边界内
☑ 弹幕飞出屏幕？→ 自动销毁（超出屏幕 200px → queue_free）
☑ 怪物堆积过多（性能问题）？→ 单屏最多 200 只，超过时暂停刷怪
☑ 连升 2 级？→ 依次处理（先弹第一级→选完→第二级弹出）
☑ 0 座山峰修复就进战斗？→ 允许，只有基础弹幕（1发/次，无额外能力）
☑ 战斗中器灵回血？→ 基础回血 2%/s（通过 MainPeakDefense）
```

## 11. 验收标准

### 入场
1. 桌面态点击 [⚔️ 挑战] → 灵气 ≥ 100 时进入全屏 → 3 秒倒计时
2. 灵气 < 100 → 按钮抖动 + "灵气不足"提示
3. 倒计时 "3→2→1→战！" 大字显示

### 移动
4. WASD → 器灵对应方向移动
5. 按住鼠标右键 → 器灵朝鼠标位置移动
6. 移动到战场边缘 → 停止（不穿墙）

### 攻击
7. 敌人进入屏幕 → 器灵自动朝最近敌人发射弹幕
8. 修复剑峰（弹射+1）→ 弹幕命中后弹跳一次
9. 360° 全方向攻击验证 → 敌人在器灵背后也会被锁定

### 波次
10. W1 开始 → 少量普通怪涌入
11. W5 → 精英怪出现（明显更大/颜色不同）
12. W15 → Boss 入场特效 + 多阶段 + 死亡结算

### 经验与升级
13. 击杀敌人 → 经验球掉落 → 自动吸入 → 经验条增长
14. 经验满 → 游戏暂停 → 3 选 1 祝福面板弹出
15. 选择祝福 → 面板关闭 → 战斗继续 → 效果立即生效

### 死亡/胜利
16. 器灵 HP ≤ 0 → 百世书免死 → 战斗结束（见结算系统）
17. Boss 死亡 → 胜利 → 结算面板（见结算系统）
