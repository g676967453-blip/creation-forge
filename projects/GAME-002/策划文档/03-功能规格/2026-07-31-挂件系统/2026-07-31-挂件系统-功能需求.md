# 挂件系统 — 功能需求文档

> 版本：v0.1 | 日期：2026-07-31 | 状态：策划中 | 优先级：P1
> GDD 依据：[开仙门-GDD-v3.0.md](../../01-愿景/开仙门-GDD-v3.0.md) §六.5

---

## 1. 功能概述

**一句话**：精英/Boss 掉落挂件，3 槽即时装备，改写攻击逻辑。新替旧，旧挂件消失。

**详细描述**：全屏战斗中，精英怪和 Boss 死亡后掉落挂件（Trinket）。器灵自动拾取后即时装备到对应槽位（武器/防具/饰品各 1 个，共 3 个槽位）。挂件提供特殊效果（麻痹/灼烧/减速/攻速/护盾等），直接改写弹幕攻击逻辑。当槽位已满时，新挂件替换旧挂件，旧挂件直接消失（V0.1 无背包）。挂件效果在整局战斗中持续生效，战斗结束不保留。V0.2 规划：挂件可存入背包、战斗后选择保留、挂件可升级。

## 2. 模块影响分析

```
触及的现有模块：
  1. EnemyBase — 修改：死亡掉落逻辑加入挂件掉落判定
  2. MainPeak — 修改：接收挂件效果参数 → 改写攻击逻辑
  3. Projectile 系统 — 修改：接收挂件效果（麻痹/灼烧/减速…）

需要新建的模块：
  1. TrinketManager（scripts/managers/trinket_manager.gd，RefCounted）
     职责：挂件池管理、掉落抽选、槽位管理、效果叠加、替换逻辑
  2. TrinketSlotsUI（修改 battle_hud.gd 挂件区域）
     职责：3 槽位 UI 显示——当前装备挂件图标+名称
  3. TrinketDrop（scripts/effects/trinket_drop.gd）
     职责：挂件掉落物实体（闪亮视觉效果+自动拾取）

不需要动的模块：
  - 桌面态/最小化态 — 挂件仅在战斗中
  - 仓库 — V0.1 挂件不入仓库
```

## 5. 信号契约

```
信号 1（新建）：trinket_dropped(trinket_data: TrinketData, position: Vector2)
  发射者：EnemyBase（死亡时）
  接收者：TrinketManager（→创建掉落物实体）
  时机：精英/Boss 死亡，掉落判定通过

信号 2（新建）：trinket_picked_up(trinket_data: TrinketData)
  发射者：TrinketDrop（器灵 Area2D 检测）
  接收者：TrinketManager（→装备/替换）
  时机：器灵进入拾取半径

信号 3（新建）：trinket_equipped(slot: String, trinket_data: TrinketData, replaced: TrinketData)
  发射者：TrinketManager
  接收者：MainPeak（→应用效果）、BattleHUD（→刷新槽位 UI）
  时机：挂件装备成功
  参数：slot — 槽位；trinket_data — 新挂件；replaced — 被替换的旧挂件（null = 空槽直接装）

信号 4（新建）：trinket_effect_triggered(trinket_id: String, effect_type: String, target: EnemyBase)
  发射者：MainPeak / Projectile
  接收者：目标 EnemyBase（→应用 debuff）、BattleHUD（→视觉反馈）
  时机：挂件效果触发时（如弹幕命中触发麻痹判定）
```

## 6. 逻辑流程

### 6.1 掉落

```
1. 精英/Boss 死亡 → EnemyBase._die()
2. 检查掉落表：随机判定是否掉落挂件
   → 精英：60%-100%（随波次递增）
   → Boss：100%（必掉）
   → 宝藏鼠：100% 稀有挂件
3. 从对应掉落池按权重随机选取 1 个挂件
4. 发射 trinket_dropped(trinket_data, death_position)
5. TrinketManager 创建 TrinketDrop 实体在死亡位置：
   → 闪亮掉落物（比经验球大 2x，有旋转+光晕）
   → 朝器灵方向缓慢飘移（速度 50 px/s）
```

### 6.2 拾取

```
1. TrinketDrop 每帧检测与器灵的距离
2. 距离 < 100px → 加速飞向器灵（300 px/s, 吸附动画）
3. 到达器灵 → 发射 trinket_picked_up(trinket_data)
4. TrinketManager.pick_up(trinket_data):
   → 查 trinket_data.slot 决定对应槽位
```

### 6.3 装备与替换

```
1. TrinketManager.equip(trinket_data):
   → 检查对应槽位是否为空
   → 空槽：直接装备 → 发射 trinket_equipped(slot, trinket, null)
   → 非空：弹出替换确认？
     → V0.1：不弹确认，直接替换（旧挂件销毁）
     → 发射 trinket_equipped(slot, new_trinket, old_trinket)
2. MainPeak 接收 → apply_trinket_effect(trinket_data):
   → 根据 effect_type 应用到对应系统
   → 武器槽效果 → Projectile 命中回调
   → 防具槽效果 → MainPeak 属性修改
   → 饰品槽效果 → MainPeak 属性修改
```

### 6.4 效果触发示例

```
雷灵珠（武器槽）：
  Projectile 命中敌人 → 10% 概率判定 → True?
  → 目标 EnemyBase.apply_stun(0.5)
  → 目标变灰+闪电粒子 0.5s → 恢复

火灵珠（武器槽）：
  Projectile 命中敌人 → 附加 DOT 效果
  → 目标 EnemyBase.apply_dot(5 dps, 3s)
  → 目标每 0.5s 跳橙色灼烧数字

土灵珠（防具槽）：
  装备时 → MainPeak.shield += max_hp * 0.2
  卸下时 → MainPeak.shield -= max_hp * 0.2（最低 0）
```

## 7. UI 表现

| 元素 | 表现 |
|------|------|
| 挂件掉落物 | 闪亮光球（20×20 px），带旋转+光晕，缓慢飘向器灵 |
| 吸附动画 | 进入拾取半径后加速飞向器灵，拖尾粒子 |
| 槽位 UI（战斗 HUD 底部） | 3 个小方框横向排列：[武器] [防具] [饰品]，装备后有挂件小图标+名称 |
| 空槽位 | 灰色方框+虚线边框+"空"字 |
| 装备挂件 | 图标填满方框，稀有度对应边框色（白=普通/蓝=稀有/紫=史诗） |
| 替换瞬间 | 旧图标缩小消失 + 新图标放大弹入（0.3s） |
| 挂件效果触发 | 命中敌人时：闪电特效（麻痹）/ 火焰粒子（灼烧）/ 冰霜粒子（减速） |

## 8. 边界条件与互斥

```
☑ 同一槽位已有同类型挂件？→ 直接替换，旧挂件消失
☑ 3 个槽位全满又掉新挂件？→ 新挂件替换对应槽位旧挂件
☑ 战斗结束挂件去哪？→ 全部销毁，不保留（roguelike 每局独立）
☑ 挂件掉落在屏幕外？→ 不可能，敌人在屏幕内死亡
☑ 多个挂件同时存在？→ 可以（不同精英掉的不同挂件同时在场）
☑ 挂件掉落物超过 30s 未拾取？→ 自动消失（防止堆积）
☑ 战斗中最小化 → 掉落物暂停移动
☑ 器灵死亡（免死触发）→ 已装备挂件随战斗结束销毁
```

## 11. 验收标准

### 掉落
1. W5 精英怪死亡 → 以 60% 概率掉落挂件（闪亮掉落物）
2. W15 Boss 死亡 → 100% 掉落挂件
3. 宝藏鼠击杀 → 100% 掉落稀有挂件

### 拾取与装备
4. 器灵靠近挂件掉落物（100px 内）→ 掉落物加速飞向器灵
5. 拾取后 → 战斗 HUD 对应槽位显示挂件图标
6. 空槽拾取 → 直接装备，槽位图标从空变为填充

### 效果
7. 装备「雷灵珠」→ 弹幕命中 10% 概率麻痹敌人（变灰 0.5s）
8. 装备「火灵珠」→ 弹幕命中附加 DOT 灼烧（橙色跳字）
9. 装备「风灵珠」→ 器灵攻击频率明显加快（+30%）
10. 装备「土灵珠」→ 器灵血条上多出护盾段（+20% HP）

### 替换
11. 武器槽已有「雷灵珠」→ 新掉「火灵珠」拾取 → 武器槽变为火灵珠，雷灵珠消失
12. 替换后旧效果立即移除，新效果立即生效

### 清理
13. 战斗结束（胜利/失败）→ 所有挂件效果清除 → 回桌面态后槽位全部为空
