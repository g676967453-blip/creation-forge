## 1. 功能概述

弟子是 V0.1 新增的局外出战单位。每座山峰可招募对应流派的弟子，在战斗阶段与器灵共同防守。弟子有独立属性（HP/攻击/防御/攻速/移速/射程），由玩家在经营阶段花费灵气招募。

### 在整体流程中的位置

```
[经营阶段] → 点击山峰 → 查看弟子列表 → 花费灵气招募 → 弟子出现在战场
[战斗阶段] → 弟子自动索敌攻击 → 弟子阵亡（本局不可复活）
[结算阶段] → 存活弟子无额外奖励（V0.1 简化）
```

## 4. 关键接口

```gdscript
# DataManager 查询
DataManager.get_disciple("sword_disciple") → DiscipleData
DataManager.get_all_disciples() → Array[DiscipleData]

# DiscipleSquad（挂在 GameManager 下）
disciple_squad.add_disciple(disciple_data) → Disciple
disciple_squad.get_active_disciples() → Array

# Disciple 实例
disciple.launch(from_pos, target_enemy)  # 发起攻击
disciple.take_damage(amount)             # 受伤结算
```

## 5. 与其他系统的关系

| 系统 | 关系 |
|------|------|
| 山峰系统 | 山峰修复后解锁对应弟子招募（peak_id 匹配） |
| 赐福系统 | `disciple_filter` 筛选特定弟子，`peak_filter` 筛选特定山峰弟子 |
| 法宝系统 | 法宝槽位（weapon/armor/accessory）可装备给弟子 |
| 器灵系统 | 弟子与器灵共享战场空间，独立于器灵攻击通道 |
| 经济系统 | 灵气花费招募，未来可扩展升级/装备费用 |
