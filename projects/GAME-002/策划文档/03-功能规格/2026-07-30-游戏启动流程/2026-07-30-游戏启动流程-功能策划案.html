功能定位

一句话：游戏启动后，根据是否有存档，走首次流程或再次流程，最终到达桌面放置态。

在整体游戏流程中的位置：

游戏启动 → 【本功能：启动流程编排】 → 桌面放置态（进入主循环）

核心分支逻辑：

游戏启动 → 存档检测
  ├─ 有存档 → 主菜单
  │    ├─ 继续游戏 → 读档 → 离线收益结算 → 桌面放置态
  │    ├─ 新游戏 → 确认弹窗 → 开场黑幕 → 器灵选择 → 桌面放置态
  │    └─ 设置 → 设置弹窗
  └─ 无存档 / 存档损坏 → 跳过主菜单，直接 → 开场黑幕 → 器灵选择 → 桌面放置态

不在范围内

  • 开场黑幕的逐段播放逻辑 → 见「开场黑幕」策划案
  • 器灵选择卡片的详细交互与美术 → 见「器灵选择」策划案
  • 存档数据结构的读写逻辑 → 见「存档系统」策划案
  • 离线收益的计算公式 → 见「存档系统」策划案
  • 桌面放置态的挂机机制与界面 → 见「桌面放置态」策划案
  • 键位设置、画质调节 → V0.2+
  • 诛仙剑 / 神农鼎器灵选择 → V0.2+

黄色=未定案 绿色=改动标注 蓝色=系统提示/可配置项 红色=强调

活动简述
目的：编排游戏启动到进入主循环的完整流程，根据存档状态决定走首次流程还是再次流程。
一、启动检测
一.存档检测
1.时机：游戏进程启动后，首个执行逻辑（在任何 UI 渲染之前）
2.检测逻辑：读取本地存档文件
1）文件存在且校验通过 → 进入主菜单
2）文件不存在 → 跳过主菜单，直接进入首次启动流程（开场黑幕 → 器灵选择 → 桌面态）
3）文件存在但校验失败（损坏/版本不兼容）→ 视为无存档，弹提示后直接进入首次启动流程
存档文件路径：user://save_data.json。校验：JSON 解析 + 必填字段完整性。
3.检测耗时：<100ms，不显示 loading 界面
4.失败兜底：任何检测异常 → 视为无存档，走首次流程。不卡死在启动阶段
5.关键规则：主菜单仅在「有存档」时显示。无存档时不渲染主菜单 UI，直接启动开场黑幕。
二、主菜单
一.进入条件
1.仅当存档检测为「有存档」时进入主菜单。无存档时此界面完全不出现。
二.界面元素
1.游戏标题：「开仙门」（大字，宗门主题字体）
2.三个按钮：
1）继续游戏 — 读档 → 离线收益 → 桌面态
2）新游戏 — 点击弹出确认弹窗
3）设置 — 点击弹出设置弹窗
3.背景：像素风格修仙宗门远景（暗色调，静态）
三.「继续游戏」行为
1.点击 → 读档 → 加载成功 → 显示离线收益结算 → 桌面放置态
2.读档失败 → 弹提示「存档读取失败」，回主菜单
3.加载过程：暂定简洁过渡（0.5s 淡入淡出），V0.1 不做 loading 进度条
四.「新游戏」行为
1.点击 → 弹出确认弹窗「当前进度将丢失，确定开始新游戏？」
2.确认 → 清空存档 → 进入首次启动流程（开场黑幕 → 器灵选择 → 桌面态）
3.取消 → 关闭弹窗，回主菜单
五.「设置」行为
1.点击 → 弹出设置弹窗
2.设置项（V0.1）：
1）主音量：滑块 0-100，默认 80
2）窗口模式：全屏 / 窗口化 切换，默认窗口化
① 全屏：1920×1080 或屏幕原生分辨率
② 窗口化：1280×720
3）关闭按钮：关闭弹窗，设置即时生效
3.V0.1 明确不做：键位设置、画质调节、语言切换
三、首次启动流程
一.触发条件
1.存档检测为「无存档」
2.主菜单中确认「新游戏」
二.流程步骤
1.开场黑幕（世界观叙事，逐段淡入淡出）
1）纯黑背景，白色文字逐段呈现
2）可点击/按键跳过，也可等待自动播放完毕
3）详见「开场黑幕」策划案
2.黑幕结束 → 过渡 → 器灵选择界面
1）过渡方式：0.5s 淡入淡出
2）V0.1 仅百世书可选（诛仙剑/神农鼎 V0.2+）
3）选定后确认 → 不可更改（永久绑定）→ 详见「器灵选择」策划案
3.器灵选择确认 → 过渡 → 桌面放置态
1）过渡方式：0.5s 淡入淡出
2）此时触发首次自动存档
3）进入主循环（详见「桌面放置态」策划案）
四、再次启动流程
一.触发条件
1.有存档 + 主菜单选择「继续游戏」
二.流程步骤
1.读档 → 加载游戏状态
2.计算离线收益（离线时长 × 灵气基础速率，上限 24h）
3.弹出离线收益提示：「你离开了 X 小时 X 分，器灵修炼获得 💨 +N 灵气」
1）玩家点击「确认」关闭
2）暂定自动 3s 后关闭
4.进入桌面放置态（挂机继续）
五、异常处理
一.存档损坏
1.检测到存档文件无法解析 → 弹提示「存档数据异常，将进入新游戏」
2.玩家确认 → 清空损坏存档 → 走首次启动流程
二.读档失败
1.继续游戏时读档失败 → 弹提示「存档读取失败，请重试」
2.回主菜单，不自动进入新游戏
三.启动崩溃恢复
1.暂不做崩溃恢复，V0.2 考虑
六、过渡规范
一.通用规则
1.所有界面切换使用淡入淡出过渡
2.过渡时长：0.5s
3.过渡期间不响应输入
二.例外
1.开场黑幕内部逐段切换有自己的过渡逻辑（见对应策划案）
2.设置弹窗不触发全屏过渡，仅弹窗本身淡入/淡出
