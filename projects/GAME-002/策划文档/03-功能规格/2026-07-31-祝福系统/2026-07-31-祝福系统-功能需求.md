## 1. 功能概述

**一句话**：战斗中升级时暂停弹窗，3 选 1 祝福。同类型叠满 3 张触发升阶质变，改写攻击形态。

**详细描述**：全屏战斗态中，器灵击杀敌人累积经验。经验满后升级，游戏暂停，弹出三张随机祝福卡片。玩家选择一张立即生效。祝福分三种类型：弹道型（改写攻击模式——弹射/分裂/穿透）、数值型（强化属性——攻速/伤害/范围）、特殊型（新增机制——护盾/吸血/暴击）。同一祝福线叠满 3 张触发质变跃迁（如弹射×3→闪电链式弹射），屏幕上攻击形态发生肉眼可见的变化。祝福池由已修复的山峰决定——修复越多山峰，可用祝福种类越多。

## 2. 模块影响分析

```
触及的现有模块：
  1. GameManager — 修改：BATTLE 状态下新增升级判定→暂停→弹窗→恢复流程
  2. MainPeak（器灵战斗实体）— 修改：提供 get_blessing_context() 接口供祝福效果查询
  3. Projectile / Channel 系统 — 修改：接收祝福效果参数（弹射/分裂/穿透/攻速/范围）

需要新建的模块：
  1. BlessingManager（scripts/managers/blessing_manager.gd，RefCounted）
     职责：祝福池管理（根据已修复山峰过滤）、抽卡逻辑、叠层追踪、升阶判定
  2. BlessingSelectionPanel（scenes/ui/blessing_selection_panel.tscn + scripts/ui/blessing_selection_panel.gd）
     职责：3 选 1 弹窗 UI——三张卡片展示+选中动画+确认过渡

不需要动的模块：
  - Enemy 系统 — 祝福效果在投射物/器灵层面生效
  - 桌面态/最小化态 — 祝福仅在战斗中
```

## 3. 触发条件与状态约束

| 维度 | 说明 |
|------|------|
| 触发方式 | 器灵经验满（自动触发）；开局首次（进入战斗后自动弹） |
| 前置游戏状态 | BATTLE |
| 互斥状态 | 弹出面板时游戏暂停，不允许其他操作 |
| 可重复性 | 每局战斗可触发多次（上限约 10-15 次） |
| 开局特殊规则 | 首次进入战斗 → 固定弹一次开局祝福（卡池含 1 张弟子卡/召唤卡的概率→V3.0去掉弟子，改为全部祝福卡） |

## 4. 数据定义

### 4.1 祝福类型

| 类型 | 说明 | 示例 | 叠满 3 张质变 |
|------|------|------|-------------|
| 弹道型 | 改写攻击模式 | 弹射+1 / 分裂+1 / 穿透+1 | 质变跃迁 |
| 数值型 | 强化属性 | 攻速+30% / 伤害+50% / 范围+20% | 质变跃迁 |
| 特殊型 | 新增机制 | 护盾 / 吸血5% / 暴击15% | 质变跃迁 |

### 4.2 祝福升阶质变表

| 祝福线 | 1 级 | 2 级 | 3 级（质变） |
|--------|------|------|-------------|
| 弹射 | +1 弹射 | +2 弹射 | 闪电网（链式弹射，每次弹跳再弹 2 次） |
| 分裂 | +1 分裂 | +2 分裂 | 扇形 5 发（前方 60° 扇形同时发射） |
| 穿透 | +1 穿透 | +2 穿透 | 穿透翻倍 + 回旋（弹幕穿到底后折返） |
| 攻速 | +20% | +40% | 双倍攻击间隔（每 tick 发射 2 发） |
| 伤害 | +30% | +60% | 暴击率+20% + 暴击伤害 200% |
| 范围 | +15% | +30% | 全屏覆盖（弹幕尺寸变大，射程全覆盖） |
| 护盾 | 20% HP 护盾 | 40% HP 护盾 | 护盾破裂时释放冲击波（击退+伤害） |
| 吸血 | 5% 吸血 | 10% 吸血 | 过量治疗转为护盾 |
| 暴击 | 10% 暴击 | 20% 暴击 | 暴击时产生闪电链（弹跳 3 次） |

### 4.3 祝福解锁条件

| 祝福线 | 前置山峰 | 解锁条件 |
|--------|---------|---------|
| 弹射 | 剑峰 | 初始解锁（修复剑峰后） |
| 护盾 | 佛峰 | 修复佛峰后解锁 |
| 分裂 | 法峰 | 修复法峰后解锁 |
| 穿透 | 兽峰 | 修复兽峰后解锁 |
| 范围 | 器峰 | 修复器峰后解锁 |
| 伤害 | 魂峰 | 修复魂峰后解锁 |
| 攻速 | — | 初始解锁（无前置山峰） |
| 吸血 | — | 初始解锁 |
| 暴击 | — | 初始解锁 |

### 4.4 祝福 CSV 配置

```
☑ CSV 已创建 → data/blessing_config.csv（27 行：9 条祝福线 × 3 层质变）

CSV 文件名：data/blessing_config.csv
列定义：
  blessing_id,string,,祝福唯一 ID（如"ricochet_1"）
  blessing_line,string,,祝福线（如"ricochet"）
  tier,int,1,层级（1/2/3，3 为质变）
  type,string,,类型（"projectile"/"stat"/"special"）
  display_name,string,,显示名称
  description,string,,效果描述
  effect_key,string,,效果键（如"ricochet_count"）
  effect_value,float,0,效果数值
  required_peak,string,,前置山峰（空=初始可用：攻速/吸血/暴击）
  rarity,string,"common",稀有度（common:15/rare:10/epic:5）
  weight,int,10,抽卡权重（common=15, rare=10, epic=5）
```

## 5. 信号契约

```
信号 1（新建）：experience_gained(current: int, max: int)
  发射者：MainPeak
  接收者：GameManager（→判断是否升级）
  时机：每次击杀敌人时

信号 2（新建）：level_up(level: int)
  发射者：GameManager
  接收者：BlessingManager（→抽卡）、BattleHUD（→刷新等级显示）
  时机：经验满时

信号 3（新建）：blessing_selection_ready(cards: Array[BlessingData])
  发射者：BlessingManager
  接收者：GameManager（→暂停战斗→显示选择面板）
  时机：抽卡完成

信号 4（新建）：blessing_selected(blessing_data: BlessingData)
  发射者：BlessingSelectionPanel
  接收者：GameManager → BlessingManager（→应用效果→叠层检查→升阶判定）
  时机：玩家选中一张卡片

信号 5（新建）：blessing_applied(blessing_id: String, effect_changes: Dictionary)
  发射者：BlessingManager
  接收者：MainPeak（→应用属性变化）、ProjectileManager（→应用弹道变化）、BattleHUD（→显示效果提示）

信号 6（新建）：blessing_transformed(blessing_line: String, tier: int, new_effect: String)
  发射者：BlessingManager
  接收者：BattleHUD（→大字提示"升阶！闪电网"）+ MainPeak（→切换攻击形态视觉）
  时机：叠满 3 张触发质变时
```

## 6. 逻辑流程

### 6.1 升级触发

```
1. 战斗中敌人死亡 → MainPeak 获得经验
2. MainPeak 发射 experience_gained(current_exp, max_exp)
3. GameManager 判断：current_exp >= max_exp？
   → 是 → 发射 level_up(new_level)
   → 否 → 继续战斗
```

### 6.2 抽卡

```
1. GameManager 发射 level_up()
2. BlessingManager.draw_cards(count=3):
   → 获取当前已修复山峰列表 → 过滤可用祝福池
   → 按权重随机抽取 3 张（不重复）
   → 若可用池 < 3 → 全部抽出，剩余空位填"灵气+50"万能卡
3. 发射 blessing_selection_ready(cards)
```

### 6.3 玩家选择

```
1. GameManager 接收 blessing_selection_ready → 切换子状态 BLESSING_SELECTION
2. 暂停所有敌人移动 + 弹幕飞行（get_tree().paused = true，或仅暂停逻辑层）
3. 显示 BlessingSelectionPanel，三张卡片动画飞入
4. 玩家点击一张 → 卡片高亮 → 0.3s 确认动画 → blessing_selected()
5. BlessingManager.apply(blessing_data):
   → 查该祝福线的当前叠层 count
   → count < 2：应用效果（+1 层）
   → count == 2：应用效果 + 触发升阶质变（发射 blessing_transformed）
6. 关闭面板 → get_tree().paused = false → 战斗继续
```

### 6.4 升阶质变

```
1. 弹射 count == 2 → 第 3 张弹射祝福 → count 变为 3
2. BlessingManager 检测 count == 3 → 触发 blessing_transformed("ricochet", 3, "闪电网")
3. MainPeak 接收：
   → 弹射逻辑从"单次弹跳"切换为"链式弹射（每次弹跳再弹 2 次）"
   → 投射物视觉从青色单线变为白色闪电链
4. BattleHUD 显示大字「升阶！闪电网」+ 0.5s 全屏特效
```

## 8. 边界条件与互斥

```
☑ 战斗中切换最小化/退出？→ 祝福选择面板不弹，状态保存，回来后继续
☑ 连续升级（经验溢出连升 2 级）？→ 依次处理：弹窗→选择→关闭→立即弹第二级
☑ 祝福池为空（0 座山峰修复）？→ 只有攻速/吸血/暴击 3 条初始线，抽不满 3 张时补万能卡
☑ 同一祝福线叠满 3 张后还出现吗？→ 不再出现（从卡池移除）
☑ 游戏频繁暂停影响手感？→ 弹窗仅在升级时，每局约 10-15 次
☑ 弹窗不选能继续战斗吗？→ 不能，必须选完才能继续（强制决策）
☑ 祝福效果跨波次保留吗？→ 是，整局战斗中累积
☑ 进入下一局战斗？→ 所有祝福重置（roguelike 每局独立构筑）
```

## 11. 验收标准

### 升级触发
1. 击杀敌人 → 经验条增长
2. 经验条满 → 游戏暂停 → 弹出 3 张祝福卡片
3. 连升 2 级 → 先弹第一级，选完立即弹第二级

### 卡片选择
4. 3 张卡片可见，各有名称+图标+描述
5. 鼠标悬停卡片放大
6. 点击一张 → 选中动画 0.3s → 效果应用 → 面板关闭 → 战斗继续
7. 不选不能继续（验证：战斗不恢复）

### 祝福效果
8. 选"弹射+1"→ 投射物命中后弹跳 1 次
9. 选"攻速+20%"→ 器灵发射频率明显加快
10. 选"护盾"→ 器灵出现护盾条

### 升阶质变
11. "弹射"选满 3 次 → 触发"闪电网"质变 → 全屏大字+粒子特效
12. 质变后 → 攻击形态明显变化（单弹跳→链式闪电弹跳）
13. 已质变的祝福线 → 后续不再出现在卡池

### 祝福池范围
14. 修复 0 座山峰 → 只有攻速/吸血/暴击可选
15. 修复剑峰 → 弹射线加入卡池
16. 修复 6 座山峰 → 全部 9 条线都加入卡池
