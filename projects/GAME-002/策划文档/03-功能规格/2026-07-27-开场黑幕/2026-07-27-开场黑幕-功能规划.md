# 开场黑幕 — 功能规划文档

> 版本：v1 | 日期：2026-07-27 | 基于：[01-功能策划](../../../docs/workflows/01-功能策划.md)

---

## §1 在整体流程中的位置

```
游戏启动 → 开场黑幕（本功能）→ 器灵选择 → 经营阶段 → ...
```

- **触发时机**：玩家首次进入游戏时自动播放
- **再次进入**：已有存档时跳过，直接进入器灵选择
- **衔接上游**：无（这是游戏入口）
- **衔接下游**：黑幕结束 → 器灵选择界面（MainPeakSelectPanel）

---

## §2 界面描述

### 待机状态
- 纯黑背景（`#000000`），无任何 UI 元素
- 居中白色文字（阿里巴巴普惠体 20px），逐段淡入

### 播放状态
- 4 段叙事文字依次自动播放
- 每段文字淡入（opacity 0→1，持续 1s）→ 停留（2s）→ 淡出（1s）→ 下一段
- 总时长约 16 秒（4 段 × 4s）

### 快进状态
- 点击屏幕任意位置 或 按任意键 → 跳过当前段直接进入下一段
- 最后一段时快进 → 直接结束，进入器灵选择

### 完成状态
- 最后一段文字淡出 → 0.5s 黑屏过渡 → 器灵选择界面出现

### 异常状态
- 无（纯叙事播放，无网络/数据依赖）

---

## §3 交互方式

| 操作 | 反馈 |
|------|------|
| 不操作 | 文字依次自动播放，16s 播完 |
| 点击屏幕 | 当前段立即结束，下一段开始（或进入器灵选择） |
| 按任意键（Enter/Space/ESC） | 同上 |
| ESC（最后一段之前） | 快进到下一段（不跳过整个黑幕） |
| ESC（最后一段时） | 进入器灵选择 |

## §4 美术与体验需求

| 类型 | 需求 | 优先级 |
|------|------|--------|
| UI | 黑幕背景（纯黑，无元素） | P0 |
| 文字 | 4 段世界观叙事文本，居中对齐，白色 | P0 |
| 动画 | 文字淡入淡出（opacity tween） | P0 |
| 音效 | 每段文字出现时的低沉音效（类似心跳/钟声） | P1 |
| 配音 | 每段文字的旁白配音（低沉男声，中文） | P1 |
| 字幕 | 文字与配音同步高亮 | P2（后期） |

## §5 模块边界

### 涉及模块
- `intro_screen.gd`（已有，需修改）— 负责播放黑幕叙事
- `game_manager.gd` — INTRO 状态管理（已有）
- `audio_manager`（待建或复用）— 音效/配音播放

### 不涉及模块
- CSV 数据表（内容硬编码在脚本中）
- EconomyManager、MountainManager（经营阶段才用到）
- 网络/存档（首次进入判断由 GameManager 处理）

### 输入
- 无

### 输出
- 信号 `intro_finished` → GameManager 切换到 MAIN_PEAK_SELECT 状态

---

## §6 数据流向

```
（无外部数据输入）
  ↓
intro_screen.gd
  ├── 硬编码 4 段文本
  ├── 播放文字动画
  ├── （可选）播放音效/配音
  └── 发射 intro_finished 信号
        ↓
  game_manager.gd
        ├── 接收信号
        └── set_state(MAIN_PEAK_SELECT)
```

- 文本内容不存 CSV（纯叙事，非游戏数据）
- 首次进入标记由 GameManager 的内存状态处理（不涉及存档读写）

---

## §7 与其他功能的衔接

- **进入条件**：`GameState.INTRO`，GameManager `_ready()` 中判断
- **退出条件**：全部文字播完 或 最后一段时用户快进
- **互斥关系**：播放期间不响应任何其他 UI 操作（除了快进）
- **前置依赖**：无
- **下游功能**：器灵选择（MainPeakSelectPanel）

---

## §8 什么不算

- ❌ 动画视频/过场 CG（只有静态文字淡入淡出）
- ❌ 跳过按钮 UI（点击任意位置即快进，不需要独立按钮）
- ❌ 背景图/渐变/云海（纯黑）
- ❌ 存档/读档（首次进入判断由 GameManager 的内存状态处理，不写磁盘）
- ❌ 配音的语音识别/字幕同步高亮（P2）
