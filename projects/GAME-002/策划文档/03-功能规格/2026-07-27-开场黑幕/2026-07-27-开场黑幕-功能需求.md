## §6 逻辑流程

### 主流程

```
1. GameManager._ready()
   → 判断首次进入（内存状态，无存档）
   → set_state(GameState.INTRO)

2. UIStateCoordinator 激活 IntroScreen

3. intro_screen._ready()
   → 显示纯黑背景
   → current_index = 0
   → 播放第 0 段文字（淡入）
   → 启动 auto_play_timer（4s 间隔）

4. auto_play_timer.timeout()
   → 当前段淡出
   → current_index += 1
   → 如果 current_index < 4：
       → 播放下一段文字（淡入）
       → （P1）播放对应音效
       → （P1）播放对应配音
       → 重置定时器
   → 如果 current_index >= 4：
       → 发射 intro_finished 信号

5. GameManager 收到 intro_finished
   → set_state(GameState.MAIN_PEAK_SELECT)
```

### 快进流程

```
用户点击/按键 → _input(event)
  → 如果 event is InputEventMouseButton 或 InputEventKey：
    → 当前段立即淡出
    → 停止 auto_play_timer
    → current_index += 1
    → 如果 current_index < 4：
        → 播放下一段（淡入）
        → 重启 auto_play_timer
    → 如果 current_index >= 4：
        → 发射 intro_finished 信号
```

### 已有存档时

```
GameManager._ready()
  → 判断非首次进入
  → 跳过 INTRO，直接 set_state(GameState.MAIN_PEAK_SELECT)
```

## §7 UI 表现

- 纯黑 ColorRect 覆盖全屏（z_index = 最高层）
- 文本 RichTextLabel 居中，白色 `#FFFFFF`，字体大小 20px，行高 28px
- 淡入：modulate.a 0→1，Tween 1s
- 淡出：modulate.a 1→0，Tween 1s
- 无任何 UI 按钮、指示器

## §8 边界条件

| 场景 | 预期行为 |
|------|---------|
| 播放中连续点击 | 每次点击只跳一段（防止连点跳过全部） |
| 播放中按 ESC | 与点击行为一致：快进一段 |
| 最后一段时快进 | 直接进入器灵选择（不走淡出动画） |
| 音频加载失败 | 静默跳过音频，文字正常播放（不阻塞） |
| 字体加载失败 | 回退到系统默认字体 |
| 非首次进入 | 完全跳过 INTRO，不产生任何副作用 |
| 定时器未触发时退出 | Tween 被 kill，不报错 |
| 播放中最小化窗口 | 定时器继续计时（不暂停） |
| 资源路径错误 | 打印 warning，不影响文字播放 |

## §10 验收标准

- [ ] 首次启动 → 黑幕 → 4 段文字依次自动淡入淡出
- [ ] 总时长约 16 秒（可接受 ±2s 偏差）
- [ ] 点击/按键 → 快进到下一段
- [ ] 最后一段结束 → 进入器灵选择界面
- [ ] 非首次启动（重新进入游戏）→ 跳过黑幕，直接器灵选择
- [ ] 无音频文件时不报错，文字正常播放
- [ ] 快进时不能连跳（每次点击只跳一段）
