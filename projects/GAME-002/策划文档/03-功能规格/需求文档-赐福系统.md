## 1. 功能概述

赐福是 V0.1 新增的局外随机增益系统。每次战斗前或特定触发条件（修复山峰/升级功法/特殊事件），玩家从随机池中 3 选 1 获得赐福。赐福分为 3 种类别（弟子/技法/增益）× 4 种稀有度（普通/稀有/史诗/传说），每局可叠加多个。

### 在整体流程中的位置

```
[经营阶段] → 触发赐福条件 → 弹窗 3 选 1 → 应用赐福效果
[战斗阶段] → 赐福被动生效（数值加成/触发效果）
[结算阶段] → 赐福随本局结束清空（roguelike 特性）
```

## 4. 关键接口

```gdscript
# DataManager 查询
DataManager.get_blessing("bless_crit") → BillData
DataManager.get_all_blessings() → Array[BillData]

# BillManager（挂在 GameManager 下）
blessing_manager.draw_blessing_candidates(count: int, filters: Dictionary) → Array[BillData]
blessing_manager.apply_blessing(blessing: BillData) → void

# BillData 字段
blessing.category      # "disciple" | "technique" | "buff"
blessing.tier           # "common" | "rare" | "epic" | "legend"
blessing.effect_type    # 效果类型标识
blessing.effect_value   # 效果数值
blessing.disciple_filter # 目标弟子 ID（空=全部弟子）
blessing.peak_filter     # 目标山峰 ID（空=全部山峰）
```

## 5. 与其他系统的关系

| 系统 | 关系 |
|------|------|
| 弟子系统 | 弟子类赐福通过 `disciple_filter` / `peak_filter` 定向加成 |
| 器灵系统 | 增益类赐福直接修改器灵属性（护甲/闪避/格挡） |
| 卡牌系统 | 赐福与卡牌是平行的 roguelike 构筑层，互不覆盖 |
| 战斗系统 | 技法类赐福影响全局伤害公式（穿透/暴击/弹射） |
| 经济系统 | 可能复用灵气作为赐福"重抽"费用 |
