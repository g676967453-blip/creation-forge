## 1. 功能概述

**一句话**：100×100 px 器灵打坐悬浮小窗，可拖动到桌面任意位置。后台持续挂机累积灵气，点击展开回桌面态。

**详细描述**：最小化态是桌面上一个 100×100 px 的无边框悬浮窗，显示器灵的卡通像素形象（带呼吸/打坐循环动画）。窗口始终置顶、可拖动到桌面任意位置。后台挂机灵气照常累积（与桌面态相同的累积速率，包括器灵+山峰加成）。点击悬浮窗展开回桌面放置态。V0.2 可扩展：显示灵气数字、挂机 buff 图标、挑战入口。

## 2. 模块影响分析

```
触及的现有模块：
  1. GameManager — 修改：新增 MINIMIZED 状态处理
  2. UIStateCoordinator — 修改：新增 minimized_panel 管理
  3. EnergyAccumulator（新建）— 读：灵气累积在最小化态持续进行
  4. WindowStateManager（新建）— 依赖：窗口大小/位置/置顶/拖动

需要新建的模块：
  1. MinimizedPanel（scenes/ui/minimized_panel.tscn + scripts/ui/minimized_panel.gd）
     职责：器灵小窗 UI——头像+动画+点击事件+拖动处理

不需要动的模块：
  - 所有战斗模块 — 最小化态不涉及战斗
  - 山峰系统 — 不在小窗中显示
  - 存档系统 — 不因最小化触发存档（定时存档独立运作）
```

## 3. 触发条件与状态约束

| 维度 | 说明 |
|------|------|
| 触发方式（进入） | 桌面态点击 [_ 最小化] 按钮 |
| 触发方式（退出） | 点击悬浮小窗 → 展开回桌面态 |
| 前置游戏状态 | DESKTOP_IDLE |
| 互斥状态 | BATTLE / 不可在战斗中最小化（V0.1） |
| 可重复性 | 可多次切换 |
| 窗口特性 | 100×100 px，无边框，始终置顶，可拖动 |

## 4. 数据定义

### 4.1 窗口参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 窗口尺寸 | 100×100 px | V0.1 固定；V0.2 可配置 |
| 初始位置 | 屏幕右下角（距右 20px，距下 40px） | 避免遮挡任务栏 |
| 拖动后位置 | 记忆（存于内存，不写入存档） | V0.2 可写入存档 |
| 置顶 | 始终 | 不被他窗口遮挡 |
| 背景 | 透明（器灵 + 轻微阴影） | 融入桌面 |

### 4.2 显示内容（V0.1）

| 元素 | 说明 |
|------|------|
| 器灵动画 | 器灵当前形态的 Q 版头像（约 80×80 px），呼吸/打坐循环动画 |
| 点击区域 | 整个 100×100 窗口可点击 → 展开回桌面态 |
| 可拖动 | 整个窗口可拖到桌面任意位置 |

### 4.3 V0.2 扩展（本次不实现）

| 扩展 | 说明 |
|------|------|
| 灵气数字 | 窗口右上角浮动显示当前灵气数 |
| buff 图标 | 有小图标显示挂机加速是否激活 |
| 右键菜单 | 右键 → "展开" / "退出游戏" |
| 气泡提示 | 偶尔冒出修炼中的文字泡（"修炼中…"） |

## 5. 信号契约

```
信号 1（新建）：minimized_clicked()
  发射者：MinimizedPanel
  接收者：GameManager（→切换到 DESKTOP_IDLE）
  时机：玩家点击悬浮小窗

信号 2（新建）：minimized_drag_ended(new_position: Vector2)
  发射者：MinimizedPanel
  接收者：WindowStateManager（→保存位置偏好，内存中）
  时机：拖动结束

信号 3（新建）：minimized_entered()
  发射者：GameManager
  接收者：MinimizedPanel（→显示小窗+启动动画）、EnergyAccumulator（→确认继续累积）
  时机：切换到 MINIMIZED 状态完成

信号 4（新建）：minimized_exited()
  发射者：GameManager
  接收者：MinimizedPanel（→隐藏小窗+停止动画）
  时机：离开 MINIMIZED 状态
```

## 6. 逻辑流程

### 6.1 进入最小化态

```
1. 桌面态点击 [_ 最小化] → state_transition_requested("desktop_idle", "minimized")
2. GameManager 切换到 MINIMIZED：
   → 桌面态 UI 面板隐藏
   → 发射 minimized_entered()
3. WindowStateManager.switch_to_minimized():
   → set_size(100, 100)
   → 读取记忆位置（或默认右下角）
   → set_always_on_top(true)
   → 无边框模式
4. MinimizedPanel 显示：
   → 器灵当前形态的 Q 版头像（spirit_level → 对应精灵帧）
   → 呼吸动画开始（缩放 1.0⇄1.05，周期 2s）
   → V0.1 可选：偶尔打坐光晕特效
5. EnergyAccumulator 继续灵气累积（无变化）
```

### 6.2 拖动

```
1. 玩家鼠标按下 100×100 窗口
2. MinimizedPanel._input(event):
   → 检测 InputEventMouseButton（左键按下）
   → 进入拖动模式
3. 每帧更新窗口位置 = 鼠标位置 - 按下偏移
4. 鼠标释放 → 发射 minimized_drag_ended(new_position)
5. WindowStateManager 记录位置（内存，下次最小化用此位置）
```

### 6.3 退出（展开回桌面态）

```
1. 玩家点击小窗 → InputEventMouseButton（判断非拖动）
   → 区分逻辑：点击（按下+释放 < 200ms 且移动 < 5px）→ 展开
   → 拖动（移动 > 5px）→ 不触发展开
2. 发射 minimized_clicked()
3. GameManager → state_transition_requested("minimized", "desktop_idle")
4. 三态切换系统接管（展开动画 → 桌面态）
```

### 6.4 离线处理

```
1. 最小化态中退出游戏 → 存档时的 offline_timestamp 正常记录
2. 下次启动 → 桌面态 → 计算离线收益（包括最小化态的时间段）
3. 离线收益上限 24h 照常适用
```

## 7. UI 表现

| 状态 | 表现 |
|------|------|
| 待机（默认） | 器灵 Q 版头像 80×80 px 居中，呼吸动画循环（1.0⇄1.05 缩放，2s 周期） |
| 悬停 | 窗口轻微放大（1.0→1.05），出现微弱光晕边框 |
| 拖动中 | 窗口跟随鼠标移动，半透明（alpha 0.8） |
| 拖动放下 | 恢复不透明（alpha 1.0），停留在新位置 |
| 点击 | 窗口闪烁（0.1s 白色高亮）→ 展开过渡 |
| 器灵外观 | 根据 spirit_level（0-6）显示不同形态：0=残破古书→1-2=半展开书卷→3-4=完整经书→5-6=金色符文环绕经书 |

## 8. 边界条件与互斥

```
☑ 拖动到屏幕外？→ clamp 到屏幕范围内（至少 20px 可见）
☑ 拖动时触发点击？→ 区分逻辑：移动 > 5px = 拖动，否则 = 点击
☑ 多显示器？→ V0.1 仅主显示器。V0.2 可跨屏拖动
☑ 窗口遮挡任务栏？→ 初始位置避开任务栏（默认右下角距边缘 20-40px）
☑ 战斗中能最小化吗？→ V0.1 不能。桌面态专属入口
☑ 最小化后注销/锁屏？→ Godot 窗口被系统隐藏，进程继续。解锁后窗口恢复
☑ 最小化窗口被其他全屏应用遮挡？→ 置顶模式下仍可能被全屏游戏覆盖（Windows 限制），可接受
```

## 11. 验收标准

### 进入/退出
1. 桌面态点击 [_ 最小化] → 窗口缩小至 100×100，出现在右下角
2. 点击小窗 → 展开回 1280×120 桌面态横条
3. 展开后所有元素（山峰/资源栏/按钮）正常显示

### 动画
4. 小窗中器灵有呼吸动画（可见缩放循环）
5. 器灵外观与 spirit_level 对应（0=残卷，6=金色经书）
6. 悬停时有微弱光晕边框

### 拖动
7. 按下并移动鼠标 → 小窗跟随移动
8. 拖动中小窗半透明（alpha 0.8）
9. 松开鼠标 → 恢复不透明 + 停留新位置
10. 快速点击（不移动）→ 拖放不触发，点击展开触发

### 挂机
11. 最小化后 10 秒 → 切回桌面态 → 灵气增加了约 100（10/s 基础）
12. 最小化态退出游戏 → 下次启动 → 离线收益包含最小化态时间

### 边界
13. 拖动到屏幕边缘 → 窗口不跑出屏幕（至少 20px 可见）
14. 被其他窗口遮挡？→ 置顶始终可见（桌面模式下）
