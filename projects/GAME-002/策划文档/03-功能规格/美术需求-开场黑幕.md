## 2. 交互需求

> 来源：功能需求 §6「逻辑流程」+ §7「UI 表现」

### 2.1 界面状态

| 状态 | 视觉效果 | 可交互 |
|------|---------|--------|
| **动画播放中** | 纯黑底，4 段文字逐段从透明淡入白色 | ✅ 点击/按键 → 快进 |
| **全部显示** | 纯黑底，4 段文字全白，底部提示可见 | ✅ 点击/按键 → 结束 |
| **完成退出** | 整个界面隐藏 | ❌（已离开该界面） |
| **再次显示** | 如重新 visible 且未完成，重播淡入动画 | 同"动画播放中" |

### 2.2 交互流程

```
游戏启动
  │
  ▼
[动画播放中] ──点击/按键──→ [全部显示] ──点击/按键──→ [结束] → 器灵选择
  │                              │
  └── ESC ───────────────────────┴── ESC ──→ [结束] → 器灵选择
```

### 2.3 交互细节

| 操作 | 触发条件 | 即时反馈 | 结果 |
|------|---------|---------|------|
| 点击鼠标左键 | `InputEventMouseButton` pressed | 动画中→文字和提示立即显示(快进)；已显示→界面消失 | 快进或结束 |
| 按任意键盘键 | `InputEventKey` pressed | 同点击 | 快进或结束 |
| 按 ESC | GameManager 层拦截 | 直接跳过 | 切换至器灵选择 |

### 2.4 信息架构

| 显示内容 | 数据来源 | 类型 |
|---------|---------|------|
| 4 段世界观文字 | `INTRO_PARAGRAPHS` 常量数组（硬编码） | 静态文本 |
| "点击任意处继续" | `_build_tips()` 硬编码 | 静态提示 |

> 无 CSV 依赖，无动态数据绑定。

## 3. 视觉方向

> 来源：功能需求 §7「UI 表现」+ [美术绘制规范 v2](../../美术制作/开仙门-美术绘制规范-v2.md) 色彩体系

### 3.1 风格定位

**基调**：极简、庄重、沉浸感。通过"纯黑 + 白字 + 慢速淡入"营造"万年后从黑暗中苏醒"的叙事氛围。

**设计意图**：开场黑幕不需要华丽的视觉装饰——信息量越低，玩家的注意力越集中在文字叙事上。纯黑背景是最有效的"留白"。

### 3.2 色彩

| 用途 | 色值 | 说明 |
|------|------|------|
| 背景 | `Color(0, 0, 0, 1)` 纯黑 | 全屏无纹理 |
| 正文 | `Color.WHITE` 纯白 | 最大对比度，保证可读性 |
| 提示文字 | `#4D4D61` 深灰蓝 | 低对比度，提示性文字不应喧宾夺主 |

> 与项目暗色修仙基调完全一致（参考美术绘制规范 v2 第三章色彩体系）。

### 3.3 字体与排版

| 属性 | 值 |
|------|-----|
| 字体 | 阿里巴巴普惠体 55 Regular（`AlibabaPuHuiTi-3-55-Regular.woff2`） |
| 正文字号 | 20px |
| 正文行高 | 28px |
| 提示字号 | 12px |
| 文字区域宽度 | 840px |
| 对齐 | 文字区域内两端对齐（`AUTOWRAP_WORD_SMART`），整体垂直居中 |
| 段落间距 | 28px（等同于行高，视觉上为空一行） |

### 3.5 动画

| 动画 | 描述 | 时长 |
|------|------|------|
| 文字逐段淡入 | 4 段文字按顺序 α: 0→1，Tween 顺序播放 | 0.9s/段（总计 ~3.6s） |
| 提示淡入 | 末段文字结束后，底部提示 α: 0→1 | 0.6s |
| 快进 | Tween kill + 全部节点 α 直接设为 1.0 | 瞬时 |

> 以上均为代码 Tween 动画，不需要帧序列资产。

## 4. 美术资产清单

> 来源：功能需求 §7-附「美术与体验需求」

### 4.1 UI 元素

无新增。纯黑背景由代码 `ColorRect` 渲染，文字由代码 `Label` 渲染。

### 4.2 图标

无。

### 4.3 插图 / 原画

无。

### 4.4 动画帧

无。所有动画为代码 Tween，不依赖外部帧序列。

### 4.5 VFX

无。文字淡入为 Godot Tween 代码动画，无粒子特效需求。

### 4.6 SFX

无。
