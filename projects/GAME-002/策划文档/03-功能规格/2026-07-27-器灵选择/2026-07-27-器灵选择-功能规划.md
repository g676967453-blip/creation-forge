# 器灵选择 — 功能规划

> 状态：[规划完成] | 验证日期：2026-07-27 | 基准：[器灵系统-功能规划](../器灵系统-功能规划.md)
> 本功能是器灵系统的子功能，聚焦「选择器灵」这一 UI 流程。

---

## 1. 在整体流程中的位置

```
[游戏启动] → [开场黑幕] → [选择器灵] → [经营阶段主场景]
                                ↑              ↓
                          仅首次进入       [下山历练] ⇄ [战斗]
                                                ↓
                                           通关 → 回经营
                                   （器灵永久绑定，不重选）
```

开场黑幕和器灵选择是两个独立子功能，各自有独立的功能规划/需求/美术需求文档。

---

## 2. 界面描述

### 2.1 选择界面（默认状态）

- 深色云海背景，中央百世书卡片居中展示
- 百世书卡片：亮色，可点击（古书/卷轴意象，金色边框 `#f0c040`，240×320）
- 左右两侧各一个空槽位（灰色虚影，标注"???"，暗示未来有更多器灵）
- 底部「开始游戏」按钮（未选中时置灰）
- 顶部标题"选择器灵"（金色，32px）

### 2.2 操作状态

- 点击百世书卡片 → 卡片高亮（金色光晕脉冲）
- 「开始游戏」按钮变为可点击（金色渐变亮色）
- 再次点击 → 取消选中，按钮置灰

### 2.3 完成态

- 点击「开始游戏」→ 面板淡出（~1s）+ 卡片飞入器灵位置 → 进入经营主场景
- 器灵绑定（不可更换）

## 4. 美术与体验需求

### 4.1 界面美术（UI）

| 资源 | 类型 | 尺寸 | 说明 |
|------|------|------|------|
| 器灵选择背景 | 贴图 | 1280×720 | 深色云海背景，星光粒子 |
| 百世书卡片 | 图标+底板 | 240×320 | 金色边框，古书居中，圆角8px |
| 开始按钮 | 贴图（4态） | 200×48 | 默认/悬浮/按下/禁用，金色渐变 |
| 标题文字 | 字体 | — | "选择器灵"，32px，金色 `#f0c040`，居中 |

### 4.2 器灵图标

| 资源 | 尺寸 | 说明 |
|------|------|------|
| 百世书图标（卡片用） | 80×64 | 古书/卷轴，金色系，展开状态 |
| 百世书图标（小） | 64×64 | 同上，经营阶段器灵位置使用 |

### 4.3 视觉特效（VFX）

| 特效 | 触发时机 | 表现描述 | 持续时间 |
|------|---------|---------|---------|
| 卡片高亮 | 选中器灵 | 金色光晕脉冲（scale 1.0→1.05，alpha 呼吸） | 循环 |
| 确认过渡 | 点击开始 | 面板淡出 + 卡片缩小飞入器灵位置 | ~1s |

### 4.4 音效（SFX）

| 音效 | 触发时机 | 风格描述 | 优先级 |
|------|---------|---------|--------|
| 卡片选中 | 点击百世书 | 清脆古风点击音 | P2 |
| 确认选择 | 点击开始按钮 | 庄严厚重 | P2 |

## 5. 模块边界草图

```
涉及的系统：
  ☑ UI 系统 — MainPeakSelectPanel 选择面板、过渡动画
  ☑ 器灵（MainPeak）— 器灵数据绑定（set_form + set_meta）
  ☑ 数据层 — spirit_profile_config.csv

明确不涉及：
  - 多器灵解锁系统 — V0.3
  - 经营阶段器灵展示 — 属器灵系统其他子功能
  - 战斗系统 — 器灵战斗表现属于战斗模块
```

---

## 6. 数据流向草图

```
spirit_profile_config.csv（器灵档案：id/名称/特性/图标）
      ↓
  DataManager 加载 → get_all_spirit_profiles()
      ↓
  MainPeakSelectPanel 读取 → 渲染卡片
      ↓
  玩家选择 → _update_selection(profile_id)
      ↓
  点击开始 → 发射 start_game_requested 信号
      ↓
  GameManager._on_start_game_requested() → set_form(icon_path) → 切换到 PREPARATION
```

---

## 7. 与其他功能的衔接

| 维度 | 说明 |
|------|------|
| 进入条件 | 开场黑幕结束 → INTRO 状态完成 → 进入 MAIN_PEAK_SELECT |
| 退出条件 | 确认选择后进入经营阶段，此后**不再返回** |
| 互斥功能 | 选择阶段不能进行经营或战斗操作 |
| 前置依赖 | 开场黑幕（intro_screen.gd 发射 intro_finished 信号） |
| 后续触发 | 器灵永久绑定，特性影响战斗失败处理（百世书免死） |

---

## 8. 验收标准

1. 开场黑幕结束后 → 看到器灵选择界面，百世书居中展示
2. 点击百世书 → 卡片高亮（金色光晕），开始按钮亮起
3. 再次点击百世书 → 取消高亮，按钮置灰
4. 点击开始 → 面板淡出过渡动画 → 进入经营场景
5. 器灵永久绑定，无法返回更改
