## 1. 功能概述

**一句话**：战斗结束后的结算流程——胜利获得材料+挂机加速 buff，失败触发百世书免死（无惩罚回桌面态）。

**详细描述**：全屏战斗态结束时，根据结果（胜利/失败/免死）进入不同的结算流程。胜利：清完 15 波并击败 Boss → 获得女娲石 ×1 + 流派秘宝 ×1（随机或对应 Boss 类型）+ 灵气奖励 + 限时挂机加速 buff。失败（百世书）：器灵 HP 归零 → 触发免死动画 → 回桌面态，无惩罚。失败（其他器灵，V0.2+）：Game Over，重新开始。结算完成后回到桌面放置态，刷新所有资源显示。

## 2. 模块影响分析

```
触及的现有模块：
  1. GameManager — 修改：新增 BATTLE_RESULT 状态，区分胜利/免死/失败流程
  2. EconomyManager — 修改：结算奖励入库（灵气/女娲石/秘宝）
  3. SpiritManager — 读：免死触发（immortality_triggered 信号已定义）
  4. DesktopIdlePanel — 修改：接收结算完成 → 刷新资源显示
  5. SaveManager — 触发保存（结算后自动存档）

需要新建的模块：
  1. SettlementPanel（scenes/ui/settlement_panel.tscn + scripts/ui/settlement_panel.gd）
     职责：结算界面 UI——结果标题+奖励列表+统计+返回按钮

不需要动的模块：
  - 战斗内模块（WaveManager/Enemy/BlessingManager）— 战斗已结束
  - 山峰系统 — 结算不涉及
```

## 3. 触发条件与状态约束

| 维度 | 说明 |
|------|------|
| 触发方式 | 自动：Boss 死亡（胜利）/ 器灵 HP ≤ 0（免死/失败） |
| 前置游戏状态 | BATTLE |
| 结算后状态 | DESKTOP_IDLE |
| 互斥状态 | 结算中不可操作其他界面 |
| 可重复性 | 每局战斗结束触发一次 |

## 4. 数据定义

### 4.1 胜利奖励

| 奖励 | 数量 | 说明 |
|------|------|------|
| 女娲石 | ×1 | 修复山峰通用材料 |
| 流派秘宝 | ×1 | 随机 6 种之一（或与 Boss 类型对应，V0.1 随机） |
| 灵气 | 累计（战斗内击杀数 × 1） | 战斗击杀奖励灵气 |
| 挂机加速 buff | +50% 灵气产出速率，持续 30 分钟 | 限时增益 |

### 4.2 失败（百世书免死）

| 结果 | 说明 |
|------|------|
| 免死动画 | 1.5s 百世书虚影 + 金光 + 「百世轮回，护你真灵不灭」 |
| 惩罚 | 无（V0.1） |
| 保留 | 不获得任何战利品，已消耗的挑战灵气不返还 |
| 进入战斗前灵气 | 已被消耗（进入挑战的 100 灵气），不返还 |

### 4.3 失败（其他器灵，V0.2+）

| 结果 | 说明 |
|------|------|
| Game Over | 需要重新开始（新档） |

## 5. 信号契约

```
信号 1（新建，复用现有概念）：battle_ended(result: String, stats: Dictionary)
  发射者：GameManager
  接收者：SettlementPanel（→显示结算界面）
  时机：Boss 死亡 / 免死触发
  参数：result — "victory" / "immortality" / "defeat"
        stats — { waves_completed, enemies_killed, time_elapsed, damage_dealt, blessings_collected }

信号 2（新建）：settlement_closed()
  发射者：SettlementPanel
  接收者：GameManager（→切换 DESKTOP_IDLE）
  时机：玩家点击"返回"或结算面板自动关闭

信号 3（新建）：rewards_distributed(rewards: Dictionary)
  发射者：GameManager
  接收者：EconomyManager（→入库）、DesktopIdlePanel（→刷新资源栏）、SaveManager（→触发存档）
  时机：结算奖励确定后
```

## 6. 逻辑流程

### 6.1 胜利结算

```
1. Boss HP ≤ 0 → Boss 死亡动画（2s 碎裂消散）
2. GameManager 收集战斗统计：
   → waves_completed: 15
   → enemies_killed: 总击杀数
   → time_elapsed: 战斗时长
   → damage_dealt: 总伤害
   → blessings_collected: 本局获得祝福数
3. 计算奖励：
   → 女娲石 ×1
   → 流派秘宝 ×1（从 6 种中随机）
   → 灵气 = 击杀数 × 1
   → 挂机加速 buff：能量产出速率 ×1.5，持续 30 分钟
4. 发射 battle_ended("victory", stats)
5. SettlementPanel 显示：
   → 标题「仙门大开！」（大字金色）
   → 统计摘要（波次/击杀/时长/祝福数）
   → 奖励列表（逐个弹出动画）
   → 「返回」按钮
6. 玩家点击「返回」→ rewards_distributed → 回桌面态
```

### 6.2 免死结算

```
1. 器灵 HP ≤ 0 → SpiritManager.trigger_immortality()
2. 免死动画播放（1.5s）
3. 发射 battle_ended("immortality", stats)
4. SettlementPanel 显示：
   → 标题「百世轮回」（大字银灰色）
   → 副标题「护你真灵不灭」
   → 统计摘要（波次/击杀/时长）
   → 提示：无奖励获得，已消耗灵气不返还
   → 「返回」按钮
5. 玩家点击「返回」→ 回桌面态（器灵 HP 自动回满）
```

### 6.3 加速 buff 管理

```
1. 胜利结算 → GameManager 设置 buff_timer
2. EnergyAccumulator 查询 buff_active → 应用 ×1.5 倍率
3. DesktopIdlePanel 显示 buff 图标 + 剩余时间倒计时
4. buff 到期 → EnergyAccumulator 恢复正常倍率 → buff 图标消失
5. 离线期间 buff 时间继续计算（如果离线 30min+，上线时 buff 已过期）
```

## 8. 边界条件与互斥

```
☑ 结算面板弹出时退出游戏？→ 自动保存（奖励已入库），下次启动进桌面态
☑ 免死后瞬间再进战斗？→ 允许，器灵 HP 已回满
☑ Buff 时间内再次胜利？→ 刷新 buff 时长（重新开始 30 分钟，不叠加）
☑ Buff 时间内离线？→ 离线期间 buff 时间照常流逝
☑ 6 种秘宝已集齐再掉同一种？→ 允许（可重复拥有），山峰修复只需 1 个
☑ 免死后器灵 HP 状态？→ 回桌面态自动回满
☑ Boss 和器灵同时死亡？→ 免死优先，不算胜利
```

## 11. 验收标准

### 胜利结算
1. Boss 死亡 → 战斗结束 → 结算面板弹出
2. 面板显示：标题"仙门大开！"、波次 15/15、击杀数、时长、祝福数
3. 奖励逐条弹出：女娲石 ×1 → 秘宝 ×1 → 灵气 +N → 加速 buff
4. 点击"返回宗门"→ 回到桌面态，资源栏数字已更新
5. 桌面态显示加速 buff 图标 + 倒计时
6. 灵气产出速率确认为 1.5x（基础 10/s → 15/s）

### 免死结算
7. 战斗中器灵 HP 归零 → 免死动画（1.5s 书影+金光）→ 结算面板
8. 面板显示"百世轮回，护你真灵不灭"，无奖励列表
9. 点击"返回宗门"→ 桌面态，器灵 HP 满，灵气/材料无变化

### 存档
10. 结算后退出游戏再进入 → 资源与结算时一致
11. 加速 buff 离线期间照常计时 → 上线时可能已过期

### 边缘
12. Boss 和器灵同时死亡 → 免死触发优先 → 进入免死结算（不算胜利）
13. 胜利回桌面后立即再挑战 → 上次 buff 继续生效（剩余时间）
