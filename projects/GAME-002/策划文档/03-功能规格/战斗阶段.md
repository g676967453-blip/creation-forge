## 1. 功能概述

**一句话**：玩家进入战斗阶段，器灵自动攻击敌人，撑过 10 波或器灵被摧毁。

**详细描述**：经营阶段结束后，玩家点击"开始战斗"，倒计时 1.5 秒后进入 BATTLE 状态。器灵按当前装备的功法自动攻击扇形范围内的敌人。每波敌人从场外生成、沿路径走向器灵。击杀敌人获得经验，经验满后弹出三选一卡牌升级面板。10 波全清则胜利，器灵血量归零则失败。战斗中玩家不可操作山峰，仅通过卡牌选择影响战局。

## 2. 模块影响分析

```
触及的现有模块：
  1. GameManager — 状态切换（PREPARATION→BATTLE）、倒计时、升级弹窗、胜败判定
  2. WaveManager — 波次调度（start_battle、start_next_wave）、敌人实例化
  3. MainPeak/main_peak.gd — 战斗激活/停用、自动攻击、HP 管理
  4. CardManager — 升级时提供可选卡牌、应用卡牌效果
  5. BattleHUD/scripts/ui/battle_hud.gd — 波次/敌数/灵气/HP/经验/等级显示
  6. EnemyBase/enemy_base.gd — 敌人移动、受击、死亡
  7. DataManager — 读取 wave_config / enemy_config / main_peak_config / card_config
  8. ResultPanel/scripts/ui/result_panel.gd — 胜败结算面板

需要新建的模块：
  （无——战斗阶段全部使用现有模块）

不需要动的模块（明确排除）：
  - MountainManager — 战斗中玩家不操作山峰
  - peak_base.gd — 战斗中山峰不参与
  - MountainSelectPanel / RepairPromptPanel — 经营阶段 UI，战斗时不显示
```

## 5. 信号契约

```
现有信号（复用）：

battle_started()
  发射者：GameManager
  接收者：WaveManager、BattleHUD、MainPeak
  时机：倒计时结束后
  说明：WaveManager 开始生成敌人、MainPeak 开始攻击、BattleHUD 显示

battle_ended(result: String)
  发射者：GameManager
  接收者：ResultPanel
  时机：10 波全清（"victory"）或器灵 HP=0（"defeat"）
  参数：result — "victory" 或 "defeat"

wave_changed(wave_index: int)
  发射者：WaveManager
  接收者：BattleHUD（通过 GameManager 转发）
  时机：每波开始
  参数：wave_index — 当前波次（0-based）

enemy_count_changed(count: int)
  发射者：WaveManager
  接收者：BattleHUD（通过 GameManager 转发）
  时机：敌人死亡/生成时

enemy_killed(exp: int, spirit: int)
  发射者：EnemyBase
  接收者：GameManager
  时机：敌人 HP 归零
  参数：exp/spirit — 该敌人的经验值和灵气值

level_up(new_level: int)
  发射者：GameManager
  接收者：CardManager、BattleHUD
  时机：经验值达到升级阈值
  说明：CardManager 准备卡牌选项，BattleHUD 更新等级显示

card_selected(card_id: String)
  发射者：CardSelectionPanel
  接收者：CardManager、GameManager
  时机：玩家在升级面板中选择一张卡牌

main_peak_hp_changed(current: float, max_hp: float)
  发射者：MainPeak
  接收者：BattleHUD（通过 GameManager 转发）
  时机：器灵 HP 变化时
```

## 6. 逻辑流程

```
主流程：
  1. 玩家点击"开始战斗" → GameManager.start_battle()
  2. 状态切换到 BATTLE，MainPeak 暂停攻击
  3. 显示倒计时 "第 1 波即将来临"（1.5s）
  4. 倒计时结束 → 发射 battle_started()
  5. WaveManager 读 wave_config.csv，逐波生成敌人
  6. MainPeak 恢复攻击，按 attack_interval 发射投射物
  7. 敌人沿路径移动 → 被投射物命中扣血 → HP=0 死亡 → 发射 enemy_killed
  8. GameManager 累加经验/灵气 → 更新 BattleHUD
  9. 经验满 → 暂停战斗（paused=true）→ 弹出 CardSelectionPanel
  10. 玩家选卡 → CardManager 应用效果 → 恢复战斗（paused=false）
  11. 重复 5-10，直到波次结束

分支流程：
  - 10 波全清 → 发射 battle_ended("victory") → ResultPanel 显示胜利
  - 器灵 HP=0 → 发射 battle_ended("defeat") → ResultPanel 显示失败
  - 倒计时期间游戏被重置 → 检查 current_state != BATTLE，取消后续流程

异常处理：
  - main_peak 引用为空 → 跳过攻击逻辑，不崩溃
  - wave_config.csv 读取异常 → DataManager 返回空数组，WaveManager 不生成敌人
```

## 7. UI 表现

| 状态 | 表现 |
|------|------|
| 正常战斗 | BattleHUD 顶部栏显示：波次(N/10)、剩余敌数、Lv.X、经验条、灵气值、HP/HP条 |
| 倒计时 | 屏幕中央大字"第 X 波即将来临"，1.5 秒后消失 |
| HP 低于 30% | HP 条变红（Color(1, 0.2, 0.2)） |
| 升级弹窗 | 三选一卡牌面板居中，背景半透明遮罩，游戏暂停 |
| 卡牌选中 | 卡牌高亮→应用效果→面板消失→战斗继续 |
| 胜利 | ResultPanel 显示"胜利"，统计击杀/波次/灵气 |
| 失败 | ResultPanel 显示"失败"，统计击杀/波次/灵气 |
| 空态 | BattleHUD 默认不可见，仅在 BATTLE 状态下显示 |

## 8. 边界条件与互斥

```
☑ 能重复操作吗？不能——start_battle() 检查 current_state != PREPARATION 时直接 return
☑ 有数值上下限吗？HP 下限 0（触发失败），经验无上限（持续升级）
☑ 和其他功能互斥吗？战斗中不可操作山峰、不可修复、不可选择功法
☑ 数据不够时：wave_config 为空时 WaveManager 不生成敌人；card_config 为空时跳过升级弹窗
☑ 极端值处理：HP=0 时立即触发失败；wave_index 超出配置时触发胜利
☑ 快速连续点击"开始战斗"：start_battle() 的状态检查防止重复触发
☑ 操作中途切换状态：倒计时期间 BATTLE 状态被重置则取消后续流程
☑ 器灵攻击间隔在暂停期间：get_tree().paused=true 时自动暂停（Godot 引擎级别）
```

## 11. 验收标准

1. 经营阶段点击"开始战斗" → 显示倒计时 "第 1 波即将来临"，1.5 秒后战斗开始
2. 第 1 波生成 50 只疾冲魔（红色、speed=60、沿直线路径） → HUD 显示 "波次 1 / 10"、"剩余：50"
3. 器灵自动发射投射物攻击进入范围的敌人 → 敌人 HP 条减少
4. 敌人到达器灵 → 器灵 HP 条实时更新（500→逐渐减少），低于 30% 时 HP 条变红
5. 击杀敌人 → 经验条增长、灵气值增加
6. 经验满 → 游戏暂停，弹出三选一卡牌面板，每张卡显示 card_name 和 description
7. 选择卡牌 → 面板消失，游戏恢复，卡牌效果生效（如伤害+20%、攻速+15%）
8. 10 波全部清完 → 显示胜利面板
9. 器灵 HP=0 → 显示失败面板
10. 第 5 波包含 1 只巨兽（紫色、speed=20、HP=300） → 巨兽比普通敌人大、移动慢、更耐打
11. 第 10 波包含 1 只天魔（暗红色、speed=30、HP=800） → Boss 体型最大
12. 战斗中点击山峰/修复按钮 → 无反应
13. 倒计时期间切换场景 → 战斗取消，不崩溃
