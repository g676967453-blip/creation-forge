# 开仙门-核心名词统一表 v1

项目名称：`开仙门`  
文档类型：`核心名词统一表`  
版本：`v1`  
用途：统一策划文档中核心系统的命名，减少后续写作与沟通歧义。

## 1. 战斗核心名词

| 名词 | 定义 | 备注 |
|---|---|---|
| 器灵 | 战斗唯一核心与失败判定主体 | 不可替代 |
| 器灵法阵 | 围绕器灵展开的战场中枢区域 | 峰主回阵、法宝共鸣中心 |
| 山峰 | 道统流派 | 不是具体技能 |
| 功法 | 山峰下的具体战斗路线 | 不是简单上位替代 |
| 峰主 | 该峰唯一可出战的护法单位 | 普通弟子不出战 |
| 普通弟子 | 战外养成、产出、修炼单位 | 不参与器灵战斗 |

## 2. 成长系统名词

| 名词 | 定义 | 备注 |
|---|---|---|
| 天赋池 | 局内随机成长系统总称 | 对外可表现为机缘/悟道 |
| 功法天赋 | 围绕当前主修功法的成长项 | 主构筑核心 |
| 峰主天赋 | 强化峰主的成长项 | 中后期深化 |
| 法宝天赋 | 围绕已携带法宝的成长项 | 第二构筑轴 |

## 3. 法宝系统名词

| 名词 | 定义 | 备注 |
|---|---|---|
| 法宝 | 局外炼制、局内展开变化的长期资产 | 第二长期成长轴 |
| 本命法宝 | 直接强化器灵本体的法宝 | 核心法宝 |
| 护卫法宝 | 围绕器灵自动行动的法宝 | 偏防线与自动输出 |
| 领域法宝 | 改变器灵周边战场规则的法宝 | 偏结界与范围影响 |
| 法宝共鸣 | 功法、峰主、法宝满足条件后的强化联动 | 局内核心变化 |

## 4. 续航相关名词

| 名词 | 定义 | 备注 |
|---|---|---|
| 续航 | 生存维度总称 | 不等于回血 |
| 回血 | 生命值恢复机制 | 只放特定功法与法宝 |
| 护体 | 护盾、减伤、免伤等非回血生存手段 | 可较普遍存在 |

## 5. 统一命名原则

- 不再使用“卡牌强化”作为正式系统名，统一使用 `天赋池`
- 不再把山峰与功法混为一体，统一区分 `山峰 = 道统`、`功法 = 路线`
- 不再把普通弟子视作战斗单位，统一明确 `只有峰主随器灵出战`
- 法宝统一定义为 `局外炼宝 + 局内共鸣` 系统
