## 2. 普攻

### 数值层

| 属性 | 值 |
|------|-----|
| 发射物 | 1 把飞剑 |
| 伤害 | 等级攻击力（见 §6） |
| 攻速 | 等级攻速（见 §6） |
| 射程 | 等级射程（见 §6） |
| 弹道速度 | 520 px/s（基础值） |

### 逻辑层

```
timer 归零 → 生成飞剑 → 按索敌优先级找目标 → 直线飞行 → 命中
```

- 飞剑命中后消失（无回旋、无穿透，除非天赋加持）
- 连射（Lv9+）：每轮并列 2 发，左右各偏移 8px
- 穿透（天赋/卡牌）：飞剑命中后不消失，穿透继续飞行

### 表现层

- 青色半透明飞剑精灵，拖尾粒子
- 命中敌人：火花粒子特效
- 暴击时：命中特效强化

## 3. 核心机制：剑意追击

> 集中火力攻打同一目标，伤害越叠越高。

### 数值层

| 属性 | 值 |
|------|-----|
| 最大层数 | 5 层 |
| 每层增伤 | +8%（叠满 +40%） |
| 暴击叠层 | 一次暴击 +2 层 |
| 衰减规则 | 目标 3 秒未被命中，层数清零 |
| 切换目标 | 新目标从 0 层开始 |

### 逻辑层

```
飞剑命中目标
  → 目标不是当前锁定目标？→ 旧目标开始 3 秒衰减倒计时
  → 目标 = 当前锁定目标，锁定目标更新
  → 是暴击？→ 层数 +2
  → 非暴击？→ 层数 +1
  → 层数上限 5
  → 该目标后续所有飞剑伤害 × (1 + 层数 × 0.08)
  → 3 秒内再次命中 → 重置倒计时
  → 3 秒到期 → 层数清零
```

此机制鼓励玩家集中火力打一个高价值目标（先远程、再精英、再 BOSS），体现「单体」定位。

### 表现层

- 目标身上浮现旋转小剑标记，数量 = 当前层数（1~5 把）
- 层数越高小剑转速越快
- 叠满 5 层瞬间：目标身上爆发一次小范围剑气光华
- 衰减时：小剑逐渐变暗直至消失

## 4. 万剑归宗（大招）

### 数值层

| 属性 | 值 |
|------|-----|
| CD | 25 秒（Lv3 解锁） |
| CD 随等级缩减 | 每级 -0.5 秒（Lv3=25s → Lv17=18s） |
| 飞剑总数 | 50 把 |
| 每把伤害倍率 | 2.0× 等级攻击力 |
| 扇面角度 | 180° |
| 扇面半径 | 230 px（飞剑悬浮排列位置） |
| 发射间隔 | 0.04 秒/把（依次高速射出，总时长约 2 秒） |
| 释放方式 | CD 归零自动释放 |

### 逻辑层

```
CD 归零
  → 器灵暂停普攻 0.3 秒（起手）
  → 50 把飞剑在器灵上方 180° 扇形悬浮排列
  → 依次高速射出（每把间隔 0.04 秒）
  → 未射出的飞剑保持悬浮
  → 每把飞剑各自锁定射程内敌人（优先均分，每目标最多 5 把）
  → 命中叠加剑意层数
  → CD 重新开始计时
```

- Lv < 3：大招不可用，CD 条隐藏/锁定
- 天赋「快攻」3 级：每发飞剑命中 -0.1 秒 CD（加快大招循环）
- 大招飞剑同样享受暴击判定和剑意加成

### 表现层

- **CD 中**：HUD 底部技能图标显示扇形倒计时扫光（类似魔兽世界技能冷却）
- **CD 就绪**：图标亮起、外框闪烁金光
- **悬浮**：50 把飞剑以器灵为圆心，180° 扇面排列，半径 230px。每把剑沿半径方向放置：剑尖朝外、剑柄指向圆心
- **射出**：依次高速离弦，每把飞剑带青色拖尾和音效
- **全部射出后**：残留短暂剑痕消散

## 7. 天赋树

御剑诀 **4 个天赋方向**，每个可选 **3 次**，逐级质变。选满 3 次后移出卡池。

| 天赋 | 1级 | 2级 | 3级 |
|------|-----|-----|-----|
| **齐射** | 弹道 +1，伤害 -10% | 取消伤害惩罚 | 弹道再 +1（累计 +2） |
| **强化** | 伤害 +60% | 暴击伤害 +50% | 暴击时无视目标护甲 |
| **快攻** | 攻速 +100% | 弹道飞行速度 +50% | 每发命中 -0.1 秒大招 CD |
| **穿透** | 穿透 +1，伤害 -20% | 取消伤害惩罚 | 穿透敌人后伤害翻倍 |

## 8. 伤害计算

```
单发伤害 = 等级攻击力 × (1 + 卡牌伤害加成) × (1 + Lv6 最终增伤) × 连射惩罚

剑意加成后 = 单发伤害 × (1 + 剑意层数 × 0.08)

暴击时     = 上者 × 等级暴击伤害 × (1 + 强化2级暴伤加成)

无视护甲   = 暴击时若强化3级已激活，忽略目标 armor 值
```

大招飞剑同样适用此公式（单发伤害额外 × 2.0 大招倍率）。

| 章节 | 性质 | 差异点 |
|------|------|--------|
| §1 身份定位 | 个性 | 标签 2 词、攻击类型、防御类型、索敌优先级 |

每个功法的 §2~§5 严格遵循 **数值层 / 逻辑层 / 表现层** 三板块格式。
