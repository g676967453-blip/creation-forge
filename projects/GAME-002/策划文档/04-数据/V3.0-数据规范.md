## 0. 总原则

1. **CSV 是运行时数值的最终真相**（CSV > 代码 > 设计文档）。
2. 字段名全小写 snake_case；ID 全英文小写（命名约定见规则决策表第 10 章）。
3. 本规范定义的是 **v3.0 目标结构**。现有 CSV 的迁移方式见第 11 章冲突清单，**由 Codex 统一执行**。

## 1. game_config.csv（🆕 新建，全局常量表）

**为什么需要**：经济与战斗常量目前散落在各 spec 的「const 常量」表述中且数值互相冲突（25/s vs 10/s），需要单一真源。结构为 3 列键值表，一行一个常量。

| 字段名 | 类型 | 必填 | 默认值 | 取值范围或枚举 | 用途 | 示例值 |
|--------|------|------|--------|---------------|------|--------|
| key | string | ✓ | — | 见下方 key 清单 | 常量键 | `energy_base_rate_per_sec` |
| value | float | ✓ | — | ≥0 | 常量值 | `10` |
| desc | string | ✗ | 空 | 任意 | 中文说明 | `灵气基础速率（每秒）` |

**v0.1 key 清单（逐行）：**

| key | value | 说明 |
|-----|-------|------|
| `energy_base_rate_per_sec` | 10 | 灵气基础速率（/秒） |
