## 四、战斗逻辑设计

### 4.1 防御判定链

```
敌人 damage 输入
  → evasion（完全闪避，randf < defense_value）
  → block（固定减伤，defense_value + summon_block_extra）
  → spirit_armor（固定减伤，0-14）
  → shield（护盾吸收，defense_value × max_hp × (1+shield_boost)）
  → spirit_def（%减伤，0-8%）
  → current_hp -= 剩余
```

lifesteal 在**造成伤害**侧触发（不在受击侧）。

### 4.2 Channel 并行攻击

每个激活的山峰 → 一个 attack channel。所有 channel 独立计时、独立攻击：

| attack_type | 攻击模式 | 目标选择 |
|-------------|---------|---------|
| projectile | 单发/多发弹道 | 最近敌人（射程内） |
| sector | 扇形范围伤害 | 角度+射程内所有敌人 |
| summon | 召唤物管理 | 召唤物自主索敌 |

## 六、数值公式

```
单功法 DPS = damage × projectile_count / attack_interval
带暴击 DPS = dps × (1 + crit_rate × (crit_dmg - 1))
对护甲 DPS = max(1, damage - armor) × count / interval（最低 1）
混合 DPS = Σ 各 channel DPS

器灵总 HP = base(500) × hp_multiplier + Σ spirit_hp_bonus
受击伤害 = max(0, raw_dmg - block - spirit_armor) × (1 - spirit_def%)
```
