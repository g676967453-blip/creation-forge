## 二、流程 1：选择器灵

### 流程

```
首次游戏启动
  ↓
器灵选择界面
  ├─ 百世书        ✅ 可选
  ├─ 诛仙剑        🔒 通关后解锁
  └─ 神农鼎        🔒 通关后解锁
  ↓
选择百世书 → 确认 → 进入经营阶段
```

### 器灵特性

| 器灵 | 解锁条件 | 特性 |
|------|---------|------|
| 百世书 | 初始 | 战斗失败免死，回到经营（V0.1 无惩罚，后续扣器灵升阶经验） |
| 诛仙剑 | 通关一次 | 待定 |
| 神农鼎 | 通关二次 | 待定 |

### 器灵绑定与成长

- **永久绑定**：器灵选定后不能更换
- **器灵升级**：随山峰修复进度提升
  - 每修复一座山峰 → 器灵获得一次强化（属性提升/解锁新能力）
  - 六座全修 → 器灵达到最终形态

### 当前代码基础

- `spirit_profile_config.csv` 已有 3 个档案
- `MainPeakSelectPanel` 已实现选择界面
- 需修改：增加解锁条件逻辑、百世书免死逻辑

### 弟子系统

| 项目 | 说明 |
|------|------|
| 招募 | 山峰界面招募，归属该峰，学习该峰功法 |
| 升级 | 战斗获得经验 + 消耗灵气快速升级 |
| Lv1-9 | 统一模板（基础属性成长） |
| Lv10 | 突破筑基，随机获得特殊天赋模板 |
| 出战条件 | 筑基以上（Lv ≥ 10） |
| 出战上限 | 全场最多 5 名，每峰最多 1 名 |

### 资源

| 资源 | 用途 | 获取方式 |
|------|------|---------|
| 灵气 | 修复剑峰(500)、修复其他峰(5,000)、招募弟子、弟子快速升级 | 点击器灵 + 自动产出 + 战斗掉落 |
| 流派秘宝 | 修复对应山峰（每峰 1 个） | 前期剧情掉落、后期特定副本 |
| 女娲石 | 修复山峰通用材料（每峰 1 个） | 前期剧情掉落、后期特定副本 |
| 功法升级材料 | 提升功法等级 | 战斗胜利掉落 |

## 四、流程 3：战斗阶段

### 定位

5 人小队塔防。器灵坐镇后方（主塔），最多 5 名筑基弟子出战。180°扇面战场。弟子自动战斗，玩家负责构筑决策。

### 完整战斗流程

```
┌─────────────────────────────────────────────┐
│ 1. 出战确认                                  │
│                                              │
│  确认出战阵容 → 「开始历练」                   │
└─────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────┐
│ 2. 进入战场                                  │
│                                              │
│  3 秒倒计时 + 「准备迎敌」                     │
│  出战弟子从器灵两侧列阵                        │
└─────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────┐
│ 3. 开局祝福 3 选 1                           │
│                                              │
│  ┌──────┐  ┌──────┐  ┌──────┐              │
│  │弟子D  │  │弹射   │  │攻速   │              │
│  │(召唤) │  │祝福   │  │祝福   │              │
│  └──────┘  └──────┘  └──────┘              │
│                                              │
│  选一张 → 立即生效                            │
└─────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────┐
│ 4. 波次战斗（W1 → W15）                      │
│                                              │
│  ┌─ 击杀怪物 → 经验 + 灵气                    │
│  ├─ 击杀精英怪 → 掉落挂件/材料                │
│  ├─ 击杀宝藏鼠 → 稀有掉落，限时追打            │
│  ├─ 触发幸运转盘 → 随机 buff/挂件/灵气         │
│  │                                           │
│  ├─ 升级 → 祝福 3 选 1                       │
│  │    ├─ 弟子卡 → 召唤新弟子 / 弟子升星        │
│  │    ├─ 功法祝福 → 改写技能逻辑（弹射/分裂/穿透）│
│  │    └─ 增益祝福 → 数值强化                   │
│  │                                           │
│  ├─ 同类型叠满 3 张 → 升阶质变                │
│  │   例：弹射×3 → 闪电网                       │
│  │                                           │
│  └─ 挂件掉落 → 即时装备 → 改写技能             │
│      例：「雷灵珠」→ 闪电网附加麻痹            │
│                                              │
│  波间：2s 停顿 + 「第 X 波」大字提示            │
└─────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────┐
│ 5. Boss 战（W15）                            │
│                                              │
│  入场：屏幕震动 + 红光 + 「天魔降临」           │
│  阶段1（100%-50%HP）：标准                    │
│  阶段2（50%-20%HP）：狂暴（速度×1.5）          │
│  阶段3（<20%HP）：全屏震荡波 → 虚弱 3s         │
└─────────────────────────────────────────────┘
```

### 战斗核心系统

#### 祝福系统

| 类型 | 效果 | 示例 |
|------|------|------|
| 弟子卡 | 召唤新弟子 / 弟子升星 | 召唤剑修弟子 |
| 功法祝福 | 改写攻击逻辑 | 弹射+1、分裂、穿透 |
| 增益祝福 | 数值强化 | 攻速+30%、伤害+50% |

**升阶**：同类型叠满 3 张 → 质变

| 祝福线 | 1 级 | 2 级 | 3 级（质变） |
|--------|------|------|-------------|
| 弹射 | +1 | +2 | 闪电网 |
| 分裂 | +1 | +2 | 扇形 3 发 |
| 穿透 | +1 | +2 | 穿透翻倍 |

#### 挂件系统

精英怪/宝藏鼠掉落，即时装备，改写技能逻辑。

| 挂件 | 效果 |
|------|------|
| 雷灵珠 | 麻痹（10% 晕 0.5s） |
| 火灵珠 | 灼烧（3s DOT） |
| 冰灵珠 | 减速（30%，2s） |
| 风灵珠 | 攻速+30% |
| 土灵珠 | 护盾（20% HP） |

#### 敌人类型

| 类型 | 行为 | 掉落 |
|------|------|------|
| 普通怪 | 直冲器灵 | 经验、灵气 |
| 精英怪 | 高血量、特殊技能 | 挂件、材料 |
| 宝藏鼠 | 快速逃跑、限时击杀 | 稀有挂件 |
| Boss | 多阶段 | 功法升级材料、山峰修复材料 |

#### 幸运转盘

战斗中途随机触发。转盘包含：挂件、30s buff、灵气翻倍、立即祝福选择。

### 割草节奏

| 阶段 | 体验 |
|------|------|
| W1-4 热身 | 弟子少、弹道稀 |
| W5-8 构筑成型 | 祝福叠起来、挂件装备上 |
| W9-13 割草 | 流派成型，全屏弹幕 |
| W14-15 Boss | 构筑检验 |

## 五、流程 4：结算阶段

### 胜利

```
Boss 死亡
  ↓
结算界面
  ├─ 获得功法升级材料
  ├─ 获得山峰修复材料
  ├─ 获得灵气
  └─ 弟子获得战斗经验
  ↓
回到经营阶段（材料可用于修复更多山峰）
  ↓
修复 + 招募 + 培养 → 再次历练
```

### 失败

```
器灵 HP 归零
  ↓
判断器灵类型
  ├─ 百世书
  │    → 「百世书护体」免死
  │    → 扣除部分经验
  │    → 回到经营阶段（可继续）
  │
  └─ 其他器灵
       → Game Over
       → 完全重新开始（新档）
```
