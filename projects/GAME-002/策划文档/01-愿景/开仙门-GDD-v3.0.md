# 《开仙门》游戏设计文档（GDD）

**版本：** 3.0
**日期：** 2026-07-30
**类型：** 桌面伴侣 × 放置挂机 × 吸血鬼幸存者
**题材：** 修仙 × 像素
**目标平台：** PC（Godot 4.7）
**窗口模式：** 多态切换（全屏战斗 / 桌面横条 / 悬浮小窗）
**对标参考：** 摸鱼小镇（放置态）+ 吸血鬼幸存者（战斗态）

> **方向变更说明**：v2.0（塔防）→ v3.0（吸血鬼+放置）。核心玩法从"弟子小队塔防"重构为"器灵弹幕割草"。弟子系统砍掉，经营系统精简为放置挂机。详见 §十 变更记录。

---

## 一、游戏概述

### 1.1 一句话描述

**桌面上的修仙宗门。** 器灵在屏幕底部挂机修炼，点一下「挑战」切全屏，360° 弹幕割草。

### 1.2 三种界面状态

```
┌──────────────────────────────────────────────────────┐
│  状态 1：全屏战斗态                                    │
│                                                      │
│  类吸血鬼幸存者。器灵在战场中央，360° 弹幕自动攻击。       │
│  海量敌人从四面涌来。升级 → 3选1祝福 → 越打越密。        │
│  Boss 每 N 波。胜利/死亡 → 回桌面态。                   │
│                                                      │
│  进入：桌面态点击 [⚔️ 挑战]                             │
│  退出：战斗结束 / 主动退出                              │
└──────────────────────────────────────────────────────┘
                          ↕
┌──────────────────────────────────────────────────────┐
│  状态 2：桌面放置态（1280 × 120 px，贴屏幕底部）          │
│                                                      │
│  横板侧视图。像素风格修仙宗门。                          │
│  器灵在中央打坐修炼。六座山峰分布两侧。                   │
│  灵气自动累积。修复山峰解锁器灵新能力。                   │
│                                                      │
│  常态界面，始终可见，偶尔互动。                          │
└──────────────────────────────────────────────────────┘
                          ↕
┌──────────────────────────────────────────────────────┐
│  状态 3：最小化态（可拖到屏幕任意位置）                    │
│                                                      │
│  一个器灵卡通形象，有呼吸/打坐动画。                      │
│  后台持续挂机累积灵气。可拖动到桌面任意位置。              │
│  点击 → 展开回桌面态。                                 │
└──────────────────────────────────────────────────────┘
```

### 1.3 核心循环

```
桌面放置态（常态，挂机累积资源）
  │
  │  灵气自动增长
  │  偶尔操作：修复山峰 / 点击收菜
  │
  ├─ [⚔️ 挑战] ──→ 消耗灵气，进入全屏战斗
  │
  ▼
全屏战斗态（吸血鬼割草）
  │
  │  器灵 360° 弹幕自动攻击
  │  击杀敌人 → 经验 → 升级 → 3选1祝福
  │  精英/Boss → 挂件掉落
  │  越打越密 → 割草爽感 → Boss → 胜利/死亡
  │
  └─ 结算 → 回桌面态（获得材料，挂机加速 buff）

随时可最小化 → 器灵打坐小窗 → 后台继续挂机
```

### 1.4 差异化特色

- **桌面常驻**：不是打开才玩的游戏，是"住在桌面上的修仙宗门"
- **器灵 = 你**：唯一主角。你养它，它为你战斗。没有弟子管理、没有复杂经营
- **三态切换**：全屏割草 → 桌面挂机 → 悬浮小窗，无缝切换
- **轻量放置**：挂机自动成长，不肝，但想打随时打
- **祝福构筑**：战斗内 3 选 1 + 叠 3 升阶质变，每局 build 不同

## 二、游戏启动与存档

### 2.1 启动流程

```
首次启动                    再次启动
  ↓                          ↓
┌──────────────┐      ┌──────────────┐
│   开场黑幕     │      │    主菜单      │
│  「仙门崩塌…」 │      │              │
│  世界观文字淡入 │      │  继续游戏 → 读档 → 桌面态  │
└──────┬───────┘      │  新游戏   → 器灵选择          │
       ↓              │  设置     → 音量/窗口         │
┌──────────────┐      └──────────────────────────────┘
│  器灵选择界面  │
│  百世书（唯一）│
└──────┬───────┘
       ↓
┌──────────────┐
│  桌面放置态    │  ← 进入主循环
└──────────────┘
```

首次启动走「开场黑幕 → 器灵选择 → 桌面态」。之后每次启动走「主菜单」，可选择继续游戏或开新档。

### 2.2 存档系统

**存档内容：**

| 数据 | 说明 |
|------|------|
| 器灵绑定 | 当前选定的器灵 ID |
| 器灵等级 | 修复山峰数 → 成长阶段 |
| 山峰状态 | 每座峰：已修复 / 未修复 |
| 资源数量 | 灵气 / 女娲石 / 流派秘宝 |
| 通关次数 | 用于解锁诛仙剑 / 神农鼎 |
| 离线时间戳 | 用于计算离线挂机收益 |
| 设置 | 音量、窗口模式等 |

**保存时机：**
- 战斗结算后自动保存
- 退出游戏时自动保存
- 定时自动保存（每 60 秒）
- 手动保存（设置菜单）

**读档：**
- 启动时检测存档文件 → 有存档显示「继续游戏」
- 读档失败 → 提示「存档损坏，是否新游戏？」
- 无存档 → 直接进入首次启动流程

### 2.3 离线挂机收益

离线期间灵气按基础速率自动累积。回到游戏时弹出提示：

```
「你离开了 3 小时 20 分，器灵修炼获得 💨 +12,800 灵气」
```

离线收益上限：最多累积 24 小时。超过后不再增长，鼓励回来收菜。

## 三、仓库（背包）

### 3.1 V0.1 定位

V0.1 不做复杂背包系统。采用**纯数值仓库**——资源以数字形式存储，无格子、无图标、无整理操作。

### 3.2 存储内容

| 资源 | 类型 | 说明 |
|------|------|------|
| 灵气 | 货币 | 挂机产出 + 战斗掉落，用于修复剑峰、进入挑战 |
| 女娲石 | 材料 | 战斗胜利获得，修复山峰消耗（每峰 1 个） |
| 流派秘宝 | 材料 | Boss 掉落，共 6 种对应 6 座山峰 |

### 3.3 挂件说明

挂件**不入仓库**。战斗中即时装备到 3 个槽位，新替旧（旧挂件直接消失）。

> V0.2 规划：挂件可存入背包，战斗结束后选择保留哪些。

### 3.4 仓库界面

桌面态底部显示资源栏，无需打开独立仓库界面：

```
💨 灵气 1,280    ⛰️ 女娲石 ×2    📜 剑峰秘宝 ×1
```

## 四、世界观与器灵

### 2.1 故事

上古时代，仙界与凡间有仙门相连。仙门一夜崩塌，仙人陨落消散。

至强法宝在仙门崩碎时护住最后根基，耗尽灵力，化为凡间荒山，陷入沉睡。

无数年后，器灵苏醒，发出跨越轮回的呼唤。你作为听到呼唤的转世者，承担起修复神器、重开仙门的使命。

### 2.2 器灵（初始选择）

| 器灵 | 解锁 | 特性 |
|------|------|------|
| 百世书 | 初始 | 战斗失败免死，回桌面态继续挂机 |
| 诛仙剑 | 通关 1 次 | 待定 |
| 神农鼎 | 通关 2 次 | 待定 |

- 永久绑定，选定后不可更换
- 随山峰修复成长，外观和数值同步变化

### 2.3 六座山峰

| 山峰 | 定位 | 解锁的器灵能力 |
|------|------|---------------|
| 剑峰 | 飞剑之道 | 弹射 +1 |
| 佛峰 | 金刚护体 | 护盾 |
| 法峰 | 元素掌控 | 分裂 |
| 兽峰 | 灵兽共鸣 | 穿透 |
| 器峰 | 法宝精通 | 范围 +20% |
| 魂峰 | 神魂淬炼 | 伤害 +30% |

## 五、桌面放置态

### 3.1 界面布局（1280 × 120 px）

```
┌──────────────────────────────────────────────────────────────┐
│ 🏔️剑峰  🏔️佛峰  🏔️法峰    🧘 器灵打坐    🏔️兽峰  🏔️器峰  🏔️魂峰  │
│  ✅已修  🔒未修  🔒未修    （中央C位）     🔒未修  🔒未修  🔒未修  │
│                                                              │
│ 💨 灵气 1,280  ⛰️ 女娲石 ×2  📜 秘宝 ×1    [⚔️ 挑战]  [_ 最小化] │
└──────────────────────────────────────────────────────────────┘
```

### 3.2 挂机机制

| 资源 | 产出方式 | 用途 |
|------|---------|------|
| 灵气 | 自动增长（基础速率 + 器灵加成） | 修复剑峰、进入挑战 |
| 女娲石 | 战斗胜利掉落 | 修复山峰（通用材料） |
| 流派秘宝 | 战斗 Boss 掉落 | 修复对应山峰 |

- 最小化态：挂机继续，灵气照常累积
- 回到桌面态时可以一次性收取离线累积的灵气
- 点击器灵 → 额外爆一波灵气（有 CD）

### 3.3 山峰修复

| 山峰 | 消耗 | 顺序 |
|------|------|------|
| 剑峰 | 灵气 500 | 唯一初始可修 |
| 其他 5 峰 | 流派秘宝 ×1 + 女娲石 ×1 + 灵气 5,000 | 自由选择 |

修复山峰的即时效果：
- 器灵获得对应能力（见 §2.3 山峰能力表）
- 器灵外观变化（形态升级）
- 解锁更多战斗祝福池选项

### 3.4 与旧 GDD 的关键差异

- **砍掉**：弟子招募/修炼/筑基/出战
- **砍掉**：多种材料（功法升级材料等），精简为灵气+女娲石+秘宝
- **砍掉**：经营深度操作，变为纯挂机自动累积

## 六、全屏战斗态

### 4.1 定位

类吸血鬼幸存者。器灵在战场中自动攻击，360° 弹幕。玩家控制移动（WASD / 鼠标），专注走位 + 祝福构筑决策。

### 4.2 战斗流程

```
桌面态点击 [⚔️ 挑战]
  ↓
进入战场（横板俯视/斜45°）
  ↓
3 秒倒计时「准备迎敌」
  ↓
开局祝福 3 选 1
  ↓
波次战斗（W1 → W15）
  │
  ├─ 击杀敌人 → 经验球
  ├─ 经验满 → 升级 → 祝福 3 选 1
  │   ├─ 弹射 / 分裂 / 穿透
  │   ├─ 攻速 / 伤害 / 范围
  │   └─ 特殊（护盾 / 吸血 / 暴击）
  │
  ├─ 每 N 波 → 精英怪 → 掉落挂件
  ├─ W15 → Boss 多阶段
  │
  └─ 胜利 / 死亡 → 结算 → 回桌面态
```

### 4.3 器灵战斗属性

| 属性 | 说明 |
|------|------|
| 攻击 | 自动朝最近敌人发射弹幕 |
| 弹幕基础 | 1 发 / 次，基础伤害 |
| 弹幕类型 | 随山峰修复解锁新弹幕形态 |
| 移动速度 | 玩家控制，WASD / 鼠标 |
| HP | 有血量，归零 = 死亡（百世书免死） |

### 4.4 祝福系统（核心构筑）

战斗中升级 → 暂停 → 3 选 1。

| 类型 | 效果 | 示例 |
|------|------|------|
| 弹道型 | 改写攻击模式 | 弹射 +1 / 分裂 +1 / 穿透 +1 |
| 数值型 | 强化属性 | 攻速 +30% / 伤害 +50% / 范围 +20% |
| 特殊型 | 新增机制 | 护盾 / 吸血 5% / 暴击 15% |

**升阶质变**：同类型叠满 3 张 → 质变跃迁

| 祝福线 | 1 级 | 2 级 | 3 级（质变） |
|--------|------|------|-------------|
| 弹射 | +1 弹射 | +2 弹射 | 闪电网（链式弹射） |
| 分裂 | +1 分裂 | +2 分裂 | 扇形 5 发 |
| 穿透 | +1 穿透 | +2 穿透 | 穿透翻倍 + 回旋 |
| 攻速 | +20% | +40% | 双倍攻击间隔 |
| 范围 | +15% | +30% | 全屏覆盖 |

### 4.5 挂件系统

精英怪 / Boss 掉落，即时装备，改写攻击逻辑。

| 挂件 | 效果 | 稀有度 |
|------|------|--------|
| 雷灵珠 | 10% 麻痹 0.5s | 稀有 |
| 火灵珠 | 3s DOT 灼烧 | 稀有 |
| 冰灵珠 | 30% 减速 2s | 普通 |
| 风灵珠 | 攻速 +30% | 普通 |
| 土灵珠 | 护盾 20% HP | 史诗 |

- 3 个槽位（武器 / 防具 / 饰品）
- 即时装备，新替旧（旧挂件消失）
- V0.1 无背包，捡了就装

### 4.6 敌人类型

| 类型 | 行为 | 掉落 |
|------|------|------|
| 普通怪 | 朝器灵移动，碰触扣血 | 经验球 |
| 精英怪 | 高血量 + 特殊技能（冲锋/远程） | 挂件 |
| Boss | 多阶段（入场→狂暴→濒死） | 挂件 + 材料 |

### 4.7 割草节奏

| 阶段 | 波次 | 体验 |
|------|------|------|
| 热身 | W1-4 | 弹道稀疏，走位为主 |
| 构筑成型 | W5-8 | 祝福叠起来，弹幕变密 |
| 割草 | W9-13 | 流派成型，满屏弹幕 |
| 检验 | W14-15 | Boss 多阶段，构筑验证 |

## 七、结算

### 5.1 胜利

```
清完 15 波 → Boss 死亡
  ↓
结算界面
  ├─ 获得女娲石 + 秘宝
  ├─ 获得灵气
  └─ 挂机加速 buff（限时）
  ↓
回到桌面态
```

### 5.2 失败

```
器灵 HP 归零
  ↓
百世书 → 「百世书护体」免死 → 回桌面态（V0.1 无惩罚）
其他器灵 → Game Over，重新开始
```

## 八、最小化态

### 6.1 表现

- 一个器灵卡通像素形象，有呼吸/打坐动画
- 可拖动到桌面任意位置
- 始终置顶（或可设）

### 6.2 功能

- 后台挂机继续累积灵气
- 点击 → 展开回桌面放置态
- 显示当前灵气数字（可选）
