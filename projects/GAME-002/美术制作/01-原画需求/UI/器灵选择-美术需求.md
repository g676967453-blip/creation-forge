从功能规划 §2「界面描述」提取，覆盖器灵选择流程涉及的全部 UI 界面：

|---|---------|------|---------|------------|--------|

## 2. 交互需求摘要（阶段 2 产出：交互设计）

> 详细交互规格见功能需求 §4，此处仅提取与视觉/资产相关的交互要点。

### 2.1 开场黑幕（INTRO）

| 维度 | 说明 |
|------|------|
| 状态 | 动画播放中 → 全部显示（含底部提示） → 完成退出 |
| 操作 | 点击/按键（动画中→快进，已显示→结束）；ESC 跳过 |
| 视觉要点 | 纯黑底 + 840px 宽白色叙事文本居中，阿里巴巴普惠体 55R，20px/行高28px |
| 资产 | 纯代码（ColorRect + Label + Tween），无需美术资产 |

### 2.2 器灵选择面板（MAIN_PEAK_SELECT）

| 维度 | 说明 |
|------|------|
| 状态 | 默认态（无选中，按钮置灰）→ 选中态（卡片高亮，按钮亮起）→ 确认过渡（面板淡出） |
| 操作 | 点击卡片 → 高亮/取消；点击「开始游戏」→ 过渡动画 → 进入经营 |
| 数据来源 | `spirit_profile_config.csv`（当前仅百世书） |
| 视觉要点 | 深色云海背景 + 居中卡片 + 金色标题 + 底部按钮 |

### 2.3 经营器灵展示（PREPARATION）

| 维度 | 说明 |
|------|------|
| 状态 | 正常（绿色HP条）→ 低血量（≤30%HP，红色HP条） |
| 操作 | 点击器灵 → 查看等级和成长进度 |
| 视觉要点 | 器灵图标底部中央 + 头顶HP条 |

## 3. 视觉方向（阶段 3 产出：视觉设计）

### 3.1 风格对齐

基于 [开仙门-美术绘制规范-v2](../../开仙门-美术绘制规范-v2.md) 的全局约束：
- **风格**：Pixel Art 像素艺术 + 中国仙侠题材
- **画布**：1280×720
- **基调**：暗色修仙，金色高亮，暗紫/深蓝底色
- **字体**：阿里巴巴普惠体 55R（AlibabaPuHuiTi-3-55-Regular.woff2）

### 3.2 器灵选择面板 — 视觉方向

| 维度 | 规范 |
|------|------|
| **基调** | 神秘庄重 — 深色云海衬托金色卡片的仪式感 |
| **主色调** | 底色 `#0a0a14`→`#1a1a2e`→`#16213e` 渐变，金色 `#f0c040` 用于标题/边框/高亮 |
| **辅助色** | 暗紫 `#1a1a2e`，灰蓝 `#8888aa`（提示文字），灰紫 `#555577`（锁定卡片） |
| **布局** | 顶部标题 → 中部卡片区（3卡位，V0.1 仅中卡可用）→ 底部按钮 |
| **卡片规格** | 240×320，金色边框 2px，圆角 8px |
| **按钮规格** | 200×48，金色渐变（`#f0c040`→`#c09030`），圆角 6px |

### 3.3 已有视觉参考

- **HTML 交互原型**：[器灵选择.html](../../../ui-prototypes/器灵选择.html) — 完整 CSS 视觉稿
- **Pixso 预览**：[器灵选择_Pixso预览.png](../../../ui-prototypes/器灵选择_Pixso预览.png) — Pixso 导入后的截图
- **原画参考**：[器灵选择.png](../器灵选择.png) — 已有原画需求图

## 6. 引擎实现差异清单

> 对照本美术需求文档，逐项检查现有 Godot 代码（[main_peak_select_panel.gd](../../../开仙门/scripts/ui/main_peak_select_panel.gd) + [intro_screen.gd](../../../开仙门/scripts/ui/intro_screen.gd) + [main.tscn](../../../开仙门/scenes/main.tscn)）的实现状态。

### 6.1 开场黑幕 — 实现对照

| 需求项 | 需求规格 | 实现状态 | 差异 |
|--------|---------|---------|------|
| 纯黑背景 | ColorRect 1280×720 | ✅ 已实现 | `Color(0,0,0,1)` |
| 叙事文本 | 840px宽，逐段淡入淡出，20px/28px行高 | ✅ 已实现 | intro_screen.gd v2 逐段自动播放 |
| 字体 | AlibabaPuHuiTi-3-55-Regular.woff2 | ✅ 已实现 | FONT_PATH 常量引用 |
| 快进交互 | 点击/按键跳过当前段 | ✅ 已实现 | 0.3s 防连点冷却 |
| 完成过渡 | 0.5s黑屏后发射信号 | ✅ 已实现 | FINISH_BLACK_DURATION |

> **结论**：开场黑幕 5/5 项全部实现，无差异。

### 6.2 器灵选择面板 — 实现对照

| 需求项 | 需求规格 | 实现状态 | 差异 |
|--------|---------|---------|------|
| 深色背景 | 深色云海或暗色渐变 | ⚠️ 代码实现 | 当前用 `Color(0,0,0,0.25)` 半透明黑色覆盖层 + 深紫面板底 `Color(0.08,0.08,0.12,0.97)`，缺少云海纹理（P1 资产 A1 未生产） |
| 标题"选择器灵" | 32px，金色 `#f0c040`，居中 | ⚠️ 部分实现 | 当前用 24px + `Color(0.95,0.88,0.62)`，字号和颜色与视觉方向有偏差 |
| 百世书卡片底板 | 240×320，金色边框，圆角8px | ⚠️ 部分实现 | 当前用 190×190 + `Color(0.12,0.1,0.22,0.96)` + 紫色边框 `Color(0.4,0.35,0.5)`，尺寸/颜色/边框色与视觉方向不一致 |
| 卡片图标 | 80×64 百世书古书图标 | ⚠️ 临时占位 | 当前加载 `assets/_exported/主殿-书.png`，非像素艺术风格，与全局风格不一致 |
| 卡片高亮态 | 金色光晕（V1） | ❌ 未实现 | 当前仅 modulate 调色 `Color(1.0,0.96,0.78)`，无光晕效果 |
| 开始按钮 4 态 | 默认/悬浮/按下/禁用 | ⚠️ 部分实现 | 当前仅代码 Button（默认/禁用两态），无悬浮/按下态，无金色渐变样式 |
| 锁定卡片占位 | V0.1 不做 | ✅ 符合设计 | — |
| 面板淡出过渡 | 点击开始 → 面板淡出 ~1s（V2） | ❌ 未实现 | 当前直接发射信号切换状态，无过渡动画 |
| 卡片飞入动画 | 卡片缩小飞入器灵位置（V2） | ❌ 未实现 | 当前无此动画 |

> **结论**：器灵选择面板 2/9 项完全实现，5/9 项部分实现（代码可用但视觉未对齐），2/9 项未实现（V1光晕、V2过渡动画）。**视觉未对齐是核心差距**。

### 6.3 经营器灵展示 — 实现对照

| 需求项 | 需求规格 | 实现状态 | 差异 |
|--------|---------|---------|------|
| 器灵图标显示 | 底部中央，百世书图标 | ✅ 已实现 | `main_peak.set_form()` 加载图标 |
| HP 条（头顶） | 绿色≤30%变红 | ❌ 未实现 | 当前 HP 显示在 BattleHUD 顶部信息栏，不在器灵头顶 |
| 器灵形态切换 | 7 级随修复变化 | ⚠️ 框架就位 | `apply_spirit_growth()` 方法已有，但 7 级精灵表（A14）未生产，形态切换视觉未落地 |
| 点击器灵查看信息 | 显示等级和成长进度 | ⚠️ 部分实现 | 点击有反馈（浮字），但无信息面板 |

> **结论**：经营器灵展示 1/4 项完全实现，2/4 项部分实现，1/4 项未实现。
