## 1. 范围界定 — 什么是角色原画

### 1.1 角色原画 vs 游戏内 Sprite

| 维度 | 游戏内 Sprite（美术规范 v2 §4） | 角色原画（本文档） |
|------|-------------------------------|-------------------|
| **用途** | 游戏运行时交互资产（敌人移动、弹道飞行、UI 按钮） | 独立插画：角色选择、图鉴、加载画面、宣传 |
| **画布尺寸** | 8×8 ~ 128×128 px | 512×512 ~ 1024×1024 px |
| **构图** | 单一物体、正/侧视角、动作帧 | 角色为核心、氛围背景、叙事姿态 |
| **细节** | 极低分辨率下的轮廓可读性、4-6 帧动画 | 完整角色设计：服装、武器、气场、环境 |
| **背景** | 透明 PNG（RGBA） | 深色氛围背景或透明 PNG（按场景） |
| **后处理** | NEAREST 缩放 + 品红色键抠除 | NEAREST 缩放（无需抠除） |
| **Prompt 关键词** | "pixel art sprite sheet, game asset" | "pixel art character portrait, key visual" |

**判断规则**：如果资产出现在 Godot 战斗场景中 → 用美术规范 v2。如果出现在 UI 面板、图鉴、或宣传素材中 → 用本文档。

### 1.2 适用场景

| 场景 | 尺寸 | 构图 | 优先级 |
|------|------|------|--------|
| 角色选择卡片（山峰选择 UI） | 512×720 | 胸像 (Bust) | P0 |
| 图鉴/修士录条目 | 512×512 | 半身像 (Half-body) | P0 |
| 加载画面背景 | 1280×720 | 场景 (Scene) | P1 |
| 标题画面主视觉 | 1024×1024 | 群像 (Group) | P2 |
| 宣传图/封面 | 1024×1024 | 全身像 (Full-body) | P2 |

## 3. 尺寸规格与构图类型

### 3.1 标准规格

| 用途 | 目标尺寸 | 宽高比 | 构图 | 生成尺寸 |
|------|---------|--------|------|---------|
| 角色选择卡片 | 512 × 720 | ~5:7（竖版） | 胸像 (Bust) | 1024×1024 → 裁剪后缩放 |
| 图鉴条目 | 512 × 512 | 1:1（方形） | 半身像 (Half-body) | 1024×1024 → 裁剪后缩放 |
| 加载画面 | 1280 × 720 | 16:9（横版） | 场景 (Scene) | 1024×1024 → 裁剪后缩放 |
| 标题/宣传 | 1024 × 1024 | 1:1（方形） | 全身像/群像 | 1024×1024 直出 |

> **核心原则**：始终在 1024×1024 下生成（Lovart 默认输出），再 NEAREST 缩放到目标尺寸。避免直接生成小尺寸导致细节丢失。

### 3.2 构图类型

| 类型 | 画面范围 | 最佳用途 |
|------|---------|---------|
| **胸像 (Bust)** | 胸部以上 — 面部、肩部、标志法器/灵兽可见 | 角色选择卡片 |
| **半身像 (Half-body)** | 腰部以上 — 手势、武器、气场可见 | 图鉴条目、对话界面 |
| **全身像 (Full-body)** | 完整站姿 + 伴身物 + 环境 | 宣传图、角色详情 |
| **场景 (Scene)** | 角色 + 完整环境氛围 | 加载画面、标题画面 |

### 3.3 各角色构图映射

```
剑峰峰主    → 胸像 (512×720) + 半身像 (512×512)
佛峰峰主    → 胸像 (512×720) + 半身像 (512×512)
法峰峰主    → 胸像 (512×720) + 半身像 (512×512)
魔峰峰主    → 胸像 (512×720) + 半身像 (512×512)
兽峰峰主    → 胸像 (512×720) + 半身像 (512×512) [含灵狐]
宝峰峰主    → 胸像 (512×720) + 半身像 (512×512) [含环绕法器]
百世书器灵  → 半身像 (512×512)
```

## 4. 可复用提示词模板

以下模板使用 `{VARIABLE}` 占位符。生成每个角色时填入具体值即可。

### 4.1 主模板 A — 半身像（图鉴/展示用）

```text
pixel art character portrait for a Chinese xianxia game called "Opening the Immortal Gate",
{cultivator_description},
half-body composition, {pose_description},
{color_description},
{background_description},
16-bit RPG pixel art style, limited color palette, clean pixel edges,
no anti-aliasing, dark mystical atmosphere, Chinese ink-wash influence,
readable silhouette, game key visual, character illustration
```

### 4.2 主模板 B — 胸像（角色选择卡片用）

```text
pixel art character bust portrait for a Chinese xianxia game,
{cultivator_description},
chest-up composition, facing {direction}, {pose_description},
{color_description},
dark atmospheric background with {aura_description},
pixel art portrait style, clean pixel edges, no anti-aliasing,
limited color palette, game character card, readable at small size
```

### 4.3 占位符说明

| 占位符 | 填写内容 | 示例 |
|--------|---------|------|
| `{cultivator_description}` | 角色身份、外貌、年龄、性别、标志性视觉特征 | "a stern male sword cultivator in flowing cyan robes, silver hair tied in a Daoist topknot, a glowing flying sword hovering beside his shoulder" |
| `{pose_description}` | 身体语言、手势、正在做什么 | "right hand forming a sword-finger gesture, intense focused gaze" |
| `{color_description}` | 主色和辅色，引用现有调色板 | "jade green (#4ecca3) sword aura, dark ink-black robes with cloud-white trim" |
| `{background_description}` | 角色身后的场景 | "misty mountain peak shrouded in clouds, distant pagoda silhouettes, ink-wash style" |
| `{aura_description}` | 角色周围的能量效果（胸像用，较简洁） | "subtle jade-green spiritual energy glow, floating light particles" |
| `{direction}` | 朝向 | "slightly right" / "slightly left" / "forward" |

## 6. 风格一致性规则

### 6.1 强制共享关键词

**每个 Prompt 必须包含以下关键词**（保证所有肖像属于同一游戏）：

```
pixel art, limited color palette, clean pixel edges, no anti-aliasing,
dark mystical atmosphere, Chinese ink-wash influence,
game key visual, character illustration
```

### 6.2 色彩互斥矩阵

每个峰主肖像中，**只允许该峰自己的主色作为强调色**。其他峰的主色不得出现（避免视觉混淆）。

| 宝峰峰主 | 青铜棕金 | 玉石青 #4ecca3（仅点缀） | 雷电蓝、魂火紫 |
| 百世书器灵 | 玉石青 #4ecca3 + 佛门金 #f0c040 | 羊皮纸棕、奶油色 | 朱砂红、魂火紫 |

> **判断标准**：画面中其他峰的主色面积不得超过画面的 2%。如果某个颜色会让玩家误以为这是另一个峰的角色 → 不合格。

### 6.3 像素艺术保真规则

以下每一项都是 PASS/FAIL 判定：

1. **无平滑渐变** — 像素艺术使用抖动 (dithering)，而非平滑过渡。画面中出现喷枪式渐变 → 不是像素艺术，拒绝。
2. **无 3D 渲染痕迹** — 无次表面散射、无环境光遮蔽、无照片级真实感。看起来像缩小的 3D 渲染 → 拒绝。
3. **非动漫赛璐璐风格** — 这是像素艺术，不是日式动画。无粗黑描边、无 Q 版比例、无大面积平涂赛璐珞色块。
4. **半分辨率可读** — 缩放到 256×256 时仍能辨认角色身份。如果细节糊成一团 → 像素密度过高。
5. **背景必须暗色氛围** — 使用 #1a1a2e / #0a0a14 范围。无明亮天空、无白天场景。游戏美学是暗黑神秘之夜。

### 6.4 构图一致性规则

1. **半身像**：腰部以上取景，头顶上方留出气场/能量效果空间。
2. **胸像**：胸部以上取景，居中，标志武器/法器/灵兽必须在画面内可见。
3. **视线**：角色面向观众，微侧（各角色 spec 中已指定方向）。
4. **无地面**：角色浮于雾气/氛围虚空中。无可见地面、无地平线切割人物。

### 7.3 后处理脚本

```python
from PIL import Image

def process_portrait(input_path: str, output_path: str, target_w: int, target_h: int):
    """
    处理 Lovart 生成的角色肖像：
    1. 转 RGBA
    2. 如有品红背景 → 色键抠除
    3. NEAREST 缩放至目标尺寸
    4. 保存透明 PNG
    """
    img = Image.open(input_path).convert("RGBA")

    # 品红色键抠除（仅在检测到品红时执行）
    pixels = img.load()
    has_magenta = any(
        pixels[x, y][0] > 240 and pixels[x, y][1] < 15 and pixels[x, y][2] > 240
        for y in range(min(img.height, 10))
        for x in range(min(img.width, 10))
    )

    if has_magenta:
        for y in range(img.height):
            for x in range(img.width):
                r, g, b, a = pixels[x, y]
                if r > 240 and g < 15 and b > 240:
                    pixels[x, y] = (0, 0, 0, 0)

    # NEAREST 缩放 — 像素艺术的关键
    img = img.resize((target_w, target_h), Image.NEAREST)
    img.save(output_path, "PNG")
    print(f"Saved portrait: {output_path} ({target_w}×{target_h})")

# 使用示例
# process_portrait("lovart_output.png", "portrait_sword_master_bust.png", 512, 720)
# process_portrait("lovart_output.png", "portrait_sword_master_half.png", 512, 512)
```

## 8. 质量检查清单

每张肖像生成后，逐项检查。全部 PASS 才能入库。

### 8.1 像素艺术保真 ✅/❌

- [ ] 图像使用像素艺术风格（1x 缩放可见像素格，非平滑数字绘画）
- [ ] 无平滑/照片级渐变（仅允许抖动 dithering）
- [ ] 无 3D 渲染痕迹（无次表面散射、环境光遮蔽、照片级真实感）
- [ ] 非日式动画赛璐璐风格、非 Q 版比例
- [ ] 像素边缘清晰、无抗锯齿模糊
- [ ] 有限调色板（角色部分不超过 ~32 种可辨识颜色，越少越好）

### 8.2 色彩合规 ✅/❌

- [ ] 强调主色与 §6.2 指定的峰主色一致
- [ ] 禁止色未在画面大面积出现（<2% 面积）
- [ ] 背景使用暗色调基准（#1a1a2e, #0a0a14）
- [ ] 角色与背景有足够明度对比（亮部 vs 暗底）
- [ ] 色彩鲜艳但不霓虹/不过饱和

### 8.3 构图与取景 ✅/❌

- [ ] 取景正确（胸像 = 胸部以上；半身像 = 腰部以上）
- [ ] 角色居中，头部上方留有气场空间
- [ ] 标志视觉元素（武器/法器/伴身兽）清晰可见
- [ ] 无可见地面 — 氛围虚空背景
- [ ] 角色面向观众（微侧，非背对）

### 8.4 仙侠美学 ✅/❌

- [ ] 角色读起来是中国仙侠（非西方奇幻、非日式动画、非韩式漫画）
- [ ] 服装是中国风（汉服/道袍影响，非西方束腰外衣、非日式 kimono）
- [ ] 3 秒内能辨认出修炼流派
- [ ] 背景可见水墨风影响

### 8.5 技术输出 ✅/❌

- [ ] 输出为 1024×1024（缩放前）
- [ ] 无品红 (#FF00FF) 残留（如用了品红底生成）
- [ ] NEAREST 缩放到目标尺寸后，图像保持锐利可读
- [ ] 保存为 PNG，文件名正确

### 8.6 横向一致性（2+ 肖像存在后检查）✅/❌

- [ ] 新肖像与已有肖像看起来属于同一游戏
- [ ] 像素密度/分辨率一致（块大小相似）
- [ ] 光照方向一致（如全部从左上打光）
- [ ] 比例一致（无角色显得巨大或微小）

## 9. 制作流程

### 9.1 推荐制作 Pipeline

```
Phase 1 — 草稿探索
  1. 使用 Nano Banana Pro 快速生成全部 7 个角色的胸像
     → 目标：快速迭代、确定构图和配色大方向
  2. 全员放在一起审视一致性
  3. 选出最佳 1-2 张作为 Phase 2 的参考基准

Phase 2 — 成品输出
  4. 使用 Midjourney 重新生成全部 7 个角色（半身像 + 胸像）
     → 使用 Phase 1 经验微调后的 Prompt
  5. 后处理：NEAREST 缩放到目标尺寸
  6. 每张运行 §8 完整质量检查清单
  7. 7 张横向对比，确认一致性
  8. 放入 assets/runtime/portraits/

Phase 3 — 游戏集成
  9. 集成到 Godot UI（角色选择、图鉴、加载画面）
  10. 在 1280×720 原生分辨率下验证显示效果
  11. 微调 UI 尺寸和位置
```
