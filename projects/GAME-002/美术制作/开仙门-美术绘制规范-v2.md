## 1. 总体美术风格

### 1.1 核心风格定义

| 维度 | 规范 |
|------|------|
| **类型** | Pixel Art（像素艺术） |
| **题材** | 中国仙侠/修仙（Xianxia / Chinese Cultivation Fantasy） |
| **画布分辨率** | 1280 × 720（Godot 窗口） |
| **渲染风格** | 手绘水墨风背景 + 像素艺术角色/特效 |
| **参考风格** | 16-bit RPG 像素风（非 8-bit），中国风暗黑奇幻 |

### 1.2 视觉关键词（用于 AI Prompt）

```
Chinese xianxia pixel art, dark mystical atmosphere,
ink-wash mountain background, jade green accents,
golden glow effects, limited color palette,
clean pixel edges, readable at small sizes,
floating clouds, ancient temples, spirit beasts
```

### 1.3 设计原则

1. **小尺寸可读性优先** — 敌人 sprite 仅 19-31px 宽，必须保证轮廓清晰
2. **暗色背景 + 亮色主体** — 战斗场景偏暗，角色/特效需有足够的明度对比
3. **功法区分靠色彩** — 6 种功法各有专属配色，不能混用
4. **中国风意象** — 云纹、山石、法器、符箓、灵兽等传统修仙元素
5. **透明背景** — 所有 sprite 必须 RGBA 透明 PNG，不要白色/品红色底

## 2. 资产分类与规格表

### 2.1 敌人精灵表（Enemy Spritesheet）

**格式**：水平 stripe spritesheet，所有帧等宽等高排列在一行

| enemy_id | 中文名 | 帧数 | 帧宽 | 帧高 | FPS | 体型 | 备注 |
|----------|--------|------|------|------|-----|------|------|
| enemy_rush | 疾冲魔 | 4 | 25 | 25 | 6 | 小 | 快速冲撞型，红色调 |
| enemy_flank | 侧袭者 | 4 | 19 | 28 | 10 | 瘦高 | 侧翼绕行型，绿色调 |
| enemy_giant | 巨兽 | 4 | 31 | 24 | 10 | 大型 | 坦克型，橙棕色调 |
| enemy_boss | 天魔 | 6 | 70 | 73 | 8 | Boss | 最终Boss，紫黑红色调 |
| enemy_ranged | 远程魔 | 4 | 19 | 28 | 10 | 瘦高 | 远程射击型，紫色调 |
| enemy_frost_beast | 霜寒兽 | 4 | 19 | 28 | 10 | 中型 | 冰系精英，蓝白色调 |
| enemy_armored | 铁甲卫 | 4 | 31 | 24 | 10 | 大型 | 重甲坦克，铁灰色调 |
| enemy_flyer | 翼魔 | 4 | 19 | 28 | 12 | 飞行 | 飞行单位，白/浅蓝调 |
| enemy_summoner | 召魔师 | 4 | 25 | 25 | 8 | 中型 | 召唤型精英，暗紫调 |

> **重要**：同一 spritesheet 路径的敌人必须共用同一套帧规格（如 enemy_flank / enemy_ranged / enemy_frost_beast / enemy_flyer 共用 `enemy_flank_sheet.png`，但设计时需确保帧规格一致 19×28×4）。

> **参考**：色板参考图 `_参考-UI色板.png` 可同时作为附件，约束色彩。

#### Lovart 生成工作流（UI 界面专用）

```
1. 完成 HTML 交互原型（含完整布局+组件）
2. Playwright 截图 → 1280×720 PNG
3. upload HTML 截图到 Lovart → 获得 CDN URL
4. 用本模板 + --attachments "截图URL" + --attachments "色板URL" → chat
5. 检查布局是否对齐 → 同 thread 迭代修正
```

#### 视觉风格关键词白名单

> 在 Prompt 中只用白名单内的风格词。禁止词会导致生成结果偏离像素游戏 UI 风格。

```
✅ 允许：
  pixel art, 2D, flat, stylized, dark fantasy, Chinese xianxia,
  clean lines, limited palette, game UI, hand-drawn feel,
  dark minimalist, subtle gradient, muted colors,
  ink-wash texture, golden glow, mystical atmosphere

❌ 禁止：
```

## 5. 生成后处理流程

### 5.1 Lovart 生成 → 游戏资产标准流程

```
┌─────────────────────────────────────────────────────┐
│ 1. Lovart 生成 1024×1024 品红底 (#FF00FF)            │
│    Prompt 中指定 "magenta #FF00FF background"        │
├─────────────────────────────────────────────────────┤
│ 2. Python PIL 色键抠除品红底                          │
│    from PIL import Image                             │
│    img = Image.open("input.png").convert("RGBA")     │
│    data = img.getdata()                              │
│    new_data = []                                     │
│    for r,g,b,a in data:                              │
│        if r > 250 and g < 10 and b > 250:            │
│            new_data.append((0,0,0,0))                │
│        else:                                         │
│            new_data.append((r,g,b,a))                │
│    img.putdata(new_data)                             │
├─────────────────────────────────────────────────────┤
│ 3. NEAREST 缩放至目标尺寸                             │
│    img = img.resize((target_w, target_h),            │
│                     Image.NEAREST)                   │
│    重要：必须用 NEAREST，不能用 LANCZOS/BILINEAR      │
├─────────────────────────────────────────────────────┤
│ 4. 保存为透明 PNG                                    │
│    img.save("output.png", "PNG")                     │
├─────────────────────────────────────────────────────┤
│ 5. 放置到正确路径                                    │
│    敌人 → assets/runtime/enemies/                    │
│    投射物 → assets/runtime/projectiles/              │
│    其他 → 按类型放入对应目录                          │
└─────────────────────────────────────────────────────┘
```

### 5.2 Spritesheet 生成脚本模板

```python
from PIL import Image
import os

def process_lovart_sprite(input_path, output_path, frame_w, frame_h, frame_count, target_w, target_h):
    """
    处理 Lovart 生成的 spritesheet：
    1. 抠除品红底
    2. NEAREST 缩放到目标尺寸
    3. 验证帧数
    """
    img = Image.open(input_path).convert("RGBA")
    
    # 色键抠除
    pixels = img.load()
    for y in range(img.height):
        for x in range(img.width):
            r, g, b, a = pixels[x, y]
            if r > 250 and g < 10 and b > 250:  # 品红
                pixels[x, y] = (0, 0, 0, 0)
    
    # NEAREST 缩放 — 保持像素锐利
    total_w = frame_w * frame_count
    total_h = frame_h
    img = img.resize((total_w, total_h), Image.NEAREST)
    
    img.save(output_path, "PNG")
    print(f"Saved: {output_path} ({total_w}x{total_h}, {frame_count} frames)")
    
    # 验证
    expected_size = os.path.getsize(output_path)
    print(f"File size: {expected_size} bytes")

# 使用示例
# process_lovart_sprite("lovart_output.png", "enemy_rush_sheet.png", 25, 25, 4, 100, 25)
```
