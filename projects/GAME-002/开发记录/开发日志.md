### 2026-07-01（Day 5）

**第 7 功法：雷霆诀 — 策划设计**

设计定位：链式闪电弹射，与离火诀共享御法峰（peak_magic），作为该峰入门功法。

| 字段 | 值 |
|------|-----|
| form_id | form_thunder_01 |
| damage | 20（单发） |
| attack_interval | 1.1s |
| range | 580px |
| special_mechanic | chain（链式弹射） |
| special_param | bounces=3, bounce_range=200, decay_pct=0.25 |
| projectile_color | (0.40, 0.60, 1.00) 亮蓝色 |
| projectile_shape | lightning |
| ultimate_name | 九天神雷 |
| ultimate_desc | 全场敌人雷击3倍伤害+眩晕1.0s |

**链式弹射机制**：命中第一个敌人 → 搜索 200px 内未命中敌人 → 弹射（伤害×0.75） → 继续弹射直到 bounces_remaining=0。理想总伤害 54.69（对密集敌群）。

**专属卡牌（4 张）**：连环闪电（弹射+2）/ 雷电压缩（衰减-10%）/ 雷霆领域（范围+80）/ 麻痹电流（10%概率眩晕0.5s）

**peak_magic 调整**：`entry_form_id` 从离火诀切换为雷霆诀，成为首个"一峰双法"山峰。
