## 一、游戏概述

### 1.1 核心概念

《开仙门》是一款以"修复上古神器、重开仙门"为主线的桌面放置游戏。玩家扮演转世仙人，唤醒沉睡的法宝器灵，在云海之上重建洞府，培养山峰阵法，抵御天劫，最终重开仙门。

### 1.2 核心玩法循环

```
局外挂机经营 → 积累资源/修为 → 进入局内渡劫（肉鸽塔防）→ 结算带回稀有资源 → 突破瓶颈 → 更强的角色迎接更强天劫
```

### 1.3 差异化特色

- **180度扇面防御：** 区别于横向卷轴塔防，提供空间布局的立体策略深度
- **神器选择影响全局玩法倾向：** 不同神器带来不同的经营特性和战斗风格
- **可自由搭配的山峰系统：** 六座阵眼从山峰库中自由选择搭配
- **失败即转机：** 渡劫失败不是结束，而是触发特殊事件、解锁新成长路径的机会

## 三、局外系统：模拟经营

### 3.1 主场景

固定画面，器灵位于底部中央，六座辅峰环绕分布，背景为云海。

### 3.2 核心资源

- **灵气：** 基础资源，自动从灵脉中涌出（相当于阳光/金币）
- **修为：** 主角与弟子自动修炼积累，用于境界突破
- **灵植：** 种植在灵田，自动生长，产出炼丹材料
- **丹药：** 由灵植炼制，用于加速修炼或临时增益
- **记忆碎片：** 渡劫/秘境结算获得，用于永久解锁和升级

### 3.3 建筑系统（修复工程）

建筑不叫"建造"，叫"修复"。器灵本身是法宝，修复不同部位解锁不同功能：

- **佛心/器灵核心：** 器灵核心，等级决定整体效率
- **灵脉：** 决定灵气产出速率
- **灵田：** 可种植灵植的区域
- **炼丹房：** 消耗灵植产出丹药
- **经文/铭文：** 点亮后永久提升某项属性
- **阵眼：** 六个，用于放置辅峰（随境界解锁）

### 3.4 弟子系统

- 弟子被灵气吸引而来
- 可安排工作：守田、炼丹、巡逻、修炼
- 弟子有性格和随机事件（勤奋型、贪玩型、走火入魔等）
- 弟子可在辅峰上修炼，学习该峰功法
