# 快速启动：交互规范 + 原型视觉系统 (Quick-Start)

> 在进入低保真六步原型之前，先快速声明两套规则。一次声明，整个项目的原型复用。

---

## 快速启动流程（3 步，15 分钟内完成）

```
① 选择平台 → ② 交互规则声明 → ③ 视觉系统声明 → 进入六步原型
```

---

## ① 选择平台

根据目标平台，自动套用对应的画布基准和交互规则。

### 平台预设

| 参数 | 📱 竖版手游 | 📱 横版手游 | 🖥️ PC | 🎮 主机 |
|------|------------|------------|--------|---------|
| 画布 (w×h) | 750×1334 | 1334×750 | 1920×1080 | 1920×1080 |
| 触控 | ✅ 拇指热区 | ✅ 双手持机 | ❌ 鼠标+键盘 | ❌ 手柄 |
| 安全区 | 顶≥44 底≥34 | 左右≥44 | 任务栏区 | TV 过扫描 5% |
| 按钮最小尺寸 | 44×44px | 44×44px | 24×24px | 以焦点框覆盖 |
| 导航方式 | 触摸+手势 | 触摸+手势 | 鼠标悬停+键盘 | D-pad 焦点 |
| 弹窗适配 | 全屏/底部抽屉 | 居中弹窗 | 居中弹窗 | 居中弹窗 |

### 声明格式

```
平台：[竖版手游]
画布：750 × 1334 px
输入：触摸（单手）+ 手势
```

## ② 交互规则声明

基于平台预设，逐项确认以下规则。可直接套用默认值，也可逐项调整。

### 2.1 安全区

| 方向 | 默认值 | 你的调整 |
|------|--------|---------|
| 顶部 | [默认] | — |
| 底部 | [默认] | — |
| 左侧 | [默认] | — |
| 右侧 | [默认] | — |

### 2.2 操作热区

```
竖版示例：                    横版示例：
┌──────────────────┐         ┌──────────────────────────────┐
│  ⚠️ 不可触 (Y:0~500) │         │ ← 左手区    │   右手区 →   │
├──────────────────┤         │              │              │
│  ⚡ 伸展 (Y:500~800) │         └──────────────────────────────┘
├──────────────────┤
```

**高频操作策略**：[放在自然热区 / 底部固定栏]

### 2.3 按钮策略

| 规则 | 值 |
|------|-----|
| 最小触控尺寸 | 44×44 px |
| 按钮间距 | ≥ 16 px |
| 主 CTA 位置 | 底部居中 / 右下角 |
| 次要操作位置 | 左上角 / 顶部栏 |

### 2.4 屏幕导航模式

| 模式 | 说明 | 何时用 |
|------|------|--------|
| Push/Pop 栈 | 推入子页面，返回弹出 | 大部分场景 |
| Modal 弹窗 | 叠加面板，焦点困在弹窗内 | 设置/确认/详情 |
| Tab 切换 | 同层平行视图 | 背包多标签 |

### 2.5 过渡类型表

| 动作 | 过渡方式 | 时长 |
|------|----------|------|
| 进入子页面 | `slide-left` | 250ms |
| 返回上级 | `slide-right` | 250ms |
| 弹窗打开 | `scale(0.95→1)` + `fade` | 250ms |
| 弹窗关闭 | `scale(1→0.95)` + `fade` | 200ms |
| 底部抽屉 | `slide-up` | 300ms |
| Tab 切换 | `crossfade` | 200ms |
| 即时刷新 | `none` | 0ms |

### 2.6 反馈机制

| 交互 | 反馈 |
|------|------|
| 按钮按下 | 填充灰背景（`:active` 态） |
| 操作成功 | Toast 提示（底部弹出，2s 消失） |
| 操作失败 | Toast 提示 + 原因文字 |
| 危险操作 | 确认弹窗（双按钮：确认/取消） |
| 加载中 | 屏幕中央 `[加载中…]` |
| 数据为空 | 空白区域 `[暂无内容]` |

## ④ 声明完成后进入六步原型

声明确认完毕 → 进入 `game-lo-fi-prototype` 六步工作流：
`场景梳理 → 交互骨架 → 视觉规范 → 线框图 → 交互串接 → 走查`

此时**视觉规范（第③步）已被快速启动覆盖**，六步流程中可直接引用声明结果，跳过视觉规范声明环节。

## 示例：开仙门（竖版卡牌背包）

```
平台：竖版手游 | 画布：750×1334 | 输入：触摸单手

交互规则：
  安全区：顶44px / 底34px
  拇指热区：Y:800~1334（自然+极易）
  按钮：≥44px / 间距≥16px
  导航：Modal弹窗（弹窗焦点陷阱）
  过渡：弹窗 scale+fade 250ms / 关闭 200ms
  反馈：`:active`填充灰 / Toast底部提示

视觉系统：
  基础色板：🅰 默认（#222/#E0E0E0/#999/#FAFAFA）
  功能色：稀有度4色 + 成功/警告绿黄
  字体：Courier New 24px+16px
  网格：8px / 线框2px / 圆角4px

输出物：
  projects/xxx/ui-prototypes/lo-fi/
  ├── _design-tokens.md    ← 快速启动的声明文档
  └── 01-xxx-lo-fi.html    ← 线框图
```
