## 〇、快速启动（v1.1 新增）

首次为项目建立交互规范和视觉系统时，使用 [快速启动模板](../../.claude/skills/game-lo-fi-prototype/references/quick-start.md)：

1. **选择平台**（竖版/横版/PC/主机） → 自动套用画布、安全区、输入方式
2. **交互规则声明**（安全区、热区、按钮策略、导航模式、过渡、反馈）
3. **视觉系统声明**（色板三选一 + 功能色 + 字体 + 间距 + 线框样式）

15 分钟内完成声明，之后所有该项目的原型复用同一套规则。

## 一、规范定位

本规范定义了「低保真交互原型」的方法论和视觉语言。

### 1.1 解决的问题

在功能策划案完成后、进入高保真 UI 设计之前，缺少一个**低成本验证交互流**的环节。直接跳到高保真 HTML，一旦流程有问题，返工成本高。

### 1.2 核心理念

> **先跑通流程，再追求好看。**

- 用线框图验证交互流（低成本）
- 通过后才进入高保真（避免返工）
- 剥离色彩和装饰，专注布局和交互

### 1.3 在管线中的位置

```
功能策划案 → 功能需求 → 界面交互UI设计 → 美术资产 → 代码实现
                              ↑
                    本规范在此环节之前插入：
                              ↓
              低保真交互原型（本规范）
                    ↓ 走查通过
              界面交互UI设计（高保真）
```

## 二、视觉语言标准

### 2.1 画布

| 参数 | 竖版手游（默认） | 横版游戏 | PC/主机 |
|------|-----------------|----------|---------|
| 宽度 | 750px | 1334px | 1920px |
| 高度 | 1334px | 750px | 1080px |
| 缩放 | max-width: 750px; margin: auto | 同左 | 同左 |

### 2.2 色彩

严格 **4 色系统**，禁止任何其他颜色：

| Token | 色值 | 用途 |
|-------|------|------|
| 线框黑 | `#222222` | 边框、文字、图标线 |
| 填充灰 | `#E0E0E0` | 组件背景、激活态填充 |
| 强调灰 | `#999999` | 次要文字、虚线、disabled |
| 背景白 | `#FAFAFA` | 页面底色 |

### 2.3 排版

- 字体：等宽优先（`Courier New` / `Source Code Pro` / `Noto Sans SC`）
- 字号：标题 24px、正文 16px（仅两级）
- 行高：标题 1.4、正文 1.6

### 2.4 网格

所有间距使用 8px 基础网格：`4 / 8 / 16 / 24 / 32 / 48 / 64`

### 2.5 线框样式

- 线宽：2px（实线）/ 1px（虚线分隔）
- 圆角：4px（统一）
- 禁止：阴影、渐变、模糊、透明度、彩色、真实图片

### 2.6 占位符规范

| 内容类型 | 表达方式 |
|----------|----------|
| 未确定图片 | 斜线填充矩形 + `[图片描述]` |
| 未确定短文本 | `[文字占位]` |
| 未确定长文本 | `～～～～～～` |
| 可点击区域 | 虚线外框（`outline: 2px dashed`） |
| 数值 | `[数值]` |

## 三、交互建模标准

### 3.1 屏幕状态机

每屏必须覆盖四态：`idle` → `loading` → `empty` → `error`

### 3.2 组件状态

每个交互组件覆盖五态：`idle` / `active` / `disabled` / `selected` / `focus`

### 3.3 屏幕流转

用 ASCII 或 Mermaid 格式画出所有屏幕之间的导航关系，每条边标注触发动作。

### 3.4 焦点导航

- **触摸**：按钮 ≥ 44×44px，间距 ≥ 16px，高频操作在 Y: 800~1334
- **手柄**：每屏标注初始焦点 + D-pad 方向，弹窗内焦点不泄漏
- **键盘**：Tab 序 = 自然阅读序

### 3.5 过渡声明

每对屏幕之间标注过渡方式：`fade` / `slide-left` / `slide-right` / `slide-up` / `scale` / `none`

## 四、文件命名与放置

```
projects/<项目名>/ui-prototypes/lo-fi/
├── {序号}-{屏幕名拼音}-lo-fi.html    ← 每屏一个文件
```

```
02-qi-ling-xuanze-lo-fi.html
```

## 五、走查清单

完成所有线框图后，逐项核对：

### 5.1 屏幕流转
- [ ] 每屏有明确的入口和出口
- [ ] 弹窗有关闭机制，关闭后焦点回到触发按钮
- [ ] 深层页面（>3 层）有快捷返回方式

### 5.2 触控与焦点
- [ ] 可点击元素 ≥ 44×44px
- [ ] 高频按钮在拇指热区（Y: 800~1334px）
- [ ] 键盘/手柄焦点不丢失

### 5.3 状态覆盖
- [ ] 每个按钮有 idle / active / disabled 三态
- [ ] 列表有 empty / loading / error 态
- [ ] disabled 态有明显视觉区分

### 5.4 信息展示
- [ ] 长文本有截断处理
- [ ] 数值变化有视觉反馈预期
- [ ] HUD 信息有优先级排序

### 5.5 视觉一致性
- [ ] 仅使用 4 种指定颜色
- [ ] 间距全部为 8 的倍数
- [ ] 单字体、双字号
- [ ] 无禁用视觉元素（阴影/渐变/彩色/真实图片）
