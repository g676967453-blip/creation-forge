16 横竖屏切换

方向策略：
• 不强制锁定方向（核心玩法依赖除外）
• 需要锁定则在设计文档中声明
• 切换过渡 <=0.5s
• 布局以中心锚点自适应

锁定场景：竖版跑酷/横版格斗等方向强依赖玩法可锁定。

适配策略：宽度统一 720，保证横向布局不变；纵向以中心锚点拓展。
