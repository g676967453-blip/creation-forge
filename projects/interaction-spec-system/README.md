# 通用竖版手游 UI 设计系统

> 版本：2.0.0 | 基准画布：`1080 x 1920px` | 来源：[idle-rpg-mobile-design-system](J:\Art%20Support%20AI%20Station\projects\idle-rpg-mobile-design-system)

## 项目定位

这是一套面向竖版移动端游戏的通用 UI 设计系统。系统以黑白灰、强描边、有限状态色的结构化界面为默认呈现，适用于休闲、策略、解谜、竞技、模拟经营等多类手游。

系统定义跨游戏类型可复用的视觉、组件、页面、状态与交互规则，不包含任何特定游戏的 IP、美术资产、图标、界面布局或具体文案。

## 交付内容

- [设计系统总则](docs/design-system.md)：`1080 x 1920` 画布、安全区、四列栅格、设计变量、字体、数值、层级、动效与主题边界。
- [组件详规](docs/component-spec.md)：完整母版库，覆盖操作、输入、选择、反馈、容器、弹层及尺寸、状态、命名、规则和验收。
- [页面模板](docs/screen-patterns.md)：首页、列表、网格、详情、筛选、全屏页、弹层与加载、空、错误、满容量、断线恢复模式。
- [游戏场景界面模式库](docs/game-screen-patterns.md)：加载、大厅、关卡、战斗、布阵、结算、养成、个人主页八个场景的分区结构范式（v2.1 新增，基于上线产品界面分析抽象）。
- [交互规范映射](docs/interaction-guidelines.md)：手势阈值、L1-L4 反馈、页面栈、提交、加载、弱网恢复与交互验收。
- [HTML 预览页](docs/design-system-preview.html)：保留左侧样例、右侧规格版式的可直接浏览审阅版。

## 使用边界

- 面向移动端竖屏，基准画布为 `1080x1920`。
- 优先服务 UI 生产、设计评审和后续 Figma 组件化，不包含前端代码实现。
- 默认使用中文命名，可在导入 Figma 或工程前再追加英文变量别名。
