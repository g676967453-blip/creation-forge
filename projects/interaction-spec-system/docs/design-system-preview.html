System overview

所有规则都从完整手机原型开始

  • 页面、组件、文字尺寸、间距、栅格与标注均以 1080 x 1920px 为唯一生产基准。
  • 左侧展示完整手机原型，包含顶部、中心内容与底部关系；不展示脱离页面的散点组件。
  • 右侧只说明与当前原型对应的结构、尺寸、状态、交互与验收规则。
  • 主题可替换背景、材质与插画，但不改变热区、状态语义、安全区和信息层级。

设备适配通过安全区、固定区和中心内容区处理，不通过缩小热区或字号处理。
