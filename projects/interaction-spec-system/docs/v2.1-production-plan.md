# v2.1 内容补完计划

> 目标：先把 v2.0.0 中尚未落成的生产内容补齐，再进入评审、组件化或落地验证。

## 1. 版本目标

v2.1 不进入评审验证阶段，也不重写设计系统总则。当前重点是把设计系统从“规范说明”补成“可直接生产”的内容包：

1. Figma 变量与样式：把色彩、字体、间距、圆角、阴影、动效整理成可建库的变量表。
2. Figma 组件清单：把组件母版拆成组件、变体、状态和命名规则。
3. 页面内容模板：补齐主界面、列表、网格、详情、筛选、弹窗和状态页的内容字段。
4. 工程交接规范：补充资源命名、导出尺寸、状态切图和交付清单。

## 3. 生产顺序

1. 先补 Figma 变量与样式，让设计系统有可建库的基础。
2. 再补组件与变体清单，明确每个母版在 Figma 中如何拆分。
3. 再补页面内容字段模板，让 UI 页面生产不只停留在结构描述。
4. 最后补工程交接规范和 HTML 预览页同步。

## 4. 验收标准

- 每个 Figma 组件都有命名、尺寸、状态、变体和使用边界。
- 每类页面模板都有内容字段、必要状态、长文本规则和交付说明。
- 工程导出规范能直接指导 UI 切图、命名、倍率和状态资源管理。
- 新增内容不改变 v2.0.0 的基准画布、热区、字号、栅格和状态语义。
