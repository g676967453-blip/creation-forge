# 游戏界面模板

所有模板按 UI 承载类型划分。左侧展示必须为 `1080 x 1920px` 完整手机原型，右侧说明结构、层级、关闭方式和验收规则。

## 1. 主界面与导航栏

**用途**：长期停留的主场景、内容入口和同级模块切换。

**结构**：顶部 HUD -> 主视觉场景 / 核心内容 -> 高频入口或事件入口 -> 底部导航栏。

| 区域 | 承载内容 | 规则 |
| --- | --- | --- |
| 顶部 HUD | 身份、关键资源、通知、设置 | 不超过两行；关键状态始终可见。 |
| 中心区域 | 场景、当前进度、主入口、活动入口 | 优先展示游戏内容，不以纯列表替代。 |
| 底部导航栏 | `3-5` 个同级入口 | 当前项使用图标、文字和位置共同表达；可附红点。 |
| 快捷入口 | 高频、短路径操作 | 不与底部导航的功能重复。 |

验收：同屏只有一个视觉最强的主要操作；入口锁定、倒计时、可领取和新内容状态在入口本身表达；返回后恢复内容位置与状态。

## 2. 全屏窗口

**用途**：独立、复杂或沉浸式游戏内容，例如模式选择、规则阅读、内容预览、进入前配置或完整结果展示。

**结构**：顶部 HUD 或标题可选 -> 中心内容或场景 -> 底部“返回 + TAB”导航栏或底部主要操作。

- 隐藏主界面底部导航，改用当前窗口专属的底部返回路径。
- 底部“返回 + TAB”栏中，返回按钮固定左对齐；TAB 组固定在右侧并按统一间距对齐。
- 中心内容可以滚动，底部返回、TAB 或主要操作保持稳定。
- 页面栈最大深度为 5 层；超过后回到稳定入口。
- 离开存在未确认选择、输入或重要进度的窗口时，说明后果。

## 3. 弹窗 / 设计弹窗

**用途**：不离开来源页面即可完成确认、规则说明、短内容选择、奖励展示或结果提示。

| 类型 | 推荐宽度 | 内容与操作 | 关闭规则 |
| --- | ---: | --- | --- |
| 确认弹窗 | `760-840px` | 标题、短说明、取消、确认 | 取消、关闭和系统返回结果一致。 |
| 内容弹窗 | `840-920px` | 标题、可滚动内容、固定底部操作 | 内容复杂时改用全屏窗口。 |
| 设计弹窗 | 按视觉内容确定 | 主视觉、简短结果、获得内容、主要操作 | 不用于连续阅读或复杂筛选。 |

- 关闭后恢复来源页面的滚动、筛选、选择与输入上下文。
- 同时最多保留一层普通弹窗和一层其上的确认弹窗。
- 不可逆操作或离开当前内容时，不允许仅点遮罩关闭。

## 4. Tips

**用途**：解释单一对象、图标、规则字段或首次操作，不中断当前游戏内容。

| 类型 | 触发方式 | 规则 |
| --- | --- | --- |
| 元素 Tips | 点击图标、字段或帮助入口 | 指向单一目标，核心说明最多两行。 |
| 悬浮 Tips | 首次进入、局部提醒 | 自动避开屏幕边缘、手势区和主要操作。 |
| 新手引导 Tips | 首次关键操作 | 遮罩高亮当前目标，只解释当前一步。 |

- Tips 可点外部关闭，除非当前步骤是不可跳过的关键引导。
- 不使用 Tips 承载长规则、复杂选择或危险确认。
- 多条 Tips 不并发显示；新提示等待当前提示关闭。

## 5. 状态通知

**用途**：反馈获得、操作结果、网络状态、限制状态和短时全局信息。

| 类型 | 位置 | 内容规则 | 消失规则 |
| --- | --- | --- | --- |
| Toast | HUD 下方居中 | 图标、短标题、可选一行说明 | 自动消失；同一时刻仅一条。 |
| 跑马灯 | HUD 下方或顶部独立条 | 时效全局通知、简短公告 | 可关闭，不遮挡主要操作。 |
| 局部状态条 | 对应模块内部 | 加载、错误、断线、更新状态 | 状态恢复后自动更新。 |
| 系统中断提示 | 页面最高层 | 原因、恢复时间、返回或更新操作 | 用户处理后关闭。 |

- 成功、提醒、错误和信息同时使用颜色、图标和文案表达。
- 状态通知不改变页面栈，不替代确认弹窗或全屏窗口。
- 断线、结果确认中和加载超过等待阈值时，保留当前页面上下文并阻止重复提交。

## 6. 模板验收

1. 每个模板均以 `1080 x 1920` 手机原型展示完整结构。
2. 主界面、全屏窗口、弹窗、Tips 和状态通知不混用层级和关闭规则。
3. 主要操作、返回、关闭、取消和系统返回的行为一致且可预测。
4. 长文本、加载、错误、锁定、断线和窄屏设备下无裁切、重叠或误触。
