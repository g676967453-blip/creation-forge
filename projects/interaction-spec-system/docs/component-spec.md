# 组件母版库详规

## 1. 命名、状态与交付格式

### 1.1 命名规则

- 组件：`模块/组件/变体/状态`，例如 `Action/Button/Primary/Pressed`。
- 图层：`类型.语义.位置`，例如 `text.title.page`、`icon.action.close`。
- 位图：`ui_<模块>_<名称>_<状态>_<尺寸>@2x`，例如 `ui_action_close_default_72@2x`。
- 变体优先使用 `Primary`、`Secondary`、`Danger`、`Text`、`Filled`、`Outlined`、`Compact`、`Large` 等固定词；同义词不得并存。

### 1.2 通用状态矩阵

| 状态 | 必须表现 | 交互规则 | 适用组件 |
| --- | --- | --- | --- |
| Default | 正常对比、清晰边框 | 可操作 | 全部 |
| Pressed | 表面或描边立即变化 | 按住期间保持，抬起后执行或取消 | 可点击组件 |
| Selected | 选中标记、底色或位置变化 | 保留当前选择 | 标签、卡片、单选、格子 |
| Disabled | 降低对比且保留标签 | 不响应，不显示无效加载 | 可配置、不可用操作 |
| Locked | 锁图标、条件说明 | 点击说明解锁条件或入口 | 有前置条件的内容 |
| Loading | 局部占位或加载指示 | 阻止重复提交，不抹去既有内容 | 异步控件、列表、弹层 |
| Error | 状态色加明确文字 | 说明原因并提供重试或恢复 | 输入、请求、状态页 |
| Full | 当前值与上限、处理入口 | 引导管理、清理或扩容 | 容量、数量选择、内容格 |

除非组件语义不适用，每个母版都应含以上状态。状态说明必须和设计稿一起交付，不只留在备注中。

## 2. 操作组件

| 组件 | 推荐尺寸 | 结构与变体 | 长文本与交互 | 验收条件 |
| --- | --- | --- | --- | --- |
| `Action/Button/Primary` | `360 x 104`；宽主操作 `480 x 112` | 强表面、`4px` 描边、居中文案，可带左图标 | 文案最多 6 字；同一决策区唯一；按下 `0.97` | 默认、按下、禁用、加载与资源不足原因完整 |
| `Action/Button/Secondary` | `280 x 88` 或 `360 x 96` | 中性底、`2px` 描边、居中文案 | 与主操作并列时放左侧或下方；不抢主操作视觉 | 文字不换行，禁用仍能读出用途 |
| `Action/Button/Danger` | `360 x 96` | 危险色仅用于不可逆或高风险确认 | 必须与取消操作一起出现；首次或高影响操作需二次确认 | 不以红色承载唯一风险提示，含结果说明 |
| `Action/Button/Text` | 高 `72`，热区不小于 `88` | 无底色，文字或文字加箭头 | 用于低风险跳转、查看详情、稍后处理 | 不与主要文字混淆，按下态可见 |
| `Action/IconButton` | `72 x 72` 或 `88 x 88` | 单图标、可选底板、红点锚点在右上 | 不易理解的图标需首次说明或配文本；关闭、返回位置固定 | 热区独立，图标不替代含糊操作 |
| `Navigation/Tab` | 高 `80`；2-5 项 | 文案或图标加文案，选中项有底板或下划线 | 同层内容切换，保留合理滚动位置 | 已选、禁用、红点、超长标题均可读 |
| `Selection/Segmented` | 高 `72`；2-5 等宽段 | 统一外框、选中内块 | 仅用于轻量互斥选择；超过 5 项改用筛选或全屏页 | 选中态不只依赖颜色，切换无布局抖动 |
| `Control/Toggle` | `112 x 56`，热区 `88` 高 | 轨道、圆点、开/关语义 | 切换后立即更新；涉及影响较大的选项可补确认 | 开关位置、文字与真实状态一致 |
| `Control/Slider` | 高 `56`，拖拽点直径 `48-56` | 轨道、已填充段、拖拽点、当前数值 | 拖动实时显示数值；步进值由需求标注 | 最小/最大/禁用/错误范围有明确表现 |

### 2.1 操作组件补充规则

- 资源不足、条件不满足、冷却中均不得伪装成普通禁用。使用锁定、倒计时或说明性反馈区分原因。
- 触发请求后，按钮进入 Loading；完成或失败前不得重复提交。超过 800ms 仍无结果时保留可读加载提示。
- 两个并列操作必须有明确主次，不使用两个同等级强按钮。

## 3. 输入、选择与筛选

| 组件 | 推荐尺寸 | 结构与变体 | 长文本与交互 | 验收条件 |
| --- | --- | --- | --- | --- |
| `Input/Text` | 高 `88`；多行最小高 `152` | 标签、输入区、占位、清除、辅助/错误说明 | 标签常驻；输入值可横向滚动或尾部省略；标注最大字数 | 默认、聚焦、填写、错误、禁用、加载均完整 |
| `Input/Search` | 高 `88` | 搜索图标、输入区、清除按钮、结果状态 | 输入后 `300ms` 防抖；清除恢复初始列表或历史 | 无结果可重置筛选，搜索中不清空既有结果 |
| `Input/Number` | 高 `88`；步进按钮 `72 x 72` | 数值、减、加、单位、上限说明 | 支持键盘输入或步进；超上限即时提示 | 最小、最大、满容量、错误输入均不产生跳动 |
| `Selection/Dropdown` | 触发器高 `80`；选项高 `80` | 当前值、箭头、选项浮层、可选搜索 | 浮层至少同触发器宽；默认最多露出 7 项 | 选中值可读，点击外部关闭并不丢失未确认值 |
| `Selection/Checkbox` | 图形 `40 x 40`，行热区高 `72` | 方框、标签、可选说明 | 多选；整行可点击；不可用项说明原因 | 未选、选中、半选、禁用、锁定完整 |
| `Selection/Radio` | 图形 `40 x 40`，行热区高 `72` | 圆形标记、标签、可选说明 | 同组只能选一项；默认项应明确 | 已选项视觉稳定，不允许取消后无选项，除非需求允许 |
| `Filter/Chip` | 高 `56-64` | 短标签、可选关闭或数量 | 超出一行改横向滚动或进入筛选页；不可挤压 | 选中、默认、禁用、可清除、计数显示完整 |
| `Filter/Panel` | 全屏页或宽 `840-920` 弹层 | 分类、选项、重置、确认 | 筛选较多时使用暂存选择，确认后应用 | 有已选数量、重置、应用和返回后的状态保留 |

输入类错误说明放在控件下方，不用抖动或仅改变边框表示。输入自动校验不得在用户尚未完成输入时持续打断。

## 4. 信息、反馈与状态

| 组件 | 推荐尺寸 | 结构与变体 | 规则 | 验收条件 |
| --- | --- | --- | --- | --- |
| `Info/Badge` | 高 `32-48` | 短文字、可选小图标 | 用于分类、状态、数量；文字最长 4 字 | 深浅背景均可读，状态不只靠颜色 |
| `Info/RedDot` | `20-32` | 实心点或数量徽标 | 数量超过 `99` 显示 `99+`；处理后即时刷新 | 不遮挡图标、标题或触控热区 |
| `Info/ProgressBar` | 高 `24/32/48` | 底槽、填充、数值、可选分段 | 确定进度显示当前/总量；未知进度使用循环提示 | 极值、满值、错误和加载表现可区分 |
| `Feedback/Toast` | 宽 `560-760`，高随内容 | 图标、标题、最多两行说明 | 顶部 HUD 下方居中；同一时刻仅一条，短提示自动消失 | 不盖住主操作；错误提示保留足够阅读时间 |
| `Feedback/Marquee` | 高 `64-80` | 图标、单行文案、关闭 | 仅用于时效全局信息；不遮挡 HUD 和主要内容 | 可关闭，长文案平滑滚动且可完整阅读 |
| `Feedback/Tooltip` | 宽 `320-520` | 指向箭头、标题、短说明、可选操作 | 指向单一目标；核心说明不超过两行 | 自动避开屏幕边缘和手势区 |
| `Feedback/StatusNotice` | 高 `72-112` | 状态图标、文字、操作 | 局部成功、提醒、错误或网络状态 | 语义色、图标、文本三者一致 |
| `State/Skeleton` | 跟随最终布局 | 灰色块、行、卡片占位 | 原位替换，最短显示 `300ms` | 不改变完成后元素位置 |
| `State/Empty` | 内容区垂直居中 | 图形、标题、说明、可选操作 | 解释“没有内容”的原因与下一步 | 与错误状态的文案、图形、操作区分 |
| `State/Error` | 内容区垂直居中 | 图形、原因、重试/返回 | 可恢复时提供重试；不可恢复时提供返回 | 不使用模糊的“发生错误”作为唯一说明 |
| `State/Full` | 页面内提示或弹层 | 当前值、上限、处理入口 | 可管理、清理或扩容时给出直接入口 | 阻断操作前先说明影响和处理路径 |

## 5. 容器与内容组件

| 组件 | 推荐尺寸 | 结构与变体 | 长文本与交互 | 验收条件 |
| --- | --- | --- | --- | --- |
| `Layout/TopHUD` | 高 `96-160` | 左返回/身份，中标题，可选右侧状态和操作 | 信息过多拆为两行或转入更多菜单 | 不压缩热区；在刘海区外稳定显示 |
| `Info/PlayerBar` | 高 `80-112` | 头像、名称、等级/状态、可选操作 | 名称一行省略；状态紧邻主体信息 | 无头像、超长名、离线状态均可用 |
| `Info/Avatar` | `48/64/80/112/160` | 图片、边框、状态角标 | 失败时显示默认占位；角标不遮挡主体 | 尺寸按层级固定，支持加载态 |
| `Info/Nameplate` | 高 `40-56` | 图标、短名称、弱表面 | 最长一行尾部省略 | 信息不与头像或状态角标重叠 |
| `Container/Card` | 宽按栅格；高固定或比例固定 | 标题、媒体区、元信息、状态、操作 | 整卡可点时不再叠加多个冲突按钮 | 默认、选中、锁定、禁用、加载、错误都不改尺寸 |
| `Container/ListItem` | 高 `96-168` | 左识别区、中信息区、右状态或一个操作 | 主标题两行、说明一行；右侧不挤压左中信息 | 整行与右侧操作热区不冲突，分割线对齐 |
| `Container/Grid` | `3-5` 列，间距 `16-24` | 固定列数、固定格比、滚动内容 | 仅网格滚动；筛选和标题固定 | 任何状态角标不改变格子大小 |
| `Container/Slot` | `120-184` 方形 | 图形、数量、角标、锁定层 | 数量右下，状态左上；数量过大缩写 | 空、选中、锁定、满、冷却和新内容完整 |

## 6. 弹层、全屏页与新手引导

| 组件 | 推荐尺寸 | 结构与变体 | 规则 | 验收条件 |
| --- | --- | --- | --- | --- |
| `Overlay/ConfirmDialog` | 宽 `760-840` | 标题、说明、取消、确认、关闭可选 | 仅用于需明确决策的短内容；最多两个操作 | 关闭、取消、系统返回的结果一致 |
| `Overlay/ContentDialog` | 宽 `840-920` | 标题、滚动内容、固定底部操作 | 内容超过 10 条或需要复杂筛选时改全屏页 | 滚动区与操作区独立，关闭不丢失明确输入规则 |
| `Overlay/Fullscreen` | 覆盖安全区内页面 | 返回、标题、内容、固定操作可选 | 用于复杂选择、设置、沉浸内容或长列表 | 有稳定返回路径和恢复原页面上下文 |
| `Guide/Spotlight` | 全屏遮罩 | 高亮目标、短文案、手势提示、步骤 | 只解释当前一步；允许跳过时入口固定 | 高亮准确，键盘/弹层出现时能重新定位 |
| `Overlay/CloseRule` | 不单独出图 | 关闭、取消、返回、遮罩点击 | 破坏性内容不允许仅点遮罩关闭；未保存输入需说明结果 | 所有关闭路径都可预测且不造成意外丢失 |

### 6.1 优先级规则

1. 系统中断与强制更新最高，其次是不可忽略的新手引导，再次是高风险确认。
2. 同一时刻不叠加两层普通弹窗；后到的低优先级内容排队或转为 Toast。
3. 全局公告、短提示、红点不抢占用户正在填写或确认的操作。
4. 关闭高优先弹层后，恢复底层页面原有滚动位置、筛选和输入状态。

## 7. 生产验收清单

每个组件分类交付时至少检查以下五项：

1. **尺寸**：视觉尺寸、最小热区、内边距、图标尺寸和栅格占位已标注。
2. **状态**：默认、按下、选中、禁用、锁定、加载、错误、满容量中适用项齐全。
3. **命名**：母版、变体、图层与资源命名符合本页规则。
4. **规则**：长文本、红点、倒计时、资源不足、重复点击和返回行为明确。
5. **验收**：在基准、窄屏、长屏和手势设备中无裁切、重叠、跳动或不可触达内容。
