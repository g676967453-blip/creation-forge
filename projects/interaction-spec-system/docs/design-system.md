# 通用竖版手游 UI 设计系统

> 版本：1.0.0<br>
> 生产基准：`1080 x 1920px` 竖版手机原型<br>
> 使用对象：UI、交互、美术、产品与界面生产协作人员

---

## 01 系统说明

### 1.1 系统定位

本系统面向多种竖版移动游戏，提供可复用的页面、组件、视觉和交互生产规则。它不绑定任何题材、玩法、美术资产或具体项目内容；不同项目可在同一结构上叠加各自的主题风格。

### 1.2 生产基准

1. 当前页面、组件、文字尺寸、间距、栅格与规则，均基于 `1080 x 1920px` 竖版画布生成与标注。
2. 页面适配通过安全区、固定区与中心内容区处理；不得为了适配设备而改变组件语义、最小热区或字号层级。
3. 所有页面均以完整手机原型图进行展示和验收，不使用脱离页面的散点组件展示。
4. 设计系统页面采用固定双栏结构：左侧展示等比例 `1080 x 1920` 手机原型，右侧说明对应规则、尺寸、状态和验收要求。

### 1.3 使用边界

- 可替换：背景、材质、插画、品牌强调色、局部图标风格与内容文案。
- 不可替换：组件结构、触控尺寸、状态语义、信息层级、安全区和基础可读性规则。
- 同一页面只保留一个视觉最强的主要操作；其余操作按优先级降级。
- 颜色、图标、文案和位置共同表达状态，不能只依赖其中一种。

### 1.4 页面展示原则

| 区域 | 内容 | 规则 |
| --- | --- | --- |
| 左侧 | `1080 x 1920` 手机原型 | 完整页面或完整状态，包含顶部、内容与底部关系。 |
| 右侧 | 规则说明 | 说明用途、结构、尺寸、状态、长文本、交互和验收。 |
| 样例 | 一次只说明一个重点 | 不在单个原型中堆叠无关组件。 |
| 状态 | 与默认原型同结构 | 加载、空、错误、锁定等状态不得改变页面骨架。 |

## 02 设计指令

基础视觉采用黑、白、灰构建信息层级；美术主题可替换背景、材质、插画与局部强调色，但不改变组件结构、状态语义、热区和可读性。

### 2.1 色彩系统

| 类别 | 色值 | 用途 | 使用规则 |
| --- | --- | --- | --- |
| 页面背景 | `#F5F5F5` | 整体底色 | 承载页面结构，不作为状态色。 |
| 内容表面 | `#FFFFFF` | 卡片、列表、弹层、输入框 | 与页面背景形成明确层次。 |
| 弱表面 | `#EEEEEE` | 次级内容、选中底色、占位 | 不承载关键文字。 |
| 主文字 / 强描边 | `#000000` | 标题、正文、图标、主要操作 | 用于最高识别层级。 |
| 次文字 | `#616161` | 说明、时间、单位、辅助信息 | 不用于关键操作。 |
| 弱描边 | `#BDBDBD` | 分隔线、次级边界 | 与强描边搭配使用。 |
| 成功 | `#2B8A3E` | 完成、有效、可领取 | 同时配合文案或图标。 |
| 提醒 | `#E67700` | 待处理、临近上限、注意事项 | 不用于危险操作。 |
| 错误 | `#C92A2A` | 失败、不可执行、危险操作 | 必须提供原因或处理路径。 |
| 信息 | `#1864AB` | 帮助、说明、可跳转提示 | 不能与主要操作混淆。 |
| 普通品质 | `#868E96` | 普通内容的品质边框 | 不与禁用状态混用。 |
| 稀有品质 | `#1864AB` | 稀有内容的品质边框 | 依靠品质上下文区分信息色。 |
| 史诗品质 | `#6741D9` | 史诗内容的品质边框 | 只用于品质表达。 |
| 传说品质 | `#E67700` | 传说内容的品质边框 | 不替代提醒状态。 |
| 神话品质 | `#C92A2A` | 神话内容的品质边框 | 不替代危险状态。 |

**中性色阶**：`#111418`（强文字与描边）、`#343A40`（次级强文字）、`#646B73`（辅助文字）、`#CFD3D7`（分割线）、`#E8EBED`（弱表面）、`#F1F2F3`（页面底）、`#FFFFFF`（内容表面）。

**使用比例**：中性色承担 80% 以上的页面面积和信息层级；语义色仅用于结果、提醒、帮助和需要立即识别的状态。主题层只能替换背景、材质、插画和品牌强调，不能重定义成功、提醒、错误、信息的含义。

### 2.2 字体系统

| 层级 | 字号 / 行高 | 用途 | 文本规则 |
| --- | --- | --- | --- |
| 页面主标题 | `64 / 76` | 页面首要标题、关键结果 | 最多两行。 |
| 页面标题 | `48 / 60` | 全屏页、模块标题 | 最多两行。 |
| 区块标题 | `40 / 52` | 面板、列表组标题 | 最多两行。 |
| 主要正文 | `32 / 44` | 主按钮、关键数值 | 单行优先。 |
| 正文 | `28 / 40` | 列表、说明、操作 | 最多三行。 |
| 辅助说明 | `24 / 32` | 标签、时间、单位 | 最多两行。 |
| 角标 | `20 / 28` | 徽标、短状态、数量 | 单行。 |

| 用途 | 字族 | 参考命名 |
| --- | --- | --- |
| 标题 / 按钮 | 几何无衬线、粗体 | `--font-heading` |
| 正文 / 标签 | 中性无衬线、常规 | `--font-body` |
| 数值 / 代码 / 单位 | 等宽字形 | `--font-mono` |

- 数字优先使用等宽字形；同一页面统一使用 `1,250`、`1.2K` 或 `1.2万` 中的一种格式。
- 时间统一使用 `02:30:00` 或 `1h 23m` 中的一种格式。
- 按钮文案不超过 6 个汉字；名称单行省略；说明限定最大行数。
- 不可通过缩小字号来容纳长文本，应采用省略、换行限制、详情页或 Tips。

| 数值类型 | 显示规则 | 示例 |
| --- | --- | --- |
| 数量 | 千位分隔；超过 `999,999` 时按项目规则简写 | `12,450` / `1.2M` |
| 进度 | 当前值 / 总值；总值未知时显示加载状态 | `24 / 50` |
| 倒计时 | 同屏统一为 `HH:MM:SS` 或 `D 天 HH:MM` | `02:14:32` |
| 增减 | 必须有正负号和语义色，同时保留文字说明 | `+120` / `-20` |

### 2.3 间距系统

| 分类 | 规则 |
| --- | --- |
| 间距 | 以 `4px` 为基准：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64px`；组件内基准 `8px`。 |

### 2.8 动效系统

| 场景 | 时长 | 规则 |
| --- | ---: | --- |
| Instant | `100ms` | 按钮按下、开关切换。 |
| Fast | `200ms` | Hover 反馈、元素显隐。 |
| Base | `300ms` | 弹窗进出、页面路由过渡。 |
| Slow | `500ms` | 关键结算、获得演出。 |

- 同一屏持续动效不超过三处。
- 动效、声音、触感只增强反馈，不能替代文字或状态说明。
- 非关键演出可跳过；声音与触感可在设置中关闭。

## 03 组件规范

### 3.1 通用交付字段

每个组件母版必须提供以下内容：用途、结构、推荐尺寸、变体、默认 / 按下 / 选中 / 禁用 / 锁定 / 加载 / 错误 / 满容量中的适用状态、命名、长文本规则、交互规则和验收条件。

### 3.2 命名规则

| 对象 | 命名格式 | 示例 |
| --- | --- | --- |
| 组件 | `模块/组件/变体/状态` | `Action/Button/Primary/Pressed` |
| 图层 | `类型.语义.位置` | `text.title.page` |
| 图片资源 | `ui_<模块>_<名称>_<状态>_<尺寸>@2x` | `ui_action_close_default_72@2x` |

### 3.3 按钮 Button

| 变体 | 推荐尺寸 | 必备状态 | 规则 |
| --- | --- | --- | --- |
| 主按钮 | `360 x 104`；宽按钮 `480 x 112` | 默认、按下、禁用、加载、资源不足 | 同一决策区唯一，文案不超过 6 字。 |
| 次按钮 | `280 x 88` 或 `360 x 96` | 默认、按下、禁用 | 不与主按钮争夺优先级。 |
| 危险按钮 | `360 x 96` | 默认、按下、禁用、确认中 | 用于不可逆操作，必须说明后果。 |
| 文字 / 图标按钮 | 热区高 `88`；`72 / 88` 方形 | 默认、按下、红点、禁用 | 难懂图标需配文字或首次说明。 |

参考变体包含实底主按钮、浅底次按钮、透明线框按钮、文字按钮、小尺寸与大尺寸按钮；主要操作使用强调实底，线框和文字按钮不与主操作竞争。

### 3.4 徽章 Badge

| 类型 | 推荐尺寸 | 规则 |
| --- | --- | --- |
| 文本徽章 | 高 `32-48` | 分类或状态文案最长 4 字。 |
| 数量角标 | `20-32` | 超过 `99` 显示 `99+`，处理后立即更新。 |
| 状态徽章 | 高 `32-48` | 同时使用颜色、图标或文案，不只依赖颜色。 |

徽章可用于品质、等级、分类、状态和数量；品质色只表达品质，错误、提醒等业务状态仍使用语义功能色。

### 3.5 开关 & 滑块 Toggle & Slider

| 组件 | 推荐尺寸 | 必备状态 | 规则 |
| --- | --- | --- | --- |
| 开关 Toggle | `112 x 56` | 开、关、禁用、加载 | 状态与文字一致，不只依赖圆点位置。 |
| 滑块 Slider | 高 `56` | 默认、拖动、禁用、范围错误 | 实时显示当前值、最小值与最大值。 |

滑块轨道、已选区和拖拽把手必须始终可区分；禁用态整体降低对比度且保留当前值。

### 3.6 页签 Tab

| 组件 | 推荐尺寸 | 必备状态 | 规则 |
| --- | --- | --- | --- |
| 标签页 | 高 `80` | 默认、选中、禁用、红点 | 仅用于同层内容切换。 |
| 分段切换 | 高 `72` | 默认、选中、禁用 | 限 `2-5` 项互斥选择。 |

选中页签使用深色实底或明确下划线，未选页签保持可读；页签切换在原位完成，不推动页面框架。

### 3.7 进度条 Progress

| 类型 | 推荐尺寸 | 规则 |
| --- | --- | --- |
| 确定进度 | 高 `24 / 32 / 48` | 显示当前值 / 总量，进度变化不改变容器尺寸。 |
| 不确定进度 | 高 `24 / 32 / 48` | 使用循环提示，完成后原位替换。 |

确定进度必须同时显示数值或百分比；未知进度不可伪装为 `0%`。

### 3.8 输入框 Input

| 类型 | 推荐尺寸 | 必备状态 | 规则 |
| --- | --- | --- | --- |
| 文本输入 | 高 `88`；多行最小高 `152` | 默认、聚焦、填写、错误、禁用 | 标签常驻，错误文案置于控件下方。 |
| 搜索输入 | 高 `88` | 默认、搜索中、无结果、错误 | 保留已展示结果，输入后延迟请求。 |
| 数值输入 | 高 `88` | 默认、最小、最大、满容量、错误 | 减 / 加热区不小于 `72 x 72`。 |

输入框聚焦时使用品牌描边和轻光晕；搜索、数值和文本输入均保留已输入内容，错误信息固定出现在控件下方。

### 3.9 Toast / 红点 Notification

| 组件 | 推荐尺寸 | 规则 |
| --- | --- | --- |
| Toast | 宽 `560-760` | 位于 HUD 下方；同一时刻只显示一条，显示 `2-4s` 后自动消失。 |
| 红点 | `20-32` | 数量超过 `99` 显示 `99+`；处理后立即更新。 |
| 跑马灯 | 高 `64-80` | 时效全局信息，可关闭，不覆盖主要操作。 |

Toast 以图标、短标题和可选一行说明构成；红点可为空心提示或数量角标，数量超过 `99` 时统一显示 `99+`。

## 04 网格与框架

### 4.1 画布与安全区

| 项目 | 规则 |
| --- | --- |
| 基准画布 | `1080 x 1920px`，竖屏 `9:16`。 |
| 顶部安全区 | 基准 `88px`；实际设备按系统避让区域增加。 |
| 底部安全区 | 基准 `120px`；与系统手势条至少保留 `32px`。 |

| 紧凑边距 | 左右 `32px`，仅用于密集页面。 |
| 弹层内边距 | `40px`。 |

### 4.2 四列栅格

内容宽度为 `984px`，使用四列等宽栅格：列宽 `231px`，沟槽 `20px`。

| 占列 | 使用场景 |
| ---: | --- |
| 1 列 | 图标入口、内容格、短卡片。 |
| 2 列 | 双卡片、双数据、并列操作。 |
| 3-4 列 | 列表项、筛选条、数据面板。 |
| 4 列 | 主内容、宽卡片、正文和弹层内容。 |

### 4.3 页面三段框架

| 区域 | 推荐高度 | 规则 |
| --- | ---: | --- |
| 顶部 HUD | `96-160px` | 返回、标题、身份、状态、设置。 |
| 中心内容区 | 自适应 | 页面唯一主滚动容器。 |
| 底部导航 | `144-176px`，含安全区 | 3-5 个同级入口。 |
| 底部主操作 | `160-240px`，含安全区 | 服务当前任务，替代而非叠加底部导航。 |

- 长屏只增加中心内容可视范围，不放大固定控件。
- 窄屏优先折叠次要信息，不缩小正文、按钮或热区。
- 键盘弹出时，使当前输入和提交操作保持可见。

## 05 界面模板

模板按 UI 的承载类型划分。所有样例都以 `1080 x 1920` 完整手机原型呈现，右栏说明对应层级、关闭方式和适用边界。

### 5.1 主界面与导航栏

**用途**：游戏长期停留的主场景、内容入口和同级模块切换。

**标准结构**：顶部 HUD -> 主视觉场景 / 核心内容 -> 高频入口或事件入口 -> 底部导航栏。

| 区域 | 承载内容 | 规则 |
| --- | --- | --- |
| 顶部 HUD | 身份、关键资源、通知、设置 | 不超过两行；关键状态始终可见。 |
| 中心区域 | 场景、当前进度、主入口、活动入口 | 优先展示游戏内容，不以纯列表替代主界面。 |
| 底部导航栏 | `3-5` 个同级入口 | 当前项使用图标、文字和位置共同表达；可附红点。 |
| 快捷入口 | 高频、短路径操作 | 不与底部导航的功能重复。 |

- 同屏只有一个视觉最强的主要操作。
- 主界面返回后恢复用户之前的内容位置与状态。
- 入口的锁定、倒计时、可领取和新内容状态应在入口本身表达。

**参考结构补充**：主界面 HUD 由玩家身份、资源项与活动入口构成；资源单项为图标、数值和可选加号按钮。底部 Dock 使用固定数量的图标加文字入口，中间 CTA 可高出 Dock，其余入口可挂载红点。HUD 与 Dock 之间承载主场景、快捷入口、任务或活动内容。

### 5.2 全屏窗口

**用途**：承载独立、复杂或沉浸式游戏内容，例如模式选择、规则阅读、内容预览、进入前配置或完整结果展示。

**标准结构**：顶部 HUD 或标题可选 -> 中心内容或场景 -> 底部“返回 + TAB”导航栏或底部主要操作。

- 进入全屏窗口后隐藏主界面底部导航，改用当前窗口专属的底部返回路径。
- 底部“返回 + TAB”栏中，返回按钮固定左对齐；TAB 组固定在右侧并按统一间距对齐。
- 中心内容可以滚动，底部返回、TAB 或主要操作保持稳定。
- 全屏窗口内再次进入内容时，页面栈最大深度为 5 层；超出后回到稳定入口。
- 离开存在未确认选择、输入或重要进度的窗口时，说明后果。

| 参考窗口 | 顶部 | 中部 | 底部 |
| --- | --- | --- | --- |
| 角色养成 | 返回、标题、页签 | 属性、装备、符文、升星等内容 | 返回 + 页签。 |
| 角色仓库 | 返回、标题、容量 | 分类页签、角色横向列表 | 返回 + 页签。 |
| 商店界面 | 返回、标题、资源 | 商品列表、价格与购买操作 | 返回 + 页签。 |
| 任务界面 | 返回、标题、进度 | 每日、周常、成就等纵向列表 | 返回 + 页签。 |

### 5.3 弹窗 / 设计弹窗

**用途**：在不离开来源页面的情况下完成确认、规则说明、短内容选择、奖励展示或结果提示。

| 类型 | 推荐宽度 | 内容与操作 | 关闭规则 |
| --- | ---: | --- | --- |
| 确认弹窗 | `760-840px` | 标题、短说明、取消、确认 | 取消、关闭和系统返回结果一致。 |
| 内容弹窗 | `840-920px` | 标题、可滚动内容、固定底部操作 | 内容复杂时改用全屏窗口。 |
| 设计弹窗 | 按视觉内容确定 | 主视觉、简短结果、获得内容、主要操作 | 不使用于连续阅读或复杂筛选。 |

- 弹窗出现时保留来源页面状态，关闭后恢复滚动、筛选、选择与输入上下文。
- 同时最多保留一层普通弹窗和一层其上的确认弹窗；低优先级提示转为状态通知。
- 不可逆操作、离开当前内容或可能损失进度时，不允许仅点遮罩关闭。

**参考弹窗类型**：活动弹窗用于登录后自动出现的主视觉活动信息，支持“今日不再显示”；确认弹窗按普通、危险、消费区分确认按钮；奖励弹窗用于展示获得物，主操作为确认或继续。多个弹窗按优先级排队，不可叠加。

### 5.4 Tips

**用途**：解释单一对象、图标、规则字段或首次操作，不中断当前游戏内容。

| 类型 | 触发方式 | 规则 |
| --- | --- | --- |
| 元素 Tips | 点击图标、字段或帮助入口 | 指向单一目标，核心说明最多两行。 |
| 悬浮 Tips | 首次进入、局部提醒 | 自动避开屏幕边缘、手势区和主要操作。 |
| 新手引导 Tips | 首次关键操作 | 遮罩高亮当前目标，只解释当前一步。 |

- Tips 可点外部关闭，除非当前步骤是不可跳过的关键引导。
- 不使用 Tips 承载长规则、复杂选择或危险确认。
- 多条 Tips 不并发显示；新提示应等待当前提示关闭。

**参考形态**：物品提示框使用深色背景、白色文字和指向触发对象的箭头；新手引导使用遮罩高亮目标；系统通知可使用 Toast、顶部公告条或局部状态条。

### 5.5 状态通知

**用途**：反馈获得、操作结果、网络状态、限制状态和短时全局信息。

| 类型 | 位置 | 内容规则 | 消失规则 |
| --- | --- | --- | --- |
| Toast | HUD 下方居中 | 图标、短标题、可选一行说明 | 自动消失；同一时刻仅一条。 |
| 跑马灯 | HUD 下方或顶部独立条 | 时效全局通知、简短公告 | 可关闭，不遮挡主要操作。 |
| 局部状态条 | 对应模块内部 | 加载、错误、断线、更新状态 | 状态恢复后自动更新。 |
| 系统中断提示 | 页面最高层 | 原因、恢复时间、返回或更新操作 | 用户处理后关闭。 |

- 成功、提醒、错误和信息必须同时使用颜色、图标和文案表达。
- 状态通知不改变页面栈，不替代确认弹窗或全屏窗口。
- 断线、结果确认中和加载超过等待阈值时，保留当前页面上下文并阻止重复提交。

**状态模板补充**：空状态由图标、标题、说明和下一步操作构成；骨架屏按最终布局原位占位；错误状态提供原因和重试按钮。关键反馈覆盖“恭喜获得”“战斗胜利”“等级提升”及获得、失败、锁定等结果，分别使用主视觉、品质色、奖励内容和明确的下一步操作。

## 06 资源管理

### 6.1 目录建议

```text
/assets
  /icons
  /components
  /media
  /fonts
```

### 6.2 资源命名与导出

| 类别 | 规则 |
| --- | --- |
| 图标 | `ui_<模块>_<名称>_<状态>_<尺寸>@2x`。 |
| 组件图片 | 使用模块、变体、状态和尺寸命名。 |
| 页面媒体 | 使用页面、区域、用途和尺寸命名。 |
| 导出倍率 | 交付 `@1x / @2x / @3x`，按项目工程要求选择。 |
| 可拉伸背景 | 使用 `.9.png`，并标注可拉伸区域。 |
| 字体 | 标明字重、授权状态与应用层级。 |

### 6.3 交付清单

每个页面交付时应包含：

1. `1080 x 1920` 主稿与适用状态稿。
2. 页面、组件、图层和资源命名。
3. 安全区、栅格、固定区、滚动区和弹层层级标注。
4. 长文本、异常数值、加载、空、错误、锁定、满容量与断线恢复说明。
5. 图片、图标、字体和可拉伸背景的资源清单。

### 6.4 变更与废弃

- 修改组件前说明影响页面、替代方案、状态变化和验收条件。
- 废弃组件保留两个版本周期，并提供迁移方式。
- 资源替换保持文件名、尺寸和导出规则可追溯，避免无记录覆盖。

## 07 协作说明

### 7.1 协作流程

| 阶段 | 输入 | 产出 |
| --- | --- | --- |
| 需求确认 | 页面目标、内容优先级、用户动作 | 页面框架与状态范围。 |
| 界面生产 | 组件母版、栅格、资源要求 | `1080 x 1920` 页面原型与标注。 |
| 评审 | 默认、异常、长文本与适配稿 | 问题清单与修改结论。 |
| 交付 | 已确认页面、资源清单、变更记录 | 可追溯的生产版本。 |

### 7.2 职责边界

| 角色 | 主要职责 |
| --- | --- |
| 视觉设计 | 维护颜色、字体、组件外观、样例原型与主题边界。 |
| 交互设计 | 维护状态、页面路径、反馈、异常与恢复规则。 |
| 界面生产 | 引用母版，填入内容，补齐资源、适配与交付标注。 |
| 产品 | 明确页面目标、信息优先级、规则与不可逆操作。 |
| 评审验收 | 核对画布、状态、长文本、安全区、返回和恢复行为。 |

### 7.3 评审与验收

每次评审至少检查：

1. 页面是否以 `1080 x 1920` 手机原型呈现，左侧展示与右侧说明是否一致。
2. 组件是否具备适用的默认、按下、选中、禁用、锁定、加载、错误与满容量状态。
3. 页面是否覆盖加载、空、错误、断线与恢复状态。
4. 长文本、极端数值、刘海区、手势区、窄屏与长屏是否可用。
5. 返回、关闭、取消、提交、失败重试和结果未知是否有明确规则。
6. 资源命名、交付清单和变更记录是否完整。

## 附：快速使用方式

1. 先选择界面模板，再确定 `1080 x 1920` 页面框架。
2. 依据组件规范引用母版与状态，不从零开始绘制重复控件。
3. 按设计指令使用颜色、字体、间距、层级和动效。
4. 补齐资源管理和协作说明中的标注后进入评审。
