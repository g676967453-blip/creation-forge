# 游戏场景界面模式库

> 版本：v2.1 新增（2026-08-06）<br>
> 定位：在「界面模板」（按承载类型划分）之上，按游戏场景提供具体的分区结构范式。<br>
> 来源：基于竖版放置卡牌类上线产品公开界面截图的结构分析抽象（参考样本：《龙符：天祭》，141 张截图中采样 12 张代表界面）。仅提取布局结构与信息层级，不包含题材、美术资产与文案；全部规则已通用化重写。

## 0. 与界面模板的关系

- `screen-patterns.md` 按 **UI 承载类型** 划分：主界面、全屏窗口、弹窗、Tips、状态通知。
- 本文件按 **游戏场景** 划分：每个场景套用一种承载类型，并给出具体的分区、尺寸与信息层级。
- 冲突时以本文件的承载类型映射为准回到模板规则；主题、美术、文案可替换，分区结构、信息层级、操作位与状态语义不可替换。

| 场景模式 | 承载类型 | 页面栈规则 |
| --- | --- | --- |
| 加载页 | 独立全屏层，无页面框架 | 不入页面栈，完成即销毁 |
| 主界面（场景化大厅） | 主界面与导航栏 | 栈底，返回恢复内容位置 |
| 关卡 / 征战页 | 主界面同级页签或全屏窗口 | 保留节点位置与章节选择 |
| 战斗页 | 全屏窗口；放置类可保留底部导航 | 结算后返回来源位置 |
| 布阵页 | 全屏窗口 | 未确认阵容离开需提示 |
| 结算反馈页 | 设计弹窗或全屏层 | 点击任意处继续，可跳过 |
| 养成详情页 | 全屏窗口 | 返回 + 页签结构 |
| 个人主页 | 全屏窗口 | 返回恢复来源 |

## 1. 加载页

**用途**：资源加载与品牌氛围展示，玩家对游戏的第一印象。

**结构**：

| 区域 | 位置与尺寸 | 内容 | 规则 |
| --- | --- | --- | --- |
| 版本信息 | 左上，安全区内缩 `16` | 版本号、资源版本 | `20-24` 号弱文字，单行，不干扰主视觉 |
| 主视觉 KV | 全屏出血 | 角色或场景主视觉 | 视觉重心位于上 `1/3`；前景透视构图增强纵深；遵循全屏背景 `1334 x 750` 核心区规则 |
| 进度区 | 底部，距底边安全区上方 `48` | 压暗渐变底 + 进度条 + 数值 | 进度条宽 `640-720`、高 `24-32`，居中；确定进度必须显示百分比或数值 |

- 全屏信息元素不超过 3 项（版本、进度条、进度数值），其余全部让位主视觉。
- 进度区使用自下而上的压暗渐变，保证任何美术图下文字可读。
- 进度条视觉融入主题色调，不使用系统默认样式。
- 未知进度不可伪装为 `0%`；资源校验失败时给出重试入口，不无限循环。

**验收**：弱网下进度数值持续推进可见；长屏设备主视觉中心对齐不拉伸；进度区文字在任何 KV 下对比度达标。

## 2. 主界面（场景化大厅）

**用途**：玩家长期停留的主场景，功能入口与世界观包装的统一载体。

**结构**：

| 区域 | 位置与尺寸 | 内容 | 规则 |
| --- | --- | --- | --- |
| 顶部 HUD | 高 `160-200` | 左侧身份簇：头像 + 昵称 + VIP / 等级 + 战力；右侧资源簇：货币项（≤ 3 项） | 身份与资源左右分栏；资源项为「图标 + 数值 + 加号」，加号热区 ≥ `72 x 72` |
| 主场景区 | 中心内容区 | 功能入口长在场景建筑 / 地标上，配竖排或横排标签 | 场景即菜单；未解锁功能带锁图标前置可见，不隐藏 |
| 运营入口列 | 左边缘竖排 | 活动、商城、福利等运营位 | 统一角标体系；不超过 4 个，避免遮挡场景主体 |
| 工具入口 | 右下 | 邮件、背包、设置 | 与运营位分区，不混排 |
| 底部导航 | 高 `144-176` 含安全区 | `3-5` 个同级入口 | 中央主玩法 CTA 可放大并向上凸起 `24-48` 破格，全导航唯一 |
| 信息条（可选） | 导航栏上方 | 半透明聊天 / 公告条 | 高 `48-64`，不遮挡主场景交互区 |

- 同屏只有一个视觉最强操作：中央 CTA 破格后，其余入口保持同级权重。
- 入口的锁定、倒计时、可领取、新内容状态在入口本身表达（锁图标、角标、光效）。
- 竖排文字标签适用于题材贴合的建筑立面，节省横向空间；标签必须有点击热区 ≥ `72`。
- 返回主界面后恢复之前的场景视角、入口状态与红点消费情况。

**验收**：HUD 两行信息不压缩热区；中央 CTA 凸起不遮挡导航项文字；锁定入口点击后说明解锁条件。

## 3. 关卡 / 征战页

**用途**：关卡选择、进度展示与战斗入口，放置类的核心循环页。

**结构**：

| 区域 | 内容 | 规则 |
| --- | --- | --- |
| 顶部 HUD | 与主界面一致 | 跨页签保持位置稳定 |
| 章节标识 | 章节名，可竖排横幅贴左缘 | 兼具导航与装饰；切换章节不改变 HUD |
| 关卡节点组 | 弧形 / 路径式节点排布，环绕战斗入口 | 节点直径 `96-144`；奖励图标前置展示在节点上；三态：已完成 / 当前（高亮 + 引导）/ 未解锁（锁） |
| 战斗入口 | 页面视觉中心，「挂机 / 开战」双入口并列 | 双入口同等级并列，直接传达核心循环；当前关卡号紧邻标注 |

- 弧形 / 路径排布使视线自然汇聚到战斗入口，节点奖励前置减少点击层级。
- 当前关卡节点使用唯一高亮 + 动效，已完成与未解锁降低对比。
- 关卡进度变化时节点原位更新，不重置玩家浏览位置。

**验收**：节点三态可辨识；双入口热区 ≥ `88`；长章节列表可滚动且章节标识固定。

## 4. 战斗页

**用途**：自动 / 半自动战斗演出与轻量操控，放置类的核心观感页。

**结构**：

| 区域 | 位置与尺寸 | 内容 | 规则 |
| --- | --- | --- | --- |
| VS 对抗栏 | 顶部，高 `96-128` | 左己方（冷色）/ 右敌方（暖色），中央徽章作 VS 锚点；下方关卡号 + 倒计时 | 阵营色左右对称；战斗统计面板可折叠，不遮挡演出 |
| 演出区 | 中心内容区 | 角色战斗演出 | 敌方可用剪影降低成本；聚光突出己方主体 |
| 轻量功能键 | 右缘竖排 | 暂停、倍速、弹幕 / 飘字开关 | 每键 `72 x 72`，间距 ≥ `16`；不超过 4 个；位于拇指热区 |
| 技能切入位 | 下 `1/3` | 技能立绘切入、大字演出 | 不遮挡底部导航与右侧功能键 |
| 底部导航 | 高 `144-176`（放置类可选保留） | 与主界面一致 | 当前战斗页签居中放大高亮 |

- 战斗中的数值反馈（伤害、战力变化）使用飘字，不占用固定信息位。
- 自动战斗必须提供暂停与倍速入口；倍速状态在按钮上原位表达。
- 战斗结束原位进入结算反馈页（见第 6 节），不跳闪新页面。

**验收**：功能键竖排不冲突系统手势；技能演出期底部导航仍可触达；统计面板折叠态不遮挡演出主体。

## 5. 布阵页

**用途**：战前编队、站位调整与战力预估，决策型准备页。

**结构**：

| 区域 | 内容 | 规则 |
| --- | --- | --- |
| 顶部 VS 栏 | 左玩家名 + 战力（冷色）/ 右关卡或敌方 + 战力（暖色），中央徽章 | 与战斗页 VS 栏结构一致，保持识别连贯 |
| 站位区 | 战场透视底 + 发光编号站位格 | 站位格直径 `120-160`；空位发光编号可视化，明确指示可放置位置 |
| 战力反馈 | 布阵变化时实时战力飘字或数值更新 | 原位反馈，增减带正负号与语义色 |
| 卡牌托盘 | 底部横滑卡牌列表，带品质角标与等级 | 卡高 `200-240`；选中即上阵或进入换位态 |
| 筛选行 | 阵营 / 职业筛选 Chip，一行 ≤ 6 项 | 选中态不只依赖颜色；超一行改横滑 |
| 操作栏 | 返回（左）+ 辅助操作（自动布阵）+ 确认（唯一一级按钮） | 确认热区 ≥ `360 x 104`；未确认离开需提示后果 |

- 三段式决策流：信息（顶）→ 操作对象（中）→ 操作工具（底），视线自上而下完成。
- 实时战力反馈让每次布阵调整有即时仪式感。

**验收**：空位、已站位、可替换三态可辨；筛选不改变卡牌托盘排序逻辑；确认前阵容修改可撤销。

## 6. 结算反馈页

**用途**：升级、通关、获得等正向节点的庆祝式反馈，兼具奖励展示与目标驱动。

**结构**（垂直中轴单列信息流，自上而下）：

| 层级 | 内容 | 规则 |
| --- | --- | --- |
| 1 氛围 | 暗底 + 中心聚光 + 粒子浮尘 | 四周压暗，舞台追光感 |
| 2 标题 | 大展示字（庆祝标题） | 允许超出正文字号体系使用 `72-128` 展示字形；属主题层可替换资产 |
| 3 数值变化 | `Lv.1 → Lv.2` 或「旧值 → 新值」 | 等宽数字；增长用成功色，箭头 `32-40` |
| 4 奖励区 | 获得物图标横排，带品质框 | 单排 ≤ 5 个；超出进第二行或合并展示 |
| 5 功能预告（可选） | 未解锁功能图标 + 解锁条件，≤ 3 项 | 把结算页变成目标驱动入口；点击预告说明解锁路径 |
| 6 出口 | 「点击屏幕继续」 | 无按钮设计；任何点击热区均可继续 |

- 信息动线五步一层不乱：发生了什么 → 数值变化 → 得到什么 → 接下来有什么 → 出口。
- 层级对比靠字号落差：标题极大、次级递减、说明最小并降透明度。
- 关键演出时长 ≤ `500ms`；全程可跳过，跳过直达最终状态。
- 失败 / 未达成反馈使用同结构但替换语义：标题、原因、下一步操作。

**验收**：四级信息层级一眼可辨；功能预告不超过 3 项且带解锁条件；点击任意处均可继续；跳过功能在演出任意时刻可用。

## 7. 养成详情页

**用途**：角色 / 装备 / 技能的属性展示与养成操作，游戏内最高频的全屏窗口。

**结构**：

| 区域 | 内容 | 规则 |
| --- | --- | --- |
| 顶部身份区 | 品质标签 + 名称 + 阵营 / 类型图标 + 阶级横幅 | 品质用语义色边框；横幅装饰属主题层 |
| 展示区 | 大立绘占屏约 `2/3`；左右对称贴边装备 / 槽位列 | 槽位 `120-184` 方形，距屏边 `32-48`，不遮挡立绘主体 |
| 切换件 | 左右翻页箭头，切换同类型对象 | 热区 ≥ `72 x 72`；保留筛选与位置记忆 |
| 底部操作区 | 次级槽位列（横排）→ 主次双操作 → 子导航页签 | 主操作唯一强调色；次级操作中性态；页签当前项高亮 |
| 锁定槽位 | 锁图标 + 灰化 | 点击说明解锁条件 |

- 上展示下操作：上半屏沉浸展示（浅色 / 深色底依主题），下半屏浅色低噪音操作区，互不干扰。
- 强调色只出现在主操作与当前页签上，视线自然落在关键操作。
- 养成数值变化使用「旧值 → 新值」对比组件（见 `component-spec.md` 游戏复合组件）。

**验收**：翻页切换不丢失已选槽位状态；锁定槽位点击给出解锁条件；主操作在资源不足时显示具体原因而非伪装禁用。

## 8. 个人主页 / 名片

**用途**：玩家信息展示、阵容外显与低频账号操作入口。

**结构**：

| 区域 | 内容 | 规则 |
| --- | --- | --- |
| 背景层 | 角色立绘占屏约 `2/3` 作视觉锚点 | 立绘为展示资产，不承载操作 |
| 信息面板 | 左上半透明压底面板：联盟、职位、进度、ID + 复制 | 半透明底保证任何立绘下文字可读；ID 提供复制热区 |
| 称号 / 徽章 | 立绘上叠加称号徽章 | 徽章单击查看来源 |
| 阵容面板 | 底部横排角色卡（≤ 5 张，品质角标）+ 编辑入口 + 同步开关 | 卡高 `160-200`；编辑与开关主次分明 |
| 低频功能区 | 兑换码、设置、切换账号等统一低调形态横排 | 统一尺寸与视觉权重，不抢主视觉 |
| 返回 | 左下，拇指热区 | 与全屏窗口返回规则一致 |

- 阅读动线按「身份 → 数据 → 实力证明」组织，符合名片阅读逻辑。
- 操作集中在下半屏拇指热区；上半屏纯展示。

**验收**：信息面板在深 / 浅立绘下均可读；低频入口视觉统一；复制 ID 有完成反馈。

## 9. 横切规则（场景模式通用）

| 规则 | 说明 |
| --- | --- |
| HUD 资源条 | 「图标 + 数值 + 加号」，高 `64-80`；货币 ≤ 3 项，超宽转入更多菜单；数值千位分隔 |
| 角标统一 | 红点 / 数量角标固定在元素右上角，`20-32`；同一页面只使用一种角标形态 |
| 锁定前置 | 未解锁功能可见 + 锁图标 + 解锁条件，制造成长预期；不静默隐藏 |
| 轻引导 | CTA 呼吸高光 + 引导手指为不阻断引导，与遮罩 Spotlight 二选一；同一时刻只有一处 |
| 数值对比 | 成长反馈统一使用「旧值 → 新值」+ 箭头；增长成功色、减少错误色、等宽数字 |
| 纯展示弹层 | 奖励、称号、解锁类弹层允许「点击空白关闭」并省略关闭按钮；不可逆确认不适用 |
| 双入口并列 | 表达核心循环的两个入口（如挂机 / 开战）同等级并列，不人为分主次 |
| 展示字形例外 | 结算、庆祝标题可使用 `72-128` 展示字形，仅用于标题，属主题可替换资产 |

## 10. 场景模式验收

1. 每个场景模式均映射到一种界面模板承载类型，关闭与返回规则一致。
2. 分区结构、信息层级、操作位不按题材替换；仅主题、美术、文案可替换。
3. 长屏设备只增加中心区可视范围；窄屏折叠次要信息，不缩小字号与热区。
4. 每个场景覆盖加载、空、错误、锁定与断线恢复状态。
5. 同屏唯一视觉最强操作；引导、红点、预告不并发干扰主决策。
