# 页面内容字段模板

> 来源：`design-system.md` 05 界面模板、`screen-patterns.md`、`component-spec.md`  
> 目标：把页面模板从结构描述补成可直接生产的字段模板。每类页面给出内容字段、必要状态、长文本规则和交付说明，界面生产按表填内容，不再从零定义。

## 1. 使用方式

1. 先按 `screen-patterns.md` 确定页面承载类型（主界面 / 全屏窗口 / 弹窗 / Tips / 状态通知），再按本表填字段。
2. 字段表中的"组件"列引用 `component-spec.md` 的母版命名，不新建结构。
3. 状态引用 `component-spec.md` 1.2 通用状态矩阵；本表只列每类页面必须交付的状态稿。
4. 长文本规则为上限，不是推荐长度；任何字段不得通过缩小字号容纳文本。

字段类型约定：

| 类型 | 含义 |
| --- | --- |
| 文本 | 名称、标题、说明、按钮文案 |
| 数值 | 数量、等级、进度、价格；遵循 `design-system.md` 02 字体系统数值格式 |
| 图标 | 功能图标、资源图标、状态图标 |
| 图片 | 主视觉、背景、角色形象 |
| 时间 | 倒计时、活动时间；同屏统一格式 |
| 状态 | 锁定、红点、可领取、新内容等，颜色 + 图标 + 文案共同表达 |
| 操作 | 按钮或热区，标注等级和去向 |

## 2. 主界面

结构：顶部 HUD → 主视觉场景 / 核心内容 → 高频入口 → 底部导航栏。

### 2.1 内容字段

顶部 HUD（`Layout/TopHUD`）：

| 字段 | 类型 | 必选 | 内容规则 |
| --- | --- | --- | --- |
| 玩家头像 | 图片 | 必选 | `Info/Avatar` 尺寸 `48-64`；加载失败用默认占位 |
| 玩家名称 | 文本 | 必选 | 单行尾部省略，最长 12 字 |
| 等级 / 进度 | 数值 | 可选 | `Lv.28` 或经验进度条；数值优先等宽字体 |
| 资源项 | 图标 + 数值 | 1-3 项 | 图标、当前值、可选加号入口；超 `999,999` 按项目规则简写 |
| 通知 / 邮件入口 | 图标 | 可选 | 可挂红点或数量角标 |
| 设置 / 更多入口 | 图标 | 可选 | 不挂业务状态，避免与通知混淆 |

中心区域：

| 字段 | 类型 | 必选 | 内容规则 |
| --- | --- | --- | --- |
| 主视觉背景 | 图片 | 必选 | 按 6.3 全屏背景出图：`1334 x 1750`，核心内容区居中 `1334 x 750` |
| 主入口 | 操作 | 必选 | 同屏唯一视觉最强操作；可高出 Dock 的中央 CTA，按钮文案 ≤6 字 |
| 活动入口 | 图片 + 文本 + 时间 | 0-2 个 | 活动图、短标题（≤6 字）、结束倒计时、状态角标（可领取 / 进行中 / 即将开启） |
| 当前进度 / 任务提示 | 文本 + 数值 | 可选 | 一行，点击进详情 |
| 快捷入口 | 图标 | 0-4 个 | 高频短路径，不与底部导航功能重复 |

底部导航栏（`Navigation/Tab` Dock 变体）：

| 字段 | 类型 | 必选 | 内容规则 |
| --- | --- | --- | --- |
| 入口项 | 图标 + 文本 | 3-5 项 | 文字 ≤4 字；当前项图标 + 文字 + 位置共同表达 |
| 红点 / 角标 | 状态 | 可选 | 数量超 `99` 显示 `99+` |

### 2.2 必要状态

| 状态稿 | 内容 |
| --- | --- |
| 默认 | 全字段就位，HUD 与中心区分层清晰 |
| 加载 | 骨架屏按最终布局原位占位，HUD 数值显示占位符 |
| 入口锁定 | 锁图标 + 解锁条件，点击说明条件 |
| 活动倒计时 | 倒计时格式统一为 `HH:MM:SS` 或 `D 天 HH:MM` |
| 可领取 | 入口角标 + 语义色，点击后即时刷新 |
| 断线 | 局部状态条，不改页面骨架，关键资源显示"--"或最后缓存值 |

### 2.3 长文本规则

- 玩家名称超 12 字尾部省略。
- 活动标题超 6 字省略，详情进活动页。
- 底部导航文字不超过 4 字。
- 资源数值不换行，超上限按项目简写规则显示。

### 2.4 交付说明

按 `design-system.md` 6.7 交付清单，主界面额外附：

1. 主视觉背景资源：`1334 x 1750` 画布 + 居中 `1334 x 750` 核心内容区标注 + `_ignore` 后缀。
2. 入口锁定条件表：条件文案、跳转去向、未满足提示。
3. 红点 / 角标刷新规则：触发条件、清除时机、数量上限。
4. 底部导航当前态与未选态资源各一套。

## 3. 列表页

结构：顶部 HUD → 筛选 / 页签 → 可滚动列表 → 底部可选主操作。

### 3.1 内容字段

页头（`Layout/TopHUD`）：

| 字段 | 类型 | 必选 | 内容规则 |
| --- | --- | --- | --- |
| 返回 | 图标 | 必选 | 左对齐，热区 `88 x 88` |
| 页面标题 | 文本 | 必选 | 单行，≤8 字；使用 `type/page-title` |
| 容量 / 进度 | 数值 | 可选 | 当前 / 总量，如 `24 / 50`；满值时进入 `Full` 状态 |
| 搜索 / 筛选入口 | 图标 | 可选 | 点击进搜索或筛选页 |

筛选 / 页签区：

| 字段 | 类型 | 必选 | 内容规则 |
| --- | --- | --- | --- |
| 页签项 | 文本 | 2-5 项 | `Navigation/Tab`，每项 ≤4 字 |
| 筛选 Chip | 文本 + 状态 | 可选 | `Filter/Chip`，单行，超出横向滚动或进筛选页 |

列表项（`Container/ListItem`）：

| 字段 | 类型 | 必选 | 内容规则 |
| --- | --- | --- | --- |
| 左识别区 | 图标 / 头像 | 必选 | `Info/Avatar` 或 `Container/Slot`，可挂品质框、新内容角标 |
| 主标题 | 文本 | 必选 | 最多两行，超则省略 |
| 副标题 / 说明 | 文本 | 可选 | 一行，超则省略；使用 `type/caption` |
| 进度 / 数量 | 数值 | 可选 | 进度条或数量，如 `12 / 30` |
| 右侧状态 | 状态 / 操作 | 可选 | 状态徽章（≤4 字）或三级按钮（`Action/Button/Level3`） |

### 3.2 必要状态

| 状态稿 | 内容 |
| --- | --- |
| 默认 | 列表正常展示，分割线对齐 |
| 加载 | `State/Skeleton` 按最终行高原位占位，至少显示 `300ms` |
| 空 | `State/Empty`：图标、标题、说明、可选跳转操作 |
| 错误 | `State/Error`：原因说明 + 重试 / 返回 |
| 满容量 | 当前值 = 上限，提示清理或扩容入口 |
| 项锁定 | 该项锁图标 + 条件说明，右侧操作变为"解锁"或置灰 |
| 项可领取 / 可前往 | 语义色状态或三级按钮，点击后即时刷新 |

### 3.3 长文本规则

- 页面标题单行 ≤8 字。
- 列表主标题最多两行，副标题一行。
- 状态徽章 ≤4 字，超则改用"详情"或弹窗说明。
- 三级按钮文案 ≤4 字。

### 3.4 交付说明

1. 至少提供默认、加载、空、错误、满容量五张状态稿。
2. 列表项各状态（默认、锁定、可领取、选中）在同一行高下展示。
3. 分页 / 加载更多规则：阈值、加载提示文案、无更多数据提示。
4. 搜索无结果状态单独出稿，包含"清除筛选"或"返回全部"入口。

## 4. 网格页

结构：顶部 HUD → 分类页签 / 筛选 → 网格内容区 → 底部可选操作。

### 4.1 内容字段

页头：

| 字段 | 类型 | 必选 | 内容规则 |
| --- | --- | --- | --- |
| 返回 | 图标 | 必选 | 左对齐 |
| 页面标题 | 文本 | 必选 | 单行，≤8 字 |
| 容量 | 数值 | 可选 | 当前 / 总量 |

分类 / 筛选区：

| 字段 | 类型 | 必选 | 内容规则 |
| --- | --- | --- | --- |
| 分类页签 | 文本 | 可选 | 2-5 项，每项 ≤4 字 |
| 筛选入口 | 图标 / 文本 | 可选 | 点击进入筛选页 |

网格项（`Container/Slot` / `Container/Grid`）：

| 字段 | 类型 | 必选 | 内容规则 |
| --- | --- | --- | --- |
| 图标 | 图片 | 必选 | 主体在 `Container/Slot` 安全区内居中 |
| 数量 | 数值 | 可选 | 右下对齐；超 `999` 显示 `999+` 或按项目简写 |
| 品质框 | 状态 | 可选 | 按品质色表达，不与禁用状态混用 |
| 状态角标 | 状态 | 可选 | 左上；如新内容、锁定、限时、冷却 |
| 选中框 | 状态 | 可选 | 多选模式下出现，选中态不只靠颜色 |

### 4.2 必要状态

| 状态稿 | 内容 |
| --- | --- |
| 默认 | 网格按固定列数、间距展示 |
| 空 | `State/Empty` |
| 选中 | 选中框 / 底色 / 边框，多选模式下可见 |
| 锁定 | 锁定遮罩 + 条件提示 |
| 满 | 数量达到上限，给出处理入口 |
| 冷却 | 倒计时覆盖或角标 |
| 新内容 | 新内容角标，查看后移除 |
| 长按 Tips | `Feedback/Tooltip` 显示物品详情 |

### 4.3 长文本规则

- 页签文案 ≤4 字。
- 网格项名称如展示，单行 ≤6 字。
- 数量显示不换行；超上限用统一简写。

### 4.4 交付说明

1. 网格列数、间距、格比在默认稿中明确标注。
2. 提供选中态与未选中态对比稿，确保选中态在品质色背景上仍可读。
3. 状态角标不得挤占主体识别区；提供角标层级规范。
4. 空状态与满状态不共用同一视觉稿。

## 5. 详情页

结构：顶部 HUD → 主视觉 / 形象区 → 核心信息区 → 描述 / 规则区 → 消耗 / 条件区 → 底部操作。

### 5.1 内容字段

页头：

| 字段 | 类型 | 必选 | 内容规则 |
| --- | --- | --- | --- |
| 返回 | 图标 | 必选 | 左对齐 |
| 标题 | 文本 | 可选 | 对象名称；单行 ≤10 字 |
| 分享 / 收藏 / 帮助 | 图标 | 可选 | 不挤占返回热区 |

主视觉 / 形象区：

| 字段 | 类型 | 必选 | 内容规则 |
| --- | --- | --- | --- |
| 主视觉 | 图片 | 必选 | 角色 / 道具大图，居中展示 |
| 品质框 | 状态 | 可选 | 围绕主视觉，使用品质色 |
| 等级 / 星级 | 数值 | 可选 | 等宽字体，如 `Lv.30` 或 `★★★★☆` |

核心信息区：

| 字段 | 类型 | 必选 | 内容规则 |
| --- | --- | --- | --- |
| 名称 | 文本 | 必选 | 单行，≤12 字，使用 `type/section-title` |
| 品质徽章 | 状态 | 可选 | `Info/Badge`，文字 ≤4 字 |
| 属性列表 | 文本 + 数值 | 可选 | 每项图标 + 名称 + 数值，最多两行 |
| 技能 / 特性条目 | 文本 + 图标 | 可选 | 标题 + 短说明，点击进 Tips |

描述 / 规则区：

| 字段 | 类型 | 必选 | 内容规则 |
| --- | --- | --- | --- |
| 描述标题 | 文本 | 可选 | 如"简介"、"规则" |
| 描述内容 | 文本 | 可选 | 最多 3 行，超出用"展开"或"查看详情" |

消耗 / 条件区：

| 字段 | 类型 | 必选 | 内容规则 |
| --- | --- | --- | --- |
| 消耗项 | 图标 + 数值 | 可选 | 需要 / 拥有数量，资源不足时标红 |
| 前置条件 | 文本 + 状态 | 可选 | 未满足条件列出，点击说明 |
| 冷却 / 倒计时 | 时间 | 可选 | 统一时间格式 |

底部操作区：

| 字段 | 类型 | 必选 | 内容规则 |
| --- | --- | --- | --- |
| 主操作 | 操作 | 必选 | `Action/Button/Level1`，文案 ≤6 字 |
| 次操作 | 操作 | 可选 | 二级或文字按钮，与主操作主次明确 |

### 5.2 必要状态

| 状态稿 | 内容 |
| --- | --- |
| 默认 | 全字段可读，操作可点 |
| 资源不足 | 消耗项用错误色，主按钮进入资源不足状态 |
| 条件不满足 | 列出未满足条件，主按钮置灰或锁定 |
| 冷却中 | 倒计时 + 操作禁用 |
| 已满级 / 满星 | 满容量状态，给出替代入口 |
| 加载 | 骨架屏按最终布局占位 |

### 5.3 长文本规则

- 页头标题单行 ≤10 字。
- 对象名称单行 ≤12 字。
- 属性名称单行，数值等宽对齐。
- 描述最多 3 行，超出用展开或进全屏规则页。
- 按钮文案 ≤6 字。

### 5.4 交付说明

1. 提供默认、资源不足、条件不满足、冷却中、已满级五张状态稿。
2. 消耗项必须标注"需要 / 拥有"数量格式，资源不足时提供获取入口。
3. 主视觉加载失败时提供默认占位图。
4. 长规则内容提供展开态或全屏规则页链接，不在详情页无限加长。

## 6. 筛选页

结构：顶部 HUD → 分类栏 → 选项区 → 底部操作。

### 6.1 内容字段

页头：

| 字段 | 类型 | 必选 | 内容规则 |
| --- | --- | --- | --- |
| 返回 | 图标 | 必选 | 左对齐；未确认选择时提示"放弃修改？" |
| 标题 | 文本 | 必选 | 如"筛选"，单行 ≤6 字 |
| 已选数量 | 数值 | 可选 | 如"已选 3 项" |

分类栏：

| 字段 | 类型 | 必选 | 内容规则 |
| --- | --- | --- | --- |
| 分类项 | 文本 | 必选 | 纵向或横向分类，每项 ≤6 字 |

选项区：

| 字段 | 类型 | 必选 | 内容规则 |
| --- | --- | --- | --- |
| 选项标签 | 文本 | 必选 | `Filter/Chip`，单行 ≤6 字 |
| 选项数量 | 数值 | 可选 | 如"(12)"，用于说明结果数 |
| 选项状态 | 状态 | 必选 | 未选 / 选中 / 禁用 |
| 全选 / 清空 | 操作 | 可选 | 多选分类下出现 |

底部操作：

| 字段 | 类型 | 必选 | 内容规则 |
| --- | --- | --- | --- |
| 重置 | 操作 | 必选 | 二级按钮，清除当前暂存选择 |
| 确认 / 应用 | 操作 | 必选 | 二级按钮或一级按钮，应用后返回列表页 |

### 6.2 必要状态

| 状态稿 | 内容 |
| --- | --- |
| 默认 | 显示当前已应用筛选，选项按分类展示 |
| 暂存未应用 | 用户已选但未点确认，返回时提示是否放弃 |
| 已应用 | 返回列表页后，筛选条显示已选条件 |
| 无结果 | 列表页展示空状态，提供"清除筛选"入口 |
| 禁用选项 | 该选项在当前条件下无结果，说明原因或置灰 |

### 6.3 长文本规则

- 分类项和选项标签均单行 ≤6 字。
- 已选数量文案固定，如"已选 N 项"。
- 无结果说明 ≤2 行。

### 6.4 交付说明

1. 筛选逻辑必须支持"暂存选择 + 确认应用"，避免每次选择都刷新列表。
2. 单选与多选在同一页中需明确区分；多选提供全选 / 清空。
3. 返回行为：未保存选择时二次确认；已保存选择时恢复列表页上下文。
4. 提供筛选结果为空时的空状态稿。

## 7. 弹窗

结构：遮罩层 → 弹窗容器 → 标题 / 内容 / 操作区。

### 7.1 内容字段

#### 7.1.1 确认弹窗（`Overlay/ConfirmDialog`）

| 字段 | 类型 | 必选 | 内容规则 |
| --- | --- | --- | --- |
| 标题 | 文本 | 必选 | 单行，≤8 字 |
| 说明 | 文本 | 必选 | 最多两行；不可逆操作必须说明后果 |
| 取消 | 操作 | 必选 | 二级按钮中性态 |
| 确认 | 操作 | 必选 | 二级按钮强调态；危险操作使用错误色 |
| 关闭 | 图标 | 可选 | 不可逆操作不得仅依赖关闭 / 遮罩关闭 |

#### 7.1.2 内容弹窗（`Overlay/ContentDialog`）

| 字段 | 类型 | 必选 | 内容规则 |
| --- | --- | --- | --- |
| 标题 | 文本 | 必选 | 单行，≤8 字 |
| 滚动内容 | 文本 / 列表 | 必选 | 规则、条款、选择列表；固定底部操作 |
| 主操作 | 操作 | 必选 | 固定底部，文案 ≤6 字 |
| 关闭 | 图标 | 可选 | 复杂内容可改为"全屏查看"入口 |

#### 7.1.3 设计弹窗（奖励 / 活动弹窗）

| 字段 | 类型 | 必选 | 内容规则 |
| --- | --- | --- | --- |
| 主视觉 | 图片 | 可选 | 活动图、角色立绘、获得物展示 |
| 标题 | 文本 | 必选 | 单行，≤8 字，如"恭喜获得" |
| 获得内容列表 | 图标 + 文本 + 数值 | 必选 | 每项含图标、名称、数量 |
| 主操作 | 操作 | 必选 | 一级或二级按钮，文案 ≤6 字 |
| 今日不再显示 | 操作 | 可选 | 复选框 + 文字，登录弹窗常用 |
| 关闭 | 图标 | 可选 | 设计弹窗可点关闭，但不可逆操作时除外 |

### 7.2 必要状态

| 状态稿 | 内容 |
| --- | --- |
| 普通确认 | 标题 + 说明 + 取消 / 确认 |
| 危险确认 | 确认按钮使用错误色，说明强调后果 |
| 消费确认 | 展示消耗项（图标 + 数量），资源不足时提示 |
| 排队 | 多个弹窗按优先级排队，低优先级不叠加 |
| 结果展示 | 奖励弹窗展示获得物，操作后关闭 |

### 7.3 长文本规则

- 标题单行 ≤8 字。
- 说明最多两行，超出改用内容弹窗或全屏页。
- 按钮文案 ≤6 字；底部两个按钮尺寸一致。
- 获得内容列表名称单行，数量等宽对齐。

### 7.4 交付说明

1. 明确关闭规则：哪些可点遮罩关闭，哪些必须点取消 / 确认。
2. 多弹窗排队规则：优先级、最大数量、超时处理。
3. 奖励弹窗必须提供空奖励 / 单奖励 / 多奖励三种样例。
4. 设计弹窗主视觉资源标注尺寸、拉伸规则和 `_ignore` 后缀（如适用）。

## 8. 状态页

状态页不改变页面骨架，在原布局上替换中心内容区。

### 8.1 内容字段

#### 8.1.1 加载状态（`State/Skeleton`）

| 字段 | 类型 | 必选 | 内容规则 |
| --- | --- | --- | --- |
| 骨架块 | 图形占位 | 必选 | 按最终布局行高、卡片尺寸原位占位 |
| 局部加载提示 | 文本 | 可选 | 如"加载中..."，≤1 行 |

#### 8.1.2 空状态（`State/Empty`）

| 字段 | 类型 | 必选 | 内容规则 |
| --- | --- | --- | --- |
| 图形 | 图标 / 插画 | 必选 | 空状态图形，不与错误状态混用 |
| 标题 | 文本 | 必选 | 单行，如"暂无内容" |
| 说明 | 文本 | 可选 | 最多两行，解释原因 |
| 操作 | 操作 | 可选 | 跳转或刷新入口 |

#### 8.1.3 错误状态（`State/Error`）

| 字段 | 类型 | 必选 | 内容规则 |
| --- | --- | --- | --- |
| 图形 | 图标 / 插画 | 必选 | 错误状态图形，与空状态区分 |
| 标题 | 文本 | 必选 | 单行，如"加载失败" |
| 原因说明 | 文本 | 必选 | 最多两行，避免"发生错误"等模糊文案 |
| 重试 | 操作 | 可选 | 可恢复时提供 |
| 返回 | 操作 | 可选 | 不可恢复时提供 |

#### 8.1.4 满容量状态（`State/Full`）

| 字段 | 类型 | 必选 | 内容规则 |
| --- | --- | --- | --- |
| 当前值 / 上限 | 数值 | 必选 | 如"50 / 50" |
| 说明 | 文本 | 必选 | 最多两行，说明影响 |
| 处理入口 | 操作 | 必选 | 清理、扩容或前往管理 |

#### 8.1.5 断线恢复状态

| 字段 | 类型 | 必选 | 内容规则 |
| --- | --- | --- | --- |
| 状态图标 | 图标 | 必选 | 断线 / 重连中 / 已恢复 |
| 原因 / 提示 | 文本 | 必选 | 如"网络异常，正在尝试恢复" |
| 倒计时 / 重试 | 时间 / 操作 | 可选 | 恢复时间或手动重试 |
| 返回 | 操作 | 可选 | 长时间无法恢复时提供 |

### 8.2 必要状态

| 状态稿 | 内容 |
| --- | --- |
| 骨架屏加载 | 原位占位，不改变布局 |
| 空 | 无内容，提供下一步 |
| 错误 | 可恢复 / 不可恢复两种 |
| 满容量 | 当前值达到上限 |
| 断线 | 保留页面上下文，阻止重复提交 |
| 恢复成功 | 自动刷新内容，轻量提示 |

### 8.3 长文本规则

- 状态标题单行。
- 说明最多两行。
- 操作按钮文案 ≤6 字。

### 8.4 交付说明

1. 每个列表 / 网格 / 详情页至少提供加载、空、错误三种状态稿。
2. 错误状态必须区分可恢复与不可恢复，并给出对应操作。
3. 断线状态保留原页面框架，不强制返回首页。
4. 满容量状态在页面内或弹层中提供处理入口，不阻断用户查看已有内容。

## 9. 通用字段规范

### 9.1 文本长度上限

| 位置 | 上限 | 溢出处理 |
| --- | --- | --- |
| 页面主标题 | 8-10 字 | 单行省略 |
| 区块标题 | 8 字 | 单行省略 |
| 按钮文案 | 6 字 | 不换行 |
| 列表主标题 | 两行 | 尾部省略 |
| 列表副标题 | 一行 | 尾部省略 |
| 状态徽章 | 4 字 | 不改尺寸 |
| 导航文字 | 4 字 | 不换行 |
| 描述说明 | 3 行 | 展开或进详情 |
| Toast 说明 | 2 行 | 自动消失，不展开 |

### 9.2 数值显示规则

| 类型 | 规则 | 示例 |
| --- | --- | --- |
| 数量 | 千位分隔；超 `999,999` 按项目规则简写 | `12,450` / `1.2M` |
| 进度 | 当前值 / 总值 | `24 / 50` |
| 倒计时 | 同屏统一格式 | `02:14:32` / `1 天 02:14` |
| 增减 | 正负号 + 语义色 + 文字说明 | `+120` / `-20` |

### 9.3 每页交付检查项

1. 是否标注每个字段的类型、来源和必选性。
2. 是否覆盖默认、加载、空、错误、满容量、锁定 / 断线中的适用状态。
3. 长文本是否给出上限和溢出处理，未通过缩小字号解决。
4. 资源字段是否标注尺寸、倍率、命名和 `_ignore` 后缀（如适用）。
5. 操作字段是否标注按钮等级、去向和主次关系。
6. 状态改变是否保持页面骨架不变，是否保留原页面上下文。
