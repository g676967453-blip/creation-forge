## 一、画布与安全区

### 1.1 基准分辨率

| 版本 | 分辨率 | 宽高比 | 用途 |
|------|--------|--------|------|
| 基准版 | 720 × 1280 | 9:16 | 主设计稿，优先保证此版本 |
| 适配版 | 720 × 1600 | 9:20 | 全面屏适配，以中心锚点上下拓展 |

> **原则**：优先考虑最小分辨率做设计，向大分辨率扩展适配。宽度统一 720，保证横向布局不变；纵向以中心锚点拓展。

### 1.2 安全区

```
┌─────────────────────────────┐
│ 状态栏区 (顶部 ≥44px)        │  ← iOS: 44px / Android: 24px
├─────────────────────────────┤
│                             │
│       内容安全区             │  ← 核心 UI 元素全部在此区域内
│                             │
├─────────────────────────────┤
│ 导航栏区 (底部 ≥34px)        │  ← iOS Home Indicator: 34px
└─────────────────────────────┘       Android 导航栏: 以实际高度为准
```

| 平台 | 顶部安全区 | 底部安全区 | 左右安全区 |
|------|-----------|-----------|-----------|
| iOS (刘海/灵动岛) | ≥44px | ≥34px | 内容距边 ≥16px |
| iOS (非全面屏) | ≥20px | ≥0px | 内容距边 ≥16px |
| Android (全面屏) | ≥24px | 以导航栏实际高度为准 | 内容距边 ≥16px |
| Android (传统) | ≥24px | ≥0px | 内容距边 ≥16px |
| 微信小程序 | ≥88px (避让右上胶囊) | ≥34px | 内容距边 ≥16px |

> 💊 微信小程序右上角胶囊约占屏宽 23%（720 画布约 167×61px），距右约 2%。导航栏内容必须在胶囊左侧，留 ≥10px 安全距离。

### 1.3 全屏背景图

全屏背景图输出尺寸 **1280 × 1680**，以中心锚点适配。核心内容区域限制在同中心 **1280 × 720** 范围内。

│  └─────────────────────┘    │

### 2.2 按操作频率的分区策略

| 区域 | Y 范围 | 放什么 |
|------|--------|--------|
| 顶部信息栏 | 0 ~ 120 | HUD 数值（金币/体力/等级）、标题、返回按钮 |
| 中部展示区 | 120 ~ 800 | 核心内容展示（角色/场景/列表）、卡片浏览 |

- **主 CTA 按钮**：必须放在 y > 1100 区域，宽度 ≥280px，高度 ≥52px
- **次要操作按钮**：放在 y: 900~1100 区域

- **危险操作（删除/重置）**：放在非热区，需二次确认

## 三、手势系统

### 3.1 手势定义

| 手势 | 触发条件 | 标准用途 | 禁用场景 |
|------|---------|---------|---------|
| **单击 (Tap)** | 单指点击 <200ms | 确认/选择/触发 | — |
| **长按 (Long Press)** | 单指按住 ≥500ms | 查看详情 Tooltip / 拖拽触发 | 战斗中高频操作区 |
| **双击 (Double Tap)** | 两次点击 <300ms | 点赞/快捷操作（谨慎使用，易误触） | 默认不使用 |
| **上下滑动 (Vertical Swipe)** | 单指纵向滑动 ≥10px | 列表滚动 / 页面上下浏览 | 全屏弹窗禁用背景滚动 |
| **左右滑动 (Horizontal Swipe)** | 单指横向滑动 ≥10px | Tab 切换 / 卡片翻页 / 删除操作 | — |
| **双指缩放 (Pinch)** | 双指捏合/张开 | 地图缩放 / 图片查看 | 非必要不使用 |
| **拖拽 (Drag)** | 长按后移动 | 物品拖放 / 排序 | — |

### 3.2 手势冲突解决规则

```
优先级从高到低：
1. 弹窗层 — 弹窗内手势优先，遮罩层阻断下层所有手势
2. 列表/滚动层 — 滚动内容优先进入手势识别
3. 可点击元素 — 按钮、卡片等
4. 背景层 — HUD 纯展示区域（无手势）

冲突判定：
- 纵向滑动优先于横向滑动（竖版游戏中列表滚动更常见）
- 子元素手势优先于父容器手势
- 面板打开时，下层所有手势穿透禁用
```

### 3.3 滑动参数标准

| 参数 | 值 | 说明 |
|------|-----|------|
| 滑动识别阈值 | ≥10px | 小于此距离视为点击 |
| 惯性滚动减速率 | 0.95 | 手指离开后每帧速度衰减 |
| 最小惯性速度 | 5px/s | 低于此速度停止滚动 |
| 回弹力度 | 0.3s ease-out | 超出边界后的回弹时间 |
| 翻页吸附阈值 | 卡片宽度的 30% | 滑动超过此比例自动翻到下一页 |
| Tab 切换阈值 | 30px | 横向滑动距离超过此值切换 Tab |

## 四、触控规格

### 4.1 最小触控热区

| 元素类型 | 最小尺寸 | 建议尺寸 |
|---------|---------|---------|
| 按钮 | 44 × 44 px | 52~56 px 高，200~300 px 宽 |
| 图标按钮 | 44 × 44 px | 48 × 48 px |
| 列表项 | 44 px 高 | 56~72 px 高 |
| 卡片（可选） | 44 × 44 px | ≥120 × 160 px |
| 页签 (Tab) | 44 × 44 px | ≥60 × 44 px |
| 复选框/单选框 | 44 × 44 px | 行高 ≥48 px |

> 参照 iOS HIG：最小触控目标 44×44pt。Android Material：最小触控目标 48×48dp。

### 4.2 触控容差

- 实际命中区域 = 视觉边界 + **4px padding**
- 相邻可点击元素间距 ≥8px，防止误触
- 列表行之间的分割线不属于任何一行的触控区

### 4.3 防误触机制

| 场景 | 防护措施 |
|------|---------|
| 弹窗打开 | 遮罩层阻断下层所有点击 |
| 按钮点击后 | 300ms 冷却期，防连点 |
| 快速滑动中 | 滑动期间禁用子元素点击，滑动停止后 100ms 恢复 |
| 加载中 | 全屏半透明遮罩阻断所有操作 |
| 战斗中 | 暂停非战斗交互（经营/商店等入口不可点击） |

### 5.2 竖版特有布局原则

1. **纵向优先**：内容流向自上而下。卡片列表垂直排列优先于水平排列。充分利用纵向空间展示更多内容。
2. **底部固定**：核心操作固定在屏幕底部，不随内容滚动。
3. **层级递进**：信息密度从顶部到底部递增——顶部稀疏（标题/数值），底部密集（按钮/操作）。
4. **避免横向拥挤**：一行不超过 4 个并列元素。超过则换行或变为垂直列表。
5. **滚动方向单一**：同一区域内只允许一个滚动方向。避免嵌套横向滚动在纵向滚动内（或反之），除非使用明确的分页组件。

## 六、导航系统

### 6.1 竖版导航模式

| 模式 | 适用场景 | 交互方式 | 位置 |
|------|---------|---------|------|
| **底部 Tab 栏** | 3~5 个顶级入口 | 点击切换 | 屏幕底部 (H: 80~100) |
| **顶部 Tab 栏** | 二级分类筛选 | 点击 + 左右滑切换 | 导航栏下方 (H: 44) |
| **汉堡菜单** | 低频功能入口 | 点击展开侧边栏 | 左上角 |
| **返回按钮** | 层级返回 | 点击返回上一级 | 左上角 (< 箭头) |
| **浮动按钮** | 全局主操作 | 点击触发 | 右下角悬浮 (距边 16~24px) |

### 6.2 底部 Tab 规范

| 项目 | 规范 |
|------|------|
| Tab 数量 | 3~5 个（推荐 4 个） |
| 高度 | 80~100px（含安全区） |
| 图标尺寸 | 24~28px |
| 文字字号 | 10~11px |
| 选中态 | 图标 + 文字变色（主题色），可选加顶部指示条 |
| 未选中态 | 图标 + 文字灰色 |
| 图标风格 | 统一线性/面性，不要混用 |

### 6.3 导航层级限制

```
层级深度 ≤ 4 层：

首页 (L0)
 └─ 一级页面 (L1)
      └─ 二级页面 (L2)
           └─ 详情/编辑页 (L3)
                └─ 不在 L3 上再开新页面，用弹窗/BottomSheet 代替

每层必须有明显的返回路径。不允许"死胡同"页面。
```

## 七、状态与反馈

### 7.1 组件状态标准

每个可交互组件至少覆盖以下状态：

| 状态 | 用途 | 视觉表现 |
|------|------|---------|
| **默认 (Normal)** | 正常可交互 | 标准配色 |
| **悬停 (Hover)** | PC 鼠标悬停 | 背景色 lighten 10~15% |
| **按下 (Pressed)** | 点击瞬间 | 背景色 darken 10~15% + scale 0.97 |
| **禁用 (Disabled)** | 条件不满足不可操作 | 整体 40%~50% 透明度 + 灰度 |
| **加载 (Loading)** | 操作进行中 | 旋转指示器 + 按钮文字变为"…"|
| **选中 (Selected)** | 当前激活项 | 高亮边框 / 背景色变化 / 勾选标记 |

### 7.2 空状态规范

| 场景 | 显示内容 |
|------|---------|
| 列表为空 | 图标 + "暂无数据" + 可选的操作引导按钮 |
| 搜索无结果 | "未找到相关内容" + "换个关键词试试" |
| 网络错误 | 图标 + "网络连接失败" + "点击重试" 按钮 |
| 首次使用 | 引导性文案 + 主 CTA |

### 7.3 加载规范

| 加载类型 | 适用场景 | 表现 |
|---------|---------|------|
| 全屏加载 | 场景切换 / 首次进入 | 品牌 Logo + 进度条 / 加载动画 |
| 局部加载 | 列表刷新 / Tab 切换 | 下拉刷新 / 骨架屏 (Skeleton Screen) |
| 按钮加载 | 提交/支付等操作 | 按钮内转圈，禁止重复点击 |
| 后台加载 | 预加载 / 静默刷新 | 无感知，仅顶部微小进度条 |

### 7.4 反馈时序标准

| 反馈类型 | 触发时间 | 持续时间 |
|---------|---------|---------|
| 按钮点击 | 即时（<50ms） | 按下态持续到手指抬起 |
| Toast 提示 | 操作完成后即时 | 显示 2~3s 后自动消失 |
| 加载指示器 | 操作触发后 200ms（短操作不显示） | 直到操作完成 |
| 成功/失败动画 | 操作完成后即时 | 1~2s |
| 飘字 (Floating Text) | 事件触发后即时 | 1s 上升 + 淡出 |
| 错误抖动 | 非法操作时即时 | 0.3~0.5s |

## 八、弹窗体系

### 8.1 弹窗类型

| 类型 | 尺寸 | 用途 | 关闭方式 |
|------|------|------|---------|
| **对话框 (Alert)** | W: 560~600, H: auto | 确认/提示/二选一 | 点击按钮 |
| **底部弹出 (Bottom Sheet)** | W: 720, H: ≤600 | 选项列表/筛选/分享 | 下拉关闭 / 点击遮罩 |
| **居中面板 (Modal)** | W: 600~660, H: ≤800 | 信息展示/表单/多操作 | 关闭按钮 / 点击遮罩 |
| **全屏弹窗 (Full Screen Modal)** | W: 720, H: 1280 | 复杂表单/编辑器 | 导航栏返回按钮 |
| **Toast / Snackbar** | W: auto, H: 40~48 | 轻量提示/撤销 | 自动消失 2~3s |
| **Tooltip** | W: ≤300, H: auto | 名词解释/快速信息 | 点击其他区域消失 |

### 8.2 弹窗规范

| 规则 | 说明 |
|------|------|
| 单层弹窗 | 一个弹窗上不开第二个弹窗。需要多步骤用分步表单，而非嵌套弹窗。 |
| 遮罩透明度 | 黑色 45%~60%（`rgba(0,0,0,0.45~0.6)`） |
| 弹窗圆角 | 顶部 12~16px，底部 0（Bottom Sheet）/ 四周 8~12px（居中弹窗） |
| 关闭手势 | Bottom Sheet 支持下拉关闭（下拉超过 30% 高度触发关闭） |
| 弹窗动画 | 居中弹窗：scale 0.9→1.0 + fade in（0.2~0.3s）；Bottom Sheet：从底部滑入（0.3s） |
| 硬件返回 | Android 返回键关闭当前弹窗（而非退出页面） |

## 九、动效规范

### 9.1 过渡动画参数

| 动画类型 | 时长 | 缓动曲线 | 用途 |
|---------|------|---------|------|
| 页面转场（Push） | 0.3s | ease-out | 从右滑入 |
| 页面转场（Pop） | 0.25s | ease-in | 向右滑出 |
| 弹窗弹出 | 0.25s | ease-out + spring | scale + opacity |
| 弹窗消失 | 0.2s | ease-in | opacity |
| 列表项入场 | 0.3~0.4s | ease-out, stagger 0.05s | 从上/下淡入 |
| 卡片翻转 | 0.4s | ease-in-out | 3D rotate |
| 刷新动画 | 持续 | 自定义 | 品牌动效 |
| 数值变化 | 0.4s | ease-out | 数字滚动 |

### 9.2 页面转场方向

| 转场类型 | 方向 | 说明 |
|---------|------|------|
| 进入子页面 | 从右向左 | Push（← 进入） |
| 返回父页面 | 从左向右 | Pop（→ 返回） |
| 弹出模态 | 从下向上 | Present（↑ 弹出） |
| 关闭模态 | 从上向下 | Dismiss（↓ 关闭） |

### 9.3 动效设计原则

1. **时长不过 400ms**：任何过渡动画不超过 400ms，避免用户等待
2. **高响应优先**：操作反馈动画 <100ms，让用户感觉"即时"
3. **统一缓动**：全项目使用一致的缓动曲线（推荐 ease-out 为主）
4. **减少动效的场景**：省电模式 / 减弱动效设置下，缩短或跳过非必要动画
5. **首屏不延迟**：首屏加载动画不能阻塞交互

### 10.1 竖版字号阶梯

| 级别 | 字号 | 行高 | 字重 | 用途 |
|------|------|------|------|------|
| Display | 28~32px | 1.2 | Bold (700) | 大标题/结算/特殊强调 |
| H1 | 22~26px | 1.3 | Bold (700) | 页面主标题 |

### 10.2 竖版排版规则

| 规则 | 说明 |
|------|------|
| 最小字号 | 不小于 10px（再小无法辨认） |
| 行宽上限 | 正文单行不超过屏幕宽度 80%（约 600px），超过则换行 |

## 十二、音效规范

### 12.1 UI 音效分类

| 类别 | 触发时机 | 音效特点 |
|------|---------|---------|
| 按钮点击 | 所有按钮按下 | 短促 (<200ms)、清脆 |
| 切换/选择 | Tab 切换、卡片选中 | 轻短、确认感 |
| 弹窗弹出/关闭 | 弹窗出现和消失 | 出现：上升音；关闭：下降音 |
| 成功 | 操作成功完成 | 明亮、上扬 |
| 失败 | 操作失败 | 低沉、短促 |
| 获得物品 | 拾取/获得奖励 | 悦耳、叮咚感 |
| 倒计时 | 最后 3 秒 | 逐秒急促 |

### 12.2 音效设计原则

- UI 音效时长 **≤500ms**，不拖尾
- 同一操作的按下和释放可用同一音效
- 连续操作（如快速点击）应有防重叠机制（新音效打断旧音效，或合并播放间隔 ≥100ms）
- 提供"关闭音效"和"关闭 UI 音效"两个独立开关

## 十三、横竖屏切换

### 13.1 原则

- **不强制方向**：除非核心玩法依赖特定方向（如竖版跑酷），否则应同时支持横竖屏
- **锁定则声明**：锁定竖版的游戏，在 App Store/应用商店描述中声明
- **切换无缝**：支持的场景下，横竖屏切换应 ≤0.5s 完成布局重排，无闪烁

### 13.2 竖版锁定场景

以下游戏类型通常锁定竖版：

| 类型 | 原因 |
|------|------|
| 三消/消除类 | 竖版单手操作是核心体验 |
| 卡牌对战（CCG） | 手持卡牌隐喻，竖版更自然 |
| 放置/挂机类 | 轻量交互，竖版方便单手随时查看 |
| 跑酷（竖版） | 纵向卷轴是玩法核心 |
| 聊天/社交类 | 消息列表纵向布局 |
| 短视频/信息流 | 内容纵向消费 |
