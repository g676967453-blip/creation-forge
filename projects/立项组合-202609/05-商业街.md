## 1. 一页纸决策区（Part A · 评审必读）

### 1.1 一句话 Pitch

玩家在关卡制商业街里 **拖放刷新出的建筑到地格**，通过收入/辅助/服务建筑搭配与「明星组合」相邻加成，在顾客流动中达成目标金额；特色是 **快节奏、极简操作、直播式热度评价反馈** 的 IAA 副游。

### 1.2 体验目标与 3选2

**体验目标：** 策略搭配智力感 + 快反馈放松/爽感  

**3选2：**

- [x] 建造（地格摆放经营）
- [ ] RPG — 弱（店员技能组合偏轻养成）
- [ ] 战斗 — 无；对抗向桌游参考已排除

### 1.3 核心循环

```
刷新建筑 → 拖到地格 → 顾客入场移动消耗资金/耐心
  → 搭配收入/辅助/服务建筑与明星相邻
  → 热度/评价反馈 → 达关卡金额胜利
```

| 环节 | 时长 | 情绪 |
|------|------|------|
| 单局 | **3–8 分钟**（原文） | 从第一栋到策略成型的完整情绪弧 |
| 局外 | 店铺升级、抽店员 | 养成寿命 |

### 1.4 Design Pillars

| # | 支柱 | 描述 | 验证方法 |
|---|------|------|---------|
| 1 | 随时打开完整反馈 | 副游；快节奏关卡验证 | 一局内有明确胜负与情绪弧 |
| 2 | 低成本高辨识建筑 | 大块剪影、少光影 | 美术可 2 周 Demo 配套 |
| 3 | 涌现搭配 | 店员×受众×店铺类型组合 | 理解成本低但组合多 |

### 1.5 Scope Boundary

| # | 不做 | 原因 |
|---|------|------|
| 1 | 玩家对战（骰子街式） | 原文明确不适合 |
| 2 | 过繁商品搭配（怪奇小店痛点） | 降复杂度 |
| 3 | 重度长线数值唯一体 | 用随机与店员拉长但保持关卡制 |
| 4 | 未定题材下的大规模包装 | 先钩子 |
| 5 | 与碧海扬帆双开同规格 | 组合策略 XOR |

验收：关卡金额目标可通；搭配有策略差异；广告点位可接。

### 1.8 Go/No-Go

- [x] 玩法一句话说清

**当前建议：** **钩子确定前不开工**；确定后 Go Demo。
