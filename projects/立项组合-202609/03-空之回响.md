## 1. 一页纸决策区（Part A · 评审必读）

### 1.1 一句话 Pitch

当大地坠落、万物沉入云海，玩家以**回响钓竿**从云海钓取物资与生命，用**方块建造空岛家园**，招募宠物与居民，连接联盟空域；特色是 **「钓取未知 × 体素建造 × 宠物伙伴」**，把木筏式漂流收集搬到天空。

### 1.2 体验目标与 3选2

**体验目标：** ① 创造表达 ② 探索发现惊喜 / 收集  

**3选2：**

- [x] 建造（方块+物件模型家园）
- [x] 角色扮演（居民、宠物、轻生存叙事）
- [x] 战斗/对抗 → **后期降级/后置**：联盟争夺为 V2，首发偏协作

### 1.3 核心循环

```
选空域/钓点 → 抛竿拉取未知目标 → 识别处理资源
  → 扩建空岛、升设施、解锁蓝图
  → 探索更远空域 / 救援居民 / 协作
  → 新发现带回下一轮创造
```

| 时间盒（原文） | 内容 | 情绪 |
|----------------|------|------|
| 1 分钟 | 一次短钓取，即时收获与惊喜 | 开箱 |
| 10 分钟 | 处理物资、扩建、升级、蓝图 | 成长 |
| 1 小时 | 探索空域、救援、主线、协作事件 | 冒险/协作 |

### 1.4 Design Pillars

| # | 支柱 | 描述 | 验证方法 |
|---|------|------|---------|
| 1 | 钓取即开箱 | 钓鱼是操作形式不是纯鱼类题材；十类目标覆盖成长 | 下一竿是否始终值得期待 |
| 2 | 方块骨架 + 模型生活 | 体素塑形，家具设备赋予生活 | 玩家能展示「我的岛成为了什么」 |
| 3 | 轻生存不剥夺慢生活 | 饥饿天气促行动，不数值囚笼；灾害=机会窗口 | 休闲玩家不因惩罚流失 |

### 1.5 Scope Boundary

| # | 不做（首发） | 原因 |
|---|-------------|------|
| 1 | **SLG 联盟空域完整玩法** | 原文列为上线后 V2 |
| 2 | 永久摧毁玩家家园的战争 | 保护家园感；有保护期与战损上限原则 |
| 3 | 一次性做满七类深空域+全目标 | Demo 只验证核心循环 |
| 4 | 无门禁直接按峰值 30+ 人扩编 | 须先过 Demo |
| 5 | — | |

### 1.6 平台与变现

| 项 | 内容 |
|----|------|
| 首发 | 国内（版号材料 Alpha 提交，与 Beta 并行） |
| 变现 | F2P + 内购：宠物收集 / 建造装饰 / 礼包（原文） |
| 成本控制口径 | 复用原型 + AI 概念图；Demo 阶段零新增模型成本（原文） |

### 1.7 First Playable / MVP 定义

**原文 Demo：** 4–6 周 · 7 人 · **20 分钟核心循环闭环**。  

**【整理补全】门禁验收：** 钓取手感成立 + 至少一种稀有/危险目标反馈 + 一次「钓到→建出可见成长」闭环；崩溃率可接受。

### 1.8 Go/No-Go 速判

- [x] 概念 30 秒清晰  
- [x] 品类组合有市场叙事（Valheim/帕鲁/Raft/钓鱼手游）  
- [ ] 产能匹配 — 峰值 31–34 人，**须验证原型资产真实复用率**  
- [ ] 变现细案 — 仅点到宠物/装饰/礼包  
- [ ] 技术风险 — 体素+钓取+多人交易未拆  
- [ ] 依赖资产清单 — 未量化  
- [ ] 合规版号路径 — 有节点无细则  

**当前建议：** **Demo 门禁后的有条件 Go**；未过 20 分钟闭环不得按全量表扩。  
**理由：** 愿景与阶段意识强，工程是本组合最大项。

## 3. 市场与竞品

### 3.1 赛道结论

- **主机/PC：** Valheim、帕鲁、Raft、NMS、Enshrouded 等验证「收集×建造×养成」；小团队+长线更新规律。  
- **移动钓取：** 欢乐钓鱼大师、Fishing Clash、钓鱼大亨等验证碎片化收集+经营+赛事付费。  
- **公式（原文）：** 空之回响 = 生存建造 × 钓取 × 宠物收集。

### 3.2 竞品表（原文数据口径）

| 竞品 | 数据点（原文） | 借鉴 | 差异 |
|------|----------------|------|------|
| Valheim | 2000 万+；5 人团队叙事 | 小团队建造生存 | 天空+钓取 |
| 帕鲁 | 峰值等 | 收集×建造×探索 | 钓取主交互 |
| Raft | 1200 万+ | 漂流+钩取+建造同构 | 云海空岛 |
| 欢乐钓鱼大师等 | 流水/MAU 等 | 移动钓取商业 | 嵌入建造文明 |

### 3.3 机会与威胁

| 机会 | 威胁 |
|------|------|
| 双端验证过的基因组合 | 移动端体素建造体验与性能 |

| V2 后置 SLG 理性 | 「现有原型」名不副实则排期崩 |

## 4. 世界观与调性

### 4.1 设定

天空灾变，大地坠落；**云海=世界遗库**。漂流者继承濒坠空岛，钓竿是古代「回响牵引装置」。

### 4.2 角色

创造者而非救世主：钓取、建造、招募、连接。

### 4.3 调性

奇观天空、未知上钩、家园生活温度；后期联盟版图。

**空岛成长线：** 漂流营地 → 生活岛屿 → 移动空岛 → 浮空村落 → 浮空城邦 → 空域势力。

## 5. 核心玩法与系统

### 5.1 主循环

见 §1.3；四幕：坠入云海 → 造出家园 → 连成世界 → 争夺天空（V2）。

### 5.2 系统全景

| 系统 | 机制 | MVP/Demo | 延后 | 支柱 |
|------|------|----------|------|------|
| 云海钓取 | 天气/深度/空域/钓具；十类目标 | 核心 | 全空域 | 1 |
| 方块建造 | 地形平台自由堆叠 | 基础塑形 | 联盟城 | 2 |
| 物件模型 | 家具设备可交互 | 少量生活件 | 全套 | 2 |
| 四种建造模式 | 方块/蓝图/装修/地形 | 子集 | 全模式 | 2 |
| 轻生存 | 饥饿、天气、稳定度 | 轻量 | 高压模式 | 3 |
| 宠物 | 情感+协助探测搬运钓防 | 1–N 基础 | 深度养成 | 1 |
| 居民 | 救援招募多职业；幸福度 | 后置或极少 | 全职业 | 2 |
| 探索空域 | 七类空域；飞艇航线等 | 1–2 区 | 虚空/核心 | 1 |
| 轻社交/交易 | 参观点赞蓝图；集市订单 | 延后 | 完整经济 |  |
| 联盟 SLG | 公共岛、航线、争夺 | **V2** | 首发不做 |  |

### 5.3 关键机制

- **十类目标：** 基础物资、方块、家具、设备、蓝图、宠蛋、遗迹残骸、求救信号、怪物、风暴核心等。  
- **风险回报：** 浅云稳定；雷暴/极寒/辐射等高价值。  
- **家园方向举例：** 生活/农场/工坊/宠乐园/钓基/观景/堡垒/贸易港/联盟城/主题乐园。

## 10. 里程碑与验证计划

按 §9.3 五阶段；**第一门禁= Demo 20 分钟闭环**。

### 待验证假设

1. 移动端钓取手感能支撑「下一竿期待」。  
2. 方块建造在目标机型可玩。  
3. 原型资产能吃下 Demo 模型成本为零的承诺。  
4. 无 SLG 时仍有足够长线目标（空岛六级+探索）。  
5. 宠物/装饰 IAP 与生存循环不冲突。
