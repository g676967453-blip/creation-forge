## 1. 一页纸决策区（Part A · 评审必读）

### 1.1 一句话 Pitch

玩家组成 **4 人 PVE 搜打撤小队**，携带装备与 **1 只宠物**进入随机拼装遗迹，在时限内搜宝、机制对怪、解密撤离，回 **空岛家园** 建设并繁育宠物；特色是 **无玩家对抗的短局轻社交 + 怪物机制博弈 + 宠物培育**（作者原话：开门见山对标超自然行动组并加入宠物）。

### 1.2 体验目标与 3选2

**体验目标：** ① 紧张机制博弈 ② 成长/收集（宠物与家园）  

**3选2：**

- [x] 战斗（vs 怪物机制，非纯数值）
- [x] 建造（家园，局外）
- [ ] RPG 叙事 — 轻；角色技能三分（战斗/侦查/辅助）

### 1.3 核心循环

```
备 2 装备道具 + 1 宠 + 食物 → 选关匹配 4 人
  → 遗迹：击杀/捕捉/搜宝/宠物关联解密
  → 达撤离金额上飞船；失败安慰奖
  → 家园建设、育宠、升级罗盘解锁关卡 → 再出发
```

| 环节 | 动作 | 时长 | 情绪 |
|------|------|------|------|
| 准备 | 选装选宠选点 | 分钟 | 构筑 |
| 局内 | 搜打撤+机制 | **10–15 分钟**（原文） | 紧张、协作可选 |
| 结算 | 独立收益 | 秒 | 回报 |
| 局外 | 家园/繁育/解锁 | 会话 | 温暖、长线 |

### 1.4 Design Pillars

| # | 支柱 | 描述 | 验证方法 |
|---|------|------|---------|
| 1 | 机制对怪非数值碾压 | 如注视乌鸦、影狼背后规则 | 新手死于「不懂规则」后能学懂并反杀 |
| 2 | 短局轻社交无 PVP | 共同目标不强制配合；收益独立 | 匹配快；单人体验可接受 |
| 3 | 局内险 / 局外暖 | 搜打撤压力 + 家园宠物 | 失败后仍愿回家园再出发 |

### 1.5 Scope Boundary

| # | 不做 / 慎做 | 原因 |
|---|-------------|------|
| 1 | 玩家对抗 | 定位差异 |
| 2 | 重度微恐视野压迫 | 原文可删减超自然视野 |
| 3 | 前期游泳等 | 原文可砍开发难度 |
| 4 | 首版全地图全机制 | 先 3 图量级 |
| 5 | 【整理】4 个月完美联网上线不设为硬承诺 | 排期乐观 |

### 1.6 平台与变现

| 项 | 内容 |
|----|------|
| 平台 | iOS/Android 首发；后续 Steam Deck / Switch |
| 变现 | 免费 + 月卡 + 外观 + 季票；繁育加速/槽位/保温盒等 |
| 引擎原文 | Unity（推荐）或 UE5 |

### 1.7 First Playable / MVP 定义

**原文计划：** 4 个月：3 地图、6 角色、6 宠、20 怪，小范围测试；6 个月上线含家园孵化+再加一图。  

**【整理补全】更稳门禁：** 1 图 + 3 机制怪 + 1 宠 + 单人/本地 4 人关卡可玩，先验证「机制是否真好玩」。

### 1.8 Go/No-Go 速判

- [x] 乐趣陈述清楚  
- [x] 相对射击搜打撤差异清楚  
- [ ] 工期匹配 — **4–6 月偏紧**  
- [x] 变现点有列表  
- [ ] 最大难点闭合 — **行为树与关卡机制几乎需重做**  
- [x] 宠物资产复用叙事  
- [ ] 高度相似玩法的产品/法务评估  
- [ ] 市场量化弱  

**当前建议：** 机制原型 Go；全量研发 **补材料前 No-Go**。  
**理由：** 个性强，工程与对标风险高。

## 3. 市场与竞品

### 3.1 赛道结论（原文）

射击搜打撤已拥挤；超自然行动组式「无 PVP + 简单战斗 + 小游戏级机制深度」竞品少；微恐非大众，宠物可扩受众。

### 3.2 竞品

| 竞品 | 借鉴 | 差异 |
|------|------|------|
| 超自然行动组 | 核心流程、机制怪、短局 | 宠物、家园、非微恐美化、自称动作/场景可更好 |
| 三角洲等 | 搜打撤热度 | 无玩家对抗 |
| 帕鲁 | 宠物 | 局结构不同 |
| 蛋仔等变体 | 存在改版玩法 | 目标做独立完整产品 |

### 3.3 机会与威胁

| 机会 | 威胁 |
|------|------|
| 品类空位论述 | 对标过近的同质/合规风险 |
| 复用宠与动作 | 机制开发不可复用，是最大难点 |
| | 网传对标成本 800 万/6 月/人不足 20 — 难直接类比 |

## 4. 世界观与调性

艾琳世界光柱破碎→浮空碎片；异界来客与本地生物结为 **拾光猎人**，寻 **光之碎片** 重塑世界；顺带古董奇物流通。调性：冒险喧闹、碎片世界法则诡异；可更优美非微恐。

## 5. 核心玩法与系统

### 5.2 系统全景

| 系统 | 机制 | MVP | 延后 | 支柱 |
|------|------|-----|------|------|
| 角色 | 生命/移速/负重/体力；2 道具格+4 万用；技能 CD | 少角色 | 全解锁付费线 | 1 |
| 装备道具 | 耐久、照明、铲、剑、杖、传送卷等 | 核心套 | 全图鉴 | 1 |
| 遗迹 | 路模板+随机房间；时限内怪变强 | 1–3 主题图 | 镜子等复杂本 | 1 |
| 怪物 | 巡逻/激活/追击/逃/攻；机制向 | 3–20 | 全 20+ | 1 |
| 宠物 | 元素、天赋、被动、饱食、繁育继承 | 1–6 | 深度繁殖经济 | 3 |
| 家园 | 装饰、育宠、饲料链、修理、拜访共建 | 上线期 | 深度 | 3 |
| 匹配 | 4 人无 PVP | 做 | | 2 |

### 5.3 机制举例（原文）

- **怪：** 宝箱怪、贪财兔、影狼（注视/手电/元素）等。  
- **本：** 四方宫殿、黑滩灯塔、镜子迷宫（伪人）等。  
- **宠天赋：** 复活、滑行、二段跳、隐遁、背包格等。  
- **濒死：** 队友救；部分机制直接死。

## 10. 里程碑与验证计划

| 阶段 | 原文 | 【补】建议 |

| 机制 POC | — | 1 图 3 怪 1 宠 |
| 小测 | 4 月：3 图 6 角 6 宠 20 怪 | 视 POC 调整 |
| 上线 | 6 月+家园 | |
| 运营 | 月更角色/图/怪/宠/被动 | |

### 待验证假设

1. 机制深度在 15 分钟局内可读可学。  
2. 无 PVP 仍有足够张力与留存。  
3. 宠物繁育能撑长线不只是皮肤。  
4. 复用资产真能砍美术。  
5. 匹配与关卡随机足够抗背板。

### 造化坊阶段映射

偏阶段 1–2；全量联网排期需重估后再进阶段 4–5。
