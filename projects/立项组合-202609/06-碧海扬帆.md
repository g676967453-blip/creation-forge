## 1. 一页纸决策区（Part A · 评审必读）

### 1.1 一句话 Pitch

玩家在局外配置渔具与船只，在局内 **打鱼捕捞、收集材料、躲避海盗、捕捉珍稀鱼种**，并修船升级武器；特色是 **清新轻量的弹幕射击 IAA 变体 + 肉鸽式武器效果组合**，用 shader 鱼群剪影降本。

### 1.2 体验目标与 3选2

**体验目标：** 收集满足（洛克王国式表述）+ 轻操作爽感  

**3选2：**

- [x] 战斗（轻射击/捕捞操作）
- [x] 建造/养成（船只、武器、可选海鲜店/装饰）
- [ ] 深度 RPG — 弱

### 1.3 核心循环

```
选渔具与船 → 海域探索捕捞与收材
  → 躲海盗威胁、抓珍稀鱼
  → 修船、武器兑换/抽/升/合成
  →（可选）海鲜店/装饰家园目标
```

### 1.4 Design Pillars

| # | 支柱 | 描述 | 验证方法 |
|---|------|------|---------|
| 1 | 降特效与关卡压力 | 少地图；鱼群 shader 剪影 | 加鱼种不靠高模敌人 |
| 2 | 轻量泛用户 | 比纯战斗更休闲；随时进退 | 中轻度仅收益差别 |
| 3 | 武器组合可玩性 | 左摇杆右武器；自定义组合 | 手感+build 差异 |

### 1.5 Scope Boundary

| # | 不做 | 原因 |
|---|------|------|
| 1 | 剧情重度（戴夫痛点） | 不适合小游戏 |
| 2 | 繁琐撤离 | 同上 |
| 3 | 多地图堆美术 | 主动少地图 |
| 4 | 与商业街双开 | XOR |
| 5 | 未打磨手感就铺内容 | 待解 #1 手感 |

### 1.6 平台与变现

| 项 | 内容 |
|----|------|
| 平台 | TapTap |
| 变现 | IAA |
| 待解 | 手感、广告、数据、软著 |

### 1.7 First Playable / MVP

**原文：** 核心 Demo **2 周** + 外围 1 周 + 交互 1 周。  

验收：捕捞手感过关；至少一种武器组合差异；海盗威胁可读；广告可接。

### 1.8 Go/No-Go

- [x] 概念清晰  
- [ ] **手感** 为第一风险  
- [x] 工期小  
- [x] 主题（海洋）比商业街更有现成钩子  
- [ ] 与商业街二选一  

**当前建议：** 若 IAA 只开一槽，**主题完整度略优于商业街**，但仍须 **手感 POC 3–5 天** 再承诺 2 周 Demo。  
**理由：** 钩子相对有（海+鱼）；成败在操作手感与 shader 方案。
