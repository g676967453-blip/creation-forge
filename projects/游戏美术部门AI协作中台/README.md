# 游戏美术部门AI协作中台

> 状态：✅ 已完成 v1.0（2026-08-19，来源待办 D-014） | 建立：2026-08-06

## 是什么

面向游戏美术部门的 AI 协作中台 —— 美术资产管理、AI 生成、管线集成的一站式平台。

四大能力：

1. **资产管理**：美术资产统一存储、版本管理、检索与复用
2. **AI 生成**：接入 AI 图像生成工具（Lovart 等），标准化 Prompt 模板与批量生成
3. **管线集成**：连接美术生产工具（PS/Figma）→ AI 生成 → 游戏引擎（Godot/Unity）
4. **协作流转**：美术需求提交、分配、审核、交付闭环
