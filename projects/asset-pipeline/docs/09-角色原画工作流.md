# 09 — 角色原画生成工作流

> 最后更新：2026-08-16 | 状态：✅ 已跑通（100 角色批量生产 + 三轮比例校准）
> 产出目录：`outputs/demo-character-concept/portraits/`

## 总览

角色原画线（demo-character-concept）的目标：为「鬼面武士 × 四派系异化」设计系统找到**最有效的提示词结构、最合适的美术风格、最适配的模型**。

经过五向探索、体型四样、螳螂刺客迭代、100 角色随机批量生产，本线沉淀出：

1. **设计系统**：四派系配色 + 浸染度句式 + 头身比 3-4.5 锁（可复用配方）
2. **提示词结构**：英文直写 + 分节标注式（防转译污染）
3. **适配矩阵**：哪些模型×风格组合对比例指令可控（核心结论）

## 设计系统（鬼面武士基底）

所有角色共享基底：

```
black oni mask with two yellow horns, black-brown kimono
```

### 四派系配方

| 派系 | 配色（2 主色 + 1 点缀） | 浸染语言 |
|------|------------------------|---------|
| 机械 mech | 玄黑 #1a1a1e + 旧金 #b87333；冷青点缀仅机械件 | 黄铜骨架/液压管/齿轮/黑油 |
| 白骨 bone | 玄黑 #12121a + 骨白 #e8e4d8；金点缀仅瞳孔 | 外骨骼/肋骨外翻/骨刃/骨角 |
| 甲壳 carapace | 玄黑 #0d0d12 + 深褐 #3b2f23；暗紫点缀仅发光缝 | 节肢甲壳/甲爪/肩刺 |
| 血肉 flesh | 深紫黑 #1a1018 + 暗红 #7a1f1f；绯红点缀仅发光眼 | 肌肉开裂/血肉触须/红刺/发光静脉 |

纪律：**点缀色只许出现在指定部位**（如「冷青 accent only on mechanical parts」），防止画面花。

### 浸染度（异化程度）七档 → 四句

| 档位 | 句式 |
|------|------|
| 30% / 40% | 点状：single mutation point（一只眼 / 一片甲 / 一块骨 / 一道裂纹） |
| 50% / 60% | 半身：half body mutated（右半身 / 右臂整条） |
| 70% / 80% | 大面积：most of body mutated（全身骨架 + 局部异常突出） |
| 90% | 全身：fully mutated，**保留唯一人类特征**（一只人眼 / 一只左手 / 人脸） |

### 头身比锁：3-4.5

- 用户 2026-08-15 锁定。1:2 真 Q 版为**弃用方向**（见下）。
- 实测结论：**头身比指令是整条线最难的约束**，详见「头身比控制」节。

## 提示词结构：英文直写 + 分节标注式

### 结论一：中文提示词会被 Lovart 转译污染

Lovart agent 会把中文提示词翻译成英文再传给图片模型，语义漂移（已验证 6+ 轮）。**解决：自己写英文，加一行中文包装指令要求原样传递**：

```
请直接用下面的英文规格生成 N 张角色原画，每行规格生成一张图，不要改写每行规格内容，原样传递给图片模型。共享画风前缀：{style}

1. {mini prompt 1}
2. {mini prompt 2}
```

### 结论二：分节标注式优于叙事段落

早期叙事段落式提示词被用户判「有点不对」。改为分节后稳定：

```
STYLE:   {画风关键词 + 负向}
CHARACTER: {鬼面基底 + 派系浸染 + 定位（武器/姿态）}
COLORS:  {2主色 + 1点缀纪律}
POSE:    side view fighting game stance, full body centered
COMPOSITION: 1:1 square canvas, pure white background, no text
```

### 批量行的紧凑格式（已验证 100 张）

单行 = `{corr}% corruption: {突变句式}, {配色}, {基底}, {头身比句}, {姿态构图}`。每行一张图，行间只差参数。

## 头身比控制（三轮校准全记录）

这是本线最贵的教训：**「X heads tall」裸短语对图片模型几乎无效**。

| 轮次 | 句式 | 采样达标率 | 现象 |
|------|------|-----------|------|
| v1 | 裸短语 `3.5 heads tall` | 1/9 | 风格化3D 跑向 2.0-2.5（过Q）；其余跑向 5.5-8.5（写实） |
| v2 | 分数锚点 + 体型词 `head height equals one quarter of full body height, stocky rounded build, stubby limbs` | 4/9 | 韩系/欧美系被拉回 3-4.5；风格化3D 仍 2.0-2.5；MJ×韩 纹丝不动 7.0 |
| v3 | 按组校准（见下） | 11/18 | 5 组合 100% 达标；MJ×3D / GPT2×3D 钟摆反向甩飞；MJ×韩 仍 7.0 |

### 钟摆现象

「风格化3D」前缀自带 `toy-like proportions` Q 版引力 → 压它（加 not chibi）就反弹成写实 6-7 头身。提示词层面在 Q↔写实之间**没有稳定中间点**。

### 校准表（v3 落地代码：`tools/batch100_helper.py`）

| 漂移方向 | 组合 | 校准 |
|---------|------|------|
| 过Q（<3） | nbp-s3d / mj-s3d / gpt2-s3d / nbp-west | 前缀删 `toy-like proportions`，句式换中性比例词，加负向 `not chibi, oversized head` |
| 写实（>4.5） | mj-kr | 加 `big head small body, short sturdy limbs` 压缩拉力（⚠️ 对 MJ 无效，见适配矩阵） |

### 适配矩阵（最终结论）

| 头身比控制 | 组合 | 备注 |
|-----------|------|------|
| ✅ 稳定 | GPT2×韩系 · NBP×韩系 · MJ×欧美 · GPT2×欧美 · NBP×欧美 | 2D 类画风对比例指令敏感 |
| ⚠️ 边缘 | NBP×风格化3D | ±1 头 |
| ❌ 不可控 | MJ×风格化3D · GPT2×风格化3D（钟摆）· MJ×韩系（无视） | **不建议用这三个组合生产需精确比例的角色** |

**生产建议：** 需锁头身比的角色原画 → 优先 韩系（龙之谷风）或欧美卡通 × GPT2/NBP；MJ 只在欧美卡通下可控。

## Q 版形体参考（弃用方向，仅存档）

用户 4 张 Q 版参考 + agent 分析结论：

- 真 Q 版：**1:1.5-2.5 头身**，头宽 ≥ 肩宽，四肢短粗，手脚简化
- 关键词组 `chibi proportions, big head small body, ...` 生成 1:2 实验版（`mantis-assassin-90_chibi3d.png`）后，用户裁定**超出锁定范围，弃用**
- 本线头身比下限固定 3

## 批量生产管线（100 角色）

工具：`tools/batch100_helper.py`（确定性种子 20260815，可复现参数表）

```bash
python3 tools/batch100_helper.py gen        # 生成 100 行随机参数表 + 9 分组
python3 tools/batch100_helper.py prompt 0   # 打印组 0 的 chat prompt
python3 tools/batch100_helper.py tool 0     # 打印组 0 的 --include-tools
python3 tools/batch100_helper.py rename 0   # stdin 读 chat JSON，按序重命名 + 记状态
python3 tools/batch100_helper.py summary    # 总进度
```

### 批量执行纪律

1. **每组一个独立线程**（上下文隔离，续跑不串组）
2. `--include-tools` 硬锁模型，每组只用一个模型×风格
3. chat 输出 `| rename <i>` 管道直接落盘，JSON 不进对话上下文
4. **续跑陷阱**：同线程 result 轮询返回全部历史产物 → rename 只认 `downloaded[].new == true` 的新文件
5. timeout 不一定是失败：多数组 timeout 时产物已齐（13/13、14/14），轮询 `result --thread-id` 补收

### 产出分布（100 张）

定位：战士 24 / 将军 22 / 刺客 21 / 辅助 18 / 谋士 15；派系：甲壳 33 / 机械 28 / 血肉 23 / 白骨 16；浸染度 30-90 七档随机；头身比 3/3.5/4/4.5 随机。

## 关键参数卡

| 参数 | 值 |
|------|-----|
| 画布 | 1:1 正方形（1024） |
| 背景 | 纯白（`pure white background`，抠图后处理友好） |
| 负向（必带） | `extra limbs, deformed anatomy, text, watermark, busy background` |
| 基底 | 鬼面 + 双黄角 + 黑褐和服 |
| 头身比 | 3-4.5（用分数锚点句，禁裸短语） |
| 模型选择 | 比例敏感 → GPT2/NBP × 韩系/欧美；MJ 仅欧美卡通 |

## 踩坑（已并入 05-踩坑记录）

1. **中文转译污染** → 英文直写 + 中文包装指令（本线最大单坑）
2. **裸头身短语无效** → 分数锚点句 + 按组校准（三轮校准史）
3. **Flux Pro 家庭账号认证失败** → 自动回退，报告时如实标注
4. **续跑重命名错位** → rename 过滤 `new == true` + 清理 hash 残留
5. **timeout ≠ 失败** → 轮询 result 补收，不重发 prompt
