# 秦王殿奏对 (Qin Court Audience)

> 项目类型：🎮 小程序游戏 | 技术栈：HTML/CSS/JS | 创建：2026-07-31

## AI 协作规则

### 项目定位

战国秦王殿答题互动游戏。单 HTML 文件，无框架，纯前端。设计用于微信小程序 WebView 环境。

### Claude 的角色

**协作者 / 加速器** — 本项目是完整可玩产品，主要工作是内容扩展和体验优化。

### 能做

- 扩充题库（新增题目 + 分类）
- 调整 UI 样式和布局（色彩、字体、动画）
- 优化游戏逻辑（关键词匹配、音效、流程）
- 添加新功能（排行榜、存档、分享等）
- 修复 bug

### 不能做

- 引入需要后端的功能（数据库、API 等）—— 除非用户明确要求
- 引入大型框架（React/Vue 等）—— 保持单文件轻量
- 擅自修改游戏核心规则（10 问、关键词匹配机制）

### 文件结构

```
qin-court-audience/
├── index.html    ← 游戏本体（1080 行，含完整 HTML/CSS/JS）
├── CLAUDE.md     ← 本文件
└── README.md     ← 项目说明
```

### 修改原则

- `index.html` 是单一数据源，所有修改直接在此文件中进行
- 修改前先读文件确认当前结构
- CSS 变量定义在 `:root` 中（行 8-20），调色先从变量入手
- 题库数据在 `<script>` 中 `ALL_QUESTIONS` 数组（行 497+）
- 保持代码风格：中文注释、es5 风格（var/function）、无外部依赖
