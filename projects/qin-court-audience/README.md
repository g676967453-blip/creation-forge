# 秦王殿奏对

> 🏯 战国秦王殿答题互动游戏 · 小程序版

## 玩法

秦王坐殿，召卿问对。玩家扮演殿前奏对的臣子，回答秦王提出的治国之问。

- **规则**：随机抽取 **10 道题**，打字作答
- **判定**：答案包含任意关键词即判正确（关键词匹配，非精确比对）
- **胜负**：十问连捷则胜（"国士无双"）；任一答错即败（"拖出去砍了"）
- **题库**：300 道题，覆盖 10 个分类

## 十大分类

| # | 分类 | 说明 |
|---|------|------|
| 1 | 富国强兵 | 耕战之道、商君变法 |
| 2 | 法令制度 | 律法赏罚、以法治国 |
| 3 | 用人之道 | 选贤任能、客卿制度 |
| 4 | 军事谋略 | 攻守进退、合纵连横 |
| 5 | 外交纵横 | 远交近攻、邦交策略 |
| 6 | 君臣之道 | 上下关系、治官之术 |
| 7 | 人心教化 | 移风易俗、统一思想 |
| 8 | 乱世争霸 | 兼并战争、天下形势 |
| 9 | 为君之术 | 帝王心术、治国方略 |
| 10 | 历史借鉴 | 前代兴亡、以史为鉴 |

## 技术栈

| 层级 | 技术 |
|------|------|
| 结构 | HTML5 |
| 样式 | CSS3（CSS 变量 + 动画） |
| 逻辑 | 原生 JavaScript（ES5） |
| 音效 | Web Audio API（程序化生成 beep） |
| 视口 | 720×1280 竖屏（适配微信小程序） |

## 屏幕结构

```
标题画面 → 进场动画 → 答题循环(×10) → 胜利/死亡覆盖层
```

- **标题画面**：秦王殿 UI，开始按钮
- **进场动画**："宣 —— 进殿奏对 ——"
- **游戏画面**：进度条 + 分类标签 + 题目 + 输入框 + 反馈
- **死亡覆盖层**：红闪 + 🗡️ + 正确答案展示 + 重试
- **胜利覆盖层**：金色粒子 + 🏆 + 统计 + 重来
