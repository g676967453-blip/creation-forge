# 情景认知小程序 — 产品概念(一页纸)

> 状态:脑暴阶段 · 日期:2026-08-08 · 定位:大众用户的"情景模拟 + 认知提升"互动内容平台

## 一句话

用"类魂式"的情景模拟游戏,让大众用户在反复失败中归纳出可迁移的认知原则——首期做理财,后续扩展到为人父母、商业谈判等更多领域。

## 目标用户

大众用户(不是专业学习者)。门槛低、一局短、失败要有趣,玩家"觉得好玩顺便学到东西"。

## 核心循环

1. 玩家进入情景(首期:中了500万),面对接踵而来的问题(借钱、投资、骗局、消费诱惑……)
2. 每次选择 → 即时演后果(财富数字变化、事件旁白),让玩家自己感受情绪
3. 一局结束 → 复盘:按"原则命中"给出薄弱清单 + 个性化点评
4. 重玩:情景不重复(罗格莱克),但底层原则重复——玩家在失败中归纳原则,理财认知高→财富增长,认知低→缩水返贫

## 关键设计决策(已定)

1. 类魂式学习:死一次学一招。评价系统按"原则命中"统计,不按"这题对错"。原则库是脊椎,事件是血肉。
2. 数值模型:选择→原则→财富变化,全部走确定性规则引擎(通胀、收益率、消费、意外事件)。LLM 永远不碰数字。
3. 内容生产:原则库和事件模板人工设计(5-8条核心原则/剧本),LLM 离线批量扩写变体,人工审核后入库。运行时零生成成本。
4. 运行时 AI 只用于复盘文案:局末把薄弱原则清单喂给 LLM,生成个性化点评,一局一次调用。
5. 失败即乐趣:黑色幽默结局文案 + "理财死法"称号收集(韭菜王/接盘侠/散财童子),失败本身成为收集品,留住大众用户。
6. 类目定位:教育/互动内容类目,避开"小游戏"类目(规避游戏版号)。
7. 变现:免费体验章节 + DLC 付费剧本。iOS 禁虚拟支付 → 混合路径:免费+广告、安卓付费解锁、导流公众号。
8. 平台化:先用理财一个剧本跑通"引擎 + 内容生产流程 + 学习效果验证",再复制到其他领域。每个领域需要真专家(理财顾问/育儿专家/谈判教练)——这是护城河,也是瓶颈。
9. 原则库来源:参考得到理财课程 + 经典理财书,提炼"共识性原则"(多源交叉验证)。只取所有主流来源都认同的公理级原则,不碰具体产品推荐、收益承诺等争议内容——这既是质量线也是合规线。
10. 单局时长:≤10 分钟,一局约 10-15 个事件节点,适合碎片时间。

## 数值模型框架(待细化)

- 资产状态:现金、各类资产(存款/理财/房产/股权/负债)、每月现金流
- 时间推进:按"年"推进,10-20年一局
- 事件类型:消费诱惑、人情借贷、投资机会、骗局、意外支出、市场波动
- 原则→数值映射示例(待专家定稿):留应急金=免死金牌;分散投资=降低波动;警惕高息=避开归零事件;人情借贷=现金流侵蚀……

## 待定问题

1. 合规:生成式 AI 算法备案、内容安全要求、小程序平台 AI 内容规则——立项前查清
2. 传播机制:结局分享卡(带羞辱感的财富结局)是天然传播点,需细化
3. 产品名未定
4. 原则库候选清单(基于公开课程/书籍共识,待起草)

## 假设清单(需验证)

1. 大众用户愿意为内容付费或看广告
2. 失败收集机制能撑起重复游玩
3. AI 生成 + 人工审核的内容质量能过品控线
4. "教育/互动内容"类目定位能过微信审核
5. 玩家真的能学到东西(玩前玩后小测验证)

## 下一步

1. 起草候选原则库(参考:得到理财课程、《小狗钱钱》《穷爸爸富爸爸》《指数基金投资指南》、"四笔钱"框架)
2. 确认 MVP 剧本范围(只做"中了500万"一个开局?)

4. 查合规要求(算法备案/类目审核/理财内容红线)
5. 验证传播点(结局分享卡)的分享意愿
