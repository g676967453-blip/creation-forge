# 救火英雄 · 音效 / BGM 需求清单

> 版本：v1.0 ｜ 日期：2026-08-31 ｜ 状态：可执行基线  
> 对齐：`fire-hero-iaa.html` 现有 `sfx()` 事件、企划 IAA 点位、美术规格附录 A 界面流  
> 关联：`救火英雄美术输出规格与MVP资产清单.md`

---

## 0. 一页结论

| 项 | 规定 |
|---|---|
| 原型现状 | **0 个音频文件**；8 个 WebAudio 振荡器占位（`bounce/break/rescue/coin/lose/win/launch/click`） |
| MVP 推荐 | **12～16 条 SFX** + **1～2 条 BGM**（可无 BGM 先上 SFX） |
| P1 | SFX 扩至 **20～28**；BGM **2～3** |
| 版权 | **禁止**原版 FC《Flying Hero》音乐；仅用可商用素材库 / 原创 / 已授权 AI |
| 命名 | `sfx_*` / `bgm_*` 小写蛇形英文 |
| 格式 | 源文件 WAV；上线 **OGG 或 MP3**；SFX 建议 mono 44.1kHz；BGM stereo |

---

## 1. 与原型事件的映射

| 原型 `sfx(id)` | 建议正式文件 | 说明 |
|---|---|---|
| `click` | `sfx_ui_click` | UI 通用点击 |
| `launch` | `sfx_launch` | 发射主角 |
| `bounce` | `sfx_bounce` | 撞蹦床 |
| `break` | `sfx_fire_hit`（可再拆 `sfx_fire_out`） | 原型混用灭火/撞窗 |
| `rescue` | `sfx_rescue_save`（另补 grab） | 获救成功 |
| `coin` | `sfx_coin` | 金币/钱袋 |
| `lose` | `sfx_life_lose` | 掉命等负面 |
| `win` | `sfx_level_clear` | 过关/解锁庆祝 |

程序替换时：保留 `sfx(name)` 接口，内部改播 AudioBuffer / 小游戏 `InnerAudioContext`。

## 2. MVP 音效清单（勾选）

### 2.1 必配 SFX（12）

| # | 文件名 | 触发场景 | 时长建议 | 状态 |
|---|---|---|---|---|
| 1 | `sfx_ui_click` | 按钮、选角色、开关面板 | ≤0.10s | [ ] |
| 2 | `sfx_launch` | 开局/重新发射 | ≈0.15s | [ ] |
| 3 | `sfx_bounce` | 主角撞蹦床 | ≈0.10s | [ ] |
| 4 | `sfx_fire_hit` | 撞击燃烧窗（未灭尽） | ≈0.15s | [ ] |
| 5 | `sfx_fire_out` | 该窗火焰扑灭 | ≈0.20s | [ ] |
| 6 | `sfx_rescue_grab` | 撞入救援窗抓住人 | ≈0.15s | [ ] |
| 7 | `sfx_rescue_save` | 送回蹦床获救计分 | ≈0.25s | [ ] |
| 8 | `sfx_coin` | 得币、钱袋、结算加币 | ≈0.15s | [ ] |
| 9 | `sfx_item_pos` | 正面道具（长条/灭火器/1UP 等） | ≈0.20s | [ ] |
| 10 | `sfx_item_neg` | 负面道具（锤子/火球等） | ≈0.20s | [ ] |
| 11 | `sfx_life_lose` | 掉出屏幕掉命 | ≈0.30s | [ ] |
| 12 | `sfx_level_clear` | 通关成功 | 0.4～0.8s | [ ] |

### 2.2 强建议 SFX（+4，合计 16）

| # | 文件名 | 触发场景 | 状态 |
|---|---|---|---|
| 13 | `sfx_game_over` | 失败结算打开 | [ ] |
| 14 | `sfx_revive` | 广告复活成功 | [ ] |
| 15 | `sfx_shop_buy` | 补给队购买成功 | [ ] |
| 16 | `sfx_ad_reward` | 任意激励视频发奖 | [ ] |

### 2.3 MVP BGM（0～2）

| # | 文件名 | 场景 | 形态 | 状态 |
|---|---|---|---|---|
| B1 | `bgm_game` | 局内循环 | 30～90s seamless loop | [ ] 建议 |
| B2 | `bgm_menu` | 主菜单 | loop 或短床 | [ ] 可选 |

> 极简路径：**只做 12 条 SFX + 1 条 `bgm_game`**，菜单静音或复用 game 降音量。

## 4. 界面 × 音频挂接（制作核对）

| 界面/状态 | 应触发的音频 |
|---|---|
| 主菜单打开 | `bgm_menu` 或静音 |
| 按钮 | `sfx_ui_click` |
| 开始进关 | 切 `bgm_game`；`sfx_launch`（首次发射） |
| 弹床 / 灭火 / 救人 | bounce / fire_* / rescue_* |
| 道具落入 | item_pos / item_neg / coin |
| 通关 | 停或压低 BGM → `sfx_level_clear` →（可选双倍）`sfx_double_coins` / `sfx_ad_reward` |
| 补给队 | 可选 `bgm_shop`；购买 `sfx_shop_buy`；刷新 `sfx_shop_refresh` |
| 掉命 | `sfx_life_lose` |
| 失败页 | `sfx_game_over`；复活 `sfx_revive` |
| 角色解锁 | `sfx_unlock_char` 或 `sfx_ad_reward` |
| 暂停 | 降 BGM；可选 `sfx_pause` |

## 5. 技术规格

| 项 | 要求 |
|---|---|
| 目录建议 | `audio/sfx/` · `audio/bgm/` · `audio/src_wav/`（源文件可选不入库） |
| 导出 | SFX：OGG（优先）或 MP3；BGM：同左 |
| 采样率 | 44.1 kHz（或 48 kHz 全项目统一） |
| 声道 | SFX mono；BGM stereo |
| 响度 | 避免削波；预留主音量；SFX/BGM 分轨增益 |
| 同时播放 | 至少支持 1 BGM + 4～6 SFX 叠音（小游戏侧注意实例数） |
| 静音 | P1 设置页：音乐 / 音效开关；遵守系统静音策略 |
| 微信/抖音 | 注意首次手势解锁音频；延迟加载 BGM |
| 文件大小 | 单条 SFX 建议 &lt; 50KB（压缩后）；BGM loop 控制在合理码率 |

### 命名示例

```
audio/sfx/sfx_bounce.ogg
audio/sfx/sfx_level_clear.ogg
audio/bgm/bgm_game.ogg
audio/bgm/bgm_menu.ogg
```

## 6. 验收标准（DoD）

### 单条

- [ ] 命名符合本表  
- [ ] 无第三方游戏 OST 片段、无原版 FC 音色直接采样（除非可证授权）  
- [ ] 听感符合卡通休闲，不刺耳、不掩盖 UI 点击  

### MVP 包

- [ ] §2.1 十二条全部可播  
- [ ] 局内：发射、弹床、灭火、获救、掉命、通关 路径各至少听到对应 SFX  
- [ ] 若有 BGM：loop 无缝或接缝不可察觉；切菜单/进关不崩溃  
- [ ] 真机静音开关或系统静音下行为可接受  

### 对比交付

1. 文件列表（文件名 + 时长 + 用途一行）  
2. 可选：10 秒试听条（拼接 MVP 关键 6 声）

## 7. 工作量参考

| 方案 | 内容 | 预估 |
|---|---|---|
| A 极简 | 12 SFX，无 BGM（或库站套用） | 0.5～1.5 人日 |
| B 推荐 MVP | 16 SFX + 1～2 BGM | 1.5～3 人日（含选库精修） |
| C P1 | + 扩展 SFX/BGM | 再 +1～2 人日 |

成本清单中「音效/音乐 0.2～3 万」与上表量级匹配：MVP 走素材库+精修即可。

---

## 8. 明确不做（防膨胀）

- 全语音台词 / 角色大量语音  
- 32 关每关独立 BGM  
- 自适应互动音乐中间件（首版过重）  
- 复刻原版旋律「致敬版」
