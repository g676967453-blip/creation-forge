## 信息架构要点

### 主菜单
- 标题、玩法一句话、主 CTA「开始灭火」
- 广告 CTA「+50 金币」
- 角色入口 + 当前角色显示
- 最高分、IAA 点位提示

### 局内
- 顶栏：关卡 / 分数 / 金币 / 生命
- 右上：技能（哪吒）、暂停
- 中上：双通道目标（火 x · 人 y）
- 中部：大楼窗格（玩法主视觉）
- 底部：蹦床操作区

### 角色选择
- 5 卡：小猫/小狗/熊猫/卡皮巴拉/哪吒
- 状态：使用中 / 已拥有 / 金币价 / 广告或高价
- 能力文案必须可见（微创新核心）

### 补给队
- 英雄位 ×1 + 道具位 ×3（+ 广告扩展位示意）
- 持有金币、刷新广告、继续下一关（可不消费）

### 好友排行榜弹窗
- 形态：半屏/居中 **弹层**（底图虚化主菜单/局内），非独立全流程页
- Tab：好友（默认）/ 全服 / 本周
- 顶部：我的名次卡（名次 + 角色 + 最高分）
- 列表：Top1–3 高亮 + 普通行；列表内再次锚定「我」
- 底栏：邀请好友 / 看广告刷新 / 继续灭火；说明周榜重置
- 数据为示意占位，程序侧可接微信/抖音好友榜或本地假数据

### 广告点位映射
| 点位 | 出现界面 |
|---|---|
| 菜单领币 | 主菜单 |
| 通关双倍 | 通关结算 |
| 补给刷新 / 额外商品 | 补给队 |
| 失败复活 | 失败 |
| 角色解锁（哪吒） | 角色选择 |
| 排行榜刷新（可选） | 好友排行榜 |
