# 救火英雄 IAA · 像素风美术规范

> 目标：将 Godot 版《救火英雄 IAA》从占位图形替换为统一的像素风位图、动图和特效。

## 1. 风格方向

- **像素风**、卡通、清晰识别、竖屏 9:16
- 颜色对比强，优先使用消防红、警示黄、夜景蓝、火焰橙
- 角色轮廓要在低分辨率下仍可辨认
- 统一使用**正视建筑立面**，避免透视过强
- 反馈要夸张但短促，适合休闲 IAA 节奏

## 2. 像素资源目录

建议目录：

```text
assets/pixel/
├── characters/   # 消防员、角色、NPC
├── props/        # 蹦床、窗口、道具、金币
├── backgrounds/  # 大楼立面、天空、城市背景
├── ui/           # HUD、按钮、图标、面板
├── vfx/          # 命中特效、金币、火焰碎片、爆闪
└── anim/         # SpriteFrames / 帧动画资源
```

## 3. 资源类型与建议尺寸

| 类别 | 建议尺寸 | 说明 |
|---|---:|---|
| 角色主立绘 | 64×64 / 96×96 | 用于菜单、角色卡、HUD 图标 |
| 窗户砖块 | 48×48 | 与当前关卡格子对齐 |
| 蹦床 | 96×18 / 96×24 | 横向拉伸感强，适合横向摆动 |
| 火焰窗 | 48×48 | 分 3 个火焰等级 |
| 救援窗 / 红窗 | 48×48 | 呼救动画、红闪提示 |
| 金币 / 道具 | 16×16 / 24×24 | 适合弹出和飘字 |
| HUD 图标 | 16×16 / 24×24 | 分数、金币、生命、暂停等 |
| 背景层 | 450×800 或分层拼接 | 城市/大楼/天空 |
| 特效帧 | 16×16 / 32×32 | 爆闪、火花、烟尘、金币弹出 |

## 4. 像素动效规范

### 4.1 火焰动画
- 2~4 帧循环
- 火 1 / 火 2 / 火 3 分别使用不同亮度与轮廓
- 命中时做 1 帧抖动或亮度闪烁

### 4.2 蹦床与球
- 蹦床落球时做轻微压缩动画
- 弹起时做 2~3 帧回弹
- 命中救援时球体颜色变化或带人状态提示

### 4.3 UI 与金币
- 金币使用闪烁 / 旋转 / 发光 2~4 帧动画
- 过关提示使用像素风弹窗，不要现代渐变过重

### 4.4 命中与过关特效
- 以像素粒子、火花、爆闪、金币喷出为主
- 特效尽量短，避免遮挡核心操作区域

## 5. Godot 接入建议

- 图片导入时关闭平滑（Nearest / 无过滤）
- 需要像素风放大时，不要自动模糊
- 建议使用：
  - `Sprite2D`
  - `AnimatedSprite2D`
  - `SpriteFrames`
  - `GPUParticles2D` / `CPUParticles2D`
  - `TextureRect` / `ColorRect` 仅作为临时占位
- 先替换主角、蹦床、窗户、UI，再补背景和特效
