## 关键问题与解决
| 问题 | 解决 |
|------|------|
| 灭火器无实际用途（无「蹦床着火」来源） | 范围扩为 P0 5 种 + 火球（用户确认）：正负博弈闭环，负向道具=广告复活钩子 |
| `const NARROW_WIDTH: float = maxf(...)` 编译失败 | const 不能调用函数 → 直接写死 122/68（baseW=92 恒 > 下限 40）并注释 |
| set_on_fire(false) 不还原色调 | 记录初始 modulate，关闭时还原 |
| 道具下落不冻结（暂停后仍掉） | 每物理帧查 GameRoot 状态 |
| 冒烟脚本首版挂在 SceneTree 手推物理帧 | 改「场景内 Node + await physics_frame」由引擎驱动 |
