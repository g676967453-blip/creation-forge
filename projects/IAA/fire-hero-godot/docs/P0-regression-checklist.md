# P0 回归清单（本机 F5）

> 工程：`J:\ceshi\projects\IAA\fire-hero-godot`  
> 引擎：`F:\Godot_v4.7-stable_win64.exe`  
> 打开：双击 `open_with_godot.bat` 或 `--path` 打开后 **F5**

## 0. 启动

- [ ] 无 Parser / 脚本错误红字
- [ ] 进入主菜单，可见「开始游戏」

## 1. 开局与操作

- [ ] 点「开始游戏」进入第 1 关，HUD 显示关卡/分数/金币/生命/目标
- [ ] A/D 或 ←→ 可移动蹦床
- [ ] 按住鼠标左键可拖动蹦床
- [ ] 空格或点击可发射（球离板向上）
- [ ] 发射前球应跟着蹦床移动

## 2. 碰撞与目标

- [ ] 球碰左右/顶边会反弹
- [ ] 撞击橙色火窗：HP 数字下降，灭尽后窗消失，🔥 计数减少
- [ ] 撞击蓝色救援窗：球变黄（带人），窗消失；**带回蹦床弹起**后 👤 减少、加分
- [ ] 红窗：可抓人加分，**不要求**必须减 👤 硬目标（红窗本就不计入 👤）
- [ ] 带人时再撞救援窗：不应抓第二人；仍可撞火

## 3. 双通道胜利

- [ ] **灭光所有火** → 过关界面（即使还有人）
- [ ] **救完所有普通救援（👤到 0）** → 过关界面（即使还有火）
- [ ] 过关界面只出现一次（连撞不会叠多层）
- [ ] 「下一关」进入第 2 关，布局变化
- [ ] 双倍金币：可点一次；再点提示已领取，金币不重复翻倍

## 4. 掉落与生命

- [ ] 故意不接球 → 生命 -1，球回到板上待发射
- [ ] 生命到 0 → 失败界面
- [ ] 「看广告复活」→ 生命变 1，回本关待发射
- [ ] 再失败后复活按钮应禁用 / 提示本关已复活
- [ ] 「重新开始」→ 从第 1 关、3 命重开
- [ ] 「主菜单」→ 回菜单，再开始不残留旧砖

## 5. 暂停

- [ ] 游玩中 Esc → 暂停遮罩，球停止，蹦床不能动
- [ ] 点「继续」或再 Esc → 恢复（未发射则仍粘板；已发射则继续飞）
- [ ] 暂停时点「主菜单」可回菜单

## 6. 存档（粗测）

说明（设计如此，不是丢档）：
- **本局分数 `score`**：每次点「开始游戏 / 重新开始」会清零，**不跨局保留**。
- **最高分 `best`**：本局分创新高时更新，会写入存档。
- **金币 `coins`**：养成货币，跨局保留。

哪里看：
- 主菜单：`🏆 最高分 x　💰 金币 y`
- 局内 HUD：`分 a | 最高 b`
- 失败界面：本局得分 + 最高分 + 金币

- [ ] 打出一定分数后失败/过关，失败界面能看到「最高分」
- [ ] 回主菜单能看到「最高分 / 金币」
- [ ] 关掉游戏再开，主菜单最高分与金币仍在
- [ ] 再开一局时「本局分」从 0 开始，最高分不变（除非本局更高）

## 修过的点

### 第一轮
| 问题 | 处理 |
|------|------|
| `offset` / `dmg` 类型推断 | 全脚本关键局部变量显式类型；`maxi` 代替混用 `max` |
| 暂停后球拍仍可动 | `paddle.control_enabled` |
| 暂停球未真正停 | `freeze_motion` / `unfreeze_motion` |
| 清砖延迟 | 清场立即 `free()` |
| 连击多次过关 | `_level_closing` |
| 双倍连点 | `_double_claimed` |
| 红窗硬目标 | `_carry_is_red` |
| 坠落重复扣命 | `_fell_lock` |
| 遮罩点穿 | overlay STOP |

### 第二轮（继续 BUG）
| 问题 | 处理 |
|------|------|
| 暂停恢复后球速度/方向丢失 | `_saved_velocity` 保存再恢复 |
| 灭火/救人 `queue_free` 前同帧连撞 | `is_dead` + 立刻 `collision_layer=0` |
| `hit` 对已死砖再结算 | 返回 `"none"` |
| `FIRE_HIT_REQ` / 整数 `max` 混用 | `Array[int]` + `maxi` |
| level_builder / constants / 存档类型不稳 | 全面标注类型 |
| 竖屏拉伸 | `stretch/aspect=keep` |
