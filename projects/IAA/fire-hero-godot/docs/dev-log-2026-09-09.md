## 关键问题与解决
| 问题 | 解决 |
|------|------|
| 分身落屏后其它分身悬浮 | filter 对已释放 Object 类型转换报错中断 _process → 改手动遍历（8ad1604） |
| Godot Web 需安全上下文 | 内网自签 HTTPS 8443（make_cert.py + server.js 双监听） |
| Web 手机加载慢 | server.js gzip：wasm 线上 37.7MB→9.7MB |
| Web 中文乱码 | 无本地中文字体 → UI 全局默认 Zpix |
| 手机只能鼠标拖不能触屏操作 | 左右虚拟按钮 + _suppress_drag 防冲突 |
| 道具难辨认 | 美术 64px 像素贴图替换程序色块 |
