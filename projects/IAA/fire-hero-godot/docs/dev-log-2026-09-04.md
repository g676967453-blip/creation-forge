## 关键问题与解决
| 问题 | 解决 |
|------|------|
| PSD 烘焙窗与逻辑砖冲突 | 背景只用纯背景组 |
| 左右消防员装反 | 交换 fireman_left/right.png |
| shader 拖尾无效果/编译失败 | 弃用 shader（fragment 不支持 return + 帧采样区域小）→ 改粒子拖尾 |
| 粒子浓度难调 | amount 减半 + color_ramp 起点 alpha 下调 |
| HUD 字体/图标 | 引入 Zpix + 像素图标 TextureRect |
