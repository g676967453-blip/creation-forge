## 1. 文档说明

### 1.1 目的

当前 HTML 原型（打砖块 + 接人加分）在**基础体验**上没问题，但机制对标原版《救火英雄》**严重不全**。本文档以原版规则为基准，全面梳理：

1. 原版完整的游戏规则（玩法、对象、道具、敌人、关卡、计分）
2. 当前原型与原版的差距对照
3. IAA 化改造建议（保留/简化/去掉 + 实现优先级）

本文档是**下一阶段开发实现的规则依据**，评审通过后按本文档迭代原型。

## 2. 游戏概述

**一句话定位**：玩家操作两位消防员拉起蹦床，把第三位消防员弹向高楼各处，**撞击火焰窗户灭火、撞击救援窗救人**的竖版打砖块式闯关游戏。

**核心循环**：
```
弹起消防员 → 撞击火焰窗(灭火) / 撞击救援窗(救人) → 掉落道具(正/负) → 达成灭火或救人条件 → 过关
                                    ↑_____________________接住/躲避_____________________↓
```

**核心设计差异（对比普通打砖块）**：
- "球"是**消防员本人**（有重力、可抓人、会摔死）
- "砖块"是**大楼窗户**（三种状态，是场景对象而非纯障碍）
- 过关条件不是"清空砖块"，而是**"灭火 或 救人"二选一**（双通道胜利）

## 3. 原版规则全景（对标基准）

### 3.1 角色与操作

| 项目 | 原版规则 |
|---|---|
| 玩家角色 | 下方**两名消防员**共同拉着一张蹦床，左右移动 |
| 弹射对象 | 第三名消防员（以下称"主角"）从蹦床被弹起，持续飞行 |
| 操作 | 左/右键移动蹦床；B 键在关卡开始时发射主角上天；Select 暂停；Start 开始 |
| 类比 | 蹦床=球拍，主角=球，火焰/人员=砖块（IGN FAQ 原话：*like Arkanoid, but with people instead of balls and bricks*） |

**我方原型现状**：球拍=消防员平台，球=水球（非消防员本人）。角色设定已改版，是否回归"球=消防员"见 §5。

### 3.2 窗口对象三态

关卡由窗户格子构成，每扇窗处于三种状态之一（IGN FAQ 用 R/F/N 标注）：

| 状态 | 简称 | 行为 |
|---|---|---|
| 救援窗 Rescue | R | 窗内有人待救；主角撞入→抓住 1 人带下 |
| 燃烧窗 Flaming | F | 着火，火焰有等级，需撞击 N 次才能灭 |
| 正常窗 Normal | N | 无火无人，纯背景障碍（可能内含道具） |

**关键点**：一扇窗可以同时是"燃烧+救援"（IGN FAQ 布局中有 RF 组合），即窗内有人、窗户着火。

### 3.3 灭火规则

1. 主角撞入燃烧窗 → 火焰变小，撞击次数达到阈值 → 火焰熄灭，该窗灭火
2. **火焰有 3 个等级**，越高级的火焰需要越多撞击
3. **灭火等级（Power-Up）系统**：主角初始蓝衣，吃 1 个 1UP 变绿衣，吃 2 个变红衣/紫衣
   - 等级越高，扑灭同级火焰所需撞击次数越少（即灭火越快）
   - 注意：最高等级时"老掉火苗"（新浪攻略提示最高级未必是好事）——火苗掉落可能烧到蹦床（见 §3.10）
4. 灭火会掉落道具（部分是有害道具，见 §3.6）

### 3.4 救人规则

1. 主角撞入救援窗 → **抓住 1 人**（每次只能带 1 人）→ 带着人下落
2. 主角带着人弹回蹦床 → **弹起瞬间人获救**（获救判定）
3. 一窗可救多人？——原版为一扇窗多次撞入可陆续救出（待确认）
4. **红窗跳楼机制**：有时救援窗会**变红**，窗内人员会**周期性主动跳窗**（跳楼）
   - 跳下的人**可以不救**（不影响过关），但**救了加分**
   - 特殊规则：若某关剩余人员全部跳楼导致楼内无人 → 直升机会自动把剩余火焰浇灭，直接过关（IGN FAQ：*you don't need to rescue them, but you get more points if you do*；新浪：*人跳光后直升机把剩余的火浇灭然后过关*）

### 3.5 通关条件（双通道胜利）★核心规则

**每关胜利条件二选一，达成任一即过关：**

1. **扑灭全部燃烧窗**（剩余人员由救护车接走）
2. **救出全部人员**（剩余火焰由直升机浇灭）

**5 种实际过关方式**（新浪攻略，含道具驱动）：

| # | 方式 | 说明 |
|---|---|---|
| 1 | 全灭火 | 把所有火浇灭 → 救护车接走剩余的人 |
| 2 | 全救人 | 把所有人员救出 → 直升机浇灭剩余的火 |
| 3 | 直升机（手机道具） | 用"手机"呼叫直升机，把主角弹进直升机起落架 → 过关 + 进入 BONUS TIME 天空接道具 |
| 4 | 龙王下雨（喇叭道具） | 用"喇叭"召唤龙王喷雨浇灭所有火 → 救护车接走剩余的人（注：下雨瞬间主角摔死的话，复活后可能有剩余的火） |
| 5 | 室内钥匙（法杖/钥匙链道具） | 在室内关翻门找到白钥匙 → 进入下一关；找到红钥匙 → **跳过一关** |

**特例**：人员跳楼跳光 → 自动过关（见 §3.4）。

> ⚠️ 我方原型当前为"清空所有砖块才过关"——**与原版双通道规则不符，必须改**（§5 P0）。

### 3.6 室外道具系统（10 种）

道具由撞击窗户后掉落，**有正有负**（IGN FAQ 明确：*not all items are helpful*）。

| 道具 | 效果 | 正/负 | IAA 适配建议（§5） |
|---|---|---|---|
| 钱袋（红/蓝） | 加分（蓝袋疑似水袋） | 正 | 保留：稳定得分点 |
| 长条 | 加长蹦床，更容易接住人和道具 | 正（有隐患） | 保留：正向强化，短时加成 |
| 锤子/斧头 | 缩短蹦床，更难接 | **负** | 保留：负向道具制造失误→广告复活点 |
| 手机（白色斧头状） | 呼叫直升机，弹进起落架即过关 + BONUS TIME | 正（跳跃式过关） | 简化：BONUS TIME 见 §5 |
| 喇叭 | 召唤龙王喷雨，浇灭所有火直接过关 | 正（跳跃式过关） | 可选：强过通道具 |
| 钥匙链 | 进入室内关 | 正（内容点） | 简化：室内关做轻版（§5 P1） |
| 灭火器 | 扑灭蹦床上的火 | 正（保命） | 保留：负面火球的反制 |
| 1UP（灭火等级） | 衣服蓝→绿→红，灭火更快 | 正（有隐患） | 保留：养成线 |
| 双人 | 场上增加一个灭火消防员（=多球） | 正（强力） | 可选：后期道具，注意难度爆炸 |
| 衣服 | 短暂无敌，可穿过火焰/火鸟/飞碟 | 正（有隐患：可能提前摔死） | 可选 |

### 3.7 室内 Bonus 关卡（法杖/钥匙链触发）

主角拿到"法杖 Wand"或"钥匙链"后进入大楼内部，限时翻门寻物：

| 项目 | 规则 |
|---|---|
| 触发 | 吃到法杖/钥匙链道具 |
| 玩法 | A 键灭火、B 键开门，在时限内翻各扇门 |
| 限时 | 有倒计时 |
| 目标 | 找到白钥匙（进下一关）或红钥匙（跳关）即结束并过关 |

**门后可出现的对象**：

| 对象 | 效果 | 正/负 |
|---|---|---|
| 楼梯 | 上下楼移动 | 中性（移动） |
| 时钟 | 时间暂停（冻结敌人） | 正 |
| 定时炸弹 | 主角靠近会炸掉一条命 | **负**（需避开） |
| 人头 | +1 条命 | 正 |
| 被困人员 | 加分 | 正 |
| 衣服 | 主角暂时无敌 | 正 |
| 鞋子 | 移动速度加快 | 正 |
| 白钥匙 | 过关道具，进下一关 | 目标 |
| 红钥匙 | 跳过一关 | 目标（更优） |
| 火魔 | 血量极厚的怪物，多在左右两侧门内 | **负**（战斗/回避） |

### 3.8 BONUS TIME（天空环节）

- 触发：直升机过关方式（§3.5 方式 3）
- 玩法：直升机载主角上天，**天空接住下落道具加分**
- 定位：通关后的奖励小环节

### 3.9 敌人：飞行生物

- 每关存在**飞鸟/UFO**类飞行敌人
- 主角可以**借它们反弹**（可当移动弹跳点）
- 屏幕垂直滚动时敌人**跟随移动**（不固定在某一高度）
- 作用：增加不确定性、失误率与操作技巧

### 3.10 生命与失败方式

| 失败方式 | 说明 |
|---|---|
| 蹦床着火（火球道具） | 吃到"火球 Fireball"道具蹦床着火；**再吃一个火球直接丢一条命**；吃"灭火器"灭火 |
| 火苗掉落 | 火焰被部分扑灭后火苗可能掉落，砸到蹦床使其着火 |
| 主角摔死 | 主角接不住时坠落到底部；无敌状态下可能穿过火焰导致提前摔死 |

原版为生命制（人头道具 +1 命），未确认初始命数与上限。

### 3.11 关卡结构（32 关）

- 全 32 关，末关（第 32 关）画面为**蓝色宝塔**
- 每关由 R/F/N 三种窗户按固定布局排布（示例，IGN FAQ 前几关）：

```
Stage 01: 5R 5F 8N   RF RF RF NN FN FN NR NN RN
Stage 02: 2R 4F 2N   R F F R N F F N
Stage 03: 4R 4F 1N   F R R F F F R R N
Stage 04: 6R 6F 0N   R R R R F F F F R F F F
Stage 05: 5R 4F 3N   N R N R N F F F F R R R
Stage 06: 4R 8F 4N   F N N F R R F F R R F F N N F F
```

- 难度递增方式：窗口数量/比例、火焰等级、敌人类型（鸟→UFO）逐步变化
- 敌人标注：前 25 关多数为鸟，第 06/11/19/26 关为 UFO

### 3.12 计分规则

| 动作 | 原版分数 | 状态 |
|---|---|---|
| 钱袋 | 加分（颜色不同分值未知） | 有规则、无精确值 |
| 救人 | 加分（跳楼的人救了更多分） | 有规则、无精确值 |
| 灭火 | 有得分（数值未确认） | 无精确值 |
| BONUS TIME 接道具 | 有得分（数值未确认） | 无精确值 |
| 通关奖励 | 有（数值未确认） | 无精确值 |

| 维度 | 原版 | 当前原型 `fire-hero-iaa.html` | 差距类型 |
|---|---|---|---|

**结论**：核心循环"弹射-碰撞"保留且手感 OK，但**目标规则（双通道）、救援流程、道具、敌人、特殊关卡**五块均缺失——这正是用户指出"机制不全"的部分。

## 5. IAA 化改造建议（保留/简化/去掉 + 优先级）

### 5.1 总体原则

1. **保留原版灵魂**：双通道胜利 + 抓人救援流程 + 正负道具并存
2. **为 IAA 服务**：单局 1-2 分钟、目标清晰、有失误点（广告触发）、有养成感（重复玩）
3. **砍复杂度**：原版 19 种道具全做对休闲玩家过重，做精选子集；室内关/BONUS TIME 做轻版

### 5.2 机制改造决策表

| 机制 | 决策 | 理由 |
|---|---|---|
| 双通道胜利（灭火 or 救人） | ✅ **保留（P0）** | 原版灵魂，给玩家两种目标路径，减少挫败 |
| 抓人→带回→弹起获救 | ✅ **保留（P0）** | 替代当前"接跳伞人"简化版，救援有操作感 |
| 红窗跳楼 | ✅ **保留（P0，轻版）** | 制造"选择性救人"决策点 + 额外得分目标 |
| 火焰 3 级 + 衣服等级 | ✅ **保留（P0）** | 强化养成，衣服颜色变化是视觉成长线 |
| 道具：钱袋/长条/锤子/灭火器/1UP | ✅ **保留（P0）** | 正向强化 + 负向干扰的最小组合（5 种） |
| 道具：火球（蹦床着火） | ✅ **保留（P1）** | 经典负向机制，配合灭火器形成博弈，是广告复活强触发点 |
| 道具：手机→直升机+ BONUS TIME | ⚠️ **简化（P1）** | 做"直升机飞过+弹进起落架过关"，BONUS TIME 做 10 秒天空接币 |
| 道具：双人（多球） | ⚠️ **简化（P1）** | 后期关/广告奖励发，做"临时双球 10 秒" |
| 道具：衣服无敌 / 鞋子加速 | ⚠️ **简化（P1）** | 合并为一种"限时增益"，减少理解成本 |
| 道具：喇叭（龙王下雨）/ 钥匙链+室内关 | ⚠️ **简化（P2）** | 室内关内容量大，先不做完整版；喇叭做"全屏灭火"稀有道具 |
| 敌人：飞鸟/UFO | ✅ **保留（P1）** | 增加失误率（广告点）与操作深度，借力反弹是特色 |
| 计分结构 | ✅ **重构（P0）** | 灭火/救人/接人/钱袋/通关/红窗多来源计分，配合 IAA 双倍 |
| 关卡结构 | ✅ **重构（P0）** | 放弃纯程序化递增，改"手配窗口布局 + 参数递增"（参照 R/F/N 模式，不抄原版布局） |
| 生命制 | ✅ **保留并扩展（P0）** | 3 命 + 人头道具（P1 加入） |

### 5.3 IAA 广告点位与机制绑定

| 广告点位 | 绑定机制 | 触发时机 |
|---|---|---|
| 激励视频·复活 | 生命耗尽后，看广告续 1 命继续当前关（保留现有，限每关 1 次） | 失败结算 |
| 激励视频·双倍 | 通关结算金币双倍（保留现有） | 通关结算 |
| 激励视频·道具补给 | 看广告获得随机正向道具（钱袋/长条/1UP） | 主菜单/关卡间 |
| 插屏 | 关卡切换时低频插入（建议每 2-3 关一次） | 关卡间 |
| 激励视频·BONUS TIME 延长 | 天空接道具时间翻倍 | BONUS TIME 结束 |

> 负向道具（锤子/火球）制造的"失败点"正是激励视频复活的核心付费钩子——**正负道具并存是 IAA 设计的一部分，不能砍光**。

### 5.4 实现优先级总览

**P0（核心，必须做）**
1. 双通道胜利：灭火 or 救人任一达成即过关
2. 抓人救援流程：撞救援窗抓人→带回落蹦床→弹起获救
3. 红窗跳楼 + 跳光自动过关特例
4. 火焰 3 级 + 衣服灭火等级（蓝→绿→红）
5. 道具最小集：钱袋/长条/锤子/灭火器/1UP（5 种，正负并存）
6. 多来源计分结构 + 现有 3 广告点位保留

**P1（建议，丰富内容）**
7. 飞行敌人（鸟/UFO）+ 借力反弹
8. 火球道具（蹦床着火）+ 灭火器反制
9. 直升机道具 + 轻版 BONUS TIME
10. 双球 / 限时增益（合并衣服+鞋子）
11. 人头道具（+1 命）
12. 手配关卡布局（R/F/N 模式）+ 参数递增

**P2（可选，看数据）**
13. 喇叭（全屏灭火稀有道具）
14. 室内 Bonus 关（轻版翻门）
15. 红钥匙跳关 / 白钥匙过关的关卡捷径
16. 皮肤/合成等长线系统（IAA 买量后置）

### 5.5 明确不做的内容（版权与成本）

- 不复制原版 32 关具体布局与美术素材（版权归 EPIC・ソニー）
- 不照抄原版角色造型、音乐
- 不做 19 种道具全量（成本与休闲玩家理解成本均不支持）
