## 1. 项目背景与现有基础

### 1.1 游戏定位
竖屏 9:16 打砖块式救火小游戏：玩家操作蹦床弹射救火员，撞击燃烧窗灭火 / 撞击救援窗救人，**双通道胜利**（灭火或救人任一达成即过关）。

### 1.2 现有代码结构（必须复用/对接）
| 现有对象 | 说明 | 微创新的对接方式 |
|---|---|---|
| `S = {state, level, score, coins, lives, best, powerLevel, fireLeft, rescueLeft, skin}` | 全局游戏状态 | 金币经济直接使用 `S.coins`；角色用 `S.skin` 索引当前角色 |
| `SKINS = [{id, name, cost, suit, helm}]` | 现有 3 款皮肤（经典/抢险蓝/烈焰红），`cost` 为金币价 | **扩展为角色系统载体**：增加 `ability`、`unlock` 等字段 |

| 界面覆盖层：`ovMenu`（主菜单）、`ovLevel`（过关）、`ovOver`（失败）、`ovPause` | 已有 UI 容器 | 新增 `ovShop`（补给队）覆盖层 |

## 2. 功能总览

本次微创新共 3 大功能模块：

1. **角色系统**：5 个高认知动物角色（小猫/小狗/熊猫/卡皮巴拉/哪吒），每个角色有**专属被动能力**，混合解锁（免费/金币/激励视频）；
2. **补给队商店**：每关过关后出现的关卡间商店，金币购买**英雄**或**道具**，可看广告刷新；
3. **金币经济闭环**：多来源赚金币 + 补给队消耗金币 + 广告双倍加速。

## 3. 详细需求

### 3.1 角色系统

**3.1.1 角色阵容与专属能力（数值为建议值，可调整）**

| 角色 | 形象 | 专属能力 | 具体数值（建议） | 玩法定位 |
|---|---|---|---|---|
| 小猫 | 猫救火员 | 敏捷：蹦床移动更快 | 蹦床移动速度 +25%；接人判定范围 +10% | 新手友好 |
| 小狗 | 狗救火员 | 救援：救人更赚 | 救回人员得分 +50%（金币转化同步加成） | 冲分向 |
| 熊猫 | 熊猫救火员 | 力量：灭火更猛 | 灭火效率 +1 级（一次撞击等效两次撞击） | 高难关优势 |
| 卡皮巴拉 | 卡皮巴拉救火员 | 稳定：不怕着火 | 蹦床着火概率 -50%；着火后 3 秒自动熄灭 | 保命向 |
| 哪吒 | 哪吒救火员 | 爆发：主动技能双球 | 技能：场上双球 10 秒；每关限 1 次，过关重置 | 高价值、强爽点 |

**3.1.2 解锁方式（混合制）**

| 角色 | 解锁方式 | 建议定价 |
|---|---|---|
| 小猫 | 初始解锁 | 免费 |
| 小狗 | 初始解锁 | 免费 |
| 熊猫 | 补给队金币购买 | 2,000 金币 |
| 卡皮巴拉 | 补给队金币购买 | 3,000 金币 |
| 哪吒 | 双通道：补给队高额金币购买 **或** 看激励视频直接解锁 | 5,000 金币 / 1 次广告 |

**3.1.3 功能要求**
1. 主菜单增加「角色」入口：展示全部 5 个角色卡片（立绘色块 + 名字 + 能力说明 + 解锁状态）；
2. 已解锁角色可**免费切换**当前使用角色（切换后立即生效，能力即时变化）；
3. 未解锁角色：显示解锁条件（金币价/广告按钮），金币不足置灰；点击广告按钮走现有激励视频流程，看完即解锁；
4. 角色能力必须实际影响玩法（见 3.1.4 挂接点），不能只换外观；
5. 当前角色与拥有状态存 localStorage，**兼容旧存档**（旧 `fireHeroSkins` 只有 classic 皮肤 → 迁移为拥有小猫+小狗）。

**3.1.4 能力挂接点（实现时必须接通）**
| 能力 | 挂接位置 |
|---|---|
| 小猫·移速/接人判定 | `paddle` 移动速度计算处；接人/接球判定半径处 |
| 小狗·救人得分 | 救人得分事件处（含红窗救人） |
| 熊猫·灭火效率 | 撞击燃烧窗减血逻辑处（`FIRE_HIT_REQ` 命中次数计算处） |
| 卡皮巴拉·抗火 | 蹦床着火触发处（火球道具/火苗掉落）；着火状态更新处 |
| 哪吒·双球 | 新增技能按钮/技能键；创建第二个 ball 的逻辑（复用多球/双人道具逻辑，若已有） |

### 3.2 补给队商店

**3.2.1 触发与流程**
1. 玩家**每关过关结算后**（金币结算画面之后、进入下一关之前）弹出补给队界面；
2. 界面为覆盖层 `ovShop`，展示：**英雄位 + 道具位** + 金币余额 + 关闭/进入下一关按钮；
3. 补给队不强制消费：可直接点「继续」进入下一关。

**3.2.2 商品内容**
| 商品位 | 内容 | 规则 |
|---|---|---|
| 英雄位 ×1 | 未解锁角色中随机 1 个（已全部解锁则不显示英雄位） | 金币价见 3.1.2；看广告可刷新 |
| 道具位 ×3 | 从正向道具中随机 3 件（长条/1UP/灭火器/限时增益/钱袋等） | 价格见 3.3.3 |

**3.2.3 刷新机制**
- 每关过关自动刷新一次商品；
- 看激励视频可**手动刷新**一次商品（刷新后道具位替换）；
- 看激励视频可**额外解锁 1 个道具位**（本次补给队生效，下关恢复 3 个）。

**3.2.4 功能要求**
1. 购买道具立即生效并进入下一关（道具作为下关开局增益或即时使用，按道具类型定）；
2. 金币不足时购买按钮置灰；
3. 补给队 UI 风格与现有界面一致（同 HUD 配色体系）。

### 3.3 金币经济闭环

**3.3.1 金币收入（建议值）**
| 来源 | 建议值 |
|---|---|
| 过关结算基础金币 | 50 + 关卡数 × 10 |
| 灭火 | +2 / 次 |
| 救人 | +10 / 次（小狗角色 +15） |
| 接人回蹦床 | +5 / 次 |
| 钱袋道具 | +15 ~ 30（随机） |
| 激励视频双倍 | 通关结算金币 ×2（保留现有） |
| 广告解锁哪吒后 | 不再重复给金币 |

**3.3.2 金币消耗**
- 补给队购买英雄（2,000 / 3,000 / 5,000）；
- 补给队购买道具（见 3.3.3）。

**3.3.3 道具定价（建议值）**
| 道具 | 价格 |
|---|---|
| 长条（蹦床加长） | 100 |
| 灭火器 | 120 |
| 1UP（+1 命） | 200 |
| 限时增益（无敌/加速） | 150 |
| 钱袋 | 80 |

**3.3.4 功能要求**
1. HUD 金币数实时更新（现有 `hudCn`）；
2. 金币收支有即时反馈（飘字/音效，复用现有 feedback 机制）；
3. 金币存档与角色存档合并持久化，防丢档。
