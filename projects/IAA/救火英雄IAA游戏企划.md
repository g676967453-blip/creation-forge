## 1. 项目概述

**项目名称**：FC 救火英雄（暂定名）

**一句话定位**：以经典 FC《Flying Hero》玩法为基准，换以卡通动物包装、加入角色专属能力微创新的一款**竖屏 9:16 休闲广告小游戏（IAA）**。

**名称释义**：FC 指代红白机（Famicom）卡带游戏；「救火英雄」为原版玩法基准——竖版打砖块式救火游戏，玩家弹射消防员撞击窗户，灭火与救人二选一达成即过关（双通道胜利）。

**项目性质**：IAA 小队「选品 → 换包装 → 微创新」方法论的首个落地验证项目，同时也是小队「阶段一：快速跑通全流程」的载体。

## 2. 立项背景与市场机会

**2.1 IAA 赛道高速增长**

公开行业信息显示，IAA（广告变现）小游戏正处于高速增长期：

- 抖音小游戏官方口径：**IAA 小游戏超高速增长**，正从买量模式向「内容 + 社交」破圈；[来源](http://www.gamelook.com.cn/2025/12/585048/)
- 投放侧数据：IAA 投放**消耗增长 20%、投放游戏数量增长 106%**，已成为小游戏赛道的核心力量；[来源](https://www.gameres.com/915949.html)
- 爆款案例：抖音小游戏《狙击外星人》DAU 超 500 万；[来源](http://www.gamelook.com.cn/2025/12/584985/)
- 变现模式演进：IAA 与混合变现（IAA + IAP）结合成为主流趋势，[来源](http://www.gamelook.com.cn/2025/12/584152/)

**2.2 本项目的机会点**

| 机会 | 说明 |
|---|---|
| 经典玩法 + 零教育成本 | FC 打砖块式玩法国民级认知，用户秒懂，买量素材转化率高 |
| 高认知角色自带流量 | 小猫/小狗/熊猫/卡皮巴拉/哪吒均为大众高认知形象，天然话题性与好感度 |
| AI 低成本开发 | 规则简单、网上资料多，AI 生成策划/代码/美术素材成本低、速度快 |
| 先测后投的风险控制 | 用 5–10 万买量测试验证回收模型后再放量，规避「开发完发现不回收」的行业最大风险 |

## 3. 核心玩法设计

> 玩法规则以《fire-hero-game-rules.md》（规则梳理文档 v1.0）为设计依据，本节约取其核心结论。

**3.1 玩法框架（对标原版）**

- 玩家操作蹦床（两名救火员拉起的接人平台），将主角救火员弹向大楼窗户；
- 撞击**燃烧窗**灭火、撞击**救援窗**救人；
- **双通道胜利（P0，原版灵魂）**：每关「扑灭全部火焰」或「救出全部人员」二选一，达成任一即过关——给玩家两条目标路径，减少挫败感；
- 抓人救援流程（P0）：撞入救援窗抓 1 人 → 带回落蹦床 → 弹起获救；
- 红窗跳楼机制（P0，轻版）：救援窗变红后人员周期性跳楼，可选择性救援（救与不救都合理，救了加分；跳光则自动过关）；
- 火焰 3 级 + 灭火等级养成（P0）：主角衣服蓝→绿→红，等级越高灭火越快，形成视觉成长线；
- 正负道具并存（P0）：正向（钱袋/长条/灭火器/1UP）+ 负向（锤子缩短蹦床/火球烧蹦床）最小道具集。

**3.2 实现优先级（摘自规则文档 §5）**

| 优先级 | 内容 |
|---|---|
| P0（核心必做） | 双通道胜利、抓人救援、红窗跳楼、火焰 3 级 + 灭火等级、道具最小集（5 种）、多来源计分结构 + 广告点位 |
| P1（建议） | 飞行敌人（鸟/UFO）借力反弹、火球道具 + 灭火器反制、直升机 + 轻版 BONUS TIME、双球/限时增益、人头道具、手配关卡布局、补给队关卡间商店 + 金币经济循环 |
| P2（看数据） | 喇叭全屏灭火、室内 Bonus 关（轻版）、红/白钥匙捷径、皮肤/合成长线系统 |

**3.3 版权红线（明确不做）**

- 不复制原版 32 关具体布局与美术素材；
- 不照抄原版角色造型与音乐；
- 所有素材原创或购买授权（规则文档 §5.5）。

## 4. 美术包装设计

- **风格**：清爽卡通、卡通手绘风，竖屏 9:16，正面平视大楼立面（无透视），画面 85% 为大楼窗户网格，底部操作区极窄；
- **换皮原则**：**纯美术层面换皮**，不改核心玩法，规避版权风险的同时保持原版手感；
- **视觉基调**（参考现有概念图提示词）：卡通猫救火员（红头盔、黄反光服、背水带）、黄黑警示条纹蹦床、HUD 状态栏（关卡/分数/金币/生命）；
- **素材生产方式**：AI 生成 + 人工精修，角色立绘、场景、道具、特效素材均可 AI 批量产出，支撑低成本与快节奏迭代。

## 5. 微创新设计：角色系统 + 补给队经济（核心亮点）

**5.1 设计思路**：原版救火员为统一形象，本项目引入**角色系统 + 关卡间补给队（商店）**双层微创新——五个自带高认知度的形象，每个角色拥有**专属能力**，形成「不同角色 = 不同玩法」的差异化体验；同时以**金币经济 + 混合解锁模式**打通「过关赚钱 → 补给队消费 → 下一关更强」的成长循环，并绑定广告变现。

**5.2 角色阵容与专属能力（提案稿）**

| 角色 | 形象认知 | 专属能力提案 | 玩法定位 |
|---|---|---|---|
| 小猫 | 国民萌宠 | 敏捷型：蹦床移动速度提升、接人判定范围略增 | 新手友好、容错高 |
| 小狗 | 国民萌宠 | 救援型：救回人员得分提升、救人判定更宽松 | 冲分向 |
| 熊猫 | 国民萌宠 | 力量型：灭火效率提升（一次撞击等效更高等级） | 高难关卡优势 |
| 卡皮巴拉 | 顶流表情包 | 稳定型：蹦床不易着火、火球伤害减免 | 保命向 |
| 哪吒 | 国民神话形象 | 爆发型：激活后场上双球 10 秒（技能制） | 高价值、强爽点 |

> 注：以上为初稿提案，具体能力数值待确认后定值。

**5.3 解锁与获取（混合制，与 IAA 绑定）**

| 角色 | 获取方式 | 设计意图 |
|---|---|---|
| 小猫、小狗 | 初始解锁 | 零门槛开局，降低首局流失 |
| 熊猫、卡皮巴拉 | 补给队金币购买 | 提供中期目标，驱动重复游玩与金币消耗 |
| 哪吒 | 补给队高额金币购买 或 激励视频解锁（双通道） | 高价值角色做广告钩子，同时给零氪玩家一条攒金币路径 |

**金币获取**：过关结算、关卡内得分（灭火/救人/接人/钱袋/红窗）按比例转化为金币；看激励视频可双倍金币加速积累。

**5.4 补给队系统（关卡间商店）★微创新核心**

- **出现时机**：玩家每关通关结算后，遇到「补给队」；
- **功能**：可选择**购买英雄**或**购买道具**；
  - 购买英雄：解锁未获得的角色（熊猫、卡皮巴拉、哪吒等）；
  - 购买道具：购买下一关使用的正向道具（长条/1UP/灭火器/限时增益等）；
- **货币**：金币（游戏内赚取，激励视频双倍金币加速）；
- **商品机制**：补给队商品随机刷新，看激励视频可刷新商品或额外解锁一件商品；
- **设计价值**：
  1. 让金币有持续消耗出口，形成「过关赚钱 → 补给队消费 → 下一关更强」的经济循环，驱动重复游玩；
  2. 把微创新从「角色能力」扩展为「**完整经济循环 + 关卡间商店**」，显著拉长养成线与内容深度；
  3. 与广告双倍金币联动，形成变现与成长的正向循环。

## 6. 商业化设计（广告点位）

**变现模式**：IAA——激励视频 + 插屏，竖屏休闲游戏标准打法。

| 广告点位 | 绑定机制 | 触发时机 |
|---|---|---|
| 激励视频·复活 | 生命耗尽看广告续 1 命（限每关 1 次） | 失败结算 |
| 激励视频·双倍 | 通关结算金币双倍（加速补给队购买） | 通关结算 |
| 激励视频·补给队刷新 | 看广告刷新补给队商品 / 额外解锁一件商品 | 补给队界面 |
| 激励视频·道具补给 | 看广告获得随机正向道具（钱袋/长条/1UP） | 主菜单/关卡间 |
| 激励视频·角色解锁 | 高价值角色（哪吒）可看广告直接解锁 | 角色选择界面 |
| 插屏 | 低频插入（建议每 2–3 关一次） | 关卡间 |

**设计逻辑**：负向道具（锤子/火球）制造的「失败点」正是激励视频复活的核心付费钩子——**正负道具并存是 IAA 设计的一部分，不可砍光**。

## 7. 平台与上线策略

**首发平台**：微信小游戏 + 抖音小游戏**双端上线**。

| 平台 | 优势 | 侧重 |
|---|---|---|
| 微信小游戏 | 生态成熟、广告变现链路完整、买量成本低、HTML 原型可近乎直接迁移 | 稳定基本盘 |
| 抖音小游戏 | IAA 增长最快、短视频买量配合度高、内容+社交破圈 | 增长与破圈 |

**双端差异策略**：同一核心玩法，双端分别制作适配的买量素材（微信侧重社交分享向，抖音侧重短视频剧情向），数据侧分别观察留存与 eCPM。

## 8. 开发计划与里程碑

| 里程碑 | 时间 | 内容 | 验收标准 |
|---|---|---|---|
| M1 首版 | 第 1–2 周 | 核心循环开发、双通道胜利 + 抓人救援、道具最小集、2 个初始角色 | 2 周内出可玩首版，内部试玩通过 |
| M2 上线 | 第 3–4 周 | 美术包装、广告 SDK 接入、微信/抖音双端上架（体验版→正式版） | 双端上线 |
| M3 数据观察 | 第 2 个月 | 留存/广告数据观察、买量测试（5–10 万）验证 LTV/CPI 模型 | 产出首版数据报告 |
| M4 迭代 | 第 3 个月 | 一轮迭代（角色解锁线、补给队经济、难度曲线、广告点位调优） | 数据改善 + 阶段结论汇报 |

> 数据目标策略：**首版以跑通流程与验证手感为主，数据目标后置**——先看流程是否跑通，再定数据基线。

## 9. 团队与预算

**9.1 团队落位**：IAA 小队三人（全能主导/美术/投放）承接本项目全部工作，AI 工具为生产力底座。

**9.2 预算**（参考《IAA项目开发成本清单.md》）：

- **本阶段（验证期）申请**：仅 AI 工具订阅与模型 API 费用（小额）；
- **后续立项预算参考（B 方案·标准）**：开发上线约 **40–90 万元**，含：
  - 立项与策划：4–5 万（规则文档与 HTML 原型已部分完成，属已发生成本）
  - 美术与设计：10–14 万
  - 研发（程序）：14–16 万
  - 广告接入与合规：3–4 万
  - 测试 + 买量测试：10–12 万
  - 上线发行：2–3 万
- **买量放量（独立预算）**：首年运营与买量约 50–150 万——IAA 项目 80% 以上资金消耗在发行买量而非开发，**采用「先测后投」**：先花 5–10 万买量测试验证回收模型，再决定放量预算。

## 10. 风险与应对

| 风险 | 说明 | 应对 |
|---|---|---|
| 版权风险 | 原版《Flying Hero》美术/布局受版权保护 | 已明确红线（不抄布局/造型/音乐），素材全部原创或授权（规则文档 §5.5） |
| 政策风险 | 国内 IAA 游戏版号/备案要求近年有调整 | 立项时向主管部门/专业代理核实最新口径；微信小游戏路径相对灵活 |
| 数据不达预期 | 首版留存或广告回收不达标 | 流程优先、数据后置；先测后投控制资金风险；微创新（角色系统 + 补给队经济）作为下一轮迭代抓手 |
| AI 产出质量波动 | AI 生成的代码/素材质量不稳定 | 人工把关 + 精修环节；规则简单（选品四标准）降低 AI 出错率 |
| 品类竞争 | 休闲小游戏竞争激烈 | 经典玩法 + 高认知角色 + 快速迭代，靠速度与差异化而非重投入取胜 |
