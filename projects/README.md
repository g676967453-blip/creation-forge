## 规则

1. **任何新项目唯一合法位置是 `projects/<项目名>/`** —— 不许在仓库根或平台层建项目
2. 新建项目优先复制 [templates/](../templates/) 下的 game-phaser / game-godot 模板；README.md（中文）与 PROGRESS.md 为项目标配（仪表盘会扫描）
3. 需要做但没定项目归属的事 → 先写进 [造化仪表盘/个人待办.md](../造化仪表盘/个人待办.md)
4. 属于本项目自己的工具脚本放本项目 `tools/` 或 `scripts/`，平台级工具才放根 [tools/](../tools/)
5. 本板块只向下游消费板块1（日志/待办），**不写板块1 数据**；跨板块引用用显式相对路径
