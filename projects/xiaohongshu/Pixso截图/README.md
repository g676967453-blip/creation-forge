# Pixso截图/ — 导出截图存放

## 命名规范

### 文件夹

```
日期-主题/
```

示例：`2026-07-16-不会设计的人怎么用AI做小红书图文/`

### 图片文件

```
卡片N-描述.png
```

示例：
- `卡片1-封面.png`
- `卡片2-痛点分析.png`
- `卡片3-解决方案.png`
- `卡片4-案例展示.png`
- `卡片5-关键要点.png`
- `卡片6-金句CTA.png`

### 完整示例

```
Pixso截图/
└── 2026-07-16-不会设计的人怎么用AI做小红书图文/
    ├── 卡片1-封面.png
    ├── 卡片2-痛点分析.png
    ├── 卡片3-解决方案.png
    ├── 卡片4-案例展示.png
    ├── 卡片5-关键要点.png
    └── 卡片6-金句CTA.png
```

## 导出流程

1. 在 Pixso 中打开对应帖子 Frame
2. 逐卡片导出 PNG（1080×1440，2x 分辨率）
3. 按上述规范命名
4. 放入对应日期目录
