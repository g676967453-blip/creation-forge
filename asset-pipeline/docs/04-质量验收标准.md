# 04 — 质量验收标准

> **通用化的 PASS/FAIL 检查清单 — 适配任何像素艺术游戏项目**

---

## 使用说明

本清单是**通用框架**。对具体项目，需补充该项目的专属检查项（如 GAME-002 的色彩互斥矩阵、CSV 规格对照等）。

每张生成资产在入库前，逐项检查。全部 PASS 才能标记为完成。

---

## 1. 像素艺术保真 ✅/❌

> 适用：所有标称"像素艺术"的资产

- [ ] **像素格可见** — 1x 缩放时可见清晰的像素格边界，非平滑数字绘画
- [ ] **无平滑渐变** — 过渡使用抖动 (dithering) 而非喷枪式渐变
- [ ] **无 3D 渲染痕迹** — 无次表面散射、环境光遮蔽、照片级真实感
- [ ] **非动漫赛璐璐** — 无粗黑描边、无 Q 版比例、无大面积平涂色块
- [ ] **像素边缘清晰** — 无抗锯齿模糊（这是最常见的问题）
- [ ] **有限调色板** — 主体部分不超过 ~32 种可辨识颜色

### 常见失败模式

| 失败 | 原因 | 修复 |
|------|------|------|
| 看起来像缩小的高清图 | Prompt 缺 `no anti-aliasing` | 加技术约束关键词 |
| 角色面部模糊 | 尺寸太小 + AI 自动抗锯齿 | 生成更大尺寸再 NEAREST 缩小 |
| 色彩过渡太光滑 | 模型自带的后处理 | 换 midjourney 或加 `raw style` |

---

## 2. 色彩合规 ✅/❌

> 适用：所有资产

- [ ] **主色正确** — 画面强调色与项目指定的主色一致
- [ ] **禁止色不越界** — 其他角色/势力的专属色未在画面大面积出现（< 5% 面积）
- [ ] **背景暗色基准** — 暗色游戏用深色背景（#1a1a2e 附近），不出现明亮天空
- [ ] **前景背景对比** — 角色与背景有足够明度差，在小尺寸下可分
- [ ] **饱和度适中** — 色彩鲜艳但不霓虹、不过饱和

### 项目专属补充

各游戏项目应在此处追加自己的色彩规则。示例（GAME-002）：

```
剑峰主 → 主色 #4ecca3（玉石青），禁止 #9030c0（魂火紫）、#f0c040（佛门金）
佛峰主 → 主色 #f0c040（佛门金），禁止 #4080f0（雷电蓝）、#9030c0（魂火紫）
...
```

## 3. 构图与取景 ✅/❌

> 适用：角色原画、场景图

- [ ] **取景正确** — 胸像/半身像/全身像符合规格
- [ ] **主体居中** — 头部上方留出气息/能量效果空间
- [ ] **标志物可见** — 角色的标志性武器/法器/伴身兽在画面内且可辨识
- [ ] **无地面线** — 角色浮于氛围虚空中，无地平线切割人物（除非场景图）
- [ ] **视线朝向** — 角色面向观众或微侧，非背对

### 各构图的取景范围参考

| 类型 | 范围 | 头顶留白 |
|------|------|---------|
| 胸像 (Bust) | 锁骨以上 | 10-15% 画布高度 |
| 半身像 (Half-body) | 腰部以上 | 10-15% 画布高度 |
| 全身像 (Full-body) | 头顶到脚底 | 5-10% 画布高度 |

---

## 4. 主题与风格 ✅/❌

> 适用：有明确文化/题材要求的资产

- [ ] **文化元素正确** — 服装、建筑、道具符合指定文化背景（如中国仙侠应有 hanfu/道袍，非西方板甲或日式 kimono）
- [ ] **流派可辨识** — 3 秒内能看出角色的职业/门派/势力归属
- [ ] **氛围一致** — 与游戏整体的情绪基调一致（暗黑神秘 ≠ 明亮欢快）

---

## 5. 技术规格 ✅/❌

> 适用：所有资产

- [ ] **输出分辨率** — 生成尺寸符合要求（通常 1024×1024）
- [ ] **目标尺寸** — 后处理后的最终尺寸精确匹配规格（像素级）
- [ ] **无品红残留** — 如果用了品红底生成，抠除后无残留（品红边缘）
- [ ] **NEAREST 缩放** — 使用 NEAREST 而非 BILINEAR/LANCZOS（像素艺术关键）
- [ ] **文件格式** — PNG（RGBA 如有透明需求）
- [ ] **文件命名** — 符合 `{项目}_{类型}_{角色}_{变体}.png` 规范

---

## 6. 横向一致性 ✅/❌

> 适用：有 2+ 张同系列资产后

- [ ] **风格统一** — 所有资产看起来属于同一个游戏
- [ ] **像素密度一致** — 相似的像素块大小（不同资产用同一分辨率生成）
- [ ] **光照方向一致** — 所有角色的高光/阴影方向协调
- [ ] **比例协调** — 多个角色并排时，无角色显得异常巨大或微小

---

## 验收流程

```
每张图生成后：
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│ 第1-5类逐项检查│ ──▶ │ 人类最终确认  │ ──▶ │ 标记为完成    │
│ （Claude 可辅助）│     │ （必须人类）  │     │ 移入 outputs/ │
└──────────────┘     └──────────────┘     └──────────────┘

同系列 2+ 张后：
┌──────────────┐     ┌──────────────┐
│ 第6类横向对比  │ ──▶ │ 不一致的退回  │
│ （人类判断）   │     │ Phase 2 重做  │
└──────────────┘     └──────────────┘
```

> **关键**：第 1-5 类 Claude 可以辅助对照检查（尺寸、命名、等），但最终判断始终需要人类的眼睛。
