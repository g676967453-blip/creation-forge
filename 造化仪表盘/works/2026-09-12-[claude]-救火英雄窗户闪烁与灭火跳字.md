## 📋 问题解决日志

### 遇到了什么

需求两条：**1. 球碰到单纯窗户时增加闪烁；2. 灭火时增加跳字表现。**

「单纯窗户」需要先定位——指的不是可玩砖，而是 `level_builder.gd:95` 的 `DecorWindow`：填充空网格的纯装饰窗（无碰撞、不计目标、`z_index=-1` 垫在可玩砖之下）。球原本**直接穿过去**，撞上去毫无反馈，看起来像穿模。

顺着这条线还挖出一个真 bug（见下）。

### AI 怎么协作的

**1）闪烁：不引入物理体**

最直觉的做法是给每扇窗户挂 `Area2D`。但装饰窗一屏几十个、纯粹是视觉反馈，不值得为它铺物理体。改成：`DecorWindow` 加一个 `flash()`，由 `game_root._process` 每帧按组做一次 AABB 判定后调用。

关键是**只在「进入」时闪，不是每帧闪**：维护 `_decor_touching` 字典记录本帧仍重叠的窗户，只有「这帧有、上帧没有」才触发。

**2）跳字：自管生命周期**

`FloatText.spawn(parent, at, text, color, size)` —— 造出来自己弹一下、上升、淡出、`queue_free`，调用方不用持引用、不用手动清理。挂在 `brick_host` 下，换关时被 `_clear_bricks()` 一并清掉，不会跨关残留。

灭火成功弹金色 `+45`（按 `15 × 火级`），每一下命中弹白色 `-1`。后者嫌吵删掉三行即可，互不影响。

**3）复用已有的两个坑的教训**

- **Theme**：跳字在 GameRoot 空间下拿不到 HUD 的 Theme，必须自带 `ui_theme.tres`，否则 Web 导出（无系统中文字体）下数字全变方框。这跟昨天金币雨倒计时是同一个坑。
- **已释放对象**：`_check_decor_flash` 遍历窗户时**刻意不用带类型注解的循环变量**。窗户换关被 `free()` 后数组里会留已释放对象，带注解会触发 `Object→Node` 转换错误中断整帧——这是项目里影分身 `filter` 踩过的同一个坑，代码注释里有记录。

### 🐞 顺带修掉的崩溃（用户报的错）

用户贴出运行时错误：`Trying to assign value of type 'Nil' to a variable of type 'int'`。

全库扫「`.get()` 结果直接赋给 `int`」的写法，定位到 `skill_clone.gd:75`：

```gdscript
var bt: int = brick.get("brick_type")   # 对象没有该属性 → .get() 返回 null → 赋给 int 直接抛
```

根因在上一层 `_find_hit_brick()`：它只按「**是不是 Node2D**」筛选 `brick_host` 的子节点，而装饰窗也是 Sprite2D/Node2D，于是**被当成砖返回**，紧接着读 `brick_type` 得到 `null`。

**狐狸影分身的任何一个飘过任何一扇单纯窗户，都会触发。** 而且这个 bug 在本次改动之前就存在（装饰窗原本就是 Sprite2D）。

修法：`_find_hit_brick` 改为只接受 `b as WindowBrick`，并加回归断言 `clone_ignores_decor` 钉住它。

## 🎬 视频生产草案（三幕结构）

### 第一幕：遇到了什么问题

「给球碰到普通窗户加个闪烁」——听着是加个特效，但第一步得先搞清楚：**这个游戏里哪一扇才是「普通窗户」？**

- 核心问题：装饰窗与可玩砖在代码里是两类东西，肉眼却只看到「都是窗户」
- 为什么这是个问题：球穿过装饰窗毫无反馈，玩家会以为穿模了
- 如果没有 AI 会怎样：翻遍脚本找窗户逻辑，还可能把特效加错到可玩砖上

### 第二幕：AI 怎么协作解决的

- **我是这样问 AI 的**：两句话，没给技术细节
- **AI 给了什么方案**：先定位「单纯窗户 = DecorWindow」，然后**拒绝**了直觉方案（每扇窗挂 Area2D），改用一次性 AABB + 进入时触发
- **中间有什么调整/追问**：顺线排查用户报的 `Nil to int` 崩溃，全库扫 `.get()` 赋值模式，挖出影分身把装饰窗当砖的真 bug
- **最终方案是什么**：两个新脚本 + 一处 bug 修复，22 项冒烟，五个测试套件全绿

### 第三幕：效果展示

- **最终效果**：球擦过普通窗户时窗户亮一下；灭火时弹出金色得分数字，每一下命中弹白色伤害数字
- **演示方式（截图/GIF/屏幕录制）**：慢放球擦过一排窗户的连闪 + 灭火跳字
- **学到的关键点**：**加特效前先确认「你以为的那个东西」在代码里到底是哪个东西**

### 一句话总结（金句候选）

> 用户说的「普通窗户」，在代码里可能是个连碰撞都没有的装饰品。
