## 使用约定

- **命名**：`YYYY-MM-DD-[ai标签]-简短描述.md`（ai 标签：claude / trea / lobster / codex）
- **结构**：一个文件 = 问题解决日志 + 视频生产草案（三幕结构），模板见 [_template.md](_template.md)
- **一事一记**：每个问题/交付一条日志；多线并行各自独立
- **写日志前**：AI 每天首次对话检查当日是否已有 `YYYY-MM-DD-*.md`，没有则提醒用户
- **提交**：写好的日志随当批工作一起用中文 conventional commit 提交（`journal:` 前缀），footer 带 AI 签名
