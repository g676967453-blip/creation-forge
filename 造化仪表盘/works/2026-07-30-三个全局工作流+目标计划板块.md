# [2026-07-30] 三个全局工作流 + 目标计划板块

---

## 📋 问题解决日志

### 遇到了什么

造化坊缺少三个关键的全局层级工作流：创建项目、创建工作流（元工作流）、目标管理。同时仪表盘「目标计划」页签只有简单表格，没有进度可视化，目标与个人待办之间没有关联，归档目标也看不到。

### AI 怎么协作的

**第一阶段：三个全局工作流**

1. AI 并行探索了项目结构、现有工作流格式、配置体系，提炼出标准文档格式（引用块元数据 + 5 章节）
2. 按「创建工作流 → 创建项目 → 目标管理」的依赖顺序，生成了 3 份知识层文档和 3 个 SKILL 执行层文件
3. 更新了三大索引：README.md 流程清单 + 变更日志 + collect-data.ts workflows[]
4. 用元工作流自身验证了自举机制——创建工作流的工作流创建了三个工作流

**第二阶段：目标计划板块改造**

1. 4 个活跃目标拆解为三层结构（目标→里程碑→行动项），写入 目标规划.md
2. 9 条行动项导入个人待办（标注来源目标），打通目标↔待办关联
3. collect-data.ts 新增 goalsArchived[] 数组，goalsUser[] 新增 progress 和 todos 字段
4. 仪表盘渲染改造：目标卡片 + 进度条（绿/橙/蓝/红）+ 📋 N条待办
5. 修复 CSS bug：`.bar-green .bar-fill` → `.bar-fill.bar-green`
6. 新增「已归档目标」折叠区，4 个历史目标可见

**第三阶段：数据完整性检查**

1. 清理 goalsIssues（6→4）和 goalsAI（3→3，移除已完成项，新增月度复盘建议）
2. 目标计划板块完成后归档，活跃目标回到 3 个上限

### 产出结果

- 工作流从 13 → 16 个
- SKILL 从 8 → 11 个
- 仪表盘目标计划页签：活跃目标卡片 + 已归档折叠区 + 系统问题 + AI 建议
- 目标管理端到端流程验证通过

### 关联项目

- 造化坊（系统层）：docs/workflows/ · docs/目标规划.md · tools/collect-data.ts · tools/generate-dashboard.ts
- 个人待办：docs/个人待办.md（+9 条行动项）
