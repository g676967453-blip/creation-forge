## 📝 流程记录（边使用边记录）

### 阶段 1：确定概念关键词

**时间**：2026-08-26

**操作记录**：用户确定概念设计的第一步为「确定概念关键词」——先明确概念的核心关键词，作为后续生成的方向锚点。

**记录要点**：
- 用户确定的概念关键词：**三国、诡异、Q版（2头身）**
  - 三国：题材背景，取材三国历史/演义
  - 诡异：氛围基调，非写实、带惊悚/怪诞感
  - Q版（2头身）：造型比例，Q 版大头身比例

**经验沉淀**：
- 概念关键词是整个流程的源头，后续所有 Prompt 都围绕关键词展开
- 关键词构成：「题材 + 氛围 + 造型」，三个维度各一个词，简洁可执行
- 2头身是明确的造型约束，比"Q版"更精确，利于模型理解

### 阶段 2：风格锚点

**时间**：2026-08-26

**操作记录**：用户指定美术风格对标《王国橡果传说》，并提供 10 张该游戏 Q 版 2头身角色立绘参考图（存于 `C:\Users\Administrator\Desktop\fenggecanao\`：剑圣/小勇者/猎手/神牛/赤瞳/浮石/祭祀/秘法/胜利/苍茫）。

**风格分析（亲眼看图提炼）**：
| 维度 | 观察 | 关键词 |
|------|------|--------|
| 比例 | 约 2 头身，大头、圆润身体、粗短四肢 | chibi 2-head-tall |
| 线稿 | 干净闭合深色描边，粗细均匀 | clean bold dark outlines |
| 上色 | 平涂 + 少量赛璐璐阴影，色彩饱和干净 | flat colors, cel shading |
| 造型 | 圆润几何方块感，Q 版夸张（大眼睛/大武器） | cartoon rounded shapes |
| 配色 | 高饱和，每角色一主色（橙/绿/蓝/紫/红） | high saturation |
| 背景 | 纯白/透明，无场景 | isolated character, plain white |
| 氛围 | 活泼、手绘感、角色区分度高 | playful, hand-designed |

**关键决策**：用户明确「设计诡异元素，但颜色保持明亮」——沿用王国橡果传说的明亮高饱和色板，叠加诡异的内容/造型/氛围设计，而非靠变暗调色。

**参考图上传**：3 张官方游戏截图已 `upload` 获得 CDN 链接并 `upload-artifact` 归档到概念设计画布（artifact_id: Pq9n2tkNxZaw8SWG / av0Ytl3FXeAJEyM4 / jQRE6zY9yD2fe9EG）。

**经验沉淀**：
- 风格锚点优先使用「对标游戏 + 实际角色立绘图」，比文字描述更精确
- 角色立绘图（单角色、透明底）比游戏场景截图（俯视塔防）更适合作为**造型/线稿/配色**的风格参照
- 用户风格意图可能在关键词层面有张力（如「诡异 × 明亮」），需主动澄清融合方式，避免误判

### 阶段 3：概念图生成（刘备）

**时间**：2026-08-26

**操作记录**：用户选择付费快速生成（方案 1），先生成一张**刘备**形象验证风格。

**Prompt**（英文，含风格关键词 + 三国刘备设定）：
> chibi 2-head-tall character concept art of Liu Bei, the benevolent lord of Shu-Han from the Three Kingdoms, cute chibi proportions, big head, expressive eyes, wearing green and gold Han-dynasty robes with a gentle yet slightly eerie smile, holding a sword, cartoon rounded shapes, clean bold dark outlines, flat colors with cel shading, high saturation, isolated on plain white background, playful yet eerie mood, hand-designed game character sheet style, reference style: Kingdom Acorn Tale

**参考图附件**：3 张王国橡果传说立绘 CDN 链接（作为 style reference 传入）

**线程**：`6eeb5f79-7a24-4eb9-9123-c73f8e675afb` — 付费确认 `generate_media`，estimate_cost **23 credits**

**经验沉淀**：
- 付费生成（fast）会触发 `pending_confirmation`，长耗时需 `confirm` 命令等待
- 生成的 prompt 会带风格关键词 + 参考图附件，Agent 参照立绘风格生成
- （待生成结果补充）

**⚠️ 用户反馈（v1 刘备风格偏差）**：体型和四肢的绘画风格不像王国橡果，眼睛画法也不像。

**根因复盘**：
- 误用 `reference style: Kingdom Acorn Tale` 引导 → 模型参考了该游戏的**俯视低多边形塔防截图**，而非用户提供的**10 张手绘圆润卡通立绘**
- 两款视觉风格实为不同画法：游戏截图（3D 低多边形塔防）≠ 立绘图（手绘 2 头身卡通）
- 教训：**风格参照应以"用户提供的立绘图"为准，而非借助"游戏名"这类可能误导的词**；参考图附件应传用户立绘图，且 prompt 需明确形体规则

**v2 修正方案**：完整传入 10 张立绘 CDN 作附件，去除 `Kingdom Acorn Tale` 字样，prompt 明确 `round chubby body, stubby short limbs, large round eyes with simple white highlights`（对齐立绘的圆润体型、粗短四肢、大圆眼画法）。

**⚠️ 用户反馈（v2 刘备仍偏差）**：形体还是不像，且武器应为**双手剑**（大剑）。

**根因复盘**：
- v2 形体已接近，但四肢仍偏细、体型不够"圆滚"
- 武器用了单手剑，而参考立绘都是**小身体 + 超大双手武器**的强烈对比（剑圣/小勇者持巨型大剑）
- 教训：武器规格是立绘风格的重要部分，需在 prompt 明确 `oversized two-handed greatsword`

**v3 修正方案**：prompt 明确 `oversized two-handed greatsword`（巨型双手剑）+ 强化 `round pebble-like hands, short stubby legs, very chubby round body`（更圆滚短粗）。

**⚠️ 用户反馈（v3 刘备，4 项差距确认）**：① 身材比例仍不对（偏修长）② 线条/描边太细 ③ 眼睛神韵不够 ④ 上色太复杂（阴影细节偏多）。

**经验沉淀（核心）**：
- 参考立绘的 4 大风格特征需**逐条显式写进 prompt**，光写「Q版/2头身」不够：
  1. 上身矮胖 + 无关节短粗四肢 → `very round chubby body, no visible joints`
  2. 粗软描边 → `thick soft dark outlines`
  3. 特定大圆眼型 + 白高光 → `large round eyes with simple white highlights`
  4. 极简平涂，非复杂赛璐璐/厚涂 → `minimal flat colors, very simple shading`
- 武器规格（巨型双手剑）是立绘风格重要组成，需明确 `oversized two-handed greatsword`
- **不要借助游戏名**（如 Kingdom Acorn Tale）做风格引导，会误导模型参考错误画法

**⚠️ 用户反馈（v4 刘备，关键纠错）**：
- **武器误解纠正**：「双股剑」= **两把剑**（刘备标志性雌雄双股剑），不是一把双手大剑。前几版 `oversized two-handed greatsword` 一直理解错。
- **风格仍不对**：v4 虽有改善，但整体仍不达标。

**v5 生成方案（用户指定）**：
- **16:9 比例画布**，**3×2 网格**（3 行 2 列），**6 格全是刘备**，每格 prompt 轻微不同（变体）
- 武器：**双股剑（两把剑）**
- 风格：仍参照 10 张立绘（矮胖无关节四肢、粗软描边、特定大圆眼+白高光、极简平涂），不加游戏名
- 比例/网格布局靠 **prompt 描述**控制（脚本无 aspect-ratio 参数，同道具图标 4×4 网格思路）

**经验沉淀（武器澄清）**：
- 「双手剑」≠「双股剑」：双手剑 = 一把大剑双手握；**双股剑 = 两把剑（约等于双剑/雌雄双股剑）**，是刘备/关张的辨识武器
- 概念词需逐字澄清，AI 不能想当然从"刘备+剑"推断成单手/双手大剑

### 阶段 3 突破：图生图法（★ 用户验证「味道对了」）

**过程回顾**：v1→v6 纯文本 prompt 生成反复跑偏（误用游戏名→跑偏；体形/眼睛/线条/上色逐条修正仍不贴）。v6 形体已接近，但用户仍不满意。

**关键转折**：用户提供一张**风格对味的底图**（`C:\Users\Administrator\Desktop\赤瞳_双剑版.png`，红发双刀立绘），并要求「基于这张图，只改 3 处：武器→双股剑、衣服→刘备绿袍、头部→发髻，其他不改」。

**执行**：
1. `upload` 上传底图 → CDN：`https://assets-persist.lovart.ai/img/68351fe5bfa24640bb21f8f4da4babb3/7c634ca8-a65a-4bae-90f6-38ba764b74f6.png`
2. `chat --attachments <底图CDN>` → 触发 `edit_media`（19 credits）
3. prompt：`Based on this reference image... KEEPING exact same style/body/pose/line/shadng/color of reference. ONLY change these 3 things...`

**结果**：✅ 风格 100% 对齐底图（蛋形胖躯干、锐利大眼、粗硬线条、平涂手绘、双剑站姿全保留），只改了双剑/绿袍/发髻。**用户确认「味道对了」**。

**核心结论（写入流程文档）**：
- 纯文本生成难以精确复刻参考立绘 → **图生图（edit_media 以对味底图做编辑）是贴合风格的最优解**
- prompt 只描述「要改的 N 处 + 其余沿用底图」，比堆砌风格关键词更有效
- 定稿刘备概念图：`C:\tmp\lovart-concept\lovart_f57bbc9fce0d.png`

## 🎬 视频生产草案（三幕结构）

### 第一幕：遇到了什么问题

- 核心问题：游戏概念设计缺乏标准化流程，每次从零开始效率低
- 为什么这是个问题：视觉方向不定，后续美术资产无从下手
- 如果没有 AI 会怎样：需要反复手绘/外包试错，成本高周期长

### 第二幕：AI 怎么协作解决的

- 我是这样问 AI 的：先定关键词（三国/诡异/Q版2头身）→ 定风格锚点（王国橡果传说 + 10张立绘）→ 再生成概念图
- AI 给了什么方案：建立「概念设计工作流」文档（05-概念设计.md），边使用边记录；先生成再迭代
- 中间有什么调整/追问：纯文本 prompt 生成 v1-v6 反复跑偏；用户纠正「双股剑=两把剑」；最终改用**图生图法**（对味底图只改 N 处），一次到位
- 最终方案是什么：以「赤瞳_双剑版」底图做图生图，批量生成刘备/关羽/张飞/曹操，风格统一且贴合立绘

### 第三幕：效果展示

- 最终效果：三国武将 Q 版概念图 4 张（刘备/关羽/张飞/曹操），风格统一，王国橡果传说味
- 演示方式：Lovart 画布 + 本地概念图文件
- 学到的关键点：**复刻特定立绘风格用图生图（以对味底图编辑、只改 N 处），而非堆砌文本关键词**
