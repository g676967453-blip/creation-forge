# [2026-09-05] 仪表盘默认打开页改为「任务」总览

## 📋 问题解决日志

### 遇到了什么

造化坊仪表盘 `造化仪表盘/reports/造化坊仪表盘.html` 打开时默认落在「🧭 板块」总览页。但用户的日常入口其实是任务管理——默认应该优先显示「📋 任务」，少点一次切换。

### AI 怎么协作的

1. 定位到该 HTML 是工具生成物，直接改 HTML 会在下次 `generate-dashboard.ts` 运行时被覆盖 → 正确做法是改**生成器源码**再重生成。
2. 在 `造化仪表盘/tools/generate-dashboard.ts` 中，把侧栏「📋 任务」按钮与内容面板 `tab-personal-tasks` 标记为 `active`，「🧭 板块」取消 active；同步更新页脚/副标题文案（默认打开任务总览、任务/目标 → 板块 → 明细 → 知识）。
3. 用 `npx tsx 造化仪表盘/tools/generate-dashboard.ts` 重新生成 HTML 并 grep 复核「任务 panel active / 板块 panel 非 active」均已生效。

### 产出结果

- `造化仪表盘/tools/generate-dashboard.ts`：默认 active 页签由 boards → personal-tasks
- `造化仪表盘/reports/造化坊仪表盘.html`：重新生成，打开默认显示「📋 任务」总览
- `造化仪表盘/works/2026-09-05-[dsh]-仪表盘默认打开任务页.md`（本文档）

## 🎬 视频生产草案（三幕结构）

### 第一幕：遇到了什么问题

- 核心问题：仪表盘默认停在不常用的「板块」页，每天最需要的「任务」要手点一下才出现
- 为什么这是个问题：入口多一次点击，久而久之习惯性忽略任务总览
- 如果没有 AI 会怎样：得自己翻生成脚本定位 `class="active"`，再手工改 HTML，改完还担心被重新生成覆盖

### 第二幕：AI 怎么协作解决的

- 我是这样问 AI 的：「让造化坊仪表盘默认打开优先显示任务」
- AI 给了什么方案：识别 HTML 是生成物 → 改生成器源码而非 HTML → 重生成
- 中间有什么调整/追问：无
- 最终方案是什么：切默认 active 页签到 personal-tasks + 文案同步

### 第三幕：效果展示

- 最终效果：打开仪表盘直接就是「📋 任务」个人待办总览
- 学到的关键点：**生成物改源**——视图文件是脚本产物，要改源头脚本才不会在下次生成时丢失

### 一句话总结（金句候选）

> 改生成物的正确姿势是改源头——视图会过期，脚本不会。
