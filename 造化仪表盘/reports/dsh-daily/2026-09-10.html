0.1.5-rc.1 里与你直接相关的几条

  • 模型：DeepSeek 适配器新增 DeepSeek-V41-Flash（deepseek-flash），支持文本、图片与会话历史中的系统提示词更新；新会话默认使用它。→ 你 settings 里钉的就是这个模型。
  • 右侧 Sidebar：多标签、分栏、全屏，支持 Markdown / 代码高亮 / HTML / PDF / 图片预览；模型可显式交付文件供预览、用默认应用打开、在文件管理器中定位。原 Detail 面板已移除。
  • 任意类型文件上传：文件与图片同一预览区混排，后台上传有进度、可取消、切换会话仍续显。
  • 可继续子代理：支持消息排队、编辑、删除、单条/全部 Steer、Stop。
  • 动态系统提示词：不破坏 KV Cache（需模型显式声明支持）。
  • 代理支持：所有出站请求遵循 HTTP_PROXY / HTTPS_PROXY / ALL_PROXY / NO_PROXY。
  • Web 顶栏「在应用中打开」：用已装的编辑器 / IDE / 终端 / 文件管理器打开 Workspace。
  • 会话统计：拆成两个可展开摘要——轮次与速度、精确 Token 用量与缓存命中。
  • Skill 选择器支持模糊搜索；内置斜杠命令说明中文化。
  • /feedback 可独立提交，不必继续对话。

需要注意的破坏性 / 行为变更

  • Session 数据格式升级至 V3：旧日志会迁移为新文件并保留原文件，但升级后的会话不支持降级读取；自定义日志读取器需适配。→ 你的 sessions/ 不在 git 同步范围内，风险可控，但别在升级前把 DSH 降级回去。
  • 默认工具调整：SDK、Headless、ACP 默认使用 read / write / edit 编辑文件。→ 这条对你是好消息：本日报的自动生成正是靠 headless 写文件。
  • 插件 API 调整：移除 ctx.agent；Inbox 改为类型接口；Web 插件面板注册方式变更（sidebar.panellist / main）。→ 自己写插件的场景要留意，也是 worktable 兼容性的不确定性来源。

④ 使用技巧（偏向「怎么用」）

技巧 1 · 用右侧 Sidebar 当「第二屏」，别再切窗口

  • 一句话：DSH 现在能在右侧直接预览 HTML / PDF / 图片 / Markdown，还能多标签分栏。
  • 怎么做：把文件拖进会话，或让模型把产物「交付到 Sidebar」；HTML 报表（你的 reports/*.html）、美术规格 PDF、Godot 截图都能直接在旁边看。
  • 对你的价值：做美术排期和仪表盘时，不用再来回切换浏览器和资源管理器。

技巧 2 · 参考资料一律「拖进来」，不限类型

  • 一句话：Web 现在支持上传任意类型文件，后台上传有进度、可取消。
  • 怎么做：把 PDF 规格、PSD 说明、Godot 场景文件直接拖进输入框；模型可以用文件工具按路径按需读取。
  • 对你的价值：IAA / 概念设计工作流的参考图与文档可以一次性投喂，不用先转格式。

技巧 3 · 子代理跑着的时候，直接插话

  • 一句话：可继续对话的子代理支持排队、编辑、删除和 Steer。
  • 怎么做：子代理还在跑时继续发消息（进入队列），需要它转向就用 Steer，不需要就 Stop。
  • 对你的价值：游戏 / 美术 / 小红书几条线并行时，不用等一个子代理跑完才下一条指令。

技巧 4 · 养成看「会话统计」的习惯，把成本管住

  • 一句话：统计拆成了「轮次与速度」和「精确 Token 与缓存命中」两个摘要。
  • 怎么做：点开会话统计，重点看缓存命中率——命中高说明上下文前缀稳定，重复读文件、随便改系统提示词都会拉低它。
  • 对你的价值：日报这类周期性任务最容易悄悄烧 token，有数字才能判断要不要降级成 -NoLlm。

技巧 5 · 公司网络要代理时，写在 Harness-home 的 .env 里

  • 一句话：出站请求现在遵循 HTTP_PROXY / HTTPS_PROXY / ALL_PROXY / NO_PROXY。
  • 怎么做：写进 $DSH_HOME/.env。注意代理变量只接受 Harness-home 的 .env，不接受工作目录里的 .env（官方明确的安全边界）。
  • 对你的价值：公司/家里网络环境切换时，Web 搜索与模型调用不会莫名失败。

技巧 6 · 「在应用中打开」+ Skill 模糊搜索

  • 一句话：顶栏能把 Workspace 用已装应用打开；技能多了也能搜了。
  • 怎么做：用顶栏「在应用中打开」直接跳 VS Code / 终端 / 资源管理器；输入 / 后直接打关键词筛技能。
  • 对你的价值：你的 .claude/skills 下技能已经不少，模糊搜索省事。
