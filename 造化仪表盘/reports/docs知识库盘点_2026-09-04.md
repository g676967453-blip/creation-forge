## 四、观测到的问题 / 机会（供参考，未改动）

1. **`knowledge/` 目前只有索引无正文**：README 自带"阶段 B 可选 git mv 至 knowledge/"说明；zh-CN/README 也在 52–58 行列了待迁清单。若长期维持索引制需确保登记不漏。
2. **personal-work-records 中 2 个文件的标题含句号/无标题**（`美术支撑中心价值定位。.md`、`当前换皮模板项目-情况摸底于待办。.md`、`无标题文档.md`），文件名不规整。
3. **raw 与 rewritten 双轨并存**：`01/02/05/08` 目录内原始 md 与 `_rewritten/` 内容并存，阅读者需依赖 README 状态标记判断以哪个为准。
4. **specs/ 较空**：收口仅 1 条硬规范，多靠链接转发；若硬约束增多可考虑扩展。
5. **en/ 已声明不维护**，非问题，但盘点时需知其为极简页。
6. `index.html`（docs 根）为仪表盘、非文档树 —— 本盘点**未**将其计入知识库文档。
