# 原型验证报告 — 难度曲线(最终版)

## 二、结论:难度曲线达标(护栏全部通过)

1. 稳健策略:0% 失败、100% 守住以上、79.3% 到达财富自由 → 会玩必能跑赢 ✓
2. 大众新手:51.5% 首局翻车(破产+返贫),中位净资产 73 万 → "前 1-2 局大概率返贫"目标达成,第一局的戏剧性失败(分享钩子)有保障 ✓
3. 韭菜:83.6% 失败、0% 成功 → 最坏路径惩罚到位 ✓
4. 分层清晰:新手(51%失败)→ 韭菜(84%失败)→ 稳健(100%成功),类魂式学习曲线成立:死几次学会原则,学会就能跑赢 ✓

## 三、模型演进记录(模拟过程中发现的 6 个问题)

1. **原则命中未记录**(代码 bug):mark 逻辑未接入事件执行。已修复。
2. **空头文案**(设计 bug):事件 1"其余再规划"文案承诺配置,机制上钱却躺在现金里,导致全对玩家封顶"守住"。已修复,并立为内容生产铁律:文案承诺的机制必须真实存在。
3. **模型缺收入**(设计缺陷):玩家零收入,现金耗尽直接转 10% 负债,形成"借 10% 的钱过活"的逆向套利,稳健策略一度 12.4% 失败。修复:加入月收入 0.8 万(普通工资,基线略低于支出,让消费升级成为真实压力源)。
4. **事件顺序失控**(设计缺陷):大额支出事件可先于资产配置事件出现,钱没配置先被抽干。修复:"第一笔安排"固定第 1 年(叙事上也正确:先安排钱,再迎接各路诱惑)。
5. **同族事件可叠加**(设计缺陷):两个"买房"事件(换大房子/丈母娘买房)同局出现,两次月供升级击穿现金流。修复:同族事件每局最多 1 个(family 互斥)。
6. **现金不足直接负债不真实**(设计缺陷):有资产的人会先卖资产救急。修复:现金不足时按"进取 9 折 → 稳健 95 折 → 房产 85 折急售 → 最后才负债"的顺序自动处置——这本身成为"保命钱"原则的隐性教学。

## 四、稳健策略最差局(seed=2186,结局:守住,711 万)

最坏组合:第 2 年丈母娘买房(按揭,月供升级)+ 失业 + 大病 + 熊市。即便如此,全对玩家仍守住 711 万——好选项组合的绝对安全边际成立。

## 五、观察与调优建议

1. 大众新手中位 73 万 = 返贫线边缘,意味着首局多数人死在"守住"门前,结局文案的黑色幽默空间很大。
2. 稳健路径后期现金经常紧张(靠资产收益覆盖支出),建议 UI 展示总资产面板,现金不足时触发"现金流紧张"旁白——作为"现金流 vs 资产"的教学点。
3. 复利在中后段发力(牛市/定投事件),前期核心是"守住本金"——与真实财富规律一致,写进复盘叙事。
4. 若上线后真实玩家失败率过低(<40%),可微调新手权重或提高消费升级幅度;若过高(>65%),降低骗局损失或提高收入。护栏参数化,上线后用真实数据校准。

## 六、引擎复用价值

sim.js 即 MVP 数值引擎原型:事件数据结构(选项+原则标记+效果)可直接 JSON 化作为内容库 schema;AI 离线生成的变体符合同一 schema 即自动接入模拟与游戏;难度曲线护栏(3 策略 × 2000 局)作为内容入库的自动验收测试。
